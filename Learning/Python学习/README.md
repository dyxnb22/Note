# Python 学习

独立的学习资料:用 Python 走到**后端开发**和 **Agent 开发**。和 `Learning/Python/`(面试题库)没有关联,两边各自演进。

**前提**:你已经会一门编程语言。这里只记 Python 的行为、边界和必要内容,基础语法只给形式,不从零讲。

## 章节

| 章 | 内容 |
|---|---|
| [01 语言核心](./01_语言核心.md) | 基本类型、变量与赋值、数值、除法与取模、运算符、身份与相等、字符串与字节、容器、成员运算 in、可变性与拷贝、原地修改与返回新对象、推导式、多维数组、流程控制、函数、作用域与闭包、类与对象、异常、模块与包、常用标准库导览 |
| [02 语言进阶与异步](./02_语言进阶与异步.md) | 迭代协议、生成器、装饰器、上下文管理器、描述符、dataclass、类型注解与 Protocol/ABC、序列化、同步并发原语、GIL、线程/进程/协程、asyncio、异步资源、上下文传递、性能与内存排查 |
| [03 标准库](./03_标准库.md) | 文件与路径、文件读写与 IO 边界、原子写入、文件摘要、json、datetime、re、collections、itertools/functools、os/sys/shutil/subprocess、调试 |
| [04 工程基础](./04_工程基础.md) | 虚拟环境与依赖、项目结构、配置与密钥、日志、测试(单元/集成/契约/金/属性)、代码质量、打包与入口 |
| [05 后端服务](./05_后端服务.md) | HTTP 客户端、FastAPI、Pydantic/DTO、数据库、Redis 与缓存、后台任务、SSE/WebSocket、鉴权与安全边界 |
| [06 Agent 开发](./06_Agent开发.md) | LLM 调用、消息与 Prompt、结构化输出、Tool Calling、循环与分层、RAG、评测、安全与执行边界 |
| [07 生产与交付](./07_生产与交付.md) | 容器与部署、配置与环境、可观测性、容量与可靠性、优雅退出、灰度与回滚、事故响应、依赖与供应链 |

## 建议顺序

```
01 语言核心 → 02 语言进阶与异步 → 03 标准库 → 04 工程基础 → 05 后端服务 → 06 Agent 开发 → 07 生产与交付
```

已经会的直接跳到对应章。

## 约定

- 知识点从浅到深排。学到新的(比如刷题遇到的 `//` 和 `/`),插进对应章的对应位置。
- 章内不编号,所以插入不用重排任何东西。
- 只写知识本身,不做考点总结和刷题套路。
- 章节之间不互链,避免改名时连锁断链。
