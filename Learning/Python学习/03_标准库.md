## 文件与路径(pathlib)

```python
from pathlib import Path

p = Path("data") / "logs" / "app.log"    # 拼接,不要用字符串加
p.read_text(encoding="utf-8")
p.write_text("hi", encoding="utf-8")
p.exists(); p.is_dir(); p.suffix; p.stem
list(Path(".").glob("**/*.py"))
```

- 一律用 `Path`,不要手拼字符串,跨平台分隔符、`..` 和空格都会出问题。
- 文本读写显式给 `encoding="utf-8"`;二进制用 `read_bytes` / `write_bytes`。
- 路径校验不能只看字符串前缀:先 `Path.resolve()` 再比对根目录,否则会被 `..` 绕过。

## 文件读写与 IO 边界

```python
with open("big.csv", encoding="utf-8") as f:
    for line in f:            # 逐行处理,不整个读进内存
        ...
```

- **大文件不要 `read()`**,按行或按块流式处理。
- 二进制分块读:`f.read(64 * 1024)`。
- 每一层都要有上限:行长度、总字节数、响应体大小。
- 对外暴露的文件接口要防大文件拖垮服务(限大小、限并发、流式返回)。

## 原子写入

```python
import os, tempfile

fd, tmp = tempfile.mkstemp(dir=target_dir)
with os.fdopen(fd, "w", encoding="utf-8") as f:
    f.write(data)
os.replace(tmp, target)        # 同分区内的原子替换
```

- 先写临时文件再 `os.replace`,避免读到写了一半的内容。
- 跨分区不能原子替换,所以临时文件必须建在**同一目录**下。
- 原子写入 ≠ 事务性批量修改:多个文件之间的一致性要靠额外的日志或版本机制。

## 文件摘要与版本

- `hashlib.sha256(data).hexdigest()` 做内容指纹,用于判断变化、做缓存键。
- 内容摘要比 `mtime` 可靠——`mtime` 会被复制、检出、镜像构建抹平。
- 注意区分"内容变了"和"只需要看是否变过"。

## json

```python
import json

json.dumps(obj, ensure_ascii=False)     # 中文不转义
json.loads(text)
```

- 默认 `ensure_ascii=True` 会把中文转成转义序列,写给人看要关掉。
- `dumps` 不认 `datetime` / `set` / 自定义对象:先转基础类型,或用 `default=`。
- 解析不可信输入要设大小上限;JSON 不支持注释和尾逗号。

## datetime

```python
from datetime import datetime, timedelta, timezone

now = datetime.now(timezone.utc)         # 带时区
later = now + timedelta(minutes=30)
now.isoformat()
```

- **naive 和 aware 不能混用**,混着比较或相减会直接报错。
- 存储和传输统一用 UTC,只在展示时转本地时区。
- 按"业务日"统计要显式处理时区和日界,不要用服务器本地时间。

## re

```python
import re

PAT = re.compile(r"^[a-z]+$")   # 编译一次,复用
PAT.fullmatch(name)
```

- 正则提前编译并复用,不要在循环里反复 `re.match`。
- 用 `fullmatch` 或锚点,避免"部分匹配"放行非法输入。
- 警惕灾难性回溯:嵌套量词加长输入会卡死,必要时限长度或换解析方式。
- HTML、JSON、日期这类结构别用正则硬解。

## collections

- `deque`:两端 O(1) 插删,做队列和滑动窗口。
- `Counter`:计数、`most_common(n)`。
- `defaultdict`:分组时不必写 `setdefault`。
- `namedtuple` / `dataclass`:轻量记录。
- `OrderedDict`:现在普通 `dict` 也保序,只在需要 `move_to_end` 时用。

## itertools / functools

- `itertools`:`chain`、`islice`、`groupby`(**先排序**)、`product`、`count`。
- `functools`:`cache` / `lru_cache`(参数必须可哈希)、`partial`、`reduce`、`wraps`。

## os / sys / shutil / subprocess

- `os.environ` / `os.getenv("X", default)` 读环境变量。
- `sys.argv`、`sys.exit(code)`、`sys.path`。
- `shutil`:复制、移动、删目录树(`rmtree` 慎用)。
- `subprocess.run([...], shell=False, capture_output=True, timeout=...)`,永远用列表参数。

## 调试相关

- `breakpoint()` / `pdb`:本地调试;线上靠日志和 trace。
- `traceback.format_exc()` 记录完整堆栈,别只记 `str(e)`。
