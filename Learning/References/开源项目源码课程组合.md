## Learning 笔记中的空白

现有笔记已经系统覆盖 Agent、后端、数据库、分布式、Rust/Go、Kubernetes、安全与编译原理概念；缺少的是把以下理论压到高质量源码上的完整证据链：

1. 增量解析、错误恢复和编辑器语法树；
2. 声明式策略、授权决策、部分求值和策略分发；
3. Kubernetes reconciliation、cache/workqueue 与控制面最终一致性；
4. OS 内核中的 trap、进程、页表、锁、文件系统和系统调用；
5. 版本控制中的 DAG、工作副本即提交、冲突对象和 operation log；
6. 自动 HTTPS、动态配置和模块化长运行网络服务。
7. 小型语言实现中的字节码 VM、闭包、元方法、增量 GC 与协程；
8. 通用压缩中的匹配查找、熵编码、流式状态机和字典；
9. C 标准库在公共 API、Linux 系统调用、线程、分配器和动态加载之间的边界。
10. 数据变换语言中的生成器、回溯、路径更新、错误值与 streaming event。

## 为什么第一批是 Tree-sitter + OPA

### Tree-sitter

它把编译原理从“一次性编译”转成编辑器每次按键都要面对的增量问题：旧树复用、编辑范围、错误节点、查询语言、C runtime 与语言 binding。与 Tantivy 都处理文本，但一个解决语法结构更新，一个解决文档召回，重叠很小。

课程终点已实现：JSON 结构检查 CLI 能够执行首次 parse、增量 edit、错误恢复、query capture，并用 changed ranges 证明结构失效边界；课程入口位于 `/Users/diaoyuxuan/tree-sitter/course/README.md`。

### OPA

它把安全与治理笔记中的“授权规则”变成独立决策系统：input/data/policy、Rego 编译、topdown evaluation、partial evaluation、bundle 与 decision log。它能服务 Agent 工具授权和 Kubernetes admission，但不是另一个 Agent 框架。

课程终点已实现：Agent Tool Policy Gateway 覆盖 allow/deny、高风险审批、未知/坏结果 fail-closed、部分求值与 JSONL 决策事件；bundle transaction 和 server decision log 由上游定向测试背书。入口位于 `/Users/diaoyuxuan/opa/course/README.md`。

## 存储护栏

1. 磁盘可用空间硬下限为 140 GiB；低于该值暂停下载和构建。
2. 默认 `git clone --depth 1`；只有课程需要历史考古时才按需加深。
3. 单仓库工作树目标小于 300 MiB；超出前先评估 sparse checkout 或替代项目。
4. 不下载模型权重、大语料、容器镜像、benchmark 数据集或完整 Git 历史。
5. 构建前记录目录大小；验证后清理本轮明确生成的 `target/`、临时索引和测试 fixture。
6. 不清理任何预先存在或来源不明的缓存；不运行 `git clean`。
7. 每完成一门课重新运行 `df -h` 与 `du -sh`，把实际增量记入本页。
