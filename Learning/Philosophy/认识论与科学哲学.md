# 认识论与科学哲学

认识论回答"我们凭什么说自己知道一件事"；科学哲学回答"科学方法为什么可靠、可靠到什么程度"。这两个问题是本知识库[来源与证据](../00_Navigation/来源与证据.md)工作流的理论地基：证据分级、复现要求、可证伪表述，背后都是这里的论证。

## 1. 知识是什么

经典定义：知识 = 得到证成的真信念（Justified True Belief）。盖梯尔 1963 年的短文给出反例：一个人可能凭运气拥有"碰巧为真且有理由"的信念，但我们不愿称之为知识——证成与真之间的连接不能靠运气。此后的修补方案（可靠主义：信念来自可靠的认知过程；安全性条件等）都在试图排除运气成分。

实用要点：评估一个结论时，除了"它是否为真"，还要问**得出它的过程是否可靠**——过程不可靠的正确结论，下次会变成错误结论。这正是"结果对了但方法错了"在认识论中的位置。

## 2. 证成的结构：无穷回溯问题

任何信念的理由本身也需要理由，于是面临三选一（阿格里帕三难）：无穷回溯、循环论证，或停在某处。

- **基础主义**：停在不需进一步证成的基础信念（知觉、自明公理）。批评：真有"无需证成"的信念吗？
- **融贯主义**：信念网络互相支持，整体融贯即证成。批评：一个内部融贯的错误体系（阴谋论）如何排除？
- 实践折中：多数知识工作采用"可错的基础 + 融贯检验"——观察和测量作暂定基础，同时要求新结论与既有可靠知识网络相容，冲突时权衡哪边证据更强。

## 3. 归纳问题与证伪主义

**休谟的归纳问题**：从"过去如此"推不出"未来必然如此"，归纳的合理性无法被非循环地证明（用"归纳过去管用"来辩护归纳，正是循环）。这不是杞人忧天，而是提醒：一切经验概括都是可错的。

**波普尔的回应**：科学的标志不是可证实而是**可证伪**——好理论做出有风险的预测，主动暴露在被推翻的可能性下。"所有天鹅都是白的"可以被一只黑天鹅推翻，却永远无法被穷举证实。占星术式的理论无论发生什么都能自圆其说，因此不提供知识。

实践对应：写结论时给出**什么证据会推翻它**；不可能错的主张没有信息量。本知识库要求"失败 Case"与"边界条件"，是同一逻辑的工程版。

**对证伪主义的批评**（迪昂—蒯因论题）：单个假说从不单独面对检验，实验失败时你可以修改辅助假设而保住核心理论。所以"一次反例干净利落杀死理论"是理想化图景；现实中理论被放弃，往往是因为修补越来越多、越来越不自然（退化的研究纲领，拉卡托斯的术语）。

## 4. 库恩：范式与科学革命

库恩《科学革命的结构》（1962）：常规科学在**范式**（共享的问题、方法与标准）内解谜题；反常积累到危机时发生范式转换（地心说→日心说，牛顿→相对论）。范式转换不完全由逻辑与证据强制，还涉及标准本身的改变。

- 价值：解释了科学史的实际形态，纠正了"科学是线性逐步逼近真理"的教科书图景。
- 边界：库恩本人反对把他读成"科学是任意的/纯社会建构"。范式间仍有共享的经验约束——预测精度、解题能力可以跨范式比较。后来的科学实在论与反实在论之争（无奇迹论证 vs 悲观归纳）延续了这条线。

## 5. 贝叶斯视角：把信念当概率

当代认识论的一支把信念度处理为概率，用贝叶斯定理描述理性更新：新证据按其在不同假设下的似然比调整信念。它给出了几条可直接使用的纪律：

- 信念是程度问题，不是非黑即白；"多确信"应与证据强度成比例。
- 先验会影响结论，所以要显式写出先验并接受它被证据修正。
- 强主张需要强证据：初始概率越低的命题，翻转它所需的似然比越大。
- 寻找能**区分**假设的证据：两个假设下都会出现的现象不提供信息。

批评：真实人类远非贝叶斯机器（先验从哪来、计算不可行、确认偏误），它是规范理想而非描述事实。

## 6. 常见误区

**误区 1：科学 = 已被证明为真**
科学结论是当前证据下的最佳可错估计。"科学证明了 X"的日常说法在认识论上几乎总是过强；正确表述是"当前证据强烈支持 X，且 X 尚未被严肃挑战成功"。

**误区 2：可证伪 = 已被证伪**
可证伪性是优点（理论敢于冒险），不是缺陷。"这个理论可能错"与"这个理论错了"是两回事。

**误区 3：范式论 ⇒ 怎么说都行**
从"标准会变"推不出"没有标准"。跨范式的预测精度与解题能力比较仍然可能，否则技术进步无法解释。

**误区 4：把不确定性当成放弃判断的理由**
所有结论都可错，不等于所有结论同等可信。证据分级的意义正在于：在承认可错的前提下，仍然分出可信度的层级。

**误区 5：混淆"过程可靠"与"结论合意"**
接受一个结论应因为它的证据与推理，而不是因为它支持你的立场——这是[哲学学习方法](./哲学学习方法.md)中"立场先行"误区在认识论的版本。
