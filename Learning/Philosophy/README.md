# 哲学

这条主题学习概念澄清、论证评估和价值分歧的结构。目标不是背哲学家生平，而是获得三种可复用能力：把模糊问题拆成可讨论的问题、重构和检验论证、在价值冲突中说清各方的最强理由。

## 使用原则：多立场对照

本目录的所有立场性内容（政治哲学、伦理学）都按同一格式组织：**核心主张 → 最强论证 → 标准批评**。任何立场（包括马克思主义、自由主义、保守主义）都作为被检验的对象之一，不作为默认前提。读的时候始终问两个问题：这个立场最擅长回答什么问题？什么证据或论证会让它陷入困难？

## 边界

- 哲学正文负责概念、论证和立场结构；历史事实与制度比较回到[历史、制度与组织](../History_and_Society/INDEX.md)。
- 制度绩效的实证比较见[比较社会制度](../History_and_Society/03_Institutional_Evolution/比较社会制度：资本主义与社会主义的形态谱系.md)；本目录处理其中的规范之争（应该优先什么价值）。
- 证据分级与来源核验的工程实践见[来源与证据](../00_Navigation/来源与证据.md)；认识论与科学哲学提供其理论基础。

## 建议来源

- Stanford Encyclopedia of Philosophy（SEP）：可靠的英文条目式一手入口。
- 原典选读优先于二手转述；二手概览用于建立地图，不用于替代论证细节。
- 中文世界对哲学流派的介绍常带教材立场；重要结论至少对照一个不同立场的来源。
