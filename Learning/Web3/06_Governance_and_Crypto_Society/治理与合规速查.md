# 治理与合规速查

本页只做治理问题清单；具体规则进入目标司法辖区、监管机构和协议文档核验。

| 维度 | 先问什么 |
|---|---|
| 权力 | Token、委托、核心团队和基础设施谁真正能改变规则？ |
| 提案 | 谁能提出、投票、否决和执行？是否存在 quorum/委托偏差？ |
| 危机 | 漏洞、暂停、升级和资产损失时谁能行动？ |
| 合规 | 主体、产品、资金流、地域和 KYC/AML 义务是什么？ |
| 责任 | 前端、开发者、运营者、验证者和用户各承担什么？ |

去中心化不是二元标签；评估治理时同时看代码权限、实际控制、经济集中度、法律关系和退出机制。
