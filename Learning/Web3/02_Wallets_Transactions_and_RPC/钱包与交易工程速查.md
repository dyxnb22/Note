# 钱包与交易工程速查

本页只做交易链路检查；正文见 [钱包、私钥、签名和地址](./钱包、私钥、签名和地址.md) 与 [交易、Gas、Nonce 和确认](./交易、Gas、Nonce 和链上确认.md)。

```text
密钥/钱包 → 地址与签名 → RPC 广播 → mempool/排序
→ 执行与 Gas → receipt/确认 → 索引和用户状态
```

## 必查边界

- 私钥只在受控签名边界出现；地址不是身份本身。
- 签名消息要有 domain、nonce、deadline 和明确用途，防重放/钓鱼。
- Nonce、费用、链 ID、失败交易和替换交易要可解释。
- RPC 返回的是服务视图，重要状态要考虑确认数、重组和索引延迟。
- 账户抽象改变的是验证/支付/恢复路径，不消除权限和签名风险。
