# 区块链网络机制速查

本页只做网络机制检查；正文见 [为什么区块链是状态机](./为什么区块链是状态机而不只是数据库.md)。

| 机制 | 必须说明 |
|---|---|
| 状态机 | 状态、交易、执行规则和无效交易 |
| 共识 | 谁提议/验证、攻击假设、最终性和重组 |
| 扩容 | 执行、数据可用性、安全继承和成本搬到哪里 |
| 跨链 | 消息/资产如何验证，信任假设是什么 |
| 节点 | RPC、索引、归档数据和服务可用性 |

遇到一个网络，按“交易签名 → 广播 → 排序 → 执行 → 确认 → 读取结果”复述；不要只背 TPS。桥、预言机、排序和跨域消息都是额外信任边界。
