# Web3 概念速查

本页只做概念分层；正文见 [Web3 到底是什么](./Web3 到底是什么：它和互联网、金融、数据库各是什么关系.md) 与 [身份、资产、状态和权限](./链上世界里的身份、资产、状态和权限.md)。

| 层次 | 先问什么 |
|---|---|
| 状态与共识 | 谁维护状态，谁能写入，何时算最终？ |
| 资产与权限 | 资产是什么，所有权如何表示，谁能转移？ |
| 用户与应用 | 钱包、dApp、交易所、RPC 分别承担什么？ |
| 经济与治理 | 激励、费用、治理权和风险如何分配？ |
| 信任边界 | 依赖代码、节点、桥、前端、运营方还是法律？ |

区块链不是“更好的数据库”，智能合约也不是自动可信；关键是把状态、验证者、权限和故障假设写清楚。
