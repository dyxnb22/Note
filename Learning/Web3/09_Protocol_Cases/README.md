# Web3 协议案例

现有 Web3 目录已经覆盖概念、钱包、交易、智能合约、DeFi 和安全。本目录补充从协议机制到经济不变量、攻击面、链上证据和安全审计的完整案例。

## 案例方法

每个协议案例至少记录：

~~~text
协议目标与非目标：
参与者和权限：
状态与不变量：
关键函数/交易：
费用、激励和风险转移：
预言机/外部依赖：
攻击面与失败路径：
测试、模拟和链上证据：
结论边界：
~~~
