# 智能合约工程速查

本页只做合约工程检查；正文见 [Solidity 合约到底在解决什么问题](./Solidity 合约到底在解决什么问题.md) 与 [权限控制、所有权和多签](./权限控制、所有权和多签的基本逻辑.md)。

| 对象 | 作用/风险 |
|---|---|
| 状态变量 | 持久化业务事实，需考虑初始化、权限和升级布局 |
| 函数 | 状态转换入口，检查输入、权限、重入和失败 |
| 事件 | 给索引器和后端消费的事实，不替代状态读取 |
| modifier | 复用前置条件，避免隐藏关键权限逻辑 |
| 升级/Proxy | 地址稳定但引入管理员、实现和存储一致性风险 |

测试至少覆盖正常、边界、权限、模糊输入和业务不变量；审计不能替代权限治理、监控和升级回滚。
