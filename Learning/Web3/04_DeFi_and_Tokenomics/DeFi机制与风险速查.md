# DeFi 机制与风险速查

本页只做机制和风险定位；正文见 [AMM](./AMM 为什么能在没有订单簿时完成交易.md)、[超额抵押借贷](./借贷协议为什么离不开超额抵押.md) 与 [稳定币](./稳定币的几种基本路线.md)。

| 机制 | 先问什么 |
|---|---|
| AMM | 流动性曲线、价格、滑点、无常损失和套利如何连接？ |
| 借贷 | 抵押率、预言机、清算、坏账和流动性如何处理？ |
| 稳定币 | 价值锚定依赖储备、抵押、算法还是治理？ |
| Token | 权利、发行、解锁、激励和治理是否错配？ |
| MEV | 谁能观察、排序、抢先或重排交易？用户如何受影响？ |

分析收益时同时写最坏状态：价格跳跃、流动性枯竭、预言机失真、合约漏洞、治理失控和跨协议传染。
