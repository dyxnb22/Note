# 产品与业务决策

这里补齐从用户问题、业务约束、指标和实验到发布反馈的中间层。它把技术方案连接到真实价值，不替代 [产品文档与需求分析](../References/产品文档与需求分析.md) 或具体项目案例。

## 为什么单独维护

现有知识库已经有：

- PRD 转角色、状态、规则和接口的方法。
- BigMarket 的交易、营销和账户案例。
- Agent 产品中的自主性、接管和发布指标。
- 金融中的商业模式、财报和单位经济线索。

本目录补的是跨项目可复用的产品判断：什么问题值得解决、如何衡量结果、如何验证增量、如何处理商业和运营约束。

## 决策链路

~~~text
问题发现
  → 目标与优先级
  → 指标与事件模型
  → 方案与业务不变量
  → 实验/灰度/发布
  → 反馈、复盘与迭代
~~~

## 每个产品问题的最低记录

~~~text
目标用户、任务和痛点
当前替代方案与证据
成功/失败动作
业务不变量和合规边界
主要指标、护栏指标和数据来源
最小可验证方案
上线风险、回滚条件和反馈窗口
~~~

## 怎么使用

从正在处理的真实需求进入对应文档，不要求先通读五篇。需要形成产品判断时，用一个规模很小的需求填写上面的最低记录，再根据风险选择访谈、原型或小范围实验，并写出“继续、修改或停止”。没有当前需求时，不为完成路线虚构练习。
