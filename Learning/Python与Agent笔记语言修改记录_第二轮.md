修改后：

### 从例子说明条件为什么必要

修改前：

> 表格检索需要保存行列标题、合并单元格、单位、注释及跨页关系。对“华东区第三季度收入”的查询，相关数字还要绑定地区、时间、币种和指标口径；只召回一个数字，无法形成可靠答案。

修改后：

> 查询“华东区第三季度收入”时，只找到一个数字还不够，还要知道它对应的地区、时间、币种，以及指标按什么方式计算。因此，表格检索需要保留行列标题、合并单元格、单位、注释和跨页关系，让数字能对上这些条件。
