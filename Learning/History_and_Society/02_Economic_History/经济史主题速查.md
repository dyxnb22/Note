# 经济史主题速查

本页是比较问题清单；方法见 [经济史学习方法](./经济史学习方法.md)，增长案例见 [为什么有些国家先富起来](./为什么有些国家先富起来.md)。

| 主题 | 先问什么 |
|---|---|
| 工业化 | 技术、能源、资本、劳动力和组织如何组合？ |
| 全球化 | 贸易、金融、殖民和制度谁获得了什么？ |
| 改革与增长 | 激励、产权、国家能力和开放顺序如何变化？ |
| 金融危机 | 杠杆、流动性、资产价格和政策反馈如何连接？ |
| 人口与城市化 | 人口结构、迁移、生产率和公共品如何互动？ |
| 国际体系 | 规则、货币、储备和地缘政治如何影响增长？ |

写历史解释时同时给机制、时间顺序、证据和反例；不要用单一事件解释长期结果，也不要把相关性直接写成因果。
