# 历史、制度与组织

目标不是记忆年代，而是解释技术、资源、制度、组织和利益如何共同塑造长期结果。

## 一条主线

```text
技术与能源 → 生产率、人口与贸易 → 制度与国家能力
→ 组织、权力与协作 → 数字时代的产业和社会
```

## 需要系统入门时的路线

只有准备系统学习这条主题时，才按 `技术史 → 经济史 → 制度演化 → 组织社会 → 数字时代` 推进；平时从当前问题直接进入相关主文档。主题速查用于定位，不加入阅读进度。

## 通用判断

先限定时间、地区和比较对象；再区分触发因素、必要条件、放大机制和结果；同时检查技术、资源、制度、组织与利益分配；最后寻找反例。主题速查只提供问题框架，具体年份、规模、政策和因果结论回到专题资料核验。

同一段历史应使用多个解释框架交叉观察（唯物史观、制度学派、年鉴学派、全球史等各有擅长与盲点），避免单一立场读史：见[历史解释的多重视角](00_Methods/历史解释的多重视角.md)。规范层面的价值之争（应该优先什么）另见[政治哲学的主要立场](../Philosophy/政治哲学的主要立场.md)。

## 需要形成研究结论时

只有准备输出一份研究结论时，才选一个案例使用 [案例研究模板](./06_Case_Studies/README.md)，区分事实、推断和因果主张，并寻找反例或替代解释。概念学习阶段不要求逐篇完成练习，也不要求覆盖所有国家和时期。
