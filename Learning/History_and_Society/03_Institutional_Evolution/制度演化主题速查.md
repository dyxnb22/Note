# 制度演化主题速查

本页是制度分析卡；正文见 [制度是什么](./制度是什么：规则如何塑造行为.md) 与 [国家能力与经济发展](./国家能力与经济发展.md)。

| 维度 | 检查问题 |
|---|---|
| 规则 | 正式制度和非正式规范分别是什么？ |
| 执行 | 谁能执行、监督和惩罚？成本如何承担？ |
| 激励 | 产权、税收、监管如何改变行为？ |
| 能力 | 国家/组织能否提供公共品并落实政策？ |
| 路径 | 既有利益、标准和沉没成本如何限制改革？ |
| 分配 | 谁受益、谁承担成本、谁拥有否决权？ |

解释制度变化时要区分创新、冲击、改革、执行和结果；监管滞后、中央地方关系、信用与法治都应放回具体时间和地区讨论。
