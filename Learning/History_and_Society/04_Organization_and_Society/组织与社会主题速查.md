# 组织与社会主题速查

本页是组织分析卡；正文见 [组织为什么会出现](./组织为什么会出现.md) 与 [激励相容与委托代理问题](./激励相容与委托代理问题.md)。

| 问题 | 观察重点 |
|---|---|
| 为什么需要组织？ | 交易成本、专业化、协调和控制 |
| 组织如何扩张？ | 层级、流程、沟通成本和边界 |
| 权力如何分配？ | 决策权、信息权、资源和问责 |
| 激励为何失效？ | 目标错位、信息不对称、代理和短期主义 |
| 文化如何形成？ | 重复行为、奖惩、叙事和领导示范 |
| 信息如何失真？ | 层级过滤、选择性报告和指标替代 |

分析组织时同时看结构、激励、信息和外部制度；个人策略不能替代对系统约束的判断。
