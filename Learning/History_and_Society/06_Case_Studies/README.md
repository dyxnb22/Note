# 历史与社会案例研究

现有历史、制度与组织文档提供分析框架；本目录补充具体案例，用来检查抽象概念在时间、地区、技术和利益分配中是否真的成立。

## 案例模板

每个案例至少回答：

~~~text
研究问题：
时间与空间边界：
主要参与者与资源：
关键时间线：
技术/能源/贸易变化：
制度与国家能力：
组织、权力与利益分配：
触发因素、必要条件和放大机制：
反例与替代解释：
反事实：
来源和证据边界：
~~~

不要把单一国家或单一时期的成功经验写成普遍规律。比较案例时，先限定比较对象和指标，再讨论因果。
