# 全球化、供应链与平台经济

这个案例连接技术史、贸易、金融、组织和数字平台，研究“分工和连接扩大”如何同时带来效率、脆弱性和权力集中。

## 1. 全球化的多层结构

- 运输和通信降低交易成本。
- 企业把生产拆分到多个地区。
- 金融、标准和合同把分散活动连接起来。
- 平台通过搜索、支付、身份和数据降低匹配成本。
- 监管、战争、疫情和自然灾害重新定义风险边界。

全球化不是一个开关，而是商品、资本、技术、人员和数据在不同制度下的组合。

## 2. 供应链的效率与脆弱性

集中采购、低库存和专业化可能降低单位成本，但也会增加：

- 单点故障和地域依赖。
- 需求预测错误的放大。
- 关键设备、材料和软件的替代困难。
- 追责、劳工和环境外部性。

韧性不是库存越多越好，而是比较冗余、替代、可见性、恢复速度和成本。

## 3. 平台经济

平台通过网络效应、推荐、支付、评价和数据反馈扩大匹配效率，同时可能产生：

- 赢家通吃和进入壁垒。
- 商家或劳动者对平台规则的依赖。
- 算法排序和抽成改变分配。
- 数据集中、隐私和信息不对称。
- 平台治理与公共治理边界模糊。

## 4. 研究方法

对一个供应链或平台案例，画出：

~~~text
参与者 → 资源/数据 → 交易与控制点 → 收益分配
        → 故障传播 → 替代路径 → 治理响应
~~~

同时比较效率指标、韧性指标、分配结果和外部性，避免只用成本或增长衡量成功。
