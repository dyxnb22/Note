## 保护规则

- 不使用 `git reset --hard`、`git checkout --` 或 `git clean`。
- 现有未提交改动视为用户已有成果；同一文件包含既有改动时，不覆盖无关内容。
- 只有完成旧文档逐节核对、链接核对和实践资产核对后，才允许删除冗余旧入口。
- 任何孤立但包含实验、Trace、代码结果或项目记录的 Markdown 都按实践资产保留。
- 本机源码课程的绝对路径只在 [来源与证据](./来源与证据.md) 和源码参考页出现，并明确标记为外部、本机依赖。
