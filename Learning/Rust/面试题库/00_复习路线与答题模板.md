# Rust 面试复习路线与答题模板

## 复习路线

### Level 0｜所有权直觉

- 每个值现在由谁拥有？函数返回后谁负责释放？
- 这里需要借用、移动、共享所有权还是 clone？
- 引用为什么有效？生命周期关系在哪里证明？

### Level 1｜类型系统

- struct/enum 如何建模状态？trait/泛型/trait object 如何表达能力和多态？
- `Option`/`Result`/`?` 如何让缺失和失败进入类型？
- String/str、集合、迭代器和智能指针的所有权边界是什么？

### Level 2｜并发与 Async

- thread、channel、Send/Sync、Arc/Mutex 如何组合？
- Future、poll、await、executor、Pin/Unpin 如何协作？
- 任务如何取消、超时、背压、传播错误和安全退出？

### Level 3｜工程与系统

- Cargo/workspace/feature、Serde、配置、日志、HTTP、数据库如何组织？
- Axum/Hyper/Tokio 如何分层？异步 I/O、阻塞隔离、连接限制和优雅退出如何验证？
- Tokio 中如何隔离阻塞工作，如何做连接池、任务队列和优雅退出？
- unsafe/FFI、性能、内存和跨语言边界如何验证？

### Level 4｜手撕与项目

- 先写能通过编译器的算法，再说明复杂度和所有权选择。
- 并发题必须讲 bounded channel、取消、任务状态和资源释放。
- 项目题说明为什么 Rust 的约束值得复杂度，以及如何用指标证明。

## Rust 统一答题模板

1. **所有权**：每个值/引用/任务由谁拥有？
2. **类型**：哪个 trait/enum/Result 表达了能力或状态？
3. **编译边界**：编译器保证了什么，没保证什么？
4. **运行边界**：Future、锁、I/O、取消和资源如何运行？
5. **工程验证**：用 cargo check/test/clippy、benchmark、profile 和故障测试证明。

## 面试前 Checklist

- [ ] 能解释 move、Copy、borrow、lifetime、`'static` 和 clone 的取舍。
- [ ] 能回答 trait/Fn*、Box/Rc/Arc/RefCell/Mutex、Send/Sync。
- [ ] 能解释 Future、Pin/Unpin、async 取消和阻塞隔离。
- [ ] 能用有界 channel 写 worker pool，并测试超时、取消和关闭。
- [ ] 能说清 `cdylib`/C ABI 的布局、所有权、panic 和资源释放边界。
- [ ] 能把一个 Axum/Hyper/Tokio 服务讲清楚，并说明 Cargo/Workspace 如何保证交付。
- [ ] 能讲一个 Rust 服务的资源上限、性能、故障恢复和安全边界。
