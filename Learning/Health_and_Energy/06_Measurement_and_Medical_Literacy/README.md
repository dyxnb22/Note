# 健康测量与医学素养

这里补充健康与精力主线中的观察、训练、人体工学、营养和求助边界。目标是建立低风险的自我管理和与专业人士沟通的能力，不做个人诊断或治疗方案。

## 实践闭环

~~~text
观察 → 选择一个低风险变量 → 记录 1–2 周
→ 看趋势与功能 → 保留有效改变
→ 持续/严重/影响功能时寻求专业帮助
~~~

## 安全边界

- 通用建议不能替代个人病史、用药、检查和专业判断。
- 不因为单个指标异常就自行诊断或停药。
- 剧烈、突然、持续恶化或影响日常功能的症状，应咨询当地合格专业人士。
- 紧急风险应联系所在地急救或紧急服务。
