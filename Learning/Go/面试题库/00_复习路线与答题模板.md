# Go 面试复习路线与答题模板

## 复习路线

### Level 0｜值语义和类型

- 数组、slice、map、channel 是值、描述符还是共享对象？
- 指针接收者、方法集、interface nil 和泛型边界是什么？
- make/new、nil、零值、defer、panic/error 如何组合？

### Level 1｜Runtime

- 逃逸分析如何影响分配？如何用 benchmark 验证？
- G/M/P 如何调度 goroutine？网络轮询、阻塞和抢占如何影响服务？
- GC、分配速率、Heap、GC CPU 和延迟有什么关系？

### Level 2｜并发与内存模型

- 谁启动、谁等待、谁取消、谁接收错误、最大并发是多少？
- Channel 关闭、select、Context、Mutex/Atomic、happens-before 如何建立协议？
- 如何处理下游变慢、队列满、goroutine 泄漏、竞态、死锁和优雅退出？

### Level 3｜后端工程

- HTTP/RPC 如何设置超时、连接池、重试、幂等和优雅关闭？
- gRPC/HTTP2/Protobuf 的接口、流式、兼容和错误边界如何设计？长连接和心跳如何关闭、重连和去重？
- MySQL 索引/MVCC、Redis、Kafka、Outbox 和消息重复如何落地？
- 如何用日志、Trace、指标、pprof、trace、灰度和回滚证明服务可靠？

### Level 4｜手撕与系统设计

- 链表、LRU、堆、滑动窗口和并发容器。
- Worker Pool、Fan-out/Fan-in、限流、任务队列和状态机。
- 订单、网关、异步任务和后端服务的约束、取舍与指标。

## Go 统一答题模板

1. **语义**：先说值复制、共享底层结构、接口或方法集。
2. **机制**：讲 runtime 数据结构、调度、同步或存储路径。
3. **反例**：指出 nil、并发、版本、资源或错误边界。
4. **验证**：说 benchmark、Race、pprof、trace、执行计划或压测。
5. **工程**：补超时、取消、幂等、背压、观测和发布。

## 面试前 Checklist

- [ ] 能解释 slice 扩容、map 并发、interface nil、make/new、defer 和逃逸。
- [ ] 能画出 G/M/P、Channel/Context 和 Worker Pool 生命周期。
- [ ] 能回答 MySQL、Redis、Kafka、幂等和 Outbox 的边界。
- [ ] 能讲清 gRPC/HTTP2/Protobuf、流式背压、心跳、兼容和重试。
- [ ] 能用 pprof/trace/Race/benchmark 定位一次问题。
- [ ] 能把实践项目讲成接口、状态、测试、故障和指标。
