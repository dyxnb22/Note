# 职场沟通速查

本页只做场景检查；正文见 [如何做一次清晰的工作汇报](./如何做一次清晰的工作汇报.md) 与 [面试中的项目表达框架](./面试中的项目表达框架.md)。

| 场景 | 先说什么 |
|---|---|
| 向上汇报 | 结论、影响、风险、需要的决策 |
| 跨团队对齐 | 共同目标、边界、依赖、责任人、时间 |
| 向下传达 | 结果标准、优先级、截止时间和反馈方式 |
| 一对一 | 事实、感受、需求和下一步，而非归责 |
| 冲突 | 先复述对方目标，再区分事实、判断和方案 |
| 会议 | 目的、议程、决定、未决项和负责人 |

沟通不是展示忙碌，而是降低协作成本。描述贡献时用“问题—动作—证据—影响”，避免只报任务清单。
