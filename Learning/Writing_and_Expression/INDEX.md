# 写作与表达

目标不是辞藻，而是把理解组织成别人能判断、复用并采取行动的信息。

## 学习顺序

```text
表达目标与读者 → 结构化写作 → 技术/工作沟通
→ 论证与异议 → 专业文档和困难沟通
```

## 怎么进入

优先从手头任务进入：写方案、做汇报、准备面试、处理异议或制作演示。只有表达基础长期不稳时，才按 `表达基础 → 结构化写作 → 技术/工作沟通 → 论证` 系统补课；速查页只用于复习和查漏。

## 按任务选

写方案看设计文档，做汇报看工作汇报，写总结或复盘看总结框架，面对质疑看有效论证。每个任务只打开对应主文档，不再维护重复速查页。

需要提高某项能力时，直接使用一份真实稿件；知识库不再为每篇概念正文安排独立练习。

## 用真实输出验证

对正在交付的汇报、设计文档或困难沟通稿，检查读者、结构、证据和下一步；重要输出保留原稿、修改稿、修改理由和真实反馈。没有真实任务时不需要为了完成路线而虚构练习。
