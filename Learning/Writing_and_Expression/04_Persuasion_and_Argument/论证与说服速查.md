# 论证与说服速查

本页只做回应质疑和推动行动的检查；正文见 [什么是有效论证](./什么是有效论证.md)。

## 一个论证

```text
结论 → 证据 → 推理规则/假设 → 反例与不确定性 → 行动建议
```

## 面对质疑

- 先判断对方是在质疑事实、假设、价值目标还是风险。
- 复述对方最强版本，不用偷换问题的方式反驳。
- 承认不确定边界，再说明哪些证据会改变结论。
- 能让步时让步；不能让步时说明代价、依据和下一步验证。

故事、数据和类比服务于不同任务：故事提供情境，数据提供规模，类比帮助理解；都不能代替关键证据。表达判断时区分“已知事实、当前推断、待验证假设”。
