# 结构化写作速查

本页只做写作流程卡；正文见 [总结写作的标准框架](./总结写作的标准框架.md)。

```text
确定读者/目标 → 收集材料 → 提炼结论 → 排列依据
→ 加入例子与边界 → 删除重复 → 获取反馈 → 更新版本
```

## 快速检查

- 开头是否先说结论和阅读收益？
- 每一层是否回答同一个问题，层级是否平行？
- 例子是否解释机制，而不是只增加长度？
- 长文是否有导航、过渡和可回看的小结？
- 删除一段后，核心判断是否真的受影响？
- 复盘是否记录原稿、修改理由和真实反馈？

写不动时先写粗糙提纲；信息密度不足先补关系和证据，不靠堆术语；压缩时优先合并同义段落和重复总结。
