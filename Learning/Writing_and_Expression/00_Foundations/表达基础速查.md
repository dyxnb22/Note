# 表达基础速查

本页只做检查卡；正文见 [表达的本质](./表达的本质：传递信息、建立共识、推动行动.md)。

| 检查项 | 问题 |
|---|---|
| 目标 | 读者读完要理解、判断还是行动？ |
| 对象 | 读者已有多少背景，真正关心什么？ |
| 结构 | 结论、依据、限制和下一步是否可扫描？ |
| 抽象 | 是否在具体例子、模型和原则之间切换得当？ |
| 密度 | 每段是否只承担一个主要任务？ |
| 语言 | 是否删掉空话、重复、模糊主语和无必要术语？ |

复杂问题先分层：一句话结论 → 三个关键点 → 证据/例子 → 边界和行动。修改时优先删重复，再补缺失关系，最后调整文采。
