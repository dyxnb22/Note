# 离散数学与证明方法

离散数学不是为了背符号，而是训练如何把程序、状态和约束写成可以推理的对象。算法正确性、数据库关系、权限模型、状态机和分布式协议都会反复使用这些方法。

## 1. 命题逻辑

命题是可以判断真假的陈述。常见运算包括：

- 否定 `¬P`
- 合取 `P ∧ Q`
- 析取 `P ∨ Q`
- 蕴含 `P → Q`
- 等价 `P ↔ Q`

`P → Q` 只在 `P` 为真而 `Q` 为假时为假。工程中最容易犯的错误是把“充分条件”和“必要条件”混淆：

- `P → Q`：P 是 Q 的充分条件，Q 是 P 的必要条件。
- 逆命题 `Q → P` 不一定成立。
- 逆否命题 `¬Q → ¬P` 与原命题等价。

条件判断、策略规则和权限表达式应先明确括号与优先级，再做化简。德摩根律常用于检查否定条件：

```text
¬(P ∧ Q) = ¬P ∨ ¬Q
¬(P ∨ Q) = ¬P ∧ ¬Q
```

## 2. 谓词与量词

谓词描述对象是否满足某种性质：

```text
valid(x): x 是否为合法请求
authorized(user, action): 用户是否有权执行动作
```

两个基本量词：

- 全称量词 `∀x`：对所有 x 成立。
- 存在量词 `∃x`：至少存在一个 x 成立。

否定量词时要同时交换量词：

```text
¬∀x P(x) = ∃x ¬P(x)
¬∃x P(x) = ∀x ¬P(x)
```

“并非所有请求都成功”只意味着至少一个请求失败，不等于所有请求都失败。

## 3. 集合、关系与函数

集合运算包括并、交、差、补集和笛卡尔积。数据库中的选择、投影、连接以及权限集合计算都建立在这些概念上。

二元关系是笛卡尔积的子集。常见性质：

- 自反：`aRa`
- 对称：`aRb → bRa`
- 反对称：`aRb ∧ bRa → a=b`
- 传递：`aRb ∧ bRc → aRc`

等价关系具有自反、对称、传递性，会把集合划分为互不重叠的等价类。偏序关系具有自反、反对称、传递性，依赖图、版本顺序和权限继承常表现为偏序。

函数需要区分：

- 单射：不同输入不会映射到同一输出。
- 满射：值域中每个元素都有原像。
- 双射：同时是单射和满射，因此存在逆函数。

哈希不是单射；固定长度摘要面对无限输入必然可能碰撞。

## 4. 证明方法

### 4.1 直接证明

从已知条件和定义出发，逐步推出结论。每一步都应说明使用了哪个定义或已知事实。

### 4.2 反证法

假设结论不成立，推导出与已知事实矛盾。适合证明“不可能同时满足”一类结论，但不能把“没有找到反例”当作证明。

### 4.3 构造性证明

不仅证明对象存在，还给出构造方法。算法本身经常就是构造性证明：输出对象并验证它满足条件。

### 4.4 数学归纳法

1. 证明基础情形。
2. 假设命题对 `n=k` 成立。
3. 证明它对 `n=k+1` 成立。

递归算法、循环次数和树结构证明经常使用归纳法。强归纳允许在证明第 k+1 项时使用此前所有项。

### 4.5 反例

要否定全称命题，只需找到一个满足前提但不满足结论的对象。测试中的最小失败样例，本质上就是可执行反例。

## 5. 循环不变量

循环不变量是在每次迭代开始或结束时始终成立的性质。证明一个循环正确通常分三步：

1. 初始化：第一次迭代前成立。
2. 保持：一次迭代不会破坏它。
3. 终止：循环结束时，不变量与终止条件共同推出目标结论。

例如二分查找可以维护：

```text
若目标存在，则它始终位于闭区间 [left, right] 中。
```

选择开区间还是闭区间不是风格问题；初始化、循环条件、更新和返回值必须使用同一套区间语义。

## 6. 组合计数

基本原则：

- 加法原理：互斥方案数相加。
- 乘法原理：连续独立选择的方案数相乘。
- 排列：关注顺序。
- 组合：不关注顺序。
- 容斥原理：修正集合重叠导致的重复计数。
- 鸽巢原理：把更多对象放入更少容器，至少一个容器包含多个对象。

组合计数用于估算密码空间、测试组合、状态空间和碰撞概率。计算前必须确认选择是否有序、是否允许重复、事件是否互斥。

## 7. 图与树的数学结构

图由顶点和边组成。需要区分有向/无向、带权/无权、连通、环、路径和度。

- 树是连通且无环的无向图。
- n 个顶点的树恰有 n-1 条边。
- DAG 可以进行拓扑排序。
- 强连通分量把有向图压缩成 DAG。
- 二分图可以按两种颜色划分，相邻顶点颜色不同。

依赖管理、任务编排、调用链、权限继承和网络拓扑都可以转化为图问题。

## 8. 递推与渐近增长

递推式描述问题规模之间的关系。例如归并排序：

```text
T(n) = 2T(n/2) + O(n)
```

常用求解方式包括递归树、代入证明和主定理。渐近符号：

- `O(g(n))`：增长上界。
- `Ω(g(n))`：增长下界。
- `Θ(g(n))`：同阶紧确界。

渐近分析忽略常数和低阶项，但工程选型仍要考虑数据规模、缓存局部性、I/O、并发和实现常数。

## 9. 概率方法

基础关系：

```text
P(A | B) = P(A ∩ B) / P(B)
P(A ∩ B) = P(A | B)P(B)
```

只有在 `P(A ∩ B)=P(A)P(B)` 时，A 与 B 才独立。互斥和独立不是一回事。

期望具有线性性质，即使变量不独立也有：

```text
E[X + Y] = E[X] + E[Y]
```

概率用于分析随机算法、哈希碰撞、重试、采样和故障。平均成功率不能替代尾部概率与失败条件。

## 10. 状态机与不变量

系统可以表示为：

```text
状态集合 + 输入事件 + 转移函数 + 初始状态 + 终止状态
```

设计状态机时至少回答：

- 哪些状态是合法的？
- 哪些转移被允许？
- 重复事件是否改变结果？
- 乱序事件如何处理？
- 哪些性质在所有可达状态中都必须成立？

例如支付系统的不变量可以是“成功退款总额不能超过成功支付金额”。不变量比某条正常流程更适合描述系统安全边界。

## 最小练习

1. 用真值表验证两条德摩根律。
2. 为二分查找写出明确的区间不变量。
3. 证明一棵 n 个节点的树有 n-1 条边。
4. 把订单生命周期画成状态机，并列出两个必须保持的不变量。
5. 计算随机生成 k 个 ID 时的近似碰撞风险，并说明假设。

## 验收清单

- 能区分充分条件、必要条件、逆命题和逆否命题。
- 能使用归纳法、反证法或反例完成一段正确性论证。
- 能为循环和状态机写出可验证的不变量。
- 能把依赖、权限或任务问题转成图模型。
- 能区分渐近复杂度与真实系统性能。
