# 哈希表与状态映射

遍历时将已经处理过的数据压缩为可查找状态。键必须保留后续计算需要的区别：两数之和记录数值到下标，异位词记录规范化后的字符组合，前缀和则记录累计状态。

## 查找状态与哈希键

两数之和输入 [2, 7, 11]、目标 9。读到 2 时存入 2→0；读到 7 时查补数 2，即可返回两个不同下标。先查询再插入，避免把当前元素重复使用。

```python
def two_sum(values, target):
    seen = {}
    for index, value in enumerate(values):
        complement = target - value
        if complement in seen:
            return seen[complement], index
        seen[value] = index
    return None

assert two_sum([2, 7, 11], 9) == (0, 1)
assert two_sum([3, 3], 6) == (0, 1)
assert two_sum([], 1) is None
```

平均时间 O(n)，额外空间 O(n)。哈希相等性必须与业务相等性一致，哈希碰撞不表示两个键相等。

## 索引怎样减少重复查找

哈希表保存已经得到的局部事实。查补数、合并部分和、找到连续区间起点，都用一次查询替代了对历史数据的反复扫描。

### 记录已见数值，查找补数

两数之和的关键是只查询已经处理的前缀：当前位置为 i 时，表中若有 target−nums[i]，就得到一个不同于 i 的历史下标。前面的完整实现按这个顺序查询、再登记，输入只有一个值时也不会把它与自己配对。

如果后续需要统计所有下标对，应把“一个历史下标”改成“历史出现次数”；只改返回语句而不改状态，会漏掉重复值形成的组合。

### 把四元组合拆成两组和

四个数组各取一个元素，统计总和为 0 的下标四元组。先统计 A、B 的两两和频次，再枚举 C、D 的两两和 s，累加 countAB[−s]；也可构造两张频次表，累加 countAB[s]×countCD[−s]。重复元素对应不同下标，频次必须相乘，不能只记录和是否存在。

四个数组长度都为 n 时，期望时间与额外空间均为 O(n²)，用空间换掉四重枚举。定长整数需要检查两两和与最终计数的范围。

### 只从连续序列的起点扩张

先把数值放入集合。只对集合中满足 x−1 不存在的 x 向后扩张，因为它一定是一段连续序列的起点；沿 x+1、x+2 统计长度，遇到缺失值就停止。

必须遍历去重后的集合，避免输入中重复的起点反复触发同一段扫描。每个不同数至多被所在序列扩张一次，哈希查询期望为常数时，总时间 O(n)，空间 O(n)。

### 用前缀位移修复轨迹

把 U、D、L、R 分别解释为纵向 +1、−1 和横向 −1、+1，轨迹从原点出发。总位移为 D，目标位移为 T，删除区间的位移就必须是 Δ=D−T。设 P[j] 是前 j 步的位移，删除 [i,j) 等价于寻找 P[i]=P[j]−Δ。

依次处理 j，用二元组作为哈希键，保存每种历史位移最近出现的位置；相同 P[i] 中，i 越大，删除长度 j−i 越短。初始登记 P[0]=(0,0)，每次先查询再登记当前状态。若 D 已等于 T，直接返回 0；其余候选都不存在时返回 −1。

例如 RULR 的总位移是 (1,1)，目标为 (1,0)，需要删除的位移是 (0,1)，因此删掉 U 就得到长度 1 的方案。这里保存最近下标；计数问题则要保存频次，二者不能共用同一种状态。

## 规范表示与双向对应

分组需要把等价对象映射到同一个键；一一对应还需要同时约束两个方向，防止不同输入占用同一输出。

### 用规范表示归并异位词

对每个单词排序字符，用排序后的串作为键，把原词追加到对应列表。相同字符及频次得到相同键，因此分组不会依赖原词的字符顺序。n 个长度不超过 k 的词，排序构键的时间为 O(nk log k)。

若输入明确只有小写英文字母，也可用长度 26 的频次元组作键，把构键降为 O(k)。需要先确定大小写、Unicode 规范化和字符单位；这些规则决定哪些词应被视为等价。

### 双向映射保持单词模式

模式 abb 与单词序列 hello you you 对应。先确认模式长度等于单词数，再同时维护“模式字符→单词”和“单词→模式字符”两张表。已有对应关系必须一致，没有记录时才建立。

只检查正向会错误接受 ab 对应 hello hello，因为两个不同模式字符占用了同一个单词。分词也应遵循输入约定，不能把连续空白造成的空字段当成正常单词。

### 双向映射保持字符对应

判断两个字符串是否同构时，先比较长度，再逐位置检查 s 的字符是否始终映射到 t 的同一个字符，同时检查反向映射是否被别的字符占用。两张表共同约束一一对应。

例如 egg 与 add 成立，而 ab 与 aa 不成立：后一对在反向检查时冲突。这里保持的是对应关系，不要求两个字符串包含相同字符。

## 把访问与约束记录为集合

记录曾经到达的状态，可以识别重复路径；按独立维度记录已用值，则可以检查局部约束。

### 用访问集合识别重复状态

快乐数从一个正整数开始，反复把它替换为各位数字平方之和。每轮先判断是否已经为 1；若是则成功，否则检查当前状态是否出现过，再登记并继续转换。重复状态意味着后续会重走相同循环，不可能首次到达 1。

平方和会把足够大的数压缩到较小范围，所以这个确定过程最终到达 1 或进入有限循环。集合保存的是完整的中间整数，而非某个单独数位。

### 按行、列和宫格记录约束

对固定 9×9 数独建立 9 个行集合、9 个列集合和 9 个宫格集合。跳过表示空位的字符；对已填数字，宫格编号为 (i//3)×3+j//3。任一对应集合已经包含该数字，便违反约束；否则同时登记到三个集合。

输入还应满足格子大小与数字范围约定。这个过程只检验现有数字是否冲突，不保证剩余空位一定能够补成完整解。
