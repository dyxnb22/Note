# 前缀和与连续区间

子数组或子串要求位置连续。令 prefix[i] 为前 i 个元素之和，则半开区间 [left,right) 的和为 prefix[right]−prefix[left]。这条恒等关系不要求元素为正。

## 从区间之差得到历史查询

扫描到右边界 right，当前累计和为 s。要找和为 target 的区间，就统计历史前缀 s−target 的出现次数；因此哈希表保存频次，而非仅记录是否见过。初始登记零前缀一次，表示尚未读取元素的位置。

```python
def count_subarrays(values, target):
    counts = {0: 1}
    total = answer = 0
    for value in values:
        total += value
        answer += counts.get(total - target, 0)
        counts[total] = counts.get(total, 0) + 1
    return answer

assert count_subarrays([1, -1, 1], 1) == 3
assert count_subarrays([0, 0], 0) == 3
assert count_subarrays([], 0) == 0
```

先查询旧前缀，再登记当前前缀，才能只统计非空区间。时间与额外空间均为 O(n)；Python 整数不受固定机器字长限制，其他语言需检查累计和及计数是否溢出。

## 用一个例子区分状态与目标

在 [1,−1,1] 中，前缀依次为 0、1、0、1，目标为 1。第一个 1 能与初始零前缀配对；最后一个 1 能与两个历史零前缀配对，因此共有三个区间。只用集合会丢掉重复前缀的贡献。

若只判断存在性，可保存前缀集合；求最长区间时，同一前缀应保留最早位置；求最短非空区间时则保留最近历史位置，且仍先查询再更新。问题目标决定状态内容，不能只记住“前缀和加哈希表”的名称。

含负数时，窗口和可能随扩张或收缩增大、减小，普通滑动窗口不再能安全排除候选，移动条件见[滑动窗口](15%20滑动窗口.md)。将累计值改成横纵位移二元组，也能寻找需要删除的连续轨迹，见[轨迹修复](01%20哈希表与状态映射.md#用前缀位移修复轨迹)。
