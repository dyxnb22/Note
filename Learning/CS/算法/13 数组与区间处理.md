# 数组与区间处理

数组支持按下标访问，但插入、删除和去重经常需要移动或重写元素。先确定是否允许排序、是否原地修改，再选择扫描、前缀统计或区间合并。

## 连续存储与区间整理

合并闭区间时先按起点排序。当前区间与最后一个结果重叠，就扩大末端；不重叠才增加一个结果，因此已经输出的更早区间不需要回看。

```python
def merge_intervals(intervals):
    result = []
    for start, end in sorted(intervals):
        if start > end:
            raise ValueError("invalid interval")
        if result and start <= result[-1][1]:
            result[-1][1] = max(result[-1][1], end)
        else:
            result.append([start, end])
    return result

assert merge_intervals([(1, 3), (2, 6), (8, 9)]) == [[1, 6], [8, 9]]
assert merge_intervals([]) == []
```

排序主导时间 O(n log n)，结果使用 O(n) 空间。这里闭区间在端点相等时合并；半开区间或业务上的相邻时间段必须明确不同的重叠规则。

## 按连续范围维护结果

连续区间可以由累计状态描述，也可以先排序再合并。区分元素顺序与数值范围，才能选择合适的操作。

### 保留以当前位置结尾的最优和

最大连续子数组和用 ending 表示必须以当前元素结尾的最优和。读到 x 后，只有“从 x 重新开始”和“接到旧 ending 后面”两种选择，ending=max(x,ending+x)，再更新全局最大值。

非空输入以首元素初始化两个状态，才能在全负数组中返回最大的那个负数，而非空子数组的 0。时间 O(n)、额外空间 O(1)，空输入另定接口行为。

### 比较左右两侧累计和

寻找一个下标，使其左侧和等于右侧和，均不包含自身。先求 total，扫描时用 left 保存当前下标之前的和，右侧为 total−left−nums[i]，比较后才把 nums[i] 加入 left。

若返回最左中心下标，首次相等即结束；无解返回 −1。正负数都适用，时间 O(n)、额外空间 O(1)，无需实际分配前缀数组。

### 排序后合并重叠区间

返回一个不重叠的区间数组。用 `curStart, curEnd` 跟踪。有重叠，更新终点；没重叠，存入，开启新区间。循环结束后一定会剩下一组待处理的，直接存进去。
`Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));`
`res.add(new int[]{curStart, curEnd});`
`res.toArray(new int[res.size()][])`

### 在已有有序区间中插入并合并

输入已按左端点排序且互不重叠，三段式一次扫描，`i` 从头走到尾不回退。`O(n)`，无需再次排序；若重新排序，会把复杂度增加到 `O(n log n)`。
1. 跳过完全不重叠的前段：`intervals[i][1] < newInterval[0]`，直接进 `result`。
2. 合并所有相交的中段：`intervals[i][0] <= newInterval[1]` 时用 `min/max` 就地扩张 `newInterval` 两端。此时 `newInterval` 表示当前合并区间；若允许修改传入值，可原地扩张，否则先复制两端。
3. 合并结束后先把 `newInterval` 加入 `result`，再将剩余后段原样追加。
边界：相接算不算重叠由 `<` 与 `<=` 决定——端点相接（`[1,2]` 并 `[2,3]`，前段条件 `2 < 2` 为假）落进第 2 段被合并；中间有空隙（`[1,2]` 并 `[3,4]`，`2 < 3` 为真）才留在第 1 段不合并。`intervals` 为空、新区间全在两侧、全部相交，都要单独过一遍。

### 在不连续的位置结束当前区间

输入为严格递增、互异整数序列时，用 start 记录当前段起点；只要下一值恰比当前值大 1，就继续延伸。遇到缺口或数组结束，输出单值或首尾区间，再开启下一段。

例如 [0,1,2,4,5,7] 得到 0→2、4→5、7。无序或含重复的输入必须先明确是否允许排序、去重；定长整数比较相邻差时要避免 value+1 在最大值处溢出。

## 借助前后位置原地重排

写入位置、数值对应位置和反转范围都能作为隐含状态；修改之前需要确认尚未读取的数据仍然可用。

### 用反转重排实现轮转

非空数组向右轮转 k 位，先令 k 对 n 取模。反转整体，再反转前 k 个和剩余 n−k 个元素，就把原来的后缀移动到前面，同时恢复两段各自的内部次序。

例如 [1,2,3,4,5] 右转 2 位，整体反转后为 [5,4,3,2,1]，分别反转得到 [4,5,1,2,3]。空数组须在取模前处理，负 k 是否表示左转则由接口约定；时间 O(n)、额外空间 O(1)。

### 组合前缀与后缀乘积

每个位置的答案等于左边所有数的乘积乘以右边所有数的乘积，空侧乘积为 1。先在输出数组记录各位置的左前缀积，再从右向左用一个变量维护右后缀积并乘入结果。

这种写法不用除法，能自然处理一个或多个零。时间 O(n)，除输出数组外只需 O(1) 空间；累计乘积需要足够大的数值类型，不能以最终结果较小推断中间值不会溢出。

### 把数值放回对应下标

长度为 n 的数组，最小缺失正数一定在 [1,n+1]。只把 [1,n] 范围内的值 x 放到下标 x−1；对当前位置反复交换，直到值越界或目标位置已经有同一个值，避免重复值导致死循环。

交换后仍要检查当前位置的新值，不能每个下标只交换一次。每次有效交换都会固定一个目标位置，总次数 O(n)；最终首个 nums[i]!=i+1 的位置给出答案，若全部匹配则返回 n+1。算法修改原数组，额外空间 O(1)。

### 按有序关系合并序列

两个数组均已非递减时，用读取指针分别指向当前最小未处理值，把较小者写入结果，再推进对应指针。一个输入耗尽后，把另一个的剩余部分追加，时间 O(m+n)，新结果空间 O(m+n)。

若第一个数组已有 m+n 的容量，可从两端最大值开始倒序写入末尾，避免覆盖其尚未读取的前 m 个元素。这与新建结果数组的空间前提不同。

### 为相同值保留一个写入位置

输入已非递减，相同值必连续。扫描每个值，只有结果前缀为空或当前值不同于已写入的最后一个值时才保留；写入指针最终就是去重后的长度。

空数组直接得到 0，不需要特判“最后一个元素必加”。算法稳定、原地，时间 O(n)、额外空间 O(1)；返回长度以外的值不属于结果。

### 把允许的重复数写进更新规则

有序数组中每个值最多保留两次，可把规则写成：write<2，或当前值不同于 nums[write−2] 时才写入。write−2 指向结果前缀，而非原输入的固定相邻位置。

推广为最多 k 次时，将 2 换成正整数 k。这样无需额外计数器，也不会在值切换时忘记重置；与只保留一次一样，必须满足输入有序。

## 计数与方向状态

字符资源可以用频次表示，折返排布则只需记录当前行和方向。无需为每个目标都建立完整二维结构。

### 按字符频次消费有限资源

判断 ransomNote 能否由 magazine 的字符构成，每个来源字符最多使用一次。先统计来源频次，再逐字符扣减需求；遇到不存在或已耗尽的字符即失败。

长度 26 的数组只适合已限定的小写英文字母，字符下标为 c−a。任意字符集应改用映射，并与其他字符串章节保持相同字符单位约定。

### 用方向状态模拟折返排布

Z 字排布只需记录当前行与方向，不必构造空白矩阵。每读一个字符，将它追加到当前行的字符列表；到顶行改为向下，到底行改为向上，再更新行号，最后按行拼接。

numRows==1 或 numRows>=len(s) 时直接返回原串；非正行数应拒绝。用列表追加后统一 join，时间与输出空间均为 O(n)；循环中反复拼接不可变字符串可能产生额外复制，不能直接按 O(n) 估算。
