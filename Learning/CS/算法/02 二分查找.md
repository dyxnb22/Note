# 二分查找

二分的前提是存在可以成批排除一半候选的单调关系。先明确目标是任意命中、第一个满足还是最后一个满足，再设计区间和循环。

## 候选区间与单调判定

在 [1, 3, 3, 6] 中寻找第一个不小于 3 的位置。候选使用左闭右开区间 [left, right)，当中点已经不小于 3 时保留中点作为可能答案，把 right 移到 mid。

```python
def lower_bound(values, target):
    left, right = 0, len(values)
    while left < right:
        mid = left + (right - left) // 2
        if values[mid] >= target:
            right = mid
        else:
            left = mid + 1
    return left

assert lower_bound([1, 3, 3, 6], 3) == 1
assert lower_bound([1, 3], 8) == 2
assert lower_bound([], 0) == 0
```

循环保持左边都小于 target，right 及其右边都不小于 target；结束时 left 是插入位置。索引值等于长度是合法结果，读取元素前仍须检查。

## 从下界推导查找与范围

精确查找、插入位置和重复值范围都依赖相同的区间收缩规则。区别在于相等时保留哪一侧，以及结束后返回哪个边界。

### 保持查找区间的不变量

沿用开头的左闭右开区间 [left,right)。已排除的左侧全部小于 target，右侧全部不小于 target。中点小于目标时令 left=mid+1；否则令 right=mid，保留中点成为最终下界的可能性。

每轮区间长度严格缩短，left==right 时待定区域为空，left 就是第一个不小于目标的位置。相等时仍继续收缩，才能在重复值中得到最左位置。

### 下界统一处理存在与插入位置

先求下界 p，再检查 p<n 且 nums[p]==target，就可以判断目标是否存在。不管存在与否，p 都是把 target 插入后仍保持有序的最左位置。

例如 [1,3,3,6] 查找 3，下界为 1；若遇到相等就返回任意 mid，可能得到 2，便不再满足下界定义。目标大于所有元素时返回 n，空数组也返回 0，这些位置可以用于插入，不能直接用于读取元素。

### 用两个边界确定重复值范围

下界 start 寻找第一个 nums[i]>=target，上界 stop 寻找第一个 nums[i]>target。目标存在时，其所有位置恰为 [start,stop)，最后一个下标为 stop−1；若 start==n 或 nums[start]!=target，则没有目标。不要用 target+1 构造上界，固定宽度整数可能溢出。

下面展示同一个下界目标的闭区间变体：初始 right=n−1，循环条件为 left<=right。由于闭区间要排除已检查的中点，收缩右侧使用 mid−1；退出后返回 left。它与开头半开区间写法的更新规则不能混用。

```java
if (nums[mid] >= target) {
    right = mid - 1; // 范围缩小到 [left, mid - 1]
} else {
    left = mid + 1;  // 范围缩小到 [mid + 1, right]
}
// 循环结束时 left == right + 1，left 就是第一个 >= target 的位置；
// 若 left == n，说明所有元素都小于 target。
```

## 先识别可以排除的有序范围

二分可以作用于映射后的一维位置，也可以在部分有序结构中先判断哪一半仍然满足条件。

### 把行列坐标映射为有序位置

矩阵每行递增，且下一行首元素大于上一行末元素时，按行展开得到全局有序数组。设列数为 n，一维下标 mid 对应 row=mid//n、col=mid%n，直接比较这个格子即可，查询时间 O(log(mn))。

只有“每行有序、每列有序”还不够保证展开后有序；这种输入应使用行列排除法。计算 m×n 前也要处理空矩阵与定长整数范围。

### 在旋转数组中识别有序半段

先假设原数组严格递增、元素互异，旋转后只有一个断点。若 nums[left]<=nums[mid]，左半段有序，比较 target 是否落在 [nums[left],nums[mid]] 内；在范围内就保留左半，否则转向右半。左半无序时，对右半做对称判断。

这个判断每轮排除一半候选，时间 O(log n)。有重复元素时，左右端点与中点相等可能掩盖断点，需要额外缩边界，最坏会退化为 O(n)。

### 根据中点缩小最小值范围

对非空且元素互异的旋转升序数组，以固定末元素 nums[n−1] 为参照：大于它的元素位于断点左侧，不大于它的元素位于包含最小值的右侧。寻找第一个不大于末元素的位置，就找到最小值；未旋转时结果为 0。

也可以每轮与当前 nums[right] 比较并保留最小值候选。若允许重复，比较相等时无法直接确定最小值所在半边，不能继续声称始终 O(log n)。

## 与归并视角比较

两个有序序列还可以按合并顺序定位中间元素。保留这一方法，有助于比较二分分割与顺序推进的成本。

### 用归并视角定位中间元素

至少有一个数组非空时，用两个读取指针按从小到大取出元素，只处理到总长度的一半附近。每次把上一个取值保存在 left，本轮值保存在 right；一个数组耗尽后，直接从另一个数组继续取。

总长度为奇数，中位数是 right；为偶数，是 (left+right)/2。整数实现应先转为足够宽的类型或浮点再相加，避免和溢出。该方法时间 O(m+n)、额外空间 O(1)，不必真的生成合并数组；两个输入都为空时，中位数未定义，应拒绝输入。
