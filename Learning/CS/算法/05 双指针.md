# 双指针

快慢指针把扫描位置与写入位置分开；左右指针则依赖有序性或端点性质排除候选。每次移动都需要能解释被跳过的部分为何无需再看。

## 已处理前缀与候选排除

删除数组中等于 val 的元素时，[0, write) 保存已经确认保留的元素。扫描到需要保留的值才写入 write，之后 write 前进；扫描指针始终不落后于写入指针。

```python
def remove_value(values, unwanted):
    write = 0
    for read in range(len(values)):
        if values[read] != unwanted:
            values[write] = values[read]
            write += 1
    return write

values = [3, 2, 2, 3]
length = remove_value(values, 3)
assert length == 2 and values[:length] == [2, 2]
assert remove_value([], 3) == 0
```

返回长度以内才是结果，尾部旧数据无意义。算法原地修改，时间 O(n)，额外空间 O(1)。

## 读写位置分开后原地整理

读取指针观察每个输入，写入指针只推进需要保留的结果。两者的职责分开，就能解释覆盖为什么安全。

### 读写指针完成原地筛选

扫描指针逐个读取，写入指针只在元素需要保留时推进。由于 write 从不超过当前读取位置，把元素写到前面不会破坏尚未读取的数据；处理后 [0,write) 就是有效前缀。

这种稳定筛选保留相对顺序，返回的是新长度。调用方只能读取该前缀，不能把尾部残留值视为结果的一部分。

### 稳定筛选后填充空位

把非零元素按原顺序写到前缀，扫描完成后，将剩余位置统一填 0。这样既把零移到末尾，也保留非零元素的相对次序。

不能读到一个零就立刻向后整体搬移，否则大量零会造成反复移动，最坏 O(n²)；分离筛选与补零可保持 O(n) 时间、O(1) 额外空间。

## 从两端排除不可能更优的候选

两端比较必须依赖有序性或可以证明的界限。每次移动都需要说明被丢弃的位置为何不必再尝试。

### 比较两端平方，倒序写入结果

输入数组已非递减，绝对值最大的剩余元素只可能在左右端点。比较两端平方，把较大者写到新结果数组的末端，再移动相应指针，逐步向前填满。

这里需要独立结果数组，不能直接覆盖原数组尾部而破坏未读取值。时间 O(n)，结果空间 O(n)；固定宽度整数还要确认平方不会溢出。

### 移动较短边界以排除候选

左右指针，每次移动**较矮**的一侧。为什么安全：面积由 `min(h[l], h[r]) × 宽度` 决定，移动较高一侧时高度上限不变而宽度必减，不可能变好；所以以较矮侧为短板的所有其余组合都可以整批丢弃。`O(n)`。

### 固定一个数，再缩小两端范围

先排序，固定第一个位置 i，再在 [i+1,n−1] 内用左右指针寻找另外两个数，使三数和达到目标。和太小就右移左指针，和太大就左移右指针，有序性保证被排除的组合无需再看。

i>0 且当前值等于前值时跳过；命中后左右指针同时移动并跳过重复值，避免返回重复数值组合。时间 O(n²)，排序会改变原顺序；若需原下标，应另行保存。

### 逐层固定元素并处理去重

四数和先固定两个位置，再在其右侧用双指针求剩余目标。每一层只与同层的前一个值比较去重，命中后还需跳过左右两端的连续重复值。

时间 O(n³)。Java 等语言要在第一次加法之前提升类型，例如 sum=(long)a+b+c+d；先用 int 求和再转 long，已经发生的溢出无法恢复。

### 跳过无关字符后比较两端

按仅考虑 ASCII 字母数字、忽略大小写的约定，左右指针分别跳过无关字符，再比较归一化后的字符；相同就继续向内，不同则失败。过滤后为空或仅一个字符时也符合回文定义。

也可以先用 replaceAll("[^a-zA-Z0-9]", "").toLowerCase() 生成过滤串，再比较两端，但这会分配额外字符串。更广的文字范围需要重新定义字符分类与大小写规则，不能沿用 ASCII 正则。

### 区分单词次序与字符次序

先把前后空格去掉，并把词间多个空格压为一个。反转整个字符序列后，词的先后倒转，但每个词内部也倒了；再逐词反转，便恢复词内顺序。

例如 the sky 整体反转为 yks eht，再局部反转得到 sky the。可变字符数组能原地完成；不可变字符串实现会产生新对象，空间分析要按实际语言计算。
