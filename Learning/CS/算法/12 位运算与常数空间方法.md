# 位运算与常数空间方法

位运算、投票和原地标记之所以有效，是因为输入满足某种结构。先写前提，再证明压缩后的状态仍能保留所需信息，不能将技巧当成任意输入下的捷径。

## 从性质推导状态压缩

其余整数都恰好出现两次时，两两异或为 0，和 0 异或不改变值。因此无论顺序如何，将所有值异或后只剩单独出现的数。

```python
def single_number(values):
    answer = 0
    for value in values:
        answer ^= value
    return answer

assert single_number([4, 1, 2, 1, 2]) == 4
assert single_number([-3, 2, 2]) == -3
```

时间 O(n)，额外空间 O(1)。这个函数依赖“恰有一个数出现一次，其余出现两次”的前提，不能验证一般频次分布。投票法也需另行检查候选是否真正超过半数。

## 利用代数性质压缩状态

异或抵消和候选消去都用很少的变量保存结果，但各自成立需要不同输入前提。

### 用异或抵消成对元素

前面的完整实现依赖恰有一个值出现一次、其余均出现两次。异或满足交换律、结合律，且 a⊕a=0、a⊕0=a，所以顺序不会影响成对抵消的结果。

如果有多个单独出现的数，最终得到的是它们的异或，未必是任何输入值。因此它是利用已知频次结构求结果，不能替代对输入前提的验证。

### 用候选消去保留多数元素

Boyer–Moore 投票只保留候选 candidate 与计数 count。计数为 0 时换成当前值；相同就加一，不同就减一，相当于把不同值两两抵消。若某值严格超过一半，抵消后不可能把它全部消掉。

输入没有多数元素保证时，最后只得到候选，还要再扫描一次确认其频次大于 floor(n/2)。空输入无候选。两遍时间 O(n)、额外空间 O(1)；哈希计数更直接，但需要 O(u) 空间。

## 让下标、区域或路径承载状态

原地算法把已处理范围、数值位置或访问关系写入现有结构。额外空间减少以后，不变量必须更明确。

### 用三个区域完成原地分类

将 0、1、2 三类值一次扫描归位，维护 [0,low) 为 0、[low,i) 为 1、[i,high] 未处理、(high,n) 为 2。循环直到 i>high。

遇到 0，与 low 交换后同时推进 low、i；遇到 1，只推进 i；遇到 2，与 high 交换并后退 high，暂不推进 i，因为换回来的值尚未检查。区域不变量给出 O(n) 时间与 O(1) 额外空间，也明确了为什么最后一种交换不能直接跳过。

### 找到可提升位置后调整后缀

下一个排列是比当前排列字典序更大的最小排列；若不存在，则回到升序最小排列。例如 [1,2,3] 的下一个是 [1,3,2]，[3,2,1] 则回到 [1,2,3]。

要让一个序列在字典序上“变大一点点”，我们需要：

1.  **改变尽可能靠右的数字**（因为左边的位权更高）。
2.  **用一个稍大一点的数替换掉当前的数**。
3.  **让替换后的右侧部分尽可能小**（即变成升序）

第一步：从右向左找到第一个小于右侧相邻数字的数 nums[i]。如果找到了，进入第二步；否则跳过第二步，反转整个数组

第二步：从右向左找到 nums[i] 右边最小的大于 nums[i] 的数 nums[j]

第三步：反转 [i+1, n-1]（如果上面跳过第二步，此时 i = -1）

### 把值到下标的关系视作环

输入有 n+1 个数，每个值都在 [1,n]，并约定只有一个不同数值重复出现。把下标看成节点、nums[i] 看成后继，从 0 出发会先走一条链，再进入环；0 不可能被指回，环入口同时有来自链与环的前驱，其编号就是重复值。

先让快慢指针从 0 出发，每轮走一步与两步，先移动再比较，直到相遇。然后把一个指针放回 0，与相遇点指针每次各走一步，再次相遇即环入口。只读数组，时间 O(n)、额外空间 O(1)；范围约束不成立时，连“后继下标”都可能非法。
