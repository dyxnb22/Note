# 滑动窗口

窗口维护一个连续区间及其统计状态。右边界引入新元素后，若条件失效，就推进左边界直到恢复；这种做法依赖能证明被丢弃区间不会更优。

## 窗口含义与左边界推进

最长无重复子串中，last[ch] 记录字符最近一次出现的位置。如果这次出现落在当前窗口里，左边界直接移到旧位置之后；旧位置在窗口外时，左边界保持不动。

```python
def longest_unique(text):
    last = {}
    left = best = 0
    for right, char in enumerate(text):
        left = max(left, last.get(char, -1) + 1)
        last[char] = right
        best = max(best, right - left + 1)
    return best

assert longest_unique("abba") == 2
assert longest_unique("abcabcbb") == 3
assert longest_unique("") == 0
```

max 防止左边界倒退。时间 O(n)，空间与不同字符数有关；任意含负数的区间和问题不一定满足同样的移动条件。

## 固定与可变窗口

以下两块是状态更新的伪代码，add、remove 与更新答案操作需要替换为具体问题的统计规则。

### 固定长度窗口

窗口大小为 `k`。每次加入右侧元素、移除离开窗口的左侧元素，再读取当前状态。

```text
先建立前 k 个元素的状态
记录答案
for right = k .. n-1:
    加入 a[right]
    移除 a[right-k]
    更新答案
```

适合定长子数组和异位词匹配。查找异位词可维护两个字符计数数组；窗口达到 `len(p)` 时比较频次，而不是枚举排列。

### 可变长度窗口

右端持续扩张；当窗口违反约束时，循环移动左端直到重新合法。

```pseudocode
left = 0
for right in range(n):
    加入 a[right]
    while 窗口不合法:
        移除 a[left]
        left += 1
    用当前窗口更新答案
```
更新答案的位置取决于题意：求“最长合法窗口”通常在恢复合法后更新；求“满足条件的最短窗口”通常在条件成立时一边收缩一边更新。

## 移动成本与适用条件

不要被嵌套的 `for + while` 误导。右指针最多移动 `n` 次，左指针也最多移动 `n` 次，因此总移动次数是 `O(n)`。窗口状态必须支持增量加入和移除；若每步重新扫描整个窗口，复杂度会退化。

### 约束为何允许收缩

窗口方法需要一种可维护的单调约束：右扩后，移动左端能让窗口朝“重新合法”的方向变化。例如全为正数时，区间和随右扩不减，寻找最短达标区间时可安全收缩。

如果数组允许负数，“和至少为 target”不再满足这个单调性。例如 [1,−1,3]、target=3，整段达标后移除左端 1，和变为 2，普通窗口会停止收缩，漏掉末尾单独的 3。此时应考虑前缀和加单调队列等方法，重新证明候选如何被排除。

### 频次、位置与窗口和

- 正整数的最短达标区间：维护窗口和；条件成立时收缩并更新最短长度。仅适用于题设中的正整数。
- 最长无重复子串：维护字符最近位置或频次；出现重复时推进左端，求最长无重复子串。
- 异位词匹配：维护定长窗口的字符频次与目标频次，窗口每移动一步做一次增删。

## 极值与覆盖需要不同状态

### 用单调队列维护定长窗口极值

队列保存下标，对应数值从队头到队尾单调递减。新元素到来时，队尾不大于它的元素已经不可能在后续窗口中胜出，可以弹出；队头离开窗口时也要移除。窗口形成后，队头就是最大值。

保存下标才能同时判断过期和处理重复值。每个下标最多入队、出队一次，因此整段扫描为 `O(n)`；这个结论计算的是累计操作次数。

### 满足覆盖后继续收缩

最小覆盖子串维护目标字符频次、窗口频次和已满足的条件数。右端扩张直到覆盖全部要求，再移动左端缩短答案，直到覆盖被破坏；每个字符需要出现多少次也属于约束，不能只比较字符种类。

例如目标 AABC 需要两个 A，仅记录 A、B、C 三种字符已出现会错误接受 ABC。维护达标种类数时，只在频次跨越需求阈值的时刻增减；空目标应提前返回空串。

固定长度的计数数组只适合输入明确限制的字符集。通用文本可以使用哈希表；ASCII 字节、Unicode 码点与用户感知字符需要分别处理。

## 常见边界与失效条件

- 把 `if` 写成 `while` 的反面：一次收缩不足以恢复约束。
- 先移动指针再移除元素，导致删错位置。
- 混淆窗口 `[left, right]` 与 `[left, right)`，产生长度差一。
- 没处理空数组、`k > n`、目标为空等边界。
- 未证明单调性，机械套模板到包含负数或非连续区间的问题。

### 从状态定义检查边界

固定窗口需要先约定 k 的合法范围：通常 k<=0 为非法输入，k>n 没有完整窗口。覆盖任务的空目标可提前返回空串，不能让“已满足全部要求”的空条件反复触发收缩。

可变窗口还须保持左端不回退。例如无重复子串扫描 abba，读到最后一个 a 时，旧 a 已在窗口外，left 应保持在 2，而不是退回 1。前面的 max 更新正是在维护这个不变量。
