# 矩阵

矩阵操作先统一行列含义和边界。二维前缀用容斥把矩形求和变成四个累计值，减少重复扫描；递推时先计算上方、左方和左上角。

## 坐标、遍历与二维前缀

令 prefix[r][c] 表示前 r 行、前 c 列的总和，额外补一行一列 0。查询 [top,bottom)×[left,right) 时，减去上方和左方，再补回重复减掉的左上矩形。

```python
def prefix_grid(grid):
    rows = len(grid)
    cols = len(grid[0]) if rows else 0
    if any(len(row) != cols for row in grid):
        raise ValueError("rectangular grid required")
    prefix = [[0] * (cols + 1) for _ in range(rows + 1)]
    for row in range(rows):
        for col in range(cols):
            prefix[row + 1][col + 1] = (grid[row][col] + prefix[row][col + 1]
                + prefix[row + 1][col] - prefix[row][col])
    return prefix

def rect_sum(prefix, top, left, bottom, right):
    return (prefix[bottom][right] - prefix[top][right]
        - prefix[bottom][left] + prefix[top][left])

prefix = prefix_grid([[1, 2], [3, 4]])
assert rect_sum(prefix, 0, 0, 2, 2) == 10
assert rect_sum(prefix, 1, 0, 2, 2) == 7
```

建表 O(rows×cols)，合法坐标的一次查询 O(1)。本例 rect_sum 假设调用方已经验证半开坐标范围，不能直接将负下标当成非法输入处理。

## 标记与边界控制原地遍历

先记录修改依据，再进行覆盖，可以防止新写入的值污染后续判断；螺旋过程则靠边界记录剩余区域。

### 用行列标记延后原地修改

先只读扫描原矩阵，用行、列两个布尔数组记录哪些范围含 0；第二遍再把这些行列全部写成 0。若扫描时立刻整行置零，新写的 0 会被误当成原始依据，污染其他行列。

这属于原地改写结果，但标记仍需 O(m+n) 空间。若要求额外 O(1)，可复用首行首列作标记，同时单独保存首行、首列原本是否含 0，最后处理它们。

### 四条边界逐层收缩

用 left、right、top、bottom 表示尚未输出的闭矩形，依次遍历上边、右边、下边、左边，并收缩对应边界。每走完一边，下一边都要确认剩余范围仍非空。

单行或单列矩阵会在一轮中途耗尽，因此不能不加判断地继续走四边，否则重复输出。每个格子恰输出一次，时间 O(mn)，除结果外只需常数边界状态。

### 沿螺旋边界依次填值

在 n×n 矩阵中填入 1 到 n²，可复用四边界法，把“读取格子”换成“写入递增计数”。一边完成后立即收缩范围，避免重复写角点。

也可按圈使用左闭右开的四段，使每个角只归属一条边；两种遍历约定不能混用。奇数边长最终剩下中心点，需写入最后一个数；n=0 时按接口约定返回空矩阵。

## 由坐标和顺序排除候选

矩阵旋转由坐标变换描述，行列有序矩阵查询则依靠比较结果排除一整行或一整列。

### 用坐标变换完成旋转

n×n 方阵顺时针旋转 90 度时，原坐标 (r,c) 移到 (c,n−1−r)。一种容易实现的原地方法是先沿主对角线转置，再反转每一行，两次变换复合后正好得到该坐标关系。

也可沿四元位置环轮换，修改前保存临时值，避免覆盖尚未移动的格子。时间 O(n²)、额外空间 O(1)；非方阵旋转后行列数互换，不能直接套用相同方阵存储的原地步骤。

### 利用行列有序性排除整行或整列

矩阵每行从左到右递增、每列从上到下递增。从右上角开始查找：目标更大就向下，目标更小就向左。

## 从累计值计算切分代价

把矩形网格沿一条水平或垂直线切成两块非空矩形，比较两侧数值总和之差。设全矩阵和为 S，某个候选切法的一侧和为 part，则差为 |S−2×part|。

水平切分时逐行累加，枚举前 1 行到前 m−1 行；垂直切分时逐列累加，枚举前 1 列到前 n−1 列。每次只需与当前最小差比较，无需为每条切线重新扫描整块区域。预处理行列和共 O(mn)，之后枚举 O(m+n)。

二维前缀可以支持更一般的矩形查询，但只切一刀时行列累计值已经足够。1×1 网格不存在把两侧都留为非空的合法切法，应提前按接口约定处理。
