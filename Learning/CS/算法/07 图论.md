# 图论

先明确节点与边、方向、权重和连通关系。无权图的 BFS 按层扩展，第一次到达某节点时获得最少边数；有权最短路不能直接套用这个结论。

## 图的表示与搜索边界

从 A 经 B 到 C 与从 A 直接到 C，BFS 会先访问距离为 1 的节点。入队时标记已访问，保证同一节点不会因多个父节点重复进入队列。

```python
from collections import deque

def distance(graph, start, target):
    queue = deque([(start, 0)])
    seen = {start}
    while queue:
        node, steps = queue.popleft()
        if node == target:
            return steps
        for neighbor in graph.get(node, []):
            if neighbor not in seen:
                seen.add(neighbor)
                queue.append((neighbor, steps + 1))
    return None

graph = {"A": ["B", "C"], "B": ["C"], "C": []}
assert distance(graph, "A", "C") == 1
assert distance(graph, "C", "A") is None
assert distance(graph, "A", "A") == 0
```

邻接表搜索时间 O(V+E)。网格中的上下左右可视为隐式邻接表；课程依赖的有向环检测则需要区分当前路径与已经处理完成的节点。

## 连通块与边界可达性

网格只是图的一种表示。先确定相邻关系，再由整块扩张、边界反向搜索或已标记区域的组合回答不同问题。

### 通过连通扩张统计岛屿

把上下左右相邻的陆地视为一个连通块。扫描到尚未访问的陆地时，答案加一，再用 DFS 或 BFS 标记整个连通块；之后遇到这些格子便跳过，不会重复计数。

标记必须在继续扩展前完成，否则相邻陆地会互相递归。原地把陆地改成水会破坏输入，也可使用独立 visited；总时间 O(mn)，最坏搜索栈或队列空间 O(mn)。

### 在遍历中累计连通块面积

沿用岛屿搜索，每首次访问一格陆地便将当前面积加一，所有邻居处理完后得到整个连通块面积，再更新全局最大值。无陆地时结果为 0。

访问标记在一次搜索内防止重复计数，也在不同起点间防止重复搜索整块岛屿。递归深度可能与连通块面积同阶，较大网格可改用显式栈。

### 从边界排除非封闭陆地

如果一块陆地能通过上下左右连到边界，它就不是飞地。先从四条边界出发，把所有与边界连通的 `1` 全部标记掉，最后统计剩余的 `1`。

### 先保留与边界相通的区域

从四条边界出发，找到所有与边界连通的 `O`，临时标记为其他字符；最后把这些标记还原为 `O`，其余 `O` 改成 `X`。也就是沉没被围绕的区域，只保留连到边界的区域。

### 从目标边界反向搜索可达性

找出既能流向太平洋又能流向大西洋的网格单元。
不要从每个格子正向模拟水流，而是分别从两个海洋的边界反向搜索。正向水流只能从高处流向低处或等高处，所以反向搜索时只能从边界走向更高或等高的相邻格子。得到“能到达太平洋”和“能到达大西洋”两张可达表后取交集。时间复杂度为 `O(mn)`。

### 缓存连通块编号后合并候选

最多把一个 `0` 变成 `1`，求操作后最大岛屿面积。
先遍历所有现有岛屿，为每个岛屿赋予唯一编号并记录面积；再枚举每个 `0`，查看它四周相邻的岛屿编号，去重后把这些面积加上新填入的一个格子。取所有候选值的最大值，并单独处理原矩阵全是 `1` 的情况。核心是先把重复的连通区域信息缓存下来，避免每次翻转都重新 DFS。

### 按相邻边抵消计算周长

给定由 `0` 和 `1` 组成的网格，计算岛屿周长。
遍历每个陆地格子，检查它的四个方向：越过边界或遇到水，就贡献一条边；遇到相邻陆地则不贡献周长。把所有陆地格子的贡献相加即可，时间复杂度为 `O(mn)`，不需要额外构造图。

### 用连通关系统计省份

给定城市之间的连接矩阵，求直接或间接相连的省份数量。
每个尚未访问的城市都代表发现了一个新的连通分量，答案加一，然后用 DFS 或 BFS 把与它直接、间接相连的所有城市标记为已访问。继续扫描矩阵，直到所有城市都被归入某个分量。使用邻接矩阵时，时间复杂度为 `O(n²)`。

## 按距离或时间推进搜索层

无权边每经过一次增加相同成本，BFS 的层次就能表示最短距离；多个起点同时入队则表示同一时刻开始扩散。

### 以多源 BFS 模拟同一时刻的扩散

统计新鲜橘子数，把全部初始腐烂橘子同时入队，表示第 0 分钟的多个源。每轮固定队列长度，只让当前层感染四邻的新鲜橘子，感染时立刻改状态、减计数并入队；下一层在下一分钟扩散。

只要还有新鲜橘子且队列不空就继续。初始没有新鲜橘子时返回 0；队列耗尽仍有剩余则返回 −1，而不是已经处理的分钟数。每格最多入队一次，时间 O(mn)。

### 把单词变换建模为最短路径

把单词作为节点，一次仅替换一个字母作为无权边。从起始词 BFS，按位置尝试合法字符，只有在字典中且尚未访问的词才入队，并立即标记。相同长度与字符集是这个邻接规则的输入前提。

若返回序列中的单词数，起始词层数为 1；若返回转换次数，则起始距离为 0。目标不在允许字典内时无解，起始词与目标相等的边界需按接口定义单独处理。首次到达目标即可确定最短距离。

## 区分节点、路径和边的访问状态

检测有向环关注当前递归路径，枚举路径需要退出时恢复选择，用完所有边则要记录边的消耗。它们不能共用一个不加区分的 visited 规则。

### 用递归路径状态检测有向环

课程依赖 [a,b] 表示先完成 b 才能学习 a，构造 b→a 的有向边。对每个课程维护三种状态：未访问、正在当前递归路径中、已经完成。DFS 再次遇到“正在路径中”的节点，说明回到祖先，存在环。

进入节点时置为路径中，递归全部后继；全部成功退出后才置为完成。已完成节点可以直接复用结果，因为它的后继已验证无环。必须从所有尚未访问的节点启动，才能覆盖不连通部分；时间 O(V+E)。

### 在有向无环图中枚举路径

给定一个有向无环图，找出从节点 `0` 到节点 `n - 1` 的所有路径。
从 `0` 开始 DFS，当前路径记录已经经过的节点；枚举当前节点的每条出边，把目标节点加入路径后继续搜索，到达 `n - 1` 时复制当前路径作为一个答案，返回上一层时撤销选择。输入约定是 DAG，因此不需要为防环额外维护递归路径标记；如果图不保证无环，则必须补上访问状态。

### 按边回溯构造欧拉路径

机票是有向边，同一对机场间的多张机票仍是不同边，必须分别消费。假设存在从 JFK 使用全部机票的行程，按字典序取尚未使用的最小出边，沿途继续；无出边时将节点记录到后序结果，最后整体反转。

这是 Hierholzer 的后序拼接，能把暂时进入死路的分支接回正确位置。字典序由出边的排序保证，不能把首次走出的节点顺序直接当成答案。若输入不保证存在完整行程，还须检查可行性并验证输出逐边使用全部机票，不能仅凭后序序列长度判定成功。
