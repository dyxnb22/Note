# 动态规划

当问题包含重叠子问题时，先用一句话定义 dp[i] 的含义，再写依赖哪些更小状态。初始化与遍历方向是递推关系的一部分，不能仅凭代码模板选择。

## 状态、转移与计算顺序

零钱兑换中 dp[a] 表示凑出金额 a 的最少硬币数。最后一枚硬币为 c 时，候选是 dp[a-c]+1；dp[0]=0，无法到达的状态用无穷大表示。

```python
def min_coins(coins, amount):
    if amount < 0 or any(c <= 0 for c in coins):
        raise ValueError("positive coins and nonnegative amount required")
    dp = [float("inf")] * (amount + 1)
    dp[0] = 0
    for value in range(1, amount + 1):
        for coin in coins:
            if coin <= value:
                dp[value] = min(dp[value], dp[value - coin] + 1)
    return -1 if dp[amount] == float("inf") else dp[amount]

assert min_coins([1, 3, 4], 6) == 2
assert min_coins([2], 3) == -1
assert min_coins([2], 0) == 0
```

时间 O(amount×硬币种数)，空间 O(amount)。统计组合数量与最小硬币数是不同状态，转移中的加法和取最小值不能互换。

## 从线性依赖建立递推

状态只保存后续转移需要的信息。先从固定前驱关系入手，再考虑位置之间不能同时选择时要增加什么状态。

### 只保留转移需要的历史状态

每次可爬 1 或 2 阶，令 dp[i] 为到达第 i 阶的方法数。最后一步来自 i−1 或 i−2，两类方法互不重叠，因此 dp[i]=dp[i−1]+dp[i−2]。

以 dp[0]=1 表示不走任何一步的唯一方法，dp[1]=1；只求数量时保留前两项即可，时间 O(n)、额外空间 O(1)。计数随 n 增长很快，固定宽度整数要确认是否需要大整数或取模。

### 由上一行相邻项构造下一行

每个数是它左上方和右上方的数的和。
`row.add(c.get(i - 1).get(j - 1) + c.get(i - 1).get(j));`
边界：每行首尾恒为 1，所以整行可以先用 `[1] * (i + 1)` 撑起来，内层只算中间那段 `for j in range(1, i)`——两端不必判断。空行、`numRows == 1` 时内层循环天然为空。元素总数是 `1+2+...+n = O(n²)`，时间空间都是 `O(n²)`。

### 选择与跳过形成互斥状态

在线性房屋中选择互不相邻的位置，使收益最大。令 dp[i] 为前 i 个位置可获得的最大收益：跳过第 i 个得到 dp[i−1]，选择它则得到 dp[i−2]+nums[i−1]，取较大者。

初始 dp[0]=0，非负收益下 dp[1]=nums[0]。若允许负收益且允许一个都不选，dp[1] 应取 max(0,nums[0])；状态定义决定是否允许空选择。

### 环形依赖拆成两种线性范围

环形结构使首尾也相邻，因此任何合法选择都至少排除首、尾中的一个。分别求“排除最后一个”的范围 [0,n−1) 和“排除第一个”的范围 [1,n)，取两者最大值。

这两个范围可以重叠，求最优值不需要去重。空输入返回 0，只有一个位置时单独处理，不能把它拆成两个空范围。

### 对子树组合选择与不选状态

对每个节点返回两个状态 take、skip。选择当前节点时不能选择直接孩子，所以 take=node.val+left.skip+right.skip；不选当前节点时，每个孩子都可独立选择较优状态，所以 skip=max(left.take,left.skip)+max(right.take,right.skip)。

空节点返回 (0,0)，最后取根的两个状态最大值。后序遍历保证孩子已计算，总时间 O(n)，辅助空间为递归深度 O(h)。

## 容量、次数与遍历方向

背包状态表达已经使用或仍可达到的容量。物品能否重复使用、目标求最值还是求数量，会改变遍历顺序和转移含义。

### 枚举最后加入的平方数

令 dp[j] 表示组成非负整数 j 的最少平方数数量，dp[0]=0，其他状态初始化为不可达。枚举不超过 n 的正平方数 c=i²，按 j 从 c 到 n 正序更新 dp[j]=min(dp[j],dp[j−c]+1)。

正序使同一个平方数可以重复使用，这是完全背包。时间 O(n√n)，空间 O(n)；这里求最少数量，而非拆分方案数。

### 完全背包中的最少数量

前面的零钱示例用 dp[a] 表示组成金额 a 的最少硬币数。也可先枚举每种正面额 coin，再按金额从 coin 正序更新 dp[a]=min(dp[a],dp[a−coin]+1)，因为当前硬币允许重复使用。

dp[0]=0，其余使用不可达哨兵；最终仍不可达时返回 −1。硬币为 0 或负数会破坏这个依赖关系，应在输入阶段排除。

### 遍历顺序决定组合还是排列

统计不区分先后顺序的硬币组合时，令 dp[a] 为凑成金额 a 的方案数，dp[0]=1。外层枚举不同面额，内层金额正序，执行 dp[a]+=dp[a−coin]，每种组合只按固定面额顺序生成一次。

例如面额 1、2 凑 3，组合只有 1+1+1 与 1+2，共 2 种。若金额在外层、面额在内层，最后一枚硬币的不同选择还会区分 1+2 与 2+1，得到 3 种排列。面额需为正且先去重，否则会重复计数。

### 按前缀可达性切分单词

令 valid[i] 表示 s 的前 i 个字符能否由字典单词拼成，valid[0]=true。对每个终点 i，枚举切分点 j<i；只要 valid[j] 且 s[j:i] 在字典中，就令 valid[i]=true 并停止该轮搜索。

这里重用的是字典中的词，不是同一个字符串位置；每次转移都消费一个非空片段，因此不会产生无限递归。用集合查词，另需考虑切片复制和哈希的实际成本。

### 把等和划分转成目标容量

对非负整数数组，若总和 S 为奇数，不可能等分；否则目标是找一个和恰好为 S/2 的子集。布尔状态 reachable[0]=true，逐个处理元素 x，并把容量 j 从目标倒序到 x 更新为 reachable[j] 或 reachable[j−x]。

倒序使每个元素只使用一次。也可用“容量不超过 j 时能装入的最大总和”状态，最后检查 dp[target]==target；该状态初始为 0，不代表所有金额都恰好可达。

### 在直接拆分与继续拆分之间取最优

对 n>=2，dp[i] 表示 i 至少拆成两个正整数后的最大乘积。枚举第一部分 j∈[1,i−1]，剩余 i−j 可以保持完整，也可以继续拆，所以比较 j×(i−j) 与 j×dp[i−j]。

按 i 递增计算，dp[2]=1。无需同时把两部分写成 dp：枚举 j 时可以让它代表最终拆分中的某一完整部分，剩余部分的最优拆分已由更小状态覆盖。

### 用容量最接近总和一半的子集

把石头分为两堆，若一堆重量为 w，总和为 S，两堆差就是 |S−2w|。只需在不超过 floor(S/2) 的容量内选出尽可能重的子集。

令 dp[j] 为容量不超过 j 时能装入的最大重量，每块石头按容量倒序更新 dp[j]=max(dp[j],dp[j−x]+x)。最终差为 S−2×dp[floor(S/2)]；重量需非负，每块石头至多使用一次。

### 把正负号计数转换为子集计数

假设所有输入数非负。把带正号的部分之和记为 P，负号部分为 N，则 P−N=target、P+N=S，得到 P=(S+target)/2。只有 |target|<=S 且 S+target 为偶数时才可能有解。

转为 0-1 背包计数：dp[0]=1，每个 x 按容量倒序更新 dp[j]+=dp[j−x]，最后读取 dp[P]。输入中的 0 也要处理：+0 与 −0 是两种表达式，转移会把现有计数翻倍。

### 同时消耗两种容量

每个二进制字符串是一个物品，消耗 z 个 0、o 个 1，价值为选中一个字符串。令 dp[i][j] 表示最多使用 i 个 0、j 个 1 时可选的最多字符串数。

对每个字符串，把两种容量都倒序更新 dp[i][j]=max(dp[i][j],dp[i−z][j−o]+1)。倒序防止同一个字符串被重复选择；优化目标是字符串数量，不是其中的字符总数。

## 序列中的结尾状态与边界

把状态限定为“在当前位置结束”，能够保留连续性、递增性或正负乘积所需的信息。局部状态与全局答案需要分别更新。

### 递增子序列的结尾状态

令 dp[i] 为必须以 nums[i] 结尾的最长严格递增子序列长度，初始为 1。枚举所有 j<i，只有 nums[j]<nums[i] 时，才能用 dp[j]+1 更新当前状态。

答案是所有 dp[i] 的最大值，不一定在数组末尾。该方法允许跳过中间位置，时间 O(n²)，空间 O(n)；空数组的答案为 0。

### 连续性让状态只依赖前一位置

最长连续递增段不能跳过位置。令 dp[i] 为以当前位置结尾的连续严格递增长度：若 nums[i]>nums[i−1]，则 dp[i]=dp[i−1]+1，否则重新从 1 开始。

只保留当前段长和全局最大值即可，时间 O(n)、额外空间 O(1)。缺少比较条件而直接加一，会把下降位置也错误地连入同一段。

### 负数使最大值与最小值互相转换

最大乘积连续子数组需要同时保存以当前位置结尾的最大值 hi 和最小值 lo，因为负数会把二者角色翻转。读到 x 时，新的候选是 x、旧 hi×x、旧 lo×x，分别取最大与最小。

必须先保存旧 hi、lo，再同时计算新值，不能让第二个转移读到已经更新的第一个值。全局答案与首元素初始化，零会自然切断乘积；空输入是否允许需要由接口约定。

### 以当前位置结尾的有效括号长度

对只含括号的字符串，dp[i] 表示必须在 i 结束的最长有效括号长度。遇到左括号时保持 0；遇到右括号，跳过紧邻的完整有效段，令 pre=i−dp[i−1]−1。只有 pre>=0 且 s[pre] 为左括号时才能配对。

转移为 dp[i]=dp[i−1]+2+(pre>0 ? dp[pre−1] : 0)，把中间段、新配对和左侧相邻有效段接起来。循环从 i=1 开始，避免读取 dp[−1]；最终取全局最大值。

### 由两侧最高边界决定蓄水

对非负柱高，先计算每个位置左侧、右侧的最高柱。这里两侧不包含当前柱，当前位置水量为 max(0,min(leftMax[i],rightMax[i])−height[i])，外侧没有边界的位置不蓄水。

例如 [2,0,2] 的中间水量是 2，两端为 0。必须截掉负值；如果当前柱高于两侧较矮边界，结果是没有水，而不是负水量。两次预处理加一次累加，时间 O(n)、空间 O(n)。

## 交易过程是一组有限状态

持有、卖出、交易次数与冷冻期都限制下一步操作。先明确一天结束时的状态，再计算不同约束下的转移。

### 用有限买卖阶段表示两次交易

不考虑手续费与冷冻期，最多完成两次买卖，且不能同时持有多份股票。一天结束时，状态 0 表示尚未操作，1、2、3、4 依次表示第一次持有、第一次卖出后、第二次持有、第二次卖出后。每个转移只读昨日状态。

```java
    dp[i][1] = Math.max(dp[i - 1][1], -prices[i]);
    dp[i][2] = Math.max(dp[i - 1][2], dp[i - 1][1] + prices[i]);
    dp[i][3] = Math.max(dp[i - 1][3], dp[i - 1][2] - prices[i]);
    dp[i][4] = Math.max(dp[i - 1][4], dp[i - 1][3] + prices[i]);
```

可将所有持有状态初始化为第一天的 −price，其他状态初始化为 0，表示“最多”而非“恰好”使用这些交易阶段；这允许用零利润占位。空价格序列返回 0，最终读取所有不持有状态的最大收益。

### 推广到任意交易次数上限

用 2k+1 个阶段推广前面的状态：奇数阶段为持有，偶数阶段为卖出后。初始化时，奇数位置为第一天的 −price，偶数位置为 0。下面片段中的 j 为阶段号。

```java
        if (j % 2 == 1) {
            dp[j] = Math.max(dp[j], dp[j - 1] - prices[i]);
        } else {
            dp[j] = Math.max(dp[j], dp[j - 1] + prices[i]);
        }
```

若用同一个数组原地更新，可按 j 从 2k 倒序到 1，保证 dp[j−1] 仍是昨日值；也可显式使用前一天的副本。k=0 或价格序列为空时收益为 0。时间 O(nk)，空间 O(k)。

### 把冷冻期写进状态转移

卖出后的下一天不能买入，因此把不持有进一步分为：空闲、今天刚卖出、今天处于冷冻期；加上持有，共四种状态。持有可从昨日持有、昨日空闲或昨日冷冻期结束转来；今日刚卖出只来自昨日持有；今日冷冻只来自昨日刚卖出。

```java
    int tmp1 = dp[0];
    int tmp2 = dp[2];
    dp[0] = Math.max(dp[0], Math.max(dp[1] - prices[i], dp[3] - prices[i]));
    dp[1] = Math.max(dp[1], dp[3]);
    dp[2] = tmp1 + prices[i];
    dp[3] = tmp2;
```

初始持有为 −prices[0]，空闲为 0，刚卖出和冷冻可用不可达哨兵并在算术时保护，或按此“最多交易”模型用 0 作无收益占位。片段先保存旧持有与旧卖出状态，避免后续更新混入当日值；最终取三种不持有状态最大值。

### 在交易转移中计入手续费

只保留持有与不持有两个状态，买入时扣价格，卖出时增加价格并扣一次 fee。初始持有为 −prices[0]，不持有为 0；空输入提前返回 0。

```java
    int tmp1 = dp[0];
    dp[0] = Math.max(dp[0], dp[1] - prices[i]);
    dp[1] = Math.max(dp[1], tmp1 + prices[i] - fee);
```

tmp1 保存昨日持有值，使卖出转移不依赖当天刚买入的状态。也可选择在买入时扣手续费，但一次完整交易只能扣一次；最终答案是不持有状态。
