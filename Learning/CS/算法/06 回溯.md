# 回溯

回溯把所有候选组织为决策树。路径保存已作选择，候选集合决定下一步，终止条件决定何时记录结果；返回上层时必须恢复现场。

## 选择、递归与撤销

排列 [1,2] 的第一层可以选 1 或 2。选择一个下标后将其标记为已使用，递归完成后撤销标记，保证兄弟分支仍能使用这个元素。

```python
def permutations(values):
    result, path = [], []
    used = [False] * len(values)
    def visit():
        if len(path) == len(values):
            result.append(path.copy())
            return
        for index, value in enumerate(values):
            if used[index]:
                continue
            used[index] = True
            path.append(value)
            visit()
            path.pop()
            used[index] = False
    visit()
    return result

assert permutations([1, 2]) == [[1, 2], [2, 1]]
assert permutations([]) == [[]]
```

记录答案时复制当前路径，避免所有结果指向同一列表。本例将不同下标视为不同选择；输入包含重复值时，还需定义同层去重规则。

## 搜索路径如何产生组合与排列

递归层表示一次选择，路径表示当前部分结果。是否限制起始位置、是否允许再次选择同一元素，决定搜索树覆盖什么。

### 逐层选择尚未使用的元素

输入值互异时，路径长度表示已经确定的排列位置。每一层枚举尚未使用的下标，标记后追加、递归，再弹出路径并撤销标记。路径长度等于 n 时保存副本。

使用下标而非值记录选择，与前面的完整程序保持一致。生成 n! 个长度 n 的结果本身就需要 O(n×n!) 输出时间与空间，不能把搜索过程误称为多项式复杂度。

### 用同层去重消除重复排列

先排序，再用 used 标记当前路径已经使用的下标。当 i>0、nums[i]==nums[i−1] 且 used[i−1] 为 false 时，跳过 i：同一层已经可以由前一个相同值代表这条分支。

如果 used[i−1] 为 true，说明前一个相同值已在当前路径中，仍应允许继续选择 i，才能组成包含多个相同值的排列。排序前提与“同层”和“同路径”的区别缺一不可。

### 用选择范围枚举子集

互异数组的子集不关心选择顺序。每次进入递归都记录当前路径，包括最初的空集；之后只从 start 及其右侧选择元素，递归传 i+1。

下标严格递增，使 {a,b} 只生成一次，不会再生成 {b,a}。若输入值重复，需排序并补充同层去重，而不是把所有已见值全局禁用。

### 逐层展开每一位的候选字符

把数字 2 到 9 映射为 abc、def、ghi、jkl、mno、pqrs、tuv、wxyz。递归深度是已经处理的数字位数，每层只枚举当前位的候选字母，处理完所有位时记录一个字符串。

这里没有“元素是否用过”的限制，同一个字母可由不同数字位选择。空输入按接口约定返回空结果；出现 0、1 或其他字符应提前拒绝，而非悄悄丢弃该位。

### 允许重复选择时保留起始位置

候选数均为正且互异，寻找和为 target 的组合。选中下标 i 后仍传 i，使当前值可以再次使用；同时限制后续下标不小于 i，避免同一组合以不同顺序重复出现。

剩余和为 0 时记录，负数时停止。排序后还可以在候选大于剩余和时结束该层。严格为正的前提保证重复选择会逐步接近终止，含零或负数时不能照搬。

### 单次使用与同层去重共同限制分支

先排序。每次选中 i 后递归传 i+1，限制每个下标至多使用一次；同层若 i>start 且当前值等于前值则跳过，避免由相同数值开出重复组合。

与重复排列不同，这里不需要 used 数组，下标范围本身就表达了已消费部分。正候选数下可按剩余和剪枝，路径满足目标时复制保存。

### 同时约束数量与目标和

从数字 1 到 9 中选择恰好 k 个互异数字，使总和为 n。递归传下一起始数字、剩余数量和剩余和；只有剩余数量为 0 且剩余和为 0 时记录。

候选不足以凑满 k 个、剩余和为负，或最小可能和已经超出目标时都可剪枝。数量用满但和不对时必须退出，不能继续追加数字。

### 在保留顺序时做同层去重

枚举原数组中长度至少为 2 的非递减子序列。后续下标必须增大，候选值不能小于路径末值；输入不能排序，否则会改变原有相对次序。

每次递归新建一个集合，只记录这一层已经尝试过的候选值。它消除相同前缀下的重复分支，不阻止在更深一层再次选择相同值，因此 [7,7] 仍是合法子序列。

## 约束在搜索前缀中逐步生效

约束越早能够判断，越早可以剪掉不可能完成的分支。回溯退出时还要恢复路径和访问状态。

### 用前缀合法性限制括号分支

生成 n 对有效括号时，始终保持 0<=right<=left<=n。left<n 才可添加左括号，right<left 才可添加右括号，因此任意搜索前缀都不会出现右括号过多。

left==right==n 时复制路径作为答案。递归返回后撤销最后一个字符，或用长度 2n 的缓冲区直接覆盖 left+right 位置。n=0 时，若按组合定义处理，唯一结果是空串。

### 搜索路径退出时恢复访问状态

在字符网格中找相邻路径拼出目标词，邻接仅为上下左右，同一格在一条路径内不能重复使用。依次以每个匹配首字符的格子作为起点，递归深度表示已经匹配的词前缀长度。

访问时保存原字符并临时标记，探索后恢复，成功提前返回前也要恢复。标记不能与合法字符冲突，也可另用 visited；它限制的是当前路径，不能让一个失败起点永久禁用格子。

### 把回文判断作为分割条件

先预计算 pal[l][r]：首尾字符相同，且长度不超过 2 或内部 pal[l+1][r−1] 成立。按长度递增或左端递减计算，确保依赖已经存在。

从 start 枚举片段终点 end，只对回文片段 s[start:end+1] 继续递归到 end+1。只有 start==len(s)，整串才已切分完成并可记录；不能在刚到最后一个字符下标时提前结束。返回后移除刚加入的片段。

### 按列和对角线剪枝

逐行放置 n 个皇后，每行只选一列，所以同行冲突自然排除。另用集合记录已占列、row−col 对角线与 row+col 对角线，任一占用就跳过候选。

放置后登记三类约束，递归到下一行，返回时全部撤销。row==n 时保存棋盘副本，避免后续撤销改变已经记录的答案。

### 用分段范围限制搜索空间

把纯数字串切成恰好四段 IPv4 十进制地址，每段长度 1 到 3、数值 0 到 255，除单独的 0 外不允许前导零。递归携带起点和已生成段数，每次只尝试符合这些规则的片段。

只有段数为 4 且字符全部消费时记录。剩余 r 段至少需要 r 个、最多 3r 个字符，可据此提前剪枝；切满四段后即使还有字符也不能继续添加。

### 组合行、列和宫格约束

解数独与检验数独不同：先验证已有数字，再为每个空格尝试行、列和宫格都未使用的数字。选择后同时写入棋盘并登记三个约束，递归失败时全部撤销。

所有空格都填完才返回成功；一个格子没有合法候选时返回失败。可优先处理候选最少的空格缩小搜索树，但局部无冲突仍不保证后续有解。
