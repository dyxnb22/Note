# 二叉树

递归函数先约定它向父节点返回什么，再处理当前节点。树高只需一个返回值；直径、最大路径等还需要记录穿过当前节点的候选整体答案。

## 子树返回值与整体答案

树的直径按边数计算。某节点左右子树高度分别是 2 和 3，则穿过它的路径有 5 条边；向父节点返回的高度却只能是 1+max(2,3)，不能把整条分叉路径返回。

```python
class Node:
    def __init__(self, value, left=None, right=None):
        self.value, self.left, self.right = value, left, right

def diameter(root):
    best = 0
    def height(node):
        nonlocal best
        if node is None:
            return 0
        left, right = height(node.left), height(node.right)
        best = max(best, left + right)
        return 1 + max(left, right)
    height(root)
    return best

assert diameter(Node(1, Node(2), Node(3))) == 2
assert diameter(None) == 0
```

每个节点访问一次，时间 O(n)，调用栈 O(h)。遍历、聚合与回溯可以复用同一种递归结构，但返回值含义需要独立定义。

## 遍历顺序决定可以观察的信息

深度优先以递归或栈保存未完成的工作，广度优先则把同一层节点一起处理。节点进入结果的时机随目标改变。

### 中序遍历与显式栈

前序、中序、后序分别在处理左右子树之前、之间、之后访问当前节点。中序的迭代实现让指针不断沿左孩子下降并压栈；左侧为空后弹出一个节点并访问，再转向它的右孩子，继续重复。

栈保存的是尚未完成的祖先。循环条件为“当前节点非空或栈非空”，因此不会在一段左链结束时提前退出。时间 O(n)，辅助空间 O(h)。

### 按层组织队列

使用一个 `Queue` 存储待遍历的节点。每层开始先记 `size`，弹出 `size` 次，把节点值收集并把左右孩子入队。

### 从每一层提取最右节点

按左孩子、右孩子的顺序入队。每层开始固定当前队列长度，只处理这一批节点，最后弹出的节点就是这一层从右侧能看到的节点。后加入的孩子属于下一层，不能计入当前层次数。

将每层的最后一个值依次保存即可。空树返回空结果；节点总数为 n 时，时间 O(n)，队列空间取决于最大层宽。

### 用层序顺序确定最底层左端

找出二叉树最底层最左边的节点值。
用 DFS 记录当前深度和已经找到的最大深度，并优先访问左子树。只有遇到更深一层的叶子节点时才更新答案；由于同层始终先访问左边，第一次到达最深层的叶子就是最左边的节点。也可以用层序遍历，在每层开始时记录第一个节点。

### 进入与退出递归时维护路径

给定一棵二叉树，返回所有从根节点到叶子节点的路径。
深度优先遍历时携带当前路径。访问普通节点就把节点值加入路径，分别向左右子树继续；到达叶子节点时把当前路径记录为一个答案。递归返回后要撤销当前节点，避免左右分支共用同一份路径状态。空树直接返回空结果。

## 递归返回什么，父节点才能继续

每个调用只把父节点真正需要的信息向上返回；整棵树的答案可能还需要单独汇总。高度、直径和最大路径正好展示这两个角色。

### 由子树高度计算当前高度

约定空子树高度为 0，叶子高度为 1。当前节点高度就是 1+max(左子树高度,右子树高度)，因为向父节点延伸的路径只能选择一侧。

若题目把高度定义为边数，需要统一改成空树 −1、叶子 0。定义不同会改变初值，不能只在最终结果上随意加减。

### 交换左右子树

空节点直接返回。对当前节点交换左右孩子，再分别翻转交换后的两棵子树，就得到整棵树的镜像。也可以先处理孩子再交换，但同一节点只能交换一次。

算法原地改写节点连接，时间 O(n)，递归栈 O(h)。若调用方还需要原树，必须先复制，而不能把原地翻转当成只读查询。

### 比较镜像位置的节点

轴对称比较的是一对镜像位置 a、b。两者都为空则成立，只有一个为空则失败；其余情况必须值相等，并同时满足 mirror(a.left,b.right) 与 mirror(a.right,b.left)。

从根的左右孩子开始比较。只分别检查左右子树自身是否对称，或者把两个左孩子互相比，都不能证明整棵树轴对称。

### 区分向上返回的高度和全局直径

前面的完整示例在每个节点用 leftHeight+rightHeight 更新直径，再返回 1+max(leftHeight,rightHeight)。前者允许经过左右两侧，后者只保留可接给父节点的一条链。

按边数定义时，空树和单节点树的直径均为 0；最长路径也可能完全位于某棵子树中，所以全局答案要在每个节点更新，不能只计算根节点。

### 从两侧结果汇合公共祖先

假设 p、q 都在树中，并按节点身份识别目标。当前节点为空时返回空；等于 p 或 q 时返回当前节点。其余节点递归搜索两侧：两边都返回非空，当前节点就是最近公共祖先；只有一边非空，就把那一边的结果向上返回。

这样也覆盖一个目标本来就是另一个目标祖先的情况。如果输入不保证两个目标存在，还要另外记录是否找齐，否则只找到一个目标也会被误当成完整答案。

### 区分可向上连接的路径与完整路径

最大路径和允许从任意节点开始和结束，但路径不能分叉。左右孩子分别返回能向上连接的最大单链贡献，并把负贡献截为 0；当前完整候选为 left+right+node.val，向父节点只能返回 max(left,right)+node.val 的非负部分。

~~~java
ans = Math.max(ans, lVal + rVal + node.val); // 两条链拼成路径，尝试以当前节点为最高顶点（拐点），连接左右子树
return Math.max(Math.max(lVal, rVal) + node.val, 0); // 当前子树最大链和（注意这里和 0 取最大值了）
~~~

即使所有节点均为负数，仍必须选至少一个节点。全局 ans 应初始化为负无穷或某个实际节点值，不能初始化为 0；零只用于表示“不选择这条子链”。以下讨论默认输入非空。

### 统计路径上的前缀状态

统计从祖先到后代、节点和为 target 的路径。用当前根到节点的前缀和 s，查历史路径上 s−target 出现的次数；初始 cnt[0]=1，才能计入从根开始的路径。

每次先查询，再把 s 登记进表，递归左右孩子，返回时把 cnt[s] 减一。撤销使表只代表当前祖先链，避免把两个不同分支拼成一条并不存在的向下路径。

## 从序列或局部结构重建树

构造与改写都需要在修改前保存后续子问题的边界。根的位置确定后，剩下的序列或节点才有明确归属。

### 从有序区间构建搜索树

对严格递增数组的闭区间 [start,end]，选择中点为根，左右区间分别构造左右子树；start>end 时返回空。中点划分使两侧规模接近，得到高度 O(log n) 的搜索树，总构造时间 O(n)。

递归时只传索引范围，不必反复复制数组。若输入允许重复值，还需先规定重复节点放在哪一侧；普通中点切分不一定满足这种额外规则。

### 前序确定根，中序划分子树

假设节点值互异，且两份遍历来自同一棵树。`preorder` 确定根节点，`inorder` 划分左右子树，`locationMap` 记录值到中序位置的映射。若值可重复，仅凭这两份值序列不一定能唯一重建，需要额外身份或约束。

前序数组第一个元素是当前根节点。用这个根节点去中序数组中找到分割点，分割点左边是左子树，右边是右子树。根据左子树长度，把前序数组也切成左子树区间和右子树区间，然后递归构造。

### 后序确定根，中序划分子树

同样要求节点值互异、两份遍历对应同一棵树。中序确定左右区间，后序末元素确定当前根；索引范围为空时返回空节点。

用 `locationMap` 记录每个节点值在中序数组中的位置。因为后序遍历的最后一个节点是当前子树的根节点，所以每次从 `postorder[postEnd]` 找到根节点，再通过 `locationMap` 找到它在中序数组中的位置。这个位置就是切割点：左边是左子树，右边是右子树。然后根据左子树长度去切分后序数组，递归构造左右子树。

### 由区间最大值递归建树

给定一个没有重复元素的数组，取当前区间最大值作为根节点，再递归构造最大值左边和右边的子数组。
递归函数需要明确当前处理的数组区间。先在线性扫描中找到区间最大值及其位置，最大值左侧构成左子树，右侧构成右子树；区间为空时返回空节点。直接扫描每个区间的最坏时间复杂度为 `O(n²)`，递归栈空间为 `O(n)`。

### 原地展开前保留后续节点

将树原地展开为单链表：`right` 子指针指向下一个结点，`left` 始终为 `null`，顺序与二叉树先序遍历相同。如果当前节点有左子树，就把左子树整体搬到右边；然后把原来的右子树接到左子树最右节点后面。迭代进行这一操作。

## 搜索树的顺序约束贯穿读写

搜索树把大小关系保存在整个子树范围中。查询、插入、删除与裁剪都必须保留这个关系，中序遍历则把它转为有序序列。

### 把祖先约束传给子树

验证严格搜索树时，当前节点不仅要大于左孩子、小于右孩子，还必须落在所有祖先传下来的开区间 (low,high) 内。左递归收紧上界为当前值，右递归收紧下界为当前值；任意越界就失败。

等价做法是中序遍历，要求整个访问序列严格递增。用可为空的前一节点或更宽类型保存上一个值，避免把最小 int 当成未初始化标记。后面的众数示例允许重复，采用非递减序列约定，不能直接套用这里的严格比较。

### 借助中序顺序定位第 k 小值

用stack模拟中序遍历（从根节点开始，一直往左走，把路径上的节点全部压入栈。然后每次弹出栈顶节点，表示访问到当前最小的未访问节点，`k--`。如果弹出的节点有右子树，就进入它的右子树，并继续把这个右子树一路向左的节点全部压入栈。重复这个过程，直到 `k == 0`，此时弹出的节点就是第 `k` 小的节点）

### 用有序邻居计算最小差值

求二叉搜索树中任意两个不同节点值的最小差值。
BST 的中序遍历结果是非递减序列，最小差值一定出现在相邻访问节点之间。因此中序遍历时只需记录前一个节点，与当前节点相减并持续更新最小值，不需要比较所有节点对。时间复杂度为 `O(n)`，额外空间为递归栈的 `O(h)`。输入至少有两个节点；固定宽度整数应使用更宽类型相减，避免极端值差溢出。

### 中序遍历累计相同值

找出含重复值的 BST 中出现频率最高的所有节点值。
利用 BST 中序遍历得到有序序列，相同值会连续出现。遍历时维护当前值的连续出现次数和历史最大次数：出现更大次数就清空答案并重新记录，次数相等就追加当前值，遇到新值则重置当前计数。这样无需额外排序，时间复杂度为 `O(n)`。

### 沿搜索路径插入节点

将一个值插入 BST，并保持二叉搜索树性质。
从根节点开始比较：目标值更小就进入左子树，更大就进入右子树；走到空位置时创建新节点并接回父节点。递归返回值表示修改后的子树根节点，不能只在局部移动指针而丢失连接。时间复杂度为 `O(h)`。若使用严格搜索树，遇到相等值应按接口约定忽略或更新已有记录；允许重复时必须另定一致的放置规则。

### 删除节点时维持搜索顺序

在 BST 中删除指定值的节点并返回新的根节点。
先利用 BST 的大小关系定位目标。找到后分三种情况处理：没有左子树时由右子树顶上，没有右子树时由左子树顶上；左右子树都存在时，可找到右子树最小节点，把原左子树接到它的空左指针，再返回原右子树的根。这种接法无需把最小节点从原位置拆出；另一种做法是复制后继值，再从右子树删除后继，两种步骤不能混合。每次递归都要把修改后的子树重新接回父节点。

### 依据值域裁剪搜索树

将 BST 修剪到 `[low, high]` 范围内，同时保持保留节点的相对结构。
利用 BST 的整体性质剪枝：当前节点小于 `low` 时，当前节点及其左子树全部不可能保留，只需继续处理右子树；当前节点大于 `high` 时对称地转向左子树；当前节点合法时，递归修剪左右子树并保留当前节点。注意修剪后根节点可能发生变化。

### 反向中序累计较大值

先假设节点值互异，将每个节点改成原树中大于或等于它的所有节点值之和。若允许重复值，应先按同值分组汇总，再同时写回，否则同值节点会得到不同结果。
BST 的反向中序遍历顺序是从大到小。沿右子树、当前节点、左子树访问，并维护已经访问过的节点总和；访问当前节点时先把累计和加到它身上，再用更新后的值作为新的累计和。这样每个节点只处理一次，时间复杂度为 `O(n)`。
