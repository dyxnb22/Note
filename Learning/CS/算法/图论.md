## LeetCode **208. 实现 Trie (前缀树)**
[**Trie**](https://baike.baidu.com/item/%E5%AD%97%E5%85%B8%E6%A0%91/9825209?fr=aladdin)（发音类似 "try"）或者说 **前缀树** 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。
请你实现 Trie 类：
- `Trie()` 初始化前缀树对象。
- `void insert(String word)` 向前缀树中插入字符串 `word` 。
- `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`（即，在检索之前已经插入）；否则，返回 `false` 。
- `boolean startsWith(String prefix)` 如果之前已经插入的字符串 `word` 的前缀之一为 `prefix` ，返回 `true` ；否则，返回 `false` 。
- **`trie[N][26]`**：这是整棵树的实体。
	- 第一维 `N` 代表**节点的编号**（你可以理解为树上的每一个点都有一个唯一的 ID）。
	- 第二维 `26` 代表**26个字母**。
	- `trie[p][u] = v` 表示：从节点 `p` 沿着字母 `u` 这条路，走到了节点 `v`。
- **`count[N]`**：用来记录单词的结尾。
	- `count[p] > 0` 表示有一个单词在编号为 `p` 的节点结束了。
- **`index`**：全局计数器，每当需要创建一个新节点时，`index++` 给新节点分配一个编号。
- `trie` 数组存的是“下一步去哪”。
- `count` 数组存的是“这里是不是终点”。
- `index` 负责给每个新发现的字符组合分配坑位。
### **查找 (search)**
当你查找一个字符串是否存在时：
1. 沿着字符路径一直往下走。
2. 如果在中途发现 `trie[p][u] == 0`，说明这条路根本没修过，直接返回 `false`。
3. 如果顺利走完了所有字符，最后检查 `count[p]`。只有 `count[p] > 0` 才说明这里登记过一个完整的单词。
### **前缀查找 (startsWith)**
逻辑和 `search` 几乎一样：
1. 同样沿着字符路径走。
2. 只要这条路能走通（没遇到 `0`），就返回 `true`。
3. 它**不关心**最后停留的那个点是不是一个单词的结尾。
```java
class Trie {
int N = 100009; // 直接设置为十万级
int[][] trie;
int[] count;
int index;

public Trie() {
    trie = new int[N][26];
    count = new int[N];
    index = 0;
}

public void insert(String s) {
    int p = 0;
    for (int i = 0; i < s.length(); i++) {
        int u = s.charAt(i) - 'a';
        if (trie[p][u] == 0) trie[p][u] = ++index;
        p = trie[p][u];
    }
    count[p]++;
}

public boolean search(String s) {
    int p = 0;
    for (int i = 0; i < s.length(); i++) {
        int u = s.charAt(i) - 'a';
        if (trie[p][u] == 0) return false;
        p = trie[p][u];
    }
    return count[p] != 0;
}

public boolean startsWith(String s) {
    int p = 0;
    for (int i = 0; i < s.length(); i++) {
        int u = s.charAt(i) - 'a';
        if (trie[p][u] == 0) return false;
        p = trie[p][u];
    }
    return true;
}
}
```

**LeetCode 332. 重新安排行程** 给定从 `JFK` 出发的机票列表，所有机票必须且只能使用一次；存在多条路线时，返回字典序最小的行程。
把机场看作节点、机票看作有向边。这是一个需要用完所有边的欧拉路径问题：从当前机场出发时，优先选择字典序最小且尚未使用的航班；如果已经没有出边，不要立刻把机场追加到结果尾部，而是在回溯时把它插到结果头部。这样相当于后序遍历，能把走入死胡同的节点放到正确位置，同时处理重复航班和中途回到已有机场的情况。

**LeetCode 797. 所有可能的路径** 给定一个有向无环图，找出从节点 `0` 到节点 `n - 1` 的所有路径。
从 `0` 开始 DFS，当前路径记录已经经过的节点；枚举当前节点的每条出边，把目标节点加入路径后继续搜索，到达 `n - 1` 时复制当前路径作为一个答案，返回上一层时撤销选择。题目保证是 DAG，因此不需要为防环额外维护递归路径标记；如果图不保证无环，则必须补上访问状态。

**LeetCode 417. 太平洋大西洋水流问题** 找出既能流向太平洋又能流向大西洋的网格单元。
不要从每个格子正向模拟水流，而是分别从两个海洋的边界反向搜索。正向水流只能从高处流向低处或等高处，所以反向搜索时只能从边界走向更高或等高的相邻格子。得到“能到达太平洋”和“能到达大西洋”两张可达表后取交集。时间复杂度为 `O(mn)`。

**LeetCode 827. 最大人工岛** 最多把一个 `0` 变成 `1`，求操作后最大岛屿面积。
先遍历所有现有岛屿，为每个岛屿赋予唯一编号并记录面积；再枚举每个 `0`，查看它四周相邻的岛屿编号，去重后把这些面积加上新填入的一个格子。取所有候选值的最大值，并单独处理原矩阵全是 `1` 的情况。核心是先把重复的连通区域信息缓存下来，避免每次翻转都重新 DFS。

**LeetCode 463. 岛屿的周长** 给定由 `0` 和 `1` 组成的网格，计算岛屿周长。
遍历每个陆地格子，检查它的四个方向：越过边界或遇到水，就贡献一条边；遇到相邻陆地则不贡献周长。把所有陆地格子的贡献相加即可，时间复杂度为 `O(mn)`，不需要额外构造图。

**LeetCode 127. 单词接龙** 给定起始单词、目标单词和字典，每次只能修改一个字母，求到达目标的最短转换序列长度。
把单词看作隐式图中的节点，两个单词只差一个字符时相邻。用 BFS 按层扩散：从当前单词逐个位置尝试替换成其他字母，把字典中存在且未访问过的新单词加入下一层，并在入队时标记访问，避免同一个单词重复进入队列。第一次到达目标时的层数就是最短长度；目标不在字典中时直接无解。

**LeetCode 547. 省份数量** 给定城市之间的连接矩阵，求直接或间接相连的省份数量。
每个尚未访问的城市都代表发现了一个新的连通分量，答案加一，然后用 DFS 或 BFS 把与它直接、间接相连的所有城市标记为已访问。继续扫描矩阵，直到所有城市都被归入某个分量。使用邻接矩阵时，时间复杂度为 `O(n²)`。
