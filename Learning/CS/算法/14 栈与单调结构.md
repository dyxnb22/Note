# 栈与单调结构

普通栈保存尚未结束的上下文，单调栈保存尚未找到答案的元素。新元素一旦满足某些旧元素的条件，就将它们弹出并记录答案。

## 后进先出与待解决状态

寻找右侧第一个更大元素时，栈中保存下标，值保持非递增。读到更大值，就为比它小的栈顶下标记录当前下标；相等值不满足“严格更大”。

```python
def next_greater_index(values):
    answer = [-1] * len(values)
    stack = []
    for index, value in enumerate(values):
        while stack and values[stack[-1]] < value:
            answer[stack.pop()] = index
        stack.append(index)
    return answer

assert next_greater_index([2, 1, 3]) == [2, 2, -1]
assert next_greater_index([2, 2]) == [-1, -1]
assert next_greater_index([]) == []
```

每个下标至多入栈和出栈各一次，总时间 O(n)，额外空间 O(n)。保存下标可以同时计算距离，保存值则可能丢失位置。

## 保存尚未结束的上下文

栈把最后开始、最先结束的关系直接存起来。括号、嵌套表达式和路径返回都可以沿同一顺序恢复。

### 用栈保存尚未配对的括号

遇到左括号就入栈；遇到右括号，栈必须非空且顶部是它对应的左括号，随后弹出。任一步不匹配就失败，扫描结束还必须检查栈为空。

栈顶代表最近一个尚未闭合的上下文，所以能拒绝 ([)] 这类数量相同但嵌套顺序错误的输入。这里假设输入只含约定的括号字符。

### 把嵌套上下文压入栈

解码 k[内容] 时，保存当前层结果 res 与正在读取的多位次数 k。遇到数字执行 k=10k+digit；遇到左方括号，把外层 res 与 k 压栈，并清空当前层状态。

遇到右方括号，弹出外层结果与次数，把当前 res 重复相应次数并接回外层。每层括号必须配对，示例算法假定编码合法；复杂度至少与实际展开长度有关，不能只按压缩输入长度估计。

### 按路径段解释返回上级目录

栈里存"当前已规范化路径的目录序列"，按 `/` 切完逐段处理：`""`（连续/首尾斜杠产生）和 `.` 跳过，`..` 弹出上一级，其余入栈。最后 `"/" + "/".join(stack)`。`O(n)`。
边界：`..` 到顶时栈已空，`if stack:` 决定弹不弹——根目录再往上还在根目录，不能弹成负数；栈空时靠前面的 `"/" +` 兜底得 `"/"`，不要漏掉这个前缀。`split("/")` 必须处理空串，无参 `split()` 才会吞掉它们。

### 同步维护当前最小值

普通栈保存全部值，辅助最小栈只在新值小于或等于当前最小值时同步压入。弹出普通栈时，若该值等于最小栈顶，也弹出一项；其他历史最小值不能提前移除。

等于时也要压入，才能处理重复最小值。例如依次压入 2、1、1，再弹出一个 1，当前最小值仍是 1。各操作常数时间，辅助空间最坏 O(n)；空栈查询或弹出须按接口报错。

## 单调结构保存仍可能有用的候选

新元素出现时，一部分旧候选将永远失去价值；把它们弹出时，也就确定了相应边界或答案。

### 用单调栈等待更高温度

给定一个整数数组，表示每天的温度，返回一个数组 answer ，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。
栈里存还没有找到更高温度的下标，并让对应温度保持单调不升。 遇到更高温度时，不断弹出比它低的下标，并用当前下标减去弹出下标。

### 在单调栈弹出时确定下一个更大值

若 nums2 的值互异，扫描它并用单调不升的下标栈，遇到更大值时为被弹出的元素登记“值→右侧首个更大值”。最后按 nums1 的值查询，缺失时输出 −1，前提是 nums1 来自 nums2。

若 nums2 允许重复值，相同值在不同位置可能有不同答案，不能继续用值作为唯一键；应保留下标或明确查询哪次出现。

### 用循环扫描复用单调栈

循环数组扫描至多 2n 个位置，实际值由 nums[i%n] 读取。栈中仍只保存原数组下标，第二遍仅用来为第一遍留下的候选触发弹栈，不再重复压入。

只有严格更大的值才能解决候选，相等不算；两遍后仍在栈中的位置没有更大值，保持 −1。空数组提前返回，避免对 0 取模；累计操作仍是 O(n)。

### 在更矮柱出现时结算矩形

对非负柱高，按下标维护高度不降的候选栈。读到更矮柱时，持续弹出比它高的柱子：当前下标 i 确定右边界，弹出后的栈顶 l 确定仍可扩张的左侧界，矩形面积为 height×(i−l−1)，空栈时 l=−1。

末尾补一个虚拟高度 0，结算仍未遇到更矮柱的正高度候选。保留等高柱时，较左的等高候选会在后续结算出更宽范围，不影响最大值。每个下标只进出一次，总时间 O(n)、空间 O(n)。

另一种写法先分别求左右首个严格更矮位置 left[i]、right[i]，面积为 heights[i]×(right[i]−left[i]−1)。计算边界时可用单调栈，也可沿已求出的 left 指针跳跃；两种边界约定需要各自保持一致。

## 组合容器改变访问顺序

两个栈或重排后的队列可以实现另一种读取次序，代价需要按整段操作序列计算。

### 用两次栈转移改变读取顺序

入队栈接收新值，出队栈提供队首。只有出队栈为空时，才把入队栈全部倒入，使最早加入的值来到顶部；出队栈不空时不能再次混入新值。

单次转移可能 O(n)，但每个元素只从入队栈转移一次，整段操作序列的入队、出队、查看均摊 O(1)。队列为空时的行为应与普通队列接口一致。

### 通过队列重排暴露最后加入的元素

仅用队列入尾、出头操作模拟栈时，push 先把新值放到队尾，再将原有 n 个元素逐个出队并重新入队。新值就移动到队首，成为下次 pop 的目标。

因此 push 是 O(n)，pop 与 top 是 O(1)。不能直接调用双端队列的插头操作来宣称只使用了普通队列接口；实现方式决定成本落在哪个操作上。
