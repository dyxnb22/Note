**LeetCode 57. 插入区间**
输入已按左端点排序且互不重叠，三段式一次扫描，`i` 从头走到尾不回退。`O(n)`，不排序（排序就退化成 56 的 `O(n log n)`）。
1. 跳过完全不重叠的前段：`intervals[i][1] < newInterval[0]`，直接进 `result`。
2. 合并所有相交的中段：`intervals[i][0] <= newInterval[1]` 时用 `min/max` 就地扩张 `newInterval` 两端。此时 `newInterval` 就是当前合并中的那个区间，所以可以原地改。
3. 剩下的后段原样进 `result`，最后把 `newInterval` 插在中间。
边界：相接算不算重叠由 `<` 与 `<=` 决定——端点相接（`[1,2]` 并 `[2,3]`，前段条件 `2 < 2` 为假）落进第 2 段被合并；中间有空隙（`[1,2]` 并 `[3,4]`，`2 < 3` 为真）才留在第 1 段不合并。`intervals` 为空、新区间全在两侧、全部相交，都要单独过一遍。

**LeetCode 6. Z 字形变换**
按行模拟，不真的建矩阵。`row` 在 `[0, numRows-1]` 之间折返，走到端点翻转方向：`row == 0 → direction = 1`，`row == numRows-1 → direction = -1`，再 `row += direction`。`rows = [""] * numRows` 每行攒一个字符串，最后 `"".join(rows)`。`O(n)`。
边界：`numRows == 1` 或 `numRows >= len(s)` 时不变形，直接返回原串（不加这个判断会在 `numRows == 1` 时方向永不翻转，`row` 每轮 +1，第二次迭代 `rows[row]` 就 IndexError）。
