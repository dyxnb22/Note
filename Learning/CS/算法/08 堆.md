# 堆

堆只保证父子之间的局部顺序，因此能快速访问最小或最大元素，不保证数组整体有序。Top K 用较小的结构维护当前候选，避免保存所有元素的顺序。

## 局部极值与整体顺序

维护最大的 K 个值时使用小顶堆，堆顶是当前候选中最小的一个。新值不大于堆顶就不能进入候选；更大时替换堆顶。

```python
import heapq

def largest_k(values, k):
    if k < 0:
        raise ValueError("k must be nonnegative")
    if k == 0:
        return []
    heap = []
    for value in values:
        if len(heap) < k:
            heapq.heappush(heap, value)
        elif value > heap[0]:
            heapq.heapreplace(heap, value)
    return sorted(heap, reverse=True)

assert largest_k([3, 1, 5, 4, 2], 2) == [5, 4]
assert largest_k([1], 0) == []
```

维护阶段 O(n log k)，最后为输出顺序排序 O(k log k)。若输入不足 K 个，本例返回所有已见元素。Java 比较器用 compare 避免相减溢出。

当 k 远小于 n，有界堆能减少维持整体顺序的成本；当 k 接近 n，两者可能同阶，实际常数也不同。堆适合持续接收数据并反复查询当前边界的场景。

## 有界候选集合与分界

堆只保证最重要的边界元素位于顶部。限制候选数可以求 Top K，维护两侧边界则可以追踪持续到来的数据中位数。

### 用有界堆维护第 k 大候选

与前面返回完整 Top K 列表不同，第 k 大只读取大小为 k 的小顶堆堆顶。先填满候选，再对新元素判断：大于堆顶才替换；不大于堆顶就不影响第 k 大的值。相同数值按出现次数分别占位置。

这里要求 1<=k<=n，输入不足 k 个时不能沿用“返回所有已见值”的列表接口。维护时间 O(n log(k+1))、空间 O(k)；Java 比较器用 Integer.compare，避免相减溢出。

### 先统计频次，再维护前 k 个候选

先用哈希表统计每个不同值的频次，再用至多 k 个元素的小顶堆，按频率保留最高的候选。若不同值数量为 u，期望时间 O(n+u log(k+1))，哈希表占 O(u) 空间。

频次相同时，任取还是按数值排序应由输出约定决定，必要时把次关键字放进比较器。也可按频次 1 到 n 分桶，以 O(n+u) 的扫描换取 O(n+u) 空间；两种方法并非所有输入下都由同一种更快。

### 用两个堆维护中位数分界

left 用大顶堆保存较小一半，right 用小顶堆保存较大一半。始终维持所有 left 值不大于所有 right 值，且 left 的大小等于 right 或恰好多一个。这样奇数个元素取 left 堆顶，偶数个取两个堆顶均值。

一种插入方式是：两堆等大时先插 right，再把其最小值转到 left；left 多一个时先插 left，再把其最大值转到 right。也可以先按堆顶分区插入，再平衡大小，只要最终同时满足两个不变量。

插入 O(log n)、查询 O(1)，空流的中位数应显式拒绝。固定宽度整数求均值时先提升类型。滑动窗口中位数还需要删除过期值，通常增加延迟删除等状态，不能只复用插入操作。
