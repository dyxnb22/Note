# 字符串

字符串处理先明确按字节、码点还是字素工作。精确模式匹配可以利用已匹配的信息，在失配时跳转到仍可能匹配的前缀，避免从头比较。

## 匹配位置与可复用前后缀

前缀函数 pi[i] 保存到 i 为止的最长相等真前缀与后缀长度。在 ababaca 中读到 c 发生失配时，沿已有前缀长度回退，而不重新扫描已经处理的文本。

```python
def prefix_function(text):
    pi = [0] * len(text)
    for index in range(1, len(text)):
        length = pi[index - 1]
        while length and text[index] != text[length]:
            length = pi[length - 1]
        if text[index] == text[length]:
            length += 1
        pi[index] = length
    return pi

assert prefix_function("ababaca") == [0, 0, 1, 2, 3, 0, 1]
assert prefix_function("") == []
```

索引向前走 O(n) 次，回退总量同样受前进次数约束，因此总体 O(n)。这里按 Python 字符串元素处理，未执行 Unicode 规范化。

## 公共前缀、失配跳转与周期

字符串已经匹配的部分包含可复用结构。逐步缩短候选前缀、使用 KMP 跳转和识别周期，都在利用这些结构减少重复比较。

### 逐步缩短公共前缀

先以第一个字符串为候选前缀，逐个检查后续字符串是否以它开头；不匹配就从末尾缩短，直到匹配或为空。输入列表为空时返回空串，任何一个字符串为空也会把公共前缀缩到空。

另一个实现是逐列比较所有字符串，首个不一致的位置就是边界，避免反复创建缩短后的字符串。复杂度要计入实际比较与切片成本，不能仅按外层循环次数估计。

### 用前缀信息在失配时跳转

KMP 字符串匹配算法
`next[i]` 的含义：`s[0..i]` 中最长的"相等真前缀=真后缀"的结束下标（-1 表示没有）。失配时 `j = next[j]` 不回退主串指针，只回退模式串——已匹配部分的前后缀信息保证跳过的对齐位置不可能成功。暴力 `O(nm)`，KMP `O(n+m)`。
这里 next 保存结束下标，等于开头长度版 pi[i]−1。构建时比较 s[i] 与 s[j+1]，失配沿 next[j] 回退，不能把长度版与下标版的初值、比较位置混用。下面两个方法放在同一个 Java 类中使用，空模式在匹配入口直接返回 0。

```java
public int strStr(String haystack, String needle) {
if (needle == null || needle.length() == 0) {
    return 0;
}
int len = needle.length();
int[] next = new int[len];
getNext(next, needle);
int j = -1;
for (int i = 0; i < haystack.length(); i++) {
    while (j >= 0 && haystack.charAt(i) != needle.charAt(j + 1)) {
        j = next[j];
    }
    if (haystack.charAt(i) == needle.charAt(j + 1)) {
        j++;
    }
    if (j == len - 1) {
        return i - len + 1;
    }
}
return -1;
}

// 构建前缀表
public void getNext(int[] next, String s) {
int j = -1;
next[0] = j;
for (int i = 1; i < s.length(); i++) {
    while (j >= 0 && s.charAt(i) != s.charAt(j + 1)) {
        j = next[j]; // 有没有更短一点的相等前后缀
    }
    if (s.charAt(i) == s.charAt(j + 1)) {
        j++;
    }
    next[i] = j;
}
}
```

### 用周期结构判断重复子串

对非空串 s，把它拼接两次，移除最前和最后字符后再查找 s。若仍找到，表示它能在一个严格位于两端之间的偏移处与自身重合，因而可以由更短子串重复构成。移除两端是为了排除直接落在原串起点的平凡匹配。

用前缀函数也能判断：令 n=len(s)、border=pi[n−1]、p=n−border，必须同时满足 p<n 且 n%p==0。下标版对应 border=next[n−1]+1。缺少 p<n 时，abc 会因 3%3==0 被误判；abab 的 border=2、p=2，才有真正的重复周期。

## 把公共前缀存进数据结构

多个字符串共享前缀时，可以把相同路径只保存一次。完整词查询与前缀查询的区别在于是否要求到达词尾。

### 用共享前缀路径组织字符串

Trie 把公共前缀保存为共享路径。插入 app 与 apple 后，两词共享 a→p→p，但必须分别在第三个节点和第五个节点登记词尾；否则只能知道路径存在，无法区分完整单词与前缀。

下面的数组实现以 0 为根节点，trie[p][u] 保存字符边指向的节点编号，0 也表示该边不存在；新节点从编号 1 分配。count[p] 记录以该节点结尾的插入次数，index 记录已分配到的最大编号。

完整词 search 需要走完整条路径且 count[p]>0；startsWith 只要求路径走通。因此仅插入 apple 时，app 是前缀，但还不是已登记的完整词。单次操作访问 L 个字符，时间 O(L)。

```java
class Trie {
int N = 100009; // 直接设置为十万级
int[][] trie;
int[] count;
int index;

public Trie() {
    trie = new int[N][26];
    count = new int[N];
    index = 0;
}

public void insert(String s) {
    int p = 0;
    for (int i = 0; i < s.length(); i++) {
        int u = s.charAt(i) - 'a';
        if (trie[p][u] == 0) trie[p][u] = ++index;
        p = trie[p][u];
    }
    count[p]++;
}

public boolean search(String s) {
    int p = 0;
    for (int i = 0; i < s.length(); i++) {
        int u = s.charAt(i) - 'a';
        if (trie[p][u] == 0) return false;
        p = trie[p][u];
    }
    return count[p] != 0;
}

public boolean startsWith(String s) {
    int p = 0;
    for (int i = 0; i < s.length(); i++) {
        int u = s.charAt(i) - 'a';
        if (trie[p][u] == 0) return false;
        p = trie[p][u];
    }
    return true;
}
}
```

这个示例只接受小写英文字母，使用前须验证字符范围和节点容量；新编号不能达到数组长度 N。更广字符集可改成字符到子节点的映射，存储取舍见[数据结构中的 Trie](../数据结构.md#Trie%20字典树)。

## 编码规则与逆向转换

同一套符号可以从小值位于大值之前解释，也可以按允许的数值分段生成；两个方向需要遵守相同编码规则。

### 按相邻大小解释罗马数字

假设输入符合经典罗马数字编码规则。从右向左扫描，当前符号比右邻符号小则做减法，否则做加法，如 IV 得到 −1+5=4，VI 得到 5+1=6。

这种求值不等于语法验证，不会自动拒绝非法符号排列。若接口接受任意文本，应先验证允许的减法组合、重复次数与数值范围，再按相邻大小求值。

### 按数值分段生成罗马数字

采用经典 1 到 3999 的无横线写法时，这个过程与前面的规范编码求值互为逆向转换；范围外的数需要另定表示规则。
贪心：从大到小枚举所有特殊值（1000→M, 900→CM, 500→D, ...），每次能减就减并拼接对应符号，直到 num 归零

while num > 0:
