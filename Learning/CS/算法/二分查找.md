**LeetCode 704. 二分查找（基础：查找目标下标）**
在左闭右闭区间 `[left, right]` 中查找，循环条件是 `while (left <= right)`。每轮取 `mid` 比较；找到就返回，没找到时由于 `mid` 已排除，向左缩为 `right = mid - 1`，向右缩为 `left = mid + 1`。

**LeetCode 35. 搜索插入位置（和 704 的区别）**
如果目标值不存在于数组中，返回它按顺序插入的位置。每步维持三段：`[0, left)` 全 `< target`，`[left, right]` 待定，`(right, n)` 全 `> target`。若 `nums[mid] < target`，令 `left = mid + 1`（把 `mid` 及左侧划进左段）；若 `nums[mid] > target`，令 `right = mid - 1`；相等则直接返回 `mid`。

退出时 `left == right + 1`，待定区被压空；`right` 是最后一个 `< target` 的位置，`left` 是第一个 `>= target` 的插入位置，所以 `return right + 1` 和 `return left` 等价。

注意 1：`left` 是候选插入点，过程中它指向的值仍可能小于 `target`。例如 `[1,3,5,6]` 找 `2`，第一轮 `left=0`、`nums[0]=1<2`；只有退出后，`left` 才落在第一个 `>= target` 的下标上。

注意 2：找到 `target` 时已经提前返回，因此走到循环结束说明数组中没有 `target`；这时“第一个 `>= target`”和“第一个 `> target`”是同一个位置。若 `target` 大于所有元素，则 `left == n`，虽越过最后一个元素，仍是正确的末尾插入位置。

**LeetCode 34. 在排序数组中查找元素的第一个和最后一个位置**
用 `lowerBound` 返回第一个满足 `nums[i] >= target` 的下标 `i`（若不存在则返回 `n`）。`start = lowerBound(nums, target)`；若 `start == n` 或 `nums[start] != target`，说明目标不存在。否则 `end = lowerBound(nums, target + 1) - 1`。

`lowerBound` 的核心循环：

```java
if (nums[mid] >= target) {
    right = mid - 1; // 范围缩小到 [left, mid - 1]
} else {
    left = mid + 1;  // 范围缩小到 [mid + 1, right]
}
// 循环结束时 left == right + 1，left 就是第一个 >= target 的位置；
// 若 left == n，说明所有元素都小于 target。
```

**LeetCode 74. 搜索二维矩阵**
每一行递增，且下一行的第一个数大于上一行的最后一个数，因此可以把矩阵看成长度为 `m * n` 的一维有序数组。对一维下标 `mid`，换算为 `row = mid / n`、`col = mid % n`，再进行普通二分查找。

**LeetCode 33. 搜索旋转排序数组**
升序数组向左旋转后，形式为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`，要找 `target` 的下标。旋转后只有一个断点，因此每轮至少有一边有序；例如 `nums[left] <= nums[mid]` 表示左半边有序，再判断 `target` 是否落在该有序区间内，决定保留哪一半。

**LeetCode 153. 寻找旋转排序数组中的最小值**
利用最后一个元素 `nums[n-1]` 作为参照物，判断 `mid` 在旋转点左边还是右边：若 `nums[mid] > nums[n-1]`，最小值在 `mid` 右侧；否则最小值在 `mid` 或其左侧。

**LeetCode 4. 寻找两个正序数组的中位数（补充：归并思路，非二分解）**
模拟归并排序，只取出前 `(m + n) / 2 + 1` 个较小元素，用两个指针 `aStart` 和 `bStart` 合并。每轮比较 A、B 当前元素，取较小者并移动对应指针；每轮开始时把上一次取出的数保存到 `left`，再把本轮取出的数赋给 `right`，以处理奇偶长度：总长度为奇数时中位数是 `right`，为偶数时是 `(left + right) / 2`。这是直观的归并做法；若本页要记录二分解，还需另补“在较短数组上二分划分”的思路。
