**LeetCode 124. 二叉树中的最大路径和** 在二叉树中，一个节点的路径处理有两种情况：

1.  **作为“最高拐点”**：路径从左子树上来，经过当前节点，再下到右子树。这种路径**不能再向上延伸**给父节点了（因为二叉树路径不能有分叉）。
2.  **作为“贡献链”的一部分**：路径从当前节点出发，要么向左走，要么向右走，然后**向上延伸**给父节点，作为父节点路径的一部分。

-   **`ans`** 是在找**全局最优解**（可能是在树中间的某个“V”形）。
-   **`return`** 是在为**上一层递归**提供原材料（只能是单向的一条线）。

~~~java
ans = Math.max(ans, lVal + rVal + node.val); // 两条链拼成路径，尝试以当前节点为最高顶点（拐点），连接左右子树
return Math.max(Math.max(lVal, rVal) + node.val, 0); // 当前子树最大链和（注意这里和 0 取最大值了）
~~~

**LeetCode 257. 二叉树的所有路径** 给定一棵二叉树，返回所有从根节点到叶子节点的路径。
深度优先遍历时携带当前路径。访问普通节点就把节点值加入路径，分别向左右子树继续；到达叶子节点时把当前路径记录为一个答案。递归返回后要撤销当前节点，避免左右分支共用同一份路径状态。空树直接返回空结果。

**LeetCode 513. 找树左下角的值** 找出二叉树最底层最左边的节点值。
用 DFS 记录当前深度和已经找到的最大深度，并优先访问左子树。只有遇到更深一层的叶子节点时才更新答案；由于同层始终先访问左边，第一次到达最深层的叶子就是最左边的节点。也可以用层序遍历，在每层开始时记录第一个节点。

**LeetCode 654. 最大二叉树** 给定一个没有重复元素的数组，取当前区间最大值作为根节点，再递归构造最大值左边和右边的子数组。
递归函数需要明确当前处理的数组区间。先在线性扫描中找到区间最大值及其位置，最大值左侧构成左子树，右侧构成右子树；区间为空时返回空节点。直接扫描每个区间的最坏时间复杂度为 `O(n²)`，递归栈空间为 `O(n)`。

**LeetCode 530. 二叉搜索树的最小绝对差** 求二叉搜索树中任意两个不同节点值的最小差值。
BST 的中序遍历结果是非递减序列，最小差值一定出现在相邻访问节点之间。因此中序遍历时只需记录前一个节点，与当前节点相减并持续更新最小值，不需要比较所有节点对。时间复杂度为 `O(n)`，额外空间为递归栈的 `O(h)`。

**LeetCode 501. 二叉搜索树中的众数** 找出含重复值的 BST 中出现频率最高的所有节点值。
利用 BST 中序遍历得到有序序列，相同值会连续出现。遍历时维护当前值的连续出现次数和历史最大次数：出现更大次数就清空答案并重新记录，次数相等就追加当前值，遇到新值则重置当前计数。这样无需额外排序，时间复杂度为 `O(n)`。

**LeetCode 701. 二叉搜索树中的插入操作** 将一个值插入 BST，并保持二叉搜索树性质。
从根节点开始比较：目标值更小就进入左子树，更大就进入右子树；走到空位置时创建新节点并接回父节点。递归返回值表示修改后的子树根节点，不能只在局部移动指针而丢失连接。时间复杂度为 `O(h)`。

**LeetCode 450. 删除二叉搜索树中的节点** 在 BST 中删除指定值的节点并返回新的根节点。
先利用 BST 的大小关系定位目标。找到后分三种情况处理：没有左子树时由右子树顶上，没有右子树时由左子树顶上；左右子树都存在时，可取右子树中的最小节点作为后继，把待删除节点的左子树接到后继节点，再用右子树替代原节点。每次递归都要把修改后的子树重新接回父节点。

**LeetCode 669. 修剪二叉搜索树** 将 BST 修剪到 `[low, high]` 范围内，同时保持保留节点的相对结构。
利用 BST 的整体性质剪枝：当前节点小于 `low` 时，当前节点及其左子树全部不可能保留，只需继续处理右子树；当前节点大于 `high` 时对称地转向左子树；当前节点合法时，递归修剪左右子树并保留当前节点。注意修剪后根节点可能发生变化。

**LeetCode 538. 把二叉搜索树转换为累加树** 将每个节点改成原树中大于或等于它的所有节点值之和。
BST 的反向中序遍历顺序是从大到小。沿右子树、当前节点、左子树访问，并维护已经访问过的节点总和；访问当前节点时先把累计和加到它身上，再用更新后的值作为新的累计和。这样每个节点只处理一次，时间复杂度为 `O(n)`。
