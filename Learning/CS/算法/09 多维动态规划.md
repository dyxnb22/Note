# 多维动态规划

状态可以同时由多个位置或条件确定。先写明每个维度的含义，画出依赖方向，再决定按行、按列或按长度计算。降维后还要检查旧值是否过早被覆盖。

## 状态维度与依赖方向

无障碍网格只允许向右和向下时，到达某格的路径来自上方与左方。一维 dp[col] 在更新前表示上方，dp[col-1] 更新后表示本行左方。

```python
def grid_paths(rows, cols):
    if rows <= 0 or cols <= 0:
        return 0
    dp = [1] * cols
    for _ in range(1, rows):
        for col in range(1, cols):
            dp[col] += dp[col - 1]
    return dp[-1]

assert grid_paths(3, 2) == 3
assert grid_paths(1, 1) == 1
assert grid_paths(0, 2) == 0
```

时间 O(rows×cols)，空间 O(cols)。编辑距离与背包等多维问题需重新定义状态，不可因为用了二维表就沿用同一转移。

## 网格中的局部依赖

二维坐标本身不决定转移；允许从哪里到达当前位置，才决定依赖哪些已经求出的状态。

### 网格状态从上方和左方汇入

无障碍矩形网格只允许向右、向下，令 dp[i][j] 为从左上角到该格的路径数。内部格来自上方或左方，dp[i][j]=dp[i−1][j]+dp[i][j−1]；首行、首列只有直线到达方式，均为 1。

前面的完整程序把表压成一行，更新时 dp[j] 仍是上方，dp[j−1] 已是本行左方。空维度返回 0；有障碍时必须把障碍位置置为不可达，不能继续使用全为 1 的边界。

### 在相同依赖图中求最小代价

同样只许向右、向下时，最小路径和取两个来源的较小代价，再加当前格子的原始代价。首行和首列分别做累计和，起点只计一次，最终读取右下角。

可将 grid[i][j] 原地改成 min(grid[i−1][j],grid[i][j−1])+原值，省去额外表，但这会破坏原始输入。若后续还要使用格子代价，应另建状态表；非空矩形与合法行列是此前提。

## 两段前缀之间怎样对齐

两条序列的相对进度需要两个维度。连续匹配、非连续匹配、最小编辑代价和匹配方式计数保留的信息各不相同。

### 连续匹配在失配时归零

令 dp[i][j] 为分别以 nums1[i−1]、nums2[j−1] 结尾的最长公共连续片段长度。当前值相等时接上左上状态，取 dp[i−1][j−1]+1；不相等时直接为 0，因为连续匹配已被截断。

第 0 行与第 0 列为 0，答案取整张表最大值，不一定在右下角。降为一维时须倒序更新或保存旧对角值，避免读取本轮已经覆盖的状态。

### 两段前缀之间的最长公共子序列

令 dp[i][j] 为两条序列前 i、前 j 个元素的最长公共子序列长度，不要求位置连续。当前字符相等，取 dp[i−1][j−1]+1；否则取 max(dp[i−1][j],dp[i][j−1])，表示跳过一侧末字符。

这两个转移是互斥分支，不能先写对角加一、再无条件用上下最大值覆盖。空前缀对应的第 0 行与第 0 列为 0，最终答案在右下角；时间 O(mn)。

### 把不相交连线映射为子序列对齐

只有 `nums1[i] == nums2[j]` 时才能连接两个端点；连线不能相交，又要求两组被选下标分别保持递增。因此可连接的最多线数等于两条序列的最长公共子序列长度，直接复用前面的双前缀状态。

### 按相对顺序判断子序列

令 dp[i][j] 表示 s 的前 i 个字符能否完整匹配为 t 的前 j 个字符的子序列。空的 s 总能匹配；非空 s 不能匹配空的 t。每步可以跳过 t 的当前字符，若两个末字符相同，还可以同时消费它们。

```python
def is_subsequence(s, t):
    dp = [[False] * (len(t) + 1) for _ in range(len(s) + 1)]
    dp[0] = [True] * (len(t) + 1)
    for i in range(1, len(s) + 1):
        for j in range(1, len(t) + 1):
            dp[i][j] = dp[i][j - 1]
            if s[i - 1] == t[j - 1]:
                dp[i][j] |= dp[i - 1][j - 1]
    return dp[len(s)][len(t)]


assert is_subsequence("abc", "ahbgdc")
assert not is_subsequence("axc", "ahbgdc")
assert is_subsequence("", "")
assert not is_subsequence("ba", "a")
```

这个状态要求完整匹配 s 的前缀，与“最长公共子序列长度”不同。实际只需判断存在时，可用两个指针扫描 t，相等就推进 s，时间 O(len(t))、额外空间 O(1)；保留二维写法是为了比较布尔可达性与下一节的方式计数。

### 累计目标前缀的匹配方式

统计从源串 s 选择不同下标组成目标 t 的方式数。令 dp[i][j] 表示用 s 的前 j 个字符形成 t 的前 i 个字符的数量；空目标只有一种空选择，所以 dp[0][j]=1，非空目标与空源对应 0。

```java
for (int i = 1; i <= tLen; i++) {
    for (int j = 1; j <= sLen; j++) {
        if (t.charAt(i - 1) == s.charAt(j - 1)) {
            // 匹配时：使用 s[j-1] 的方案数 + 不使用 s[j-1] 的方案数
            dp[i][j] = dp[i - 1][j - 1] + dp[i][j - 1];
        } else {
            // 不匹配时：只能承接之前的方案数
            dp[i][j] = dp[i][j - 1];
        }
    }
}
```

匹配时，“使用当前源字符”和“不使用它”两类方案互不重叠，因此相加；不匹配则只能跳过源字符。这里计数的是下标选择而非不同结果字符串，数值可能很大，需要检查整数范围或使用大整数。

### 两段前缀之间的最小编辑代价

允许一次插入、删除或替换一个字符，每次成本为 1。dp[i][j] 表示把 word1 的前 i 个字符变成 word2 的前 j 个字符所需最少操作数；字符相等时继承对角，否则从替换、插入、删除三个来源取最小再加一。

```java
if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
    dp[i][j] = dp[i - 1][j - 1];
} else {
    dp[i][j] = Math.min(Math.min(dp[i - 1][j - 1], dp[i][j - 1]), dp[i - 1][j]) + 1;
} // 三个来源分别对应：替换、插入、删除
```

边界 dp[i][0]=i、dp[0][j]=j，分别表示全删与全插。与公共子序列同样比较两段前缀，但保存的是最小代价，不能直接复用求长度或计数的转移。

## 区间依赖决定计算顺序

当状态依赖更短的内部区间，按区间长度递增计算才能保证依赖项已经存在。

### 按区间长度计算回文状态

寻找最长回文子串时，连续区间的回文性由首尾字符与内部区间共同决定。
`dp[i][j]` 表示 `s[i..j]` 是否是回文串。先枚举子串长度（保证算 `dp[i][j]` 时 `dp[i+1][j-1]` 已就绪）。`dp[i][j] = s[i] == s[j] && (j - i < 3 || dp[i + 1][j - 1])`。长度不超过 3 时首尾相等就足够；从长度 4 开始还要检查内部区间。例如 `abca` 的首尾相同，内部 `bc` 却不构成回文。`O(n²)`。每次发现更长的回文区间时保存起点与长度，最后截取结果；空串直接返回空串。
