# 贪心算法

贪心需要证明局部选择不会破坏全局可行性或最优性，通常用交换论证、覆盖范围或某种单调边界。若无法证明，先寻找反例或改用动态规划。

## 局部选择与可交换性

跳跃游戏只关心当前能到达的最远位置。遍历到的位置若超过该边界就不可达；否则将边界扩大到 max(旧边界,当前位置+跳跃长度)，不必保存每一条路线。

```python
def can_reach(values):
    farthest = 0
    for index, jump in enumerate(values):
        if jump < 0:
            raise ValueError("nonnegative jumps required")
        if index > farthest:
            return False
        farthest = max(farthest, index + jump)
    return True

assert can_reach([2, 3, 1, 1, 4])
assert not can_reach([3, 2, 1, 0, 4])
assert can_reach([])
```

维护“已扫描可达位置能覆盖的最远端”就足以回答能否到达。空路线在此视为已经完成；最少跳跃次数是另一种状态和边界，不直接由这个布尔函数得到。

## 局部收益需要满足可组合条件

历史最低值、相邻上涨段和峰谷并不是同一个规则。每种选择都需要说明保留当前最优局部信息为什么不会损失全局结果。

### 用历史最低值计算单次交易收益

最多买入、卖出各一次时，假设今天卖出，最优买入价就是此前的最低价。扫描时维护 minPrice 与最佳非负收益；空输入或始终下跌返回 0，表示可以不交易。

也可用持有、不持有两个状态表达，持有状态只从 −price 更新，不能从卖出收益重新买入，否则会变成多次交易。下面是按日转移片段：

~~~python
	dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
	dp[i][1] = max(dp[i-1][1], -prices[i])   # ← 注意这里
~~~

### 把可重复交易拆成相邻上涨段

允许任意多次交易、同一时间最多持有一份，且没有手续费和冷冻期时，可累加每段相邻正价差。连续上涨区间的差分会望远镜相消，结果等于该段最低点买入、最高点卖出的收益。

下降价差不应包含在收益里，可以在下降前卖出、之后重新选择。加入手续费、交易次数上限或冷冻期后，各段不再独立，需要回到有限状态动态规划。

### 只在有效趋势变化时保留转折

摆动子序列要求相邻选中值的差正负交替。维护最后一次非零趋势，当前趋势首次非零或与它相反时，答案加一；连续同向变化只需保留更极端的末端，给后续反向选择留出至少同样的空间。

相等值不形成新趋势，也不能覆盖旧趋势。非空输入初始长度为 1，空输入为 0；用大小比较判断正负方向，可以避免极端整数直接相减溢出。

### 优先改变收益最大的负值

若必须恰好取反 k 次，先从最负的数开始取反，每次增加的总和最多；因此可先排序，依次处理负数直到 k 用完或没有负数。

剩余操作两次作用于同一数会相互抵消，只看奇偶性。若还剩奇数次，取反当前绝对值最小的数，损失最少；存在 0 时可用它消化剩余次数。总和与绝对值计算都需考虑整数范围。

## 让已证明无用的区间退出候选

可达范围、字符最后位置和失败油量区间提供排除依据。剩余问题的起点因此可以单向前进。

### 维护当前能够到达的最远范围

前面的布尔示例保存“已扫描可达位置能覆盖的最远端”。只有 i<=farthest 时，才能用 i+nums[i] 扩大范围；先发现 i 超出范围就应判定失败，不能让不可达位置继续贡献跳跃长度。

这个规则依赖非负最大跳长，且每个位置可选择不超过它的任意前进步数。仅有最大值但不允许短跳时，可达集合不再必然是连续前缀，不能沿用同一个状态。

### 在本轮范围耗尽时推进跳跃层

最少跳跃次数按可达层推进：currentEnd 是当前跳数能覆盖的最远位置，nextEnd 是扫描这一层所有位置后，再跳一次能到达的最远位置。扫描到 currentEnd 且还未到终点，才将次数加一并扩展到 nextEnd。

循环只需扫描到倒数第二个位置，避免到达终点后又多记一次跳跃。若 nextEnd 无法超过 currentEnd，目标不可达，应返回无解；空输入或单节点按路线约定需 0 次跳跃。时间 O(n)、额外空间 O(1)。

### 用最后出现位置确定分段边界

划分字符串，同一字母最多出现在一个片段中。先记录每个字符**最后出现的位置**，然后遍历字符串，不断更新当前片段必须到达的最远边界；当当前位置等于这个边界时，说明这个片段可以切开

### 从失败区间之后重新选择起点

（第 i 个加油站有汽油 gas[i] 升，从第 i 个加油站开往第 i+1 个加油站需要消耗汽油 cost[i] 升。从其中的一个加油站出发，开始时油箱为空，是否存在起点，可以按顺序绕环路行驶一周）
curSum 表示从当前候选起点出发，到当前位置的剩余油量。如果 curSum < 0，说明当前起点失败，并且它到当前位置之间的所有点都不能作为起点（到达之前的任意一个点，油量一定是非负的，重新从这个点出发，等于之前的油量去掉，cursum反而减少了，所以不能作为起点）。所以起点直接更新为 i + 1。totalSum 表示全局总油量是否够绕一圈。如果 totalSum < 0，返回 -1；否则返回贪心找到的 index。只要 totalSum >= 0，就必定存在一个合法的起点(整圈总油量不少于整圈总消耗)

## 先固定不容易被后续破坏的约束

处理顺序影响约束能否同时满足。双向扫描、先处理高个子、从低位回退以及树的后序汇总，分别保护不同关系。

### 分别满足左右相邻约束

（ratings表示每个孩子的评分，相邻两个孩子中，评分更高的那个会获得更多的糖果；每个孩子至少一个）从左往右看，当前孩子评分比左边高，那么当前孩子糖果数必须比左边多 1；从右往左看，如果当前孩子评分比右边高，那么当前孩子糖果数必须比右边多 1（`result[i] = Math.max(result[i + 1] + 1, result[i]) `不破坏第一遍已经满足的左边关系）

### 先固定高个子的相对次序

每人记录身高 h 与前方身高至少 h 的人数 k。先按 h 降序、同高按 k 升序排序，再依次插入结果的下标 k。已放入的人均不矮于当前人，因此插入位置直接满足当前 k；同高的人按 k 依次排定，之后更矮的人不会改变更高者的计数。

这个论证假设输入确实存在合法队列。数组列表插入需移动元素，链表按下标找位置也需遍历，因此一般实现总时间 O(n²)，不能因使用链表就声称所有插入都是 O(1)。

### 降低冲突位后最大化后缀

寻找不超过非负整数 n、数位从左到右不降的最大整数。由右向左扫描，相邻位若左大于右，就把左位减一，并记录从右位起需要填 9 的后缀；减一可能产生新的左侧冲突，因此继续向左检查。

最后统一把标记后的数位填 9。例如 332 先使中间位减一，再触发首位调整，结果为 299。只修复第一个冲突就停止，会漏掉这类连锁回退。

### 用孩子状态决定摄像头位置

后序遍历返回三种状态：未覆盖、已覆盖但无摄像头、有摄像头。空节点视为已覆盖；若任一孩子未覆盖，当前节点必须安装；否则任一孩子有摄像头，当前节点已覆盖；其余情况暂留未覆盖交给父节点。

孩子状态已经保证其更深子树被覆盖，当前选择只解决局部尚未覆盖的根。最后若整棵树的根仍未覆盖，再加一个摄像头；漏掉这一步会使单节点树返回 0。

## 组合两个局部最优窗口

多个资源不能重复使用同一元素时，局部最优还要附带不重叠的范围边界。

### 两个有序窗口的最优组合

设允许的价值差 `t` 非负。先把奖品价值排序，问题便变成选取两个互不重叠的连续窗口，使每个窗口的最大值与最小值之差不超过 `t`。排序后，每个合法集合都可以扩展成这样的窗口。

右端依次前进，左端在价值差超限时收缩，得到以当前位置结尾的最长合法窗口。令 `best[i]` 表示前 `i` 个位置中一个背包能容纳的最多奖品；当前窗口为 `[left, right]` 时，两个背包的候选结果就是 `best[left] + right - left + 1`。前缀最优只覆盖窗口之前的位置，避免两个背包重复计算同一件奖品。

窗口扫描为 `O(n)`，加上排序共 `O(n log n)`；需要单独考虑空输入以及一个窗口已经覆盖全部奖品的情况。

排序后的区间合并还可以比较[数组与区间处理](13%20数组与区间处理.md#排序后合并重叠区间)中的边界维护；它与上面的贪心选择共享“已结束区间无需再修改”的不变量。
