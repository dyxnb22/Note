## 每张题目卡片的最低信息

现有短笔记是复习记录，不因文件短就自动视为成熟概念文档。再次练习一道题时，优先补齐：

1. 状态或指针分别表示什么；
2. 为什么可以丢弃未继续搜索的候选；
3. 时间、空间复杂度和输入前提；
4. 一个最容易写错的边界或反例；
5. 最近一次独立写出的日期。

`_done` 只表示个人练习状态，不表示讲解、复杂度或边界已经完整。若某个题型只剩一两条孤立提示，优先合并到相邻题型；只有形成稳定不变量和多题迁移模式时才保留独立文件。

## 复习闭环

先遮住答案写出不变量和复杂度，再独立实现并用空输入、单元素、全相同、极值和无解输入验证。失败原因应记录为“状态定义错、边界错、复杂度退化或实现错误”，不要只记录最终代码。
