# Python 面试复习路线与答题模板

## 复习路线

### Level 0｜对象和数据

- 变量绑定的是对象还是值？赋值、复制和共享如何发生？
- list、tuple、set、dict 的语义、复杂度和使用边界是什么？
- `is`、`==`、可变性、默认参数和深浅拷贝如何影响 bug？

### Level 1｜语言机制

- 作用域、闭包、装饰器、生成器、上下文管理器、异常、模块和类如何工作？
- 类型注解、dataclass、协议和依赖注入如何表达接口？
- 文件、JSON、外部输入和错误边界如何做到可验证？

### Level 2｜运行时与并发

- CPython 字节码、引用计数、循环 GC、GIL 的准确边界是什么？
- 线程、进程、asyncio 各适合什么负载？
- Task 如何设置并发上限、超时、取消和资源清理？

### Level 3｜工程与 Web

- HTTP 客户端如何管理连接、超时、重试、幂等和响应大小？
- FastAPI 如何处理输入校验、依赖、生命周期、数据库和错误？
- Pydantic/DTO 如何把外部输入、领域命令和结构化模型输出隔离？
- SSE、WebSocket、LLM 外部调用和第三方计费如何处理断连、取消、重试与未知结果？
- 缓存、队列、日志、Trace、测试、灰度和回滚如何组合？

### Level 4｜手撕与项目

- 算法题先说不变量、复杂度和边界，再写代码。
- 并发题回答生产者、消费者、取消、背压、错误和关闭。
- 项目题按目标、约束、设计、故障、指标和复盘回答。

## Python 统一答题模板

1. **先给结论**：一句话回答题目，不绕到实现细节。
2. **讲对象/控制流**：说明引用、生命周期、事件循环或数据如何变化。
3. **给最小例子**：展示会出错或体现差异的短代码。
4. **补边界**：CPython/版本、线程安全、内存、取消、异常和性能。
5. **落工程**：结合 API、任务、数据库、日志或项目指标。

## 面试前 Checklist

- [ ] 能解释可变对象、深浅拷贝、生成器、闭包和装饰器。
- [ ] 能准确回答 GIL、线程/进程/asyncio 和事件循环。
- [ ] 能写带超时、取消和并发上限的异步调用。
- [ ] 能讲一个 FastAPI/HTTP 服务的输入、错误、数据库和观测边界。
- [ ] 能说明 pytest fixture/Mock 如何覆盖异步取消、下游超时和重复副作用。
- [ ] 能把一次 LLM/第三方调用失败讲清楚：预算、重试、计费、状态查询和对账。
- [ ] 能用 profile、日志和指标解释一次性能或线上故障。
