# Python 学习路线

用 Python 走到**后端开发**和 **Agent 开发**的系统教程。

**前提**:你已经会一门编程语言。这里只记 Python 的行为、边界和必要内容,基础语法只给形式,不从零讲。

## 约定

- 知识点从浅到深排。学到新的(比如刷题遇到的 `//` 和 `/`),插进对应章的对应位置。
- 章内不编号,所以插入不用重排任何东西。
- 只写知识本身,不做考点总结和刷题套路;00 和 08 是例外——00 是复习用的压缩卡与模板,08 是编码与项目表达的练习题,知识讲解一律在 01–07。
- 主章节之间不做交叉互链；专题从目录或对应章节入口链接，减少重复内容。
