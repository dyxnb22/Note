# 01 语言核心

> 前提:你已经会一门编程语言。基础语法只给形式,重点放在 Python 的行为和边界。

## 基本类型

```python
n = 42          # int,任意精度,不溢出
f = 3.14        # float,IEEE 754 双精度
s = "text"      # str,不可变
ok = True       # bool,是 int 的子类
v = None        # 空值单例
raw = b"bytes"  # bytes
```

字面量:`0b101`、`0o17`、`0xFF`、`1_000_000`、`1e-3`、`"""多行"""`、`f"{x}"`。

类型转换:`int("3")`、`float("1.5")`、`str(3)`、`bool([])`。

## 变量与赋值

```python
a = 1
x, y = 1, 2              # 解包
first, *rest = [1, 2, 3] # 星号收集
a, b = b, a              # 交换

s = [1]
s += [2]                 # 可变对象:原地改
s = s + [2]              # 新对象
```

- `a = obj` 是让名字指向对象,不复制值;`b = a` 后两者是同一个对象。
- 类型属于**对象**,不属于名字;同一名字可先后指向不同类型。
- `del a` 解除名字绑定,不等同于直接销毁对象。对象何时释放取决于实现和是否仍有引用；CPython 通常使用引用计数,循环引用还由垃圾回收器处理,不要把引用计数当成语言保证。参见[引用计数](https://docs.python.org/3/c-api/refcounting.html)和[`gc`](https://docs.python.org/3/library/gc.html)文档。

## 数值

- `int` 任意精度。`float` 有精度误差,`0.1 + 0.2 != 0.3`;要精确用 `decimal.Decimal`,有理数用 `fractions.Fraction`。
- 无穷:`float("inf")` 正无穷、`float("-inf")` 负无穷(`math.inf` 和 `-math.inf` 与之 `==` 相等,但是不同对象,比较用 `==` 不用 `is`),`1e400` 这种溢出字面量也得到 `inf`。与任何 `int` / `float` 比较都正常(`10**400 < float("inf")` 为 `True`,Python 不会溢出比较),常用作求最小值时的初值、或 `min()` 的"中性元"让空分支不参与比较:`return min(left, float("inf"), right)`。
- `inf` 的算术会漏出 `nan`:`inf - inf` 和 `inf * 0` 都是 `nan`,不是 `inf`。`nan` **不等于它自己**,`float("nan") == float("nan")` 为 `False`,判 `nan` 只能用 `math.isnan(x)`;`max` / `min` / 排序遇到 `nan` 结果不可预期,别把它当哨兵用。最大**有限** `float` 是 `sys.float_info.max`(约 `1.798e308`),它小于 `float("inf")`,两者不是一回事。
- `bool` 是 `int` 子类,`True == 1`。
- `None` 是单例,判断用 `is None`。

## 除法与取模(高频坑)

- 对内置 `int`:`/` 是真除法并返回 `float`,`4 / 2 == 2.0`;`Decimal`、`Fraction` 等数值类型会按各自运算规则返回结果,不要概括为所有类型都返回 `float`。
- 对内置 `int` 和 `float`,`//` 是地板除,向 **−∞** 取整:`-7 // 2 == -4`。`7.0 // 2 == 3.0`。`Decimal` 的 `//` 则向零截断,数值类型的边界要分别确认。
- 内置 `int` / `float` 的 `%` 结果符号跟随除数:`-7 % 3 == 2`,`7 % -3 == -2`。`Decimal` 的 `%` 符号跟随被除数,规则不同。
- 对遵循 Python 内置数值约定的操作数,`divmod(a, b)` 一次给出商和余数,并满足 `a == (a // b) * b + a % b`。需要整数向零截断时,按绝对值整除后再恢复符号；不要先把大整数除法转成 `float`。参见[算术运算规范](https://docs.python.org/3/reference/expressions.html#binary-arithmetic-operations)、[`decimal`](https://docs.python.org/3/library/decimal.html)与[`fractions`](https://docs.python.org/3/library/fractions.html)文档。

## 运算符与表达式

- `2 ** 10`、`2 ** -1 == 0.5`;`abs` / `min` / `max` / `round`。
- `round(2.675, 2)` 得 `2.67`,是浮点表示导致,不是 `2.68`。
- 比较可连写:`1 < x < 10`。
- 序列比较是**逐元素**的字典序:`(1, 2) < (1, 3)`、`[1, 2] < [1, 2, 3]`。从左往右一位一位比,前面分不出胜负才继续,某一位出结果就**短路**;长度只在前面全部相等时才起作用。`==` 同样逐元素。排序比较(`<` `<=` `>` `>=`)遇到类型不同(如 `list` 比 `tuple`)抛 `TypeError`,不做隐式转换;`==` 对不同类型只是 `False`。
- `and` / `or` **返回操作数本身**,不是 bool,且短路:`name = s or "默认"`。
- 位运算 `&` `|` `^` `~` `<<` `>>`;`&` / `|` 对 `set` 也可用作交并。

## 对象的身份与相等

```python
a = [1, 2]; b = [1, 2]
a == b     # True,值相等
a is b     # False,不是同一个对象
```

- `is` 比身份(是不是同一个对象),`==` 比值(可被 `__eq__` 重写)。
- 判断 `None` 和单例一律用 `is`。
- 小整数和短字符串有驻留,身份比较会"偶尔碰对",不能依赖。

## 真值判断

常见内置假值包括:`False`、`None`、数值零、空字符串和空容器(如 `[]`、`{}`、`()`、`set()`)。自定义对象也可以通过 `__bool__()` 或 `__len__()` 定义真值,因此不能把内置例子当成完整封闭清单。参见[真值测试规则](https://docs.python.org/3/reference/expressions.html#boolean-operations)。

## 字符串与字节

- `str` 不可变;所有"修改"都产生新对象。
- 切片 `s[a:b:c]`,越界不报错;`s[::-1]` 反转。
- 下标支持**负数**,从末尾数:`s[-1]` 是最后一个元素,`s[len(s)-1]` 的简写。它只在真正越界时抛 `IndexError`(`s[-len(s)-1]` 才炸),所以 `i == 0` 时的 `xs[i-1]` 会**静默变成 `xs[-1]`** 而不是报错——循环边界写错时 bug 被藏起来,不会像 Java 那样 `IndexOutOfBoundsException` 直接暴露。切片的"越界不报错"和下标的负索引是两回事,别混。
- f-string 最常用:`f"{name} {ratio:.2f}"`。
- `split(sep)` 按分隔符切,**连续分隔符和首尾都会产出空串**:`"/a//b/".split("/")` 得 `['', 'a', '', 'b', '']`,所以按 `/` 切路径要自己丢掉 `""`。无参 `split()` 按任意空白切且**吞掉连续空白、丢弃空串**,两者不能互换。
- `join` 只吃字符串序列:`",".join(parts)`,元素不是 `str` 要先转。
- 常用:`strip`、`replace`、`startswith`、`find`。
- `str` 与 `bytes` 严格区分,转换要显式编码:`"中".encode("utf-8")`、`data.decode("utf-8")`。
- 读写文件一律显式指定 `encoding="utf-8"`,不要依赖平台默认。

## 容器

- `list`:有序、可变、可重复,通用序列。
- `tuple`:有序、不可变;只有当所有成员都可哈希时,这个 `tuple` 才可哈希并能当 `dict` 的键。
- `dict`:键唯一,保留插入顺序,平均 O(1) 查找。
- `set`:无序、去重,平均 O(1) 成员判断。

```python
d = {"a": 1}
d.get("b", 0)            # 避免 KeyError
d.setdefault("c", [])    # 缺则建,常用于分组
```

- 空集合要写 `set()`;`{}` 是**空字典**,不是空集合。
- 常用内置:`len` `sum` `sorted` `reversed` `enumerate` `zip` `any` `all`。
- `sorted` 稳定,`key=` 支持多级排序:`key=lambda x: (x[0], x[1])` 每个元素只算一次 key,返回一个 tuple,剩下的先后顺序由上面的逐元素比较规则完成,不需要二次排序。

## 成员运算 in

`in` 判断"包不包含",`not in` 取反,都返回 bool。

```python
"world" in "hello world"     # True,判断子串
"x" not in "hello"           # True

3 in [1, 2, 3]               # True
"a" in {"a": 1}              # True,字典查的是键
2 in {1, 2, 3}               # True,集合
1 in {"a": 1}                # False,值不算
```

- 对字符串是判断**子串**,不限于单个字符。
- 对字典查的是**键**;想按值判断要写 `1 in d.values()`。
- 判断键存不存在用 `k in d`,不要写 `d.get(k) is None`:后者把"键不存在"和"键存在但值是 `None`"混成一件事,值可能是 `None` 时会判错。`get` 的用途是取值兜底(`d.get(k, 0)`),不是判存在。
- 复杂度差很多:`list` / `tuple` / `str` 是 O(n),`dict` / `set` 平均 O(1)。

```python
# 差:每个元素都把 other_list 扫一遍
for x in big:
    if x in other_list: ...

# 好:先转 set,平均 O(1)
other = set(other_list)
for x in big:
    if x in other: ...
```

- `for x in ...` 里的 `in` 是**迭代**,不是成员判断,别混。
- 自定义类实现 `__contains__` 就能用 `in`;没实现时会退化成用 `__iter__` 逐个比。

## 可变、不可变与拷贝

- 不可变:`int`、`float`、`str`、`tuple`、`frozenset`、`bytes`。
- 可变:`list`、`dict`、`set`,以及默认状态下的自定义对象。
- 只有可哈希对象能做 `dict` 的键 / `set` 的元素:`list` 不行;`tuple` 只有成员全部可哈希时才行。哈希性的要求是对象生命周期内哈希值稳定,不等同于“不可变”这一标签。参见 Python [hashable 定义](https://docs.python.org/3/glossary.html#term-hashable)。
- 浅拷贝只复制外层,内层仍然共享;深拷贝递归复制。

```python
import copy

a = [ [1], [2] ]
b = a.copy()             # 浅拷贝
c = copy.deepcopy(a)     # 深拷贝

b[0].append(9)           # a 也被改到
```

- `[ [0] * 3 ] * 3` 的三行其实是同一个 list,要写 `[ [0] * 3 for _ in range(3) ]`。
- 函数里 `x = arg[i]` 只是给入参的某个元素起了个别名,对 `x` 的赋值就是改调用方的对象。要把结果交给外部且不想被入参牵连,交出去之前先 `copy()`;浅拷贝对"外层 list + 不可变元素"够用,内层还共享就要 `deepcopy`。
- `deepcopy` 不适合锁、文件句柄、超大对象或有意共享的结构。

## 原地修改与返回新对象

一批方法**就地改**并返回 `None`,另一批**返回新对象**,搞混是常见 bug。

| 原地改(一般返回 `None`) | 返回新对象 |
|---|---|
| `list.sort()`、`list.reverse()` | `sorted(x)`、`reversed(x)` |
| `list.append` / `extend` / `insert` / `remove` / `clear` | `x + y`、切片、推导式 |
| `dict.update`、`set.update`、`set.add` | 集合 / 字典的 `+` 类运算符 |

```python
xs = [3, 1, 2]

ys = xs.sort()        # ys 是 None,xs 变成 [1, 2, 3]
zs = sorted(xs)       # zs 是新列表,xs 不变

xs.reverse()          # 原地反转,返回 None
xs[::-1]              # 切片反转,返回新列表
it = reversed(xs)     # 返回的是迭代器,xs 不变
list(reversed(xs))    # 想要新列表就套一层 list
```

- `sort()` / `reverse()` 返回 `None` 是**刻意**的:提醒你这是原地操作,防止误以为拿到了新列表。`xs = xs.sort()` 会把 `xs` 变成 `None`,经典 bug。
- `reversed(x)` 返回迭代器,**不改原对象**;要新列表就 `list(reversed(x))`。
- `sorted` 稳定,`sort` 和 `sorted` 都支持 `key=`。
- 集合 / 字典的运算符 `|`、`&`、`-` 返回**新对象**;对应的 `|=`、`&=`、`-=` 才是原地改。
- 删除的三种写法:`del xs[i]` 按下标删且无返回值;`xs.pop(i)` 按下标删并**返回被删元素**;`xs.remove(v)` 按值删且返回 `None`,值不存在会抛 `ValueError`。`dict` 同理:`del d[k]` 或 `d.pop(k, default)`。
- `map` / `filter` 返回迭代器、不改原对象;能用推导式就用推导式,通常更直观也更快。

下标上的 `+=` 不是原子操作,`xs[i] += v` 展开成 `xs[i] = xs[i] + v`:先 `__getitem__` 取出,算 `+`,再 `__setitem__` 写回,写回的是 `+` 的**返回值**。

```python
rows = [""] * 3
rows[0] += "a"        # str 不可变:新建后再写回
grid = [[0]]
grid[0] += [1]        # list 可变:原地改,写回的是同一个对象
```

- 元素是不是原地改,由 `+` 自己决定:可变元素原地改后写回同一对象,不可变元素产生新对象再写回。名字上的 `x += v` 只有一次绑定,没有"取值、写回"两步,所以不会遇到这个分叉。
- 写回的是 `__iadd__` / `+` 的返回值,所以返回 `None` 的 `__iadd__` 会把元素写成 `None`。
- `d[k] += 1` 还要求 `__getitem__` 先取得到值:普通 `dict` 缺键直接抛 `KeyError`,`defaultdict(int)` 能用是因为 `__getitem__` 会先补上默认值,两步之后再 `__setitem__`。

## 推导式

```python
evens = [x * 2 for x in xs if x > 0]
invert = {v: k for k, v in items}
seen = {x for x in xs}
```

生成器表达式 `(x for x in xs)` 惰性求值,省内存,但只能消费一次。

- `_` 是"用不到的值"的惯例名,例如 `[0 for _ in range(3)]`。
- 推导式每轮迭代都**新建**对象:所以 `[set() for _ in range(9)]` 得到 9 个互相独立的空集合,而 `[set()] * 9` 是 9 个引用指向同一个集合。
- 生成器表达式作为函数的**唯一参数**时可以省略外层括号:`sum(int(c) ** 2 for c in str(n))`、`any(x > 0 for x in xs)`;还有其他参数或要传元组时才必须写括号。
- 字符串是可迭代的,`for c in s` 逐个字符;逐位处理数字常用 `str(n)` 再对每个 `c` 做 `int(c)`。

## 多维数组(嵌套列表)

Python 没有内置的多维数组,统一用**嵌套列表**表示:二维就是列表的列表,三维就是列表的列表的列表,以此类推。

```python
rows, cols = 3, 4

grid = [ [0] * cols for _ in range(rows) ]   # 正确:每行都是新建的 list
grid[1][2] = 9                               # 访问:先取行,再取列

bad = [ [0] * cols ] * rows                  # 错误:所有行是同一个 list
bad[0][0] = 1                                # 每一行都会跟着变
```

- 内层 `[0] * cols` 本身是安全的(元素是不可变的 `0`);出问题的是**外层**用 `*`。
- 内层元素如果是可变对象,内层也不能用 `*`:`[ [] for _ in range(cols) ]`。
- 遍历可以双重循环,也可以直接 `for row in grid` 取整行。
- `len(grid)` 是行数,`len(grid[0])` 是列数(前提是每行等长)。
- 下标顺序固定是 `grid[row][col]`,别和 `grid[x][y]` 混着写。
- 不等长或稀疏的结构用 `dict[(r, c)]`,不要硬塞成方阵。
- 真要矩阵运算(转置、点积、切片)用 `numpy.ndarray`——它是真正的多维数组,不是列表套列表。

### 三维及更高

```python
r, c, d = 2, 3, 4

cube = [ [ [0] * d for _ in range(c) ] for _ in range(r) ]
cube[1][2][3] = 9            # 下标一层一层往下取
```

- 每多一维就多包一层推导式;**每一层都必须用推导式**,任何一层用 `*` 都会让那一层共享同一个对象。
- 层数一多,嵌套推导式可读性会崩,写个递归工厂更清楚:

```python
def zeros(*dims):
    if len(dims) == 1:
        return [0] * dims[0]
    return [zeros(*dims[1:]) for _ in range(dims[0])]

grid = zeros(2, 3, 4)
```

- 遍历所有下标用 `itertools.product(range(r), range(c), range(d))`,比手写多层循环清楚。
- 维度一高,或者要做切片、转置、数值运算,**用 `numpy`**:`arr = np.zeros((2, 3, 4))`,下标写成 `arr[i, j, k]`,切片和矩阵运算才可用。嵌套列表做这些会非常慢,内存也大得多。

## 流程控制

```python
if x > 0:
    ...
elif x == 0:
    ...
else:
    ...

for i in range(3):
    ...
for i, v in enumerate(items):
    ...
while cond:
    ...
```

- `break` / `continue`。
- `for` / `while` 可带 `else`:**没被 `break`** 时执行。
- `range(start, stop, step)`;`zip(a, b)` 长度取短的。
- 没有 `switch`;3.10+ 用 `match`,否则 `if/elif`。

## 函数

- 参数顺序:位置 → 默认 → `*args` → 仅关键字 → `**kwargs`。
- **默认值只在定义时求值一次**,可变默认值是经典坑:

```python
def f(x, acc=None):
    acc = [] if acc is None else acc
```

- 多返回值就是 tuple:`return a, b`。
- `lambda` 只能写单表达式。
- `/` 声明仅位置参数,`*` 声明仅关键字参数。

## 作用域与闭包

- 查找顺序 LEGB:Local → Enclosing → Global → Builtin。
- 函数内**赋值**即创建局部变量;改外层用 `nonlocal`,改模块级用 `global`。
- 闭包捕获的是**变量**,不是当时的值:

```python
fs = [lambda: i for i in range(3)]        # 三个都返回 2
fs = [lambda i=i: i for i in range(3)]    # 0, 1, 2
```

## 类与对象

```python
class Point:
    kind = "point"                 # 类属性,所有实例共享

    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

class Circle(Point):
    def __init__(self, x, y, r):
        super().__init__(x, y)
        self.r = r
```

- `self` 是显式参数;`__init__` 负责初始化,`__new__` 才是构造。
- 类属性共享,放可变对象会互相污染。
- 实例属性存在 `__dict__`;`__slots__` 省内存并限制可加属性。
- 常用魔术方法:`__repr__`、`__str__`、`__eq__`、`__hash__`、`__len__`、`__iter__`、`__getitem__`、`__enter__` / `__exit__`。
- 一旦定义 `__eq__`,`__hash__` 会被置为 `None`,要哈希就得自己重写。
- 继承用 `super()`;多继承走 MRO。
- `@property` 让方法以属性形式访问,可加校验。

## 异常

- `try / except / else / finally`。`else` 在 try 未抛异常时执行,`finally` 无论如何都执行。
- 自定义异常继承 `Exception`,不要继承 `BaseException`。
- 裸 `except:` 会连 `KeyboardInterrupt` 一起吞掉,至少写 `except Exception:`。
- `raise ... from e` 保留原始因果链。
- 3.11+ 用 `ExceptionGroup` 和 `except*` 处理并发中的多个异常。

## 模块与包

- 一个 `.py` 文件就是模块;带 `__init__.py` 的目录是包。
- `if __name__ == "__main__":` 区分"被导入"和"直接运行"。
- 导入会执行模块顶层代码,别在顶层做重活或产生副作用。
- 相对导入 `from . import x` 只能在包内使用。

## 常用标准库

- `pathlib`:路径用 `Path` 对象,`Path("a") / "b"`、`read_text()`、`exists()`、`glob("**/*.py")`。
- `json`:`dumps` / `loads`;写给人看时加 `ensure_ascii=False`。
- `datetime`:`datetime` / `timedelta` / `timezone`;naive 和 aware 不能混,跨时区一律带 `tzinfo`。
- `re`:正则,提前编译复用;复杂解析优先用专门库而不是堆正则。
- `collections`:`deque`(双端队列)、`Counter`(计数)、`defaultdict`(分组)、`namedtuple`。
- `itertools`:`chain`、`groupby`、`islice`、`product`。
- `functools`:`lru_cache` / `cache`、`partial`、`reduce`、`wraps`。
- `os` / `sys` / `shutil` / `subprocess`:环境变量、路径、文件操作、子进程。
