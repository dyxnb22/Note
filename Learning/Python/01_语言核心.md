Python 用缩进划分代码块，通常每层四个空格。if、for、def、class 等语句后写冒号，再缩进写代码块。括号里的表达式可以换行写。

以下以 Python 3.12 为基线，先讲名字与对象，再看容器、函数和类。

代码中的 `assert 条件` 用来检查示例结果，条件不成立时抛出 AssertionError。Python 的 `-O` 选项会移除断言，业务输入校验应使用明确的条件与异常。

## 基本类型

```python
n = 42  # int：任意精度，范围受可用内存等资源限制
f = 3.14  # float：常见 CPython 平台使用 IEEE 754 双精度
c = 1 + 2j  # complex：实部与虚部都是 float
s = "text"  # str：不可变文本
raw = b"bytes"  # bytes：不可变字节序列
ok = True  # bool：int 的子类
v = None  # None：唯一的空值单例
```

字面量：`0b101`、`0o17`、`0xFF`、`1_000_000`、`1e-3`、`1 + 2j`、`"""多行"""`、`f"{x}"`。

类型转换可能报错，也可能丢掉小数部分却不报错，例如把浮点数转成整数：

```python
assert int(3.9) == 3  # 向零截断，不四舍五入
assert float(2) == 2.0  # int 转 float 可能丢失精度；超出范围时会抛 OverflowError
assert str(3) == "3"
assert bool([]) is False  # 空容器是假值
assert True + True == 2  # bool 是 int 子类的实际效果
assert sum([True, False]) == 1

try:
    int("3.1")
except ValueError as error:
    assert isinstance(error, ValueError)
```

判断是否为 `None` 用 `is None`，见「对象的身份与相等」。float 的精度误差、`str` 与 `bytes` 的编码转换、不可变类型清单分别见后文「数值边界」「字符串与字节」「可变、不可变与拷贝」。

## 变量与赋值

### 赋值让名字指向对象

```python
a = [1]
b = a
b.append(2)
assert a == [1, 2]
b = [9]
assert a == [1, 2]
```

`b = a` 不复制列表。append 修改共享对象，而 `b = [9]` 只改变 b 的绑定。判断一行代码会不会影响其他地方，要看它修改对象，还是仅仅重新绑定名字。

### 解包与多目标赋值

赋值可以同时绑定多个名字；带星号的目标会收集其余元素。下面同时展示交换变量、解包以及列表两种更新方式的区别。

```python
a = 1
b = 2
x, y = 1, 2
first, *rest = [1, 2, 3]
a, b = b, a
assert (a, b) == (2, 1)
assert rest == [2, 3]

s = [1]
alias = s
s += [2]  # list 的 += 原地修改
assert alias is s
s = s + [3]  # 创建新列表并重新绑定
assert alias == [1, 2]
assert s == [1, 2, 3]
```

- `a = obj` 是让名字指向对象，不复制值；`b = a` 后两者是同一个对象。
- 类型属于**对象**，不属于名字；同一名字可先后指向不同类型的对象。
- `del a` 解除名字与对象的绑定，不会直接命令 Python 销毁对象。对象何时释放，还取决于是否存在其他引用和解释器的实现。

CPython 通常使用引用计数，垃圾回收器处理部分循环引用。其他解释器可能采用不同策略，资源释放时间不能只凭引用计数推断。参见[引用计数](https://docs.python.org/3/c-api/refcounting.html)和 [`gc`](https://docs.python.org/3/library/gc.html) 文档。

## 运算符与表达式

- `**` 表示乘方：`2 ** 10` 得到 `1024`，`2 ** -1` 得到 `0.5`。`abs` 取绝对值，`min` / `max` 求最小值和最大值，`round` 按规则舍入。
- `round(2.675, 2)` 得到的是 `2.67`，而非 `2.68`，原因在于浮点表示的精度限制。
- 比较可连写：`1 < x < 10`。
- 列表和元组按元素顺序比较。从左向右检查，遇到能够确定先后的元素就停止；只有前面的元素都相等时，才由长度决定先后。

例如，`(1, 2) < (1, 3)`，`[1, 2] < [1, 2, 3]`。列表与元组不能直接进行大小比较；即使元素相同，`[1, 2] == (1, 2)` 也为 `False`。其他类型按各自规则比较，例如数值 `1 == 1.0` 为 `True`。

- `and` 从左往右计算，遇到假值就返回它，后面的不再计算；没有假值就返回最后一个值。
- `or` 遇到真值就返回它，后面的不再计算；没有真值就返回最后一个值。这种提前停止计算的行为叫短路。两者返回的都是原来的值，不会自动转成 bool；`not` 的结果则是 bool。

`name = value or "默认"` 会把 0、空字符串等假值也替换掉。只想处理缺失值时，应显式判断 `is None`。
- 位运算 `&` `|` `^` `~` `<<` `>>`；`&` / `|` 对 `set` 也可用作交并。

## 除法与取模

- 对内置 `int`：`/` 是真除法并返回 `float`，`4 / 2 == 2.0`；`Decimal`、`Fraction` 等数值类型会按各自运算规则返回结果，不要概括为所有类型都返回 `float`。
- 对内置 `int` 和 `float`，`//` 是地板除，向 **−∞** 取整：`-7 // 2 == -4`，`7.0 // 2 == 3.0`。`Decimal` 的 `//` 则向零截断。
- 内置 `int` / `float` 的 `%` 结果符号跟随除数：`-7 % 3 == 2`，`7 % -3 == -2`。`Decimal` 的 `%` 符号跟随被除数，规则不同。
- `divmod(a, b)` 同时返回商和余数。除数非零时，整数运算满足 `a == (a // b) * b + a % b`；浮点运算还会受到舍入误差影响。

需要对大整数做向零截断的除法时，可以先按绝对值整除，再恢复符号。不要先转换成 `float`，否则可能丢失精度。不同数值类型的规则见[算术运算规范](https://docs.python.org/3/reference/expressions.html#binary-arithmetic-operations)、[`decimal`](https://docs.python.org/3/library/decimal.html) 和 [`fractions`](https://docs.python.org/3/library/fractions.html)。

## 真值判断

常见假值包括 `False`、`None`、数值零，以及空字符串和空容器，例如 `[]`、`{}`、`()`、`set()`。条件判断会按真值规则处理对象，不要求条件表达式本身就是布尔值。

自定义对象还可以通过 `__bool__()` 或 `__len__()` 定义真值。参见[真值测试规则](https://docs.python.org/3/reference/expressions.html#boolean-operations)。

## 对象的身份与相等

```python
a = [1, 2]
b = [1, 2]
assert a == b
assert a is not b
```

- `is` 比身份(是不是同一个对象)，`==` 比值(可被 `__eq__` 重写)。
- 判断是否为 `None` 使用 `is None` 或 `is not None`。普通数值和字符串的内容比较使用 `==`。
- 有些解释器会复用一部分整数和字符串对象，所以用 `is` 比较内容时，有时会碰巧得到正确结果。这种复用不能作为判断依据，比较内容仍用 `==`。

## 字符串与字节

- 字符串不能原地修改。字符串方法返回处理结果；内容没变时，可能直接返回原对象。
- 切片 `s[start:stop:step]` 包含 start，不包含 stop；默认步长为 1，边界超出长度时通常会截取有效部分。`s[::-1]` 反转，步长为 0 则抛出 `ValueError`。
- 负索引从末尾计数。`s[-1]` 取最后一个元素；下标超出有效范围时才抛出 `IndexError`。

因此，`i == 0` 时，`xs[i - 1]` 会访问最后一个元素，而不是报告循环越界。检查循环边界时，要同时考虑这种合法但可能不符合预期的访问。切片对边界的处理规则与单个下标不同。

- f-string 将表达式格式化为文本。冒号后的内容是格式说明，例如 `:.2f` 表示保留两位小数。格式化只改变展示文本，不会改变原数值。

```python
name = "小明"
ratio = 0.375
message = f"{name} {ratio:.2f}"
assert message == "小明 0.38"
assert ratio == 0.375
```

格式化不等于 SQL、shell 或 HTML 的安全转义。将结果交给其他系统时，仍需使用相应的参数化接口或编码规则。

- 指定分隔符的 `split(sep)` 会保留连续分隔符、首尾分隔符产生的空字符串。例如，`"/a//b/".split("/")` 得到 `['', 'a', '', 'b', '']`。
- 不带参数的 `split()` 按空白切分，并忽略连续空白和首尾空白。两种写法的结果不同，不能直接互换。处理文件路径时，优先使用路径工具，而不是手动切分分隔符。
- `join` 将多个字符串连接成一个字符串，例如 `",".join(parts)`。元素必须是字符串；需要连接其他类型的值时，先明确转换方式。
- `strip()` 删除两端空白，`lstrip()` 和 `rstrip()` 分别只处理左端或右端。传入 `chars` 时，参数表示一组可删除字符，不是要删除的一段前缀或后缀。

例如，`"abba".lstrip("ab")` 得到空字符串：它会持续删除左端属于 `a`、`b` 的字符，而不是只删除一次 `"ab"`。要删除固定前缀或后缀，使用 `removeprefix()`、`removesuffix()`。

不传参数时，`strip()` 处理 Python 认定的空白字符，其中包括部分 Unicode 空白。原字符串不变；结果内容相同时，可能复用原对象。

- 其他常用：`replace`、`startswith`、`find`(`find` 返回 -1 而不是抛异常，和 `index` 不同)。
- `str` 与 `bytes` 严格区分，转换要显式编码：`"中".encode("utf-8")`、`data.decode("utf-8")`。
- 读写 UTF-8 文本时显式指定 `encoding="utf-8"`；其他文本按实际编码处理，二进制文件不传 encoding。

## 容器

- `list`：有序、可变、可重复，通用序列。
- `tuple`：有序、不可变；只有当所有成员都可哈希时，这个 `tuple` 才可哈希并能当 `dict` 的键。
- `dict`：键唯一，保留插入顺序，平均 O(1) 查找。
- `set`：无序、去重，平均 O(1) 成员判断。

```python
d = {"a": 1}
d.get("b", 0)  # 避免 KeyError
d.setdefault("c", [])  # 缺则建,常用于分组
```

- 空集合要写 `set()`；`{}` 是**空字典**，不是空集合。
- 常用内置：`len` `sum` `sorted` `reversed` `enumerate` `zip` `any` `all`。
- `sorted` 是稳定排序。`key=` 可返回多个字段组成的元组，例如 `key=lambda x: (x[0], x[1])`；排序时先比较第一项，相同再比较第二项。每个元素只计算一次 key，无需为两个字段分别排序。

### 常见的读取、更新与遍历

```python
values = [1, 2]
values.append(3)  # 追加一个对象
values.extend([4, 5])  # 逐项追加可迭代对象的内容
assert values.pop() == 5
assert values == [1, 2, 3, 4]

scores = {"小明": 80, "小红": 90}
scores["小明"] = 85
assert list(scores) == ["小明", "小红"]
assert list(scores.items()) == [("小明", 85), ("小红", 90)]
assert list(scores.values()) == [85, 90]
```

- 遍历 dict 默认得到键，`items()` 得到键值对，`values()` 得到值。
- `append` 追加一个元素，`extend` 逐项追加。当参数也是列表时，前者把整个列表作为一个元素放进去，后者把列表里的元素逐个放进去。
- 改变字典或集合大小时，不要同时遍历原对象。可以先构造新结果，或遍历副本。

## 成员运算 in

`in` 判断“包不包含”，`not in` 取反，都返回 bool。

```python
"world" in "hello world"  # True,判断子串
"x" not in "hello"  # True

3 in [1, 2, 3]  # True
"a" in {"a": 1}  # True,字典查的是键
2 in {1, 2, 3}  # True,集合
1 in {"a": 1}  # False,值不算
```

- 对字符串是判断**子串**，不限于单个字符。
- 对字典查的是**键**；想按值判断要写 `1 in d.values()`。
- 判断键是否存在，使用 `key in mapping`。`mapping.get(key) is None` 无法区分“键不存在”与“值本来就是 `None`”。需要读取并提供默认值时，再使用 `get()`。
- list / tuple 的成员判断通常记为 O(n)，dict / set 平均是 O(1)；这里假定一次相等比较的成本为 O(1)。字符串判断的是子串，耗时还与子串长度和搜索算法有关，不能把所有 `in` 都当作同一种查找。

```python
big = [1, 2, 3]
other_list = [2, 3, 3]
slow = []
for x in big:
    if x in other_list:
        slow.append(x)

other = set(other_list)
fast = []
for x in big:
    if x in other:
        fast.append(x)
assert slow == fast == [2, 3]
```

- `for x in ...` 表示迭代，而表达式 `x in values` 表示成员判断。两处虽然使用相同关键字，但含义不同。
- 自定义类可以用 `__contains__` 定义成员判断；没有时通常尝试迭代协议。Python 也兼容用 `__getitem__` 按整数下标取值的旧式迭代方式。

## 流程控制

```python
x = 2
if x > 0:
    sign = "positive"
elif x == 0:
    sign = "zero"
else:
    sign = "negative"
assert sign == "positive"

items = ["a", "b"]
assert list(range(3)) == [0, 1, 2]
assert list(enumerate(items)) == [(0, "a"), (1, "b")]
count = 0
while count < 3:
    count += 1
assert count == 3
```

- `break` / `continue`。
- for/while 的 else 在循环正常耗尽或条件变假时执行；break 会跳过它，return 或异常离开循环也不会执行该 else。
- `range(start, stop, step)` 的 stop 不包含在结果中；zip 默认以较短输入为准，需要长度一致时可使用 `zip(..., strict=True)`，但这种检查在迭代时发生。
- 多分支条件通常用 if/elif。Python 3.10+ 的 match 是结构模式匹配：既能匹配常量，也能拆解序列和映射，不能只按普通 switch 的常量分支来理解。

### break、continue 与循环 else

```python
found = None
for value in [1, 3, 4, 6]:
    if value % 2 != 0:
        continue
    found = value
    break
else:
    found = "没有偶数"
assert found == 4

for value in [1, 3]:
    if value % 2 == 0:
        break
else:
    result = "没有偶数"
assert result == "没有偶数"
```

continue 跳过当前轮剩余语句，break 离开最内层循环。循环 else 表示正常走完仍未 break，不能按 if 的 else 理解。

### match 的常量、结构与变量绑定

```python
def describe(value):
    match value:
        case {"name": name}:
            return f"姓名：{name}"
        case [first, second]:
            return first + second
        case "quit":
            return "退出"
        case _:
            return "未知"

assert describe({"name": "小明"}) == "姓名：小明"
assert describe([2, 3]) == 5
assert describe("quit") == "退出"
```

模式里直接写 name，通常是把匹配到的值保存到 name，而不是拿它和已有变量比较。first、second 同理。字符串等字面量用于匹配常量，`_` 匹配任意值但不保存到变量。映射模式默认允许额外键，不能代替严格的模型校验。

## 推导式

```python
xs = [1, -2, 3, 1]
items = [("a", 1), ("b", 2)]
doubled_positive = [x * 2 for x in xs if x > 0]
invert = {value: key for key, value in items}
seen = {x for x in xs}
assert doubled_positive == [2, 6, 2]
assert invert == {1: "a", 2: "b"}
assert seen == {1, -2, 3}
```

生成器表达式通常在迭代时才计算元素，生成的结果只能取一遍。但有些计算会在创建时发生：例如 `(f(x) for x in make_items())` 会立刻调用 `make_items()`，等取值时才执行 `f(x)`。因此，`make_items()` 报错会在创建生成器时就暴露出来。

要立即拿到完整结果、多次遍历或按索引访问，就用列表。

- `_` 是“用不到的值”的惯例名，例如 `[0 for _ in range(3)]`。
- 推导式每轮都会求值表达式；是否新建对象取决于表达式。例如 `[set() for _ in range(9)]` 得到 9 个互相独立的空集合，而 `[set()] * 9` 是 9 个引用指向同一个集合。
- 生成器表达式作为函数的**唯一参数**时可以省略外层括号：`sum(int(c) ** 2 for c in str(n))`、`any(x > 0 for x in xs)`；还有其他参数或要传元组时才必须写括号。
- 字符串是可迭代的，`for c in s` 逐个字符；逐位处理数字常用 `str(n)` 再对每个 `c` 做 `int(c)`。

## 可变、不可变与拷贝

- 不可变：`int`、`float`、`str`、`tuple`、`frozenset`、`bytes`。
- 可变：`list`、`dict`、`set`，以及默认状态下的自定义对象。
- `dict` 的键和 `set` 的元素必须可哈希。列表不可哈希；元组只有在全部成员都可哈希时，才能作为键或集合元素。

可哈希要求哈希值在对象生命周期内保持稳定，并与相等性规则一致。它与“不可变”有关，但两者并不等同。参见 Python 对 [hashable](https://docs.python.org/3/glossary.html#term-hashable) 的定义。

- 对嵌套容器，浅拷贝创建新的外层容器，元素引用仍可共享；深拷贝递归处理内部对象。不可变对象可能复用，自定义类也可以改变复制行为，因此深拷贝不意味着每个对象都有新身份。

```python
import copy

a = [[1], [2]]
shallow = a.copy()
deep = copy.deepcopy(a)
shallow[0].append(9)
assert a == [[1, 9], [2]]
assert shallow is not a and shallow[0] is a[0]
assert deep == [[1], [2]]
```

- 容器乘法复制的是引用；嵌套列表一节会用独立行与共享行对比这个规则。
- 函数里 `x = arg[i]` 让 x 指向相同元素；`x = other` 只改变局部绑定，`x.append(...)` 等操作才可能修改共享的可变对象。需要独立结果时，先确定哪些内层对象也要独立，再选择浅拷贝或深拷贝。
- `deepcopy` 不适合锁、文件句柄、超大对象或有意共享的结构。

## 原地修改与返回新对象

读一次调用，要分开看原对象是否变化、返回值是什么。原地修改的方法，返回值可能只是 None。

| 原地改(一般返回 `None`) | 返回新对象 |
|---|---|
| `list.sort()`、`list.reverse()` | `sorted(x)`、`reversed(x)` |
| `list.append` / `extend` / `insert` / `remove` / `clear` | `x + y`、切片、推导式 |
| `dict.update`、`set.update`、`set.add` | 字典的 `\|`、集合的 `\|` / `&` / `-` |

```python
xs = [3, 1, 2]

ys = xs.sort()  # ys 是 None,xs 变成 [1, 2, 3]
zs = sorted(xs)  # zs 是新列表,xs 不变

xs.reverse()  # 原地反转,返回 None
xs[::-1]  # 切片反转,返回新列表
it = reversed(xs)  # 返回的是迭代器,xs 不变
list(reversed(xs))  # 想要新列表就套一层 list
```

- `sort()` 和 `reverse()` 原地修改列表，返回 `None`。因此，`values = values.sort()` 会让变量不再指向列表，而是指向 `None`。需要新列表时使用 `sorted(values)`。
- `reversed(x)` 返回迭代器，**不改原对象**；要新列表就 `list(reversed(x))`。
- 集合的 |、&、- 返回新集合；字典支持 | 合并，但不支持集合式的 & 和 -。相应的原地运算也要按类型区分。
- 删除的三种写法：`del xs[i]` 按下标删且无返回值；`xs.pop(i)` 按下标删并**返回被删元素**；`xs.remove(v)` 按值删且返回 `None`，值不存在会抛 `ValueError`。`dict` 同理：`del d[k]` 或 `d.pop(k, default)`。
- `map()` 和 `filter()` 返回迭代器。简单变换和筛选常可写成推导式；选择时优先考虑表达是否清楚，性能差异应结合实际数据测量。

`xs[i] += v` 分几步执行，并不是原子操作：先取出元素，尝试调用 `__iadd__`；不支持时再尝试普通加法，最后把返回值写回 `xs[i]`。它可能先原地修改元素，因此不能简单等同于先做普通加法再赋值。

```python
rows = [""] * 3
rows[0] += "a"  # str 不可变:新建后再写回
grid = [[0]]
grid[0] += [1]  # list 可变:原地改,写回的是同一个对象
```

- 是否原地修改取决于运算协议。名字上的 x += v 同样可能原地修改或绑定新对象；区别是没有容器下标的写回。
- 写回的是 `__iadd__` / `+` 的返回值，所以返回 `None` 的 `__iadd__` 会把元素写成 `None`。
- `d[k] += 1` 要先通过 `__getitem__` 读到值。普通 `dict` 缺键时直接抛 `KeyError`；`defaultdict(int)` 的这一步能够成功，是因为 `__getitem__` 会先补上默认值。取得值并完成加法后，再通过 `__setitem__` 写回结果。

## 函数

函数给一段处理逻辑起名，调用时传入参数，结束时返回结果。读函数接口时，也要看它是否修改外部状态；类型标注本身不执行输入校验。

### 先区分定义与调用

Python 执行 def 时创建函数对象，这时还不执行函数体。调用函数时，先计算传入的值，再交给对应参数，最后执行函数体。return 结束本次调用；不写 return 或只写 return，都会返回 `None`。

```python
def add(left: int, right: int = 1) -> int:
    return left + right

assert add(2) == 3
assert add(2, 4) == 6
assert add(right=4, left=2) == 6
```

位置实参按顺序绑定，关键字实参按名字绑定。同一个参数不能同时被位置与关键字赋值；缺少必填参数和传入未知关键字通常抛 `TypeError`。

### 参数种类与解包

```python
def describe(name, /, *scores, prefix="成绩", **labels):
    return name, scores, prefix, labels

result = describe("小明", 80, 90, prefix="分数", level="A")
assert result == ("小明", (80, 90), "分数", {"level": "A"})
```

上例中，各种参数的作用如下：

| 写法 | 怎样接收参数 |
|---|---|
| `/` 前的 name | 只能按位置传入 |
| `*scores` | 收集多余的位置参数，得到 tuple |
| `*scores` 后的 prefix | 只能按关键字传入 |
| `**labels` | 收集剩余的关键字参数，得到 dict |

args、kwargs 只是惯例名称，星号才决定收集或展开参数的行为。

定义里的星号负责收集；调用里的星号负责展开：

```python
def add(left, right):
    return left + right

values = [2, 3]
options = {"left": 4, "right": 5}
assert add(*values) == 5
assert add(**options) == 9
```

字典展开的键要能作为相应关键字参数使用，重复绑定仍会报错。

### 默认值为什么不能随意使用可变对象

Python 执行 def 定义函数时，就会算好默认值。以后调用函数，不会重新计算这个默认值。

```python
def append_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

assert append_item(1) == [1]
assert append_item(2) == [2]
```

把 `items=None` 改成 `items=[]`，默认列表就可能被多次调用共享。只想为缺失参数创建新列表时，使用 `items is None`；如果写成 `if not items`，调用方传入的空列表也会被替换。

### 返回多个值与函数作为值

`return a, b` 实际返回一个元组，调用方可以用 `x, y` 解包。函数也能作为参数或返回值，例如 `sorted(items, key=func)` 把函数交给排序过程调用。注意写法的区别：`key=func` 传的是函数，`key=func()` 传的是执行 func 后得到的结果。

lambda 只能写单个表达式，常用于简短排序键。逻辑复杂或需要说明时，用普通 def。

### 返回新对象与修改输入

函数接收到列表后，可以读取它并返回新列表，也可以直接修改它。下面的推导式创建新列表，输入保持原样；位置调用与关键字调用绑定的是同一个参数。

```python
def squared(values: list[int]) -> list[int]:
    return [value * value for value in values]

numbers = [-2, 0, 3, 3]
result = squared(numbers)
assert result == [4, 0, 9, 9]
assert numbers == [-2, 0, 3, 3]
assert result is not numbers
assert squared(values=numbers) == result
assert squared([]) == []
```

## 作用域与闭包

普通函数中，名字通常依次从当前函数、外层函数、当前模块和内置名称中查找，简称 LEGB：Local → Enclosing → Global → Builtin。类体等作用域另有规则，不能把所有名称查找都套成同一条链。

- 只要函数里有对某个名字赋值的语句，Python 通常就把它当作这个函数的局部变量，语句不必已经执行。在给它赋值前读取它，可能报 `UnboundLocalError`。global/nonlocal 可以改变这条规则，让赋值更新外层变量；修改已有列表的内容，则不一定需要它们。
- 闭包捕获的是**变量**，不是当时的值：

```python
functions = [lambda: i for i in range(3)]
assert [function() for function in functions] == [2, 2, 2]

functions = [lambda i=i: i for i in range(3)]
assert [function() for function in functions] == [0, 1, 2]

def make_counter():
    count = 0

    def increment():
        nonlocal count
        count += 1
        return count

    return increment

counter = make_counter()
assert (counter(), counter()) == (1, 2)
```

第一个列表中的三个函数共享同一个外层 i，调用时循环已结束，因此都读到 2。第二个列表用默认参数在每次定义函数时保存当前 i，所以分别返回 0、1、2。make_counter 返回的 increment 保留 count，nonlocal 让赋值更新这个外层绑定，因此连续调用得到 1 和 2。

闭包保留引用时，相关对象可能在外层函数返回后仍然存活；缓存和长生命周期回调需要注意内存占用。

## 类与对象

### 类定义行为，实例保存各自的状态

```python
class Counter:
    def __init__(self, start: int = 0) -> None:
        self.value = start

    def increment(self) -> None:
        self.value += 1

first = Counter()
second = Counter(10)
first.increment()
assert first.value == 1
assert second.value == 10
```

first 从 0 开始，second 从 10 开始；increment 只修改调用它的那个实例，所以两者最终分别为 1 和 10。

`Counter(...)` 创建实例，初始化时调用 `__init__`。`first.increment()` 中的 `self` 指向 first；换成 second 调用，`self` 就指向 second。调用者不用手动传 `self`。

start 是这次函数调用的参数，`self.value` 是保存在实例上的属性，后续方法仍能访问它。`__init__` 的 `-> None` 表示这个方法返回 None；`Counter(...)` 返回的仍是创建出的实例。

`_value` 这种单下划线名字表示内部使用的约定，不会禁止外部访问。像 `__init__` 这样以双下划线开头和结尾的方法有特定用途，Python 会在相应操作中调用它们。

### 属性读取和方法调用要分清

`counter.value` 读取属性，`counter.increment()` 调用方法。括号表示调用；只写 `counter.increment` 得到绑定方法对象，不执行方法体。

在普通属性赋值中，`self.closed = True` 只记录状态，关闭文件或连接需要调用相应方法。若类通过 property 等机制自定义了赋值行为，则按该实现执行。

### 定义类和创建实例发生在不同时间

执行 class 语句时，Python 先执行类体，再创建类对象。定义 `__init__` 时还没有创建或初始化实例，直到随后调用 Counter(...) 才开始这个过程。类属性属于类，在 `__init__` 中通过 `self` 设置的属性通常属于实例。

### 类属性中的可变对象

类体中的列表在定义类时创建。下面两个实例都没有自己的 history 属性，读取时找到同一个类属性，因此通过其中一个实例追加元素，另一个也能看到。需要各自保存历史时，应在 `__init__` 中写 `self.history = []`。

```python
class SharedHistory:
    history: list[int] = []

first = SharedHistory()
second = SharedHistory()
first.history.append(1)
assert second.history == [1]
assert first.history is second.history
```

### 继承与特殊方法

```python
class Point:
    kind = "point"  # 类属性,所有实例共享

    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

class Circle(Point):
    def __init__(self, x, y, r):
        super().__init__(x, y)
        self.r = r

circle = Circle(1, 2, 3)
assert (circle.x, circle.y, circle.r) == (1, 2, 3)
assert repr(circle) == "Point(1, 2)"  # 继承的表示方法没有展示半径。
```

- `self` 是显式参数；`__new__` 创建并返回实例，`__init__` 在已有实例上初始化状态。
- 不可变类型、元类或要控制实例创建时才重写 `__new__`；重写时必须正确处理父类和返回值，否则实例可能未创建或类型不匹配。
- 普通实例通常用 `__dict__` 保存属性；`__slots__` 可改变存储并限制属性，继承关系可能让实例仍有 `__dict__`。
- 常用魔术方法：`__repr__`、`__str__`、`__eq__`、`__hash__`、`__len__`、`__iter__`、`__getitem__`、`__enter__` / `__exit__`。
- 类定义 `__eq__` 却未提供 `__hash__` 时，实例通常会变为不可哈希。自行提供哈希方法时，无论对象是否可变，都要保证相等对象的哈希值相同，而且哈希值在对象生命周期内不变。
- MRO 是方法解析顺序，即 Python 在继承关系中查找方法的顺序；`super()` 沿这个顺序继续查找。
- `@property` 让方法以属性形式访问，可加校验。

### 实例方法、类方法与静态方法

```python
class Person:
    def __init__(self, name: str) -> None:
        self.name = name

    def greeting(self) -> str:
        return f"你好，{self.name}"

    @classmethod
    def from_text(cls, text: str):
        return cls(text.strip())

    @staticmethod
    def valid_name(text: str) -> bool:
        return bool(text.strip())

person = Person.from_text("  小明  ")
assert person.greeting() == "你好，小明"
assert Person.valid_name(" ") is False
```

实例方法自动接收 `self`，可以读取或修改这个实例。类方法自动接收 `cls`；上例通过 cls 创建实例，子类调用这个类方法时，就会创建子类实例。静态方法不自动接收实例或类，只处理显式参数。函数与类关系不强时，也可以直接放在模块中。

### property、继承与组合

读取 `obj.area` 时，property 会调用 area 的取值方法，按当前宽高计算面积。结果没有单独存成实例属性，每次读取都会重新计算，也会花费相应的时间。

```python
class Rectangle:
    def __init__(self, width: float, height: float) -> None:
        self.width = width
        self.height = height

    @property
    def area(self) -> float:
        return self.width * self.height

rect = Rectangle(3, 4)
assert rect.area == 12
rect.width = 5
assert rect.area == 20
```

继承表达子类型关系，并可复用或重写行为；super() 沿方法解析顺序继续查找。组合则将另一个对象保存为属性，由它承担部分工作。选择继承时，先检查调用方能否合理地将子类当作父类使用，再考虑代码复用。

## 异常

try 放需要处理错误的代码，except 处理匹配的异常。else 只在 try 正常走到结尾时执行；通过 return、break、continue 或异常离开 try，都不会进入 else。

try 正常结束，或通过 return、break、continue、异常离开时，finally 都会执行。进程被强制终止等情况下，则不保证执行。

- 自定义异常继承 `Exception`，不要继承 `BaseException`。
- 不带异常类型的 `except:` 还会捕获 `KeyboardInterrupt` 等退出信号。通常应捕获具体异常；确需处理较宽范围的普通错误时，可使用 `except Exception:`。
- `raise ... from error` 在转换异常时保留原始原因。在异常处理器中只写 `raise`，则继续传播当前异常。

```python
try:
    int("abc")
except ValueError as error:
    assert isinstance(error, ValueError)
else:
    raise AssertionError("无效输入不应转换成功")
finally:
    cleaned = True
assert cleaned is True
```

else 只在 try 正常结束时运行，finally 用于退出清理。不要在 finally 中随意 return，它可能覆盖原返回值，或让正在传播的异常不再抛出。

- 只捕获这一层能够处理的异常。参数错误、依赖失败、权限拒绝和超时等**可预期结果**，用约定好的异常类型或错误码告诉调用方，原始异常和上下文留在内部记录。如果错误说明程序内部状态已经不符合设计假设，就让异常继续抛出，别当作正常业务失败处理。
- 重试前先判断操作是否幂等，不要把有副作用的失败直接重放。
- 3.11+ 用 `ExceptionGroup` 和 `except*` 处理并发中的多个异常。

### 异常转换与原因链

`raise 新异常 from 原异常` 可以向调用方提供更明确的错误说明，同时保留底层原因。下面的函数用 int 转换文本；无效文本抛出 ValueError，成功得到的 0 仍是有效结果。`__cause__` 保存显式关联的原异常。

```python
def parse_integer(text: str) -> int:
    try:
        return int(text)
    except ValueError as error:
        raise ValueError("请输入有效的整数文本") from error

assert parse_integer(" 12 ") == 12
assert parse_integer("0") == 0
assert parse_integer("-3") == -3

for text in ["", "abc", "12.5"]:
    try:
        parse_integer(text)
    except ValueError as error:
        assert str(error) == "请输入有效的整数文本"
        assert isinstance(error.__cause__, ValueError)
    else:
        raise AssertionError("无效文本应被拒绝")
```

## 模块与包

- 一个 .py 文件通常对应模块；常规包使用 `__init__.py`，命名空间包则可以没有该文件。
- `if __name__ == "__main__":` 区分“被导入”和“直接运行”。
- 模块初始化可能执行顶层代码；避免在导入时隐式启动任务、连接外部服务或修改数据。
- 相对导入 `from . import x` 只能在包内使用。
- 循环导入常与模块相互依赖有关。可以检查职责和依赖方向，具体见[工程基础](04_工程基础.md)；延迟导入有时有用，也可能只是暂时绕开结构问题。

### import 绑定的是什么

```python
import math
from math import sqrt as square_root

assert math.sqrt(9) == 3
assert square_root(16) == 4
```

`import math` 让 math 指向模块，`from math import sqrt` 让 sqrt 指向模块导出的对象。通常首次导入会执行模块顶层代码，后续导入复用 sys.modules 中的模块。显式重载，或同一文件以另一个模块名加载时，顶层代码可能再次执行。

`python file.py` 直接运行文件。`python -m package.module` 按模块搜索路径找到它，再作为主模块运行，同时保留所属包的信息，模块内的相对导入因此可以正常工作。导入搜索受解释器、启动方式和 sys.path 等影响；不要用 json.py、typing.py 等名字遮蔽你要导入的库。

## 数值边界

整数大小受可用资源限制，浮点数则有固定的表示范围。Python 能保存 `10**1000` 这样的整数，但执行 `float(10**1000)` 会抛 `OverflowError`。以“分”为单位存储的整数金额可以直接做整数运算，避免浮点转换。

- `int` 任意精度。`float` 有精度误差，`0.1 + 0.2 != 0.3`；十进制计算可用 `decimal.Decimal`，有理数可用 `fractions.Fraction`。Decimal 通常应从字符串构造，例如 `Decimal("0.1")`；`Decimal(0.1)` 会保留已有二进制浮点值的误差。
- `float("inf")` 和 `float("-inf")` 表示正负无穷。比较数值使用 `==`，而不是 `is`。无穷可用作极值搜索的初值；遇到 `NaN` 时则需单独处理。
- 无穷参与某些运算会得到 `NaN`，例如 `inf - inf`、`inf * 0`。`NaN` 与自身也不相等，判断时通常使用 `math.isnan()`。
- `NaN` 不适合作为普通排序或极值搜索的占位值。最大的有限浮点数是 `sys.float_info.max`，约为 `1.798e308`，它仍小于正无穷。

## 嵌套列表与多维结构

Python 的 list 可以用**嵌套列表**表达多维结构：二维就是列表的列表，三维就是列表的列表的列表，以此类推。

```python
rows, cols = 3, 4

grid = [[0] * cols for _ in range(rows)]  # 正确:每行都是新建的 list
grid[1][2] = 9  # 访问:先取行,再取列

bad = [[0] * cols] * rows  # 错误:所有行是同一个 list
bad[0][0] = 1  # 每一行都会跟着变
```

- 内层 `[0] * cols` 本身是安全的(元素是不可变的 `0`)；出问题的是**外层**用 `*`。
- 如果希望各元素相互独立，就不要用乘法重复可变对象。例如，创建多个独立空列表应写成 `[[] for _ in range(cols)]`。
- 遍历可以双重循环，也可以直接 `for row in grid` 取整行。
- `len(grid)` 是行数，`len(grid[0])` 是列数，前提是至少有一行且每行等长。
- 明确各维度的含义，并保持索引顺序一致。例如，表示表格时可以约定 `grid[row][column]`。
- 对稀疏结构，可以用坐标元组作为字典键，只保存存在的数据；不必为不存在的单元分配完整矩阵。
- 需要矩阵运算或多维切片时，可以使用 `numpy.ndarray`。它提供专门的数组存储和运算接口，不等同于嵌套列表。

### 三维及更高

```python
r, c, d = 2, 3, 4

cube = [[[0] * d for _ in range(c)] for _ in range(r)]
cube[1][2][3] = 9  # 下标一层一层往下取
```

- 用 `*` 重复一个列表，只会重复引用，多个位置仍指向同一个内层对象。最里层的数字不可变，可以用 `*` 初始化。
- 维度较多时，嵌套推导式不容易阅读。可以写递归工厂函数，将每一层的创建规则集中起来：

```python
def zeros(*dims):
    if not dims or any(type(size) is not int or size < 0 for size in dims):
        raise ValueError("dimensions must be non-negative integers")
    if len(dims) == 1:
        return [0] * dims[0]
    return [zeros(*dims[1:]) for _ in range(dims[0])]

grid = zeros(2, 3, 4)
grid[0][0][0] = 9
assert grid[1][0][0] == 0  # 不同层级创建了独立的列表。
assert zeros(0, 3) == []
```

- 遍历所有下标用 `itertools.product(range(r), range(c), range(d))`，比手写多层循环清楚。
- NumPy 支持 `arr[i, j, k]` 这样的多维索引，并提供广播、向量化运算等能力。是否采用它，应根据数据规模和实际运算需求决定。

## 把语言机制用于订单记录

下面把容器、推导式和函数放在一起：输入订单记录，返回当前用户可见的订单号。筛选不修改原记录，去重保留首次出现的次序，其他字段不进入结果。

```python
def visible_order_ids(records: list[dict], tenant: str) -> list[str]:
    return list(dict.fromkeys(
        row["id"] for row in records if row["tenant"] == tenant
    ))

records = [
    {"id": "A", "tenant": "demo"},
    {"id": "X", "tenant": "private"},
    {"id": "A", "tenant": "demo"},
]
assert visible_order_ids(records, "demo") == ["A"]
assert len(records) == 3
```

推导式负责筛选，字典保留首次出现的键。示例假定记录结构正确，缺少 tenant 字段会抛 KeyError。接收外部记录时，先检查必需字段和类型；传给函数的租户身份则从可信认证入口取得，拿不到就报错或拒绝访问，见[Pydantic](专题_Pydantic.md)与[后端服务](05_后端服务.md)。
