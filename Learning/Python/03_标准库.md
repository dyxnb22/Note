# 03 标准库

## 输入输出与命令行参数

input() 返回字符串，数值需显式转换；print() 展示值，不把展示文本当作结构化数据本身。下面的 argparse 示例用固定列表模拟命令行，无需等待人工输入：

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("name")
parser.add_argument("--times", type=int, default=1)
args = parser.parse_args(["小明", "--times", "2"])
assert args.name == "小明"
assert args.times == 2
```

name 是必填位置参数，--times 是可选参数，type=int 负责转换。实际脚本通常调用不带列表的 parse_args()，从进程命令行读取；非法参数由解析器报告。

相对路径以进程当前工作目录为起点，不自动相对脚本文件。`Path.cwd()` 查看工作目录；脚本内确需相对源码定位时，可从 `Path(__file__).resolve().parent` 出发，但交互环境不一定有 `__file__`。

## 文件与路径(pathlib)

```python
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as directory:
    path = Path(directory) / "data" / "logs" / "app.log"
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text("hi", encoding="utf-8")
    assert path.read_text(encoding="utf-8") == "hi"
    assert path.exists() and path.is_file()
    assert path.suffix == ".log"
    assert path.stem == "app"
    assert path in list(Path(directory).glob("**/*.log"))
```

- 路径操作优先使用 `Path`，将拼接、后缀、父目录等含义写清楚。避免手动拼接分隔符，减少平台差异带来的问题。
- 文本读写显式给 `encoding="utf-8"`；二进制用 `read_bytes` / `write_bytes`。
- 路径校验不能只看字符串前缀：先 `Path.resolve()` 再比对根目录，否则会被 `..` 绕过；字符串前缀还会误伤同前缀路径(如 `/workspace` 匹配到 `/workspace-other`)，并要处理符号链接、大小写和校验后的变化。
- TOCTOU 指检查与实际使用之间，目标状态发生变化，导致先前检查失效。例如，路径检查通过后，符号链接可能已被替换。

涉及安全边界时，应根据平台使用文件描述符、原子操作或版本检查来缩小风险窗口。一次提前检查不能永久保证后续访问仍指向同一对象。

## 文件读写与 IO 边界

```python
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as directory:
    path = Path(directory) / "lines.txt"
    path.write_text("first\nsecond\n", encoding="utf-8")
    lines = []
    with path.open(encoding="utf-8") as file:
        for line in file:
            lines.append(line.rstrip("\n"))
    assert lines == ["first", "second"]
```

这里按行读取，但为了展示结果将所有行收集到了列表，所以整个示例仍会保留全部内容。真正的大文件处理通常在循环中消费并释放每一行，或分块读写。

- 二进制分块读：`f.read(64 * 1024)`。
- 每一层都要有上限：行长度、总字节数、响应体大小。
- 对外暴露的文件接口要防大文件拖垮服务(限大小、限并发、流式返回)。

## 原子写入

```python
import os
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as directory:
    target = Path(directory) / "message.txt"
    fd, temporary = tempfile.mkstemp(dir=target.parent)
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as file:
            file.write("complete")
        os.replace(temporary, target)
    finally:
        Path(temporary).unlink(missing_ok=True)
    assert target.read_text(encoding="utf-8") == "complete"
```

- 先写临时文件再 `os.replace`，避免读到写了一半的内容。
- 跨文件系统的替换通常无法按此方式原子完成。临时文件应位于目标所在文件系统，通常放在同一目录最方便；同一目录不是唯一可能的位置。
- 原子替换不等于跨文件事务，也不自动保证断电后的持久性；需要崩溃持久性时还需按平台设计 flush/fsync 等步骤。

## 文件摘要与版本

- `hashlib.sha256(data).hexdigest()` 做内容指纹，用于判断变化、做缓存键。
- 判断内容是否变化时，内容摘要通常比修改时间更直接。复制、检出或构建过程可能保留或重设 `mtime`，仅比较时间戳可能遗漏变化。
- 摘要表示某次读取到的内容；文件先变化再恢复原内容时，摘要也会恢复。若需要记录每次修改，应使用版本号或变更记录。

## json

```python
import json
from pathlib import Path
from tempfile import TemporaryDirectory

original = {"name": "小明", "scores": [80, 90]}
text = json.dumps(original, ensure_ascii=False)
assert isinstance(original, dict)
assert isinstance(text, str)
restored = json.loads(text)
assert isinstance(restored, dict)
assert restored == original and restored is not original

with TemporaryDirectory() as directory:
    path = Path(directory) / "person.json"
    assert not path.exists()
    path.write_text(text, encoding="utf-8")
    assert path.exists()
    loaded = path.read_text(encoding="utf-8")
    assert isinstance(loaded, str)
    assert json.loads(loaded) == original
```

dumps 将字典转换为 JSON 字符串，loads 将字符串解析为新的 Python 对象；它们不负责文件读写。write_text 才创建或覆盖文件，read_text 读回文本后仍需解析。这个例子中数据能等值往返，但元组会变为列表，字典中的非字符串键也可能改变，不能据此推断所有对象都能无损往返。

- 默认 `ensure_ascii=True` 会把中文转成转义序列，写给人看要关掉。
- `json.dumps()` 不能直接编码日期时间、集合等所有 Python 对象。需要先转换为支持的结构，或通过 `default` 明确规定序列化方式。
- 解析不可信输入要设大小上限；标准 JSON 不支持注释、尾逗号、NaN 和 Infinity。Python json 默认接受部分非标准数值，严格输出时使用 `allow_nan=False`，严格解析可通过 parse_constant 拒绝它们。

## datetime

```python
from datetime import datetime, timedelta, timezone

now = datetime.now(timezone.utc)  # 带时区
later = now + timedelta(minutes=30)
assert later - now == timedelta(minutes=30)
assert now.utcoffset() == timedelta(0)
assert now.isoformat().endswith("+00:00")
```

- naive 与 aware datetime 之间的排序比较和相减通常抛 `TypeError`；相等比较通常返回 `False`，并非所有比较都报错。时间线上的业务运算应明确时区。
- 表示已经发生的时间点时，通常以 UTC 存储和传输，展示时转换为目标时区。表示“某地每天九点”的日程还需要保留当地时区与日历规则，不能只保存一次换算后的 UTC 值。
- 按“业务日”统计要显式处理时区和日界，不要依赖服务器本地时间。ZoneInfo 可表示具有夏令时规则的地区时区；跨夏令时的当地时间加减可能不等于真实经过时长，需要经过时长时可先转 UTC。

## re

```python
import re

pattern = re.compile(r"[a-z]+")
assert pattern.fullmatch("hello") is not None
assert pattern.fullmatch("hello1") is None
assert pattern.fullmatch("hello\n") is None
```

- 重复使用的复杂模式可预编译；re 的模块级接口也有近期模式缓存，是否存在实际性能问题需测量。
- 验证完整输入优先用 fullmatch；^/$ 受多行模式和结尾换行等规则影响，不应直接认为所有锚点组合都等价。
- 某些正则在特定长输入上会出现大量回溯，导致处理时间急剧增加。应限制输入规模，并在必要时改用其他解析方式。
- 对 HTML、JSON 和日期等已有明确格式的输入，优先采用对应解析器。正则适合局部匹配，不应代替完整格式校验。

## collections

collections 提供常见的数据组织方式。Counter 聚合出现次数，defaultdict 可以在缺少键时创建默认容器，deque 适合从两端取放元素。

```python
from collections import Counter, defaultdict, deque

assert Counter(["a", "b", "a"])["a"] == 2

groups = defaultdict(list)
for name, kind in [("苹果", "水果"), ("梨", "水果")]:
    groups[kind].append(name)  # 第一次读取“水果”时自动创建列表。
assert dict(groups) == {"水果": ["苹果", "梨"]}

queue = deque(["先到", "后到"])
assert queue.popleft() == "先到"  # 从左侧取出，保持先进先出。
assert list(queue) == ["后到"]
```

- `deque`：两端 O(1) 插删，做队列和滑动窗口。
- `Counter`：计数、`most_common(n)`。
- `defaultdict`：分组时不必写 `setdefault`。
- `namedtuple`：用字段名访问的元组记录；dataclass 位于独立的 dataclasses 模块，用于定义数据类。
- 普通 dict 保留插入顺序；OrderedDict 另有高效重排、从两端弹出和自身顺序敏感比较等能力，按实际需求选择。

## itertools / functools

itertools 组合和变换迭代过程，通常按需产出结果；functools 则用于包装函数、预先绑定参数或缓存结果。

```python
from functools import partial
from itertools import chain, groupby

assert list(chain([1, 2], [3])) == [1, 2, 3]

groups = [(key, list(items)) for key, items in groupby("aaba")]
assert groups == [("a", ["a", "a"]), ("b", ["b"]), ("a", ["a"])]
# groupby 只合并相邻项；最后一个 a 不会回到第一组。


def multiply(left, right):
    return left * right


double = partial(multiply, 2)  # 先固定第一个参数，调用时再传第二个。
assert double(3) == 6
```

- `itertools`：`chain`、`islice`、groupby（只合并相邻同键元素；想按键做全量分组时通常先按相同键排序）、`product`、`count`。
- `functools`：`cache` / `lru_cache`(参数必须可哈希)、`partial`、`reduce`、`wraps`。

## os / sys / shutil / subprocess

- `os.environ` / `os.getenv("X", default)` 读环境变量。
- `sys.argv`、`sys.exit(code)`、`sys.path`。
- `shutil`：复制、移动、删目录树(`rmtree` 慎用)。
- 通常用 `subprocess.run([...], shell=False, capture_output=True, text=True, check=True, timeout=...)` 明确参数、输出、失败和超时语义；参数列表不能替代对目标程序选项和权限的校验。

## 调试相关

- `breakpoint()` / `pdb`：本地调试；线上靠日志和 trace。
- 在异常处理器中，`traceback.format_exc()` 可以保留完整调用栈。仅记录 `str(error)` 往往不足以定位错误发生的位置。
- 阅读 traceback 时，先看异常类型和消息，再沿调用链定位到相关代码。结合输入、配置和依赖响应判断原因，不要只根据最后一行猜测。
- 包装异常时使用 `raise ... from ...` 保留因果链；在异常处理器中继续传播当前异常，使用裸 `raise`。
- 排查时注意本地文件遮蔽标准库、虚拟环境不一致和错误处理代码二次失败。
- 难以复现的问题，应先保存输入、完整 traceback、版本与配置，再缩小为最小复现。
- 如果问题涉及随机、时间或并发，可固定随机种子、控制时钟或调度；修复后保留能复现原问题的测试。重启或重装环境可以帮助排查，但不能代替根因验证。
