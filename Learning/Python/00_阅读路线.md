# Python 阅读路线

这组笔记覆盖 Python 语法、工程和 Agent 开发。按自己的基础选一条路线，跟着案例运行代码，遇到具体问题再查专题。

## 首次接触 Python

先准备 Python 3.12 或更高版本。在终端执行：

```bash
python3 --version
python3 -c "print('Python 已就绪')"
```

第二条命令输出“Python 已就绪”。笔记中的 Python 代码可以保存为 .py 文件，在终端执行 python3 文件名.py。带 assert 的示例通常在检查通过时没有输出。

| 顺序 | 阅读位置 | 这一段解决什么问题 |
|---|---|---|
| 1 | [语言核心](01_语言核心.md)中的基本类型、变量与赋值、字符串与字节、容器、流程控制、函数 | 读懂值如何流过一段程序 |
| 2 | 同篇的异常、模块与包；[类型注解](02_语言进阶与异步.md#类型注解)的基本符号 | 读懂 import、失败路径、参数与返回类型 |
| 3 | [标准库](03_标准库.md)中的命令行参数、文件与路径、json | 把命令行和文件变成程序输入 |
| 4 | [完整案例：订单查询脚本](案例_订单查询脚本.md) | 把输入、读取、业务判断和输出连成可运行程序 |
| 5 | [工程基础](04_工程基础.md)中的代码分工、配置与异常处理 | 理解案例为何拆成入口与业务模块 |

类型注解先看懂 list[dict]、str 和 ->。Protocol、泛型、Self 与容器兼容性留到设计接口时再查；原地运算协议、描述符、复杂装饰器和数值极端情况也可以后读。

完整案例只依赖标准库，运行它无需安装包。开始使用 FastAPI、Pydantic 等第三方库时，再按[环境与依赖管理](专题_环境与依赖管理.md)创建项目环境。

## 已会其他语言，转学 Python

先读[语言核心](01_语言核心.md)中的名字与对象、可变对象、默认参数、解包、作用域、异常和导入。这些地方最容易把其他语言的习惯带进来。

[进阶篇](02_语言进阶与异步.md)继续讲迭代器、生成器、上下文管理器、dataclass 和类型注解。涉及并发时，再读线程／进程／协程的选择，以及 asyncio 的调度、取消和资源生命周期。

接着运行[订单查询脚本](案例_订单查询脚本.md)，看模块导入、pathlib、argparse、JSON 与异常处理怎样在一个程序里配合。项目组织、依赖和分发分别在[工程基础](04_工程基础.md)与[环境专题](专题_环境与依赖管理.md)中展开。

## 目标是后端或 Agent 开发

| 方向 | 主阅读顺序 | 按需深入 |
|---|---|---|
| 后端服务 | 函数、类型、异常 → [Pydantic](专题_Pydantic.md)的输入与输出 → [FastAPI](专题_FastAPI.md)的路由、依赖与生命周期 → [后端服务](05_后端服务.md) | 事务与幂等需要数据库基础；流式响应和后台任务在对应需求出现时阅读 |
| Agent 开发 | [订单查询脚本](案例_订单查询脚本.md) → [Python 中的 Agent 运行时](06_Agent开发.md) → [Agent 阅读路线](../Agent/00_02_阅读路线.md)与[订单 Agent 案例](../Agent/案例_订单查询Agent.md) | 完整案例使用同步调用；接入异步客户端时再阅读 asyncio 和取消传播 |
| 交付与运行 | 已有可运行程序 → [工程基础](04_工程基础.md)的安装产物 → [生产与交付](07_生产与交付.md) | 需要部署时，再读镜像构建、健康检查、退出清理、容量和回退 |
| 终端界面 | 函数、类、事件与异步基础 → [Textual 与 TUI](专题_Textual与TUI.md) | Worker、响应式状态和迟到结果处理 |

Pydantic 专题先读“模型的输入与输出 → 模型定义 → 校验入口 → ValidationError → 序列化”。别名、复杂验证器、继承和性能配置按需查阅。

## 读完案例以后去哪里
