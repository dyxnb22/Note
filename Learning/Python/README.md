## 示例与验证边界

语法以 Python 3.12 为主要基线。独立 Python 示例优先使用临时目录和内存响应桩，避免依赖日常数据或外部网络。只定义类或函数不代表其全部行为已被测试；阅读时也要查看断言。

框架专题需要先安装对应依赖，但不要求一次安装全部框架。已使用的验证样本包括 Pydantic 2.14.1、FastAPI 0.156.4、Textual 8.2.8 和 pydantic-settings 2.16.1。Bash、YAML、部署流程与其他依赖版本未做穷尽验证。
