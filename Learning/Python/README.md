# Python

本模块按用途分为三条路径：学习路线讲知识与练习方法，复习速查用主题速答卡，实践目录放可运行练习。遇到同一主题时，以学习路线作为系统学习入口。

## 进入方式

- 系统学习教程：按 [Python 学习路线](./学习路线/README.md) 从语言核心走到后端与 Agent 开发。
- 复习与答题：主题 30 秒速查用 [主题速答卡](./学习路线/00_主题速答卡.md)，复习路线与答题模板见 [00 复习路线与答题模板](./学习路线/00_复习路线与答题模板.md)。
- 编码与项目表达练习：[08 编码题与项目深挖](./学习路线/08_编码题与项目深挖.md)。
- 环境与依赖管理专题：[Python 环境与依赖管理](./学习路线/专题_环境与依赖管理.md)。
- 可运行练习：进入 [Python 基础练习](./实践/Python基础练习/README.md)。
- Agent、RAG 和工具协议：进入 [Agent 模块](../Agent/README.md)。

实践目录下的练习和 Notebook 保持独立。

## 实践验收

- 在 Python 基础练习和 Notebook 中验证语法、对象、容器和控制流。
- 在 [08 编码题与项目深挖](./学习路线/08_编码题与项目深挖.md) 的练习中，用干净虚拟环境执行格式、lint、`python -m mypy src`（适用时）和测试；命令与 Python/依赖版本应写入项目合同。
- FastAPI、异步任务和外部模型调用要用测试服务器、Fake/Mock 和可控事件验证超时、取消、重试、重复副作用和资源释放。
