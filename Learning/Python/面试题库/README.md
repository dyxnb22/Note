# Python 面试题库

这是一份 Python 面试题库，按“题目 → 答案 → 追问 → 验证”组织。

## 推荐顺序

1. [[00_复习路线与答题模板]]、[[00_主题速答卡]]
2. [[01_语言与运行时]]：对象、容器、函数、异常、迭代器、GIL、asyncio、GC 和性能。
3. [[02_工程与Web]]：工程组织、配置、HTTP、FastAPI、数据库、缓存、任务和观测。
4. [[03_编码题与项目深挖]]：算法、异步并发、限流、任务服务和项目表达。

## 覆盖范围

- 语言：对象、容器、函数、异常、模块、迭代器、生成器和异步。
- 运行时：CPython、GIL、引用计数、GC、内存和性能分析。
- 工程：依赖、配置、HTTP、FastAPI、数据库、缓存、任务、测试和观测。
- 表达：算法、并发、系统设计、调试和项目深挖。

## 答题边界

- 语言语义、CPython 实现、框架行为和项目约束要分开说。
- 版本和性能结论必须用目标环境的实验、测试和指标验证。
