# Python 主题速答卡

| 主题 | 30 秒回答 |
|---|---|
| 可变性 | 变量是名称绑定；list/dict/set 可变，str/int/tuple 通常不可变。多个名称指向同一可变对象时原地修改会互相可见，接口要明确所有权和复制语义。 |
| 深浅拷贝 | 浅拷贝只复制外层，深拷贝递归复制但成本高且不适合所有资源。优先用不可变数据、明确构造或按字段复制。 |
| `is`/`==` | `is` 比较身份，`==` 比较值；判断 `None` 用 `is None`。不要依赖小整数/字符串驻留让错误的身份比较偶尔通过。 |
| 迭代器/生成器 | 可迭代对象能产生迭代器，迭代器用 `__next__` 取值，生成器是惰性迭代器。它降低峰值内存，但通常只能消费一次。 |
| 装饰器 | 装饰器接收函数并返回包装函数，适合日志、计时、权限、重试和缓存；要保留元数据并处理同步/异步、异常和副作用。 |
| GIL | CPython 同一解释器通常只有一个线程执行 Python 字节码，限制纯 Python CPU 并行；I/O、释放 GIL 的扩展、多进程仍可并发。GIL 不等于线程安全。 |
| 引用计数/GC | 引用计数快速回收无引用对象，循环引用由 GC 处理；内存释放给分配器不等于 RSS 立即下降，要用 tracemalloc/profile 定位。 |
| asyncio | 协程在 `await` 处让出控制权，事件循环调度 I/O；不能在其中执行长阻塞调用，Task 要有超时、取消、并发上限和异常管理。 |
| HTTP 重试 | 只对明确的瞬时错误重试，带超时、退避、抖动和幂等键；超时后的副作用可能未知，必要时查询或对账。 |
| FastAPI | FastAPI 负责协议、解析和依赖注入，业务层负责授权、状态机和一致性；依赖生命周期、连接池和端点测试需要显式设计。 |
| Pydantic/DTO | Pydantic 负责外部数据的结构和类型校验，DTO 通过校验后再转换成领域命令；Schema 合法不等于有权限、资源存在或副作用成功。 |
| SSE/WebSocket | SSE 是服务端到客户端的单向事件流，适合进度/Token 推送；WebSocket 是双向会话。两者都要处理事件 ID、断线重连、去重、取消和最终状态持久化。 |
| LLM 外部调用 | 超时只代表当前等待结束，不能证明模型没有执行；按预算、幂等键、Provider request ID、状态查询和对账处理重试与计费未知。 |
| pytest | fixture/conftest 管理资源生命周期，Mock/Fake 替换外部边界；异步测试要用可控时钟、事件和测试服务器，不能靠随机 sleep。 |
| 性能排查 | 先固定负载和基线，区分 CPU、I/O、序列化、连接池和下游，再用 profiler/trace 定位，优化后复测 P95、资源和错误率。 |
