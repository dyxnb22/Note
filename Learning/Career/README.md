# Career

这里把技术学习转成求职、面试、晋升和长期成长的可执行方法。

本目录按当前职业问题使用，不形成连续课程：准备求职看招聘和项目表达，进入新团队看协作与 30/60/90 天，考虑长期方向再看能力闭环。已经发生过的真实经历和项目证据优先于模拟练习。

- [学习路线与能力闭环](./学习路线与能力闭环.md)：基础、系统设计、AI、工程化和输出顺序。
- [面试与招聘](./面试与招聘.md)：技术面、综合面、HR 面、简历和 offer 判断。
- [职场经验与成长](./职场经验与成长.md)：39 条职场材料的去重提炼。
- [项目表达](./项目表达.md)：业务目标—难点—方案—权衡—结果证据。
- [职业发展全流程](./职业发展全流程.md)：简历与作品集、求职漏斗、面试、offer、入职 30/60/90 天、晋升和裁员应对。
- [团队协作、项目管理与技术领导](./团队协作、项目管理与技术领导.md)：目标、依赖、授权、分歧、风险和复盘。

项目表达必须回链到 [Case Studies](../Case_Studies/README.md)，只写实际阅读、审计或复现过的内容。
