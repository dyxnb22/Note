# Java 后端

本目录是 Java 后端路线入口；具体知识统一按“题目 → 答案 → 追问/验证”维护在 Java 面试题库中。

版本基线（2026-07-30）：JDK 25 已于 2025-09-16 GA；LTS 支持期限由具体发行商定义。现有项目仍应按框架兼容性选择 17、21 或 25，不要只为追新升级。版本状态以 [OpenJDK 发布页](https://openjdk.org/projects/jdk/) 和目标发行商支持策略为准。

## 进入方式

- 面试与系统化复习：先读 [Java 面试题库](./面试题库/README.md)。
- 语言、JVM、集合、并发、Spring、Tomcat、数据访问和日志问题，都在题库中按问答形式组织。
- 数据库、分布式、部署、测试和跨语言可靠性回到 [Backend](../README.md) 的公共能力目录。

## Java 的边界

- Java 特有的语言、Runtime、JVM、Spring、Maven 和 Java 客户端放本目录。
- 数据库本身、消息系统、分布式一致性和生产交付方法不复制到 Java，使用公共后端正文。
- Java 实践项目出现后，放入本目录的 `实践/`；可迁移结论再回链到公共能力或案例目录。
