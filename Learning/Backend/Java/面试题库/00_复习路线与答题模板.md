# Java 面试复习路线与答题模板

## 复习路线

1. 语言、对象模型、异常和集合。
2. JVM、类加载、GC、线程和 JMM。
3. I/O、网络、线程池、并发容器和锁。
4. Spring Core、Web、Boot、数据访问和 Cloud。
5. Maven、Tomcat、日志、调试、部署和系统设计。

## 统一答题模板

回答 Java 问题时按以下顺序：

1. **先给结论**：一句话说明它解决什么问题。
2. **解释机制**：说明调用链、状态变化、内存/线程或框架生命周期。
3. **说明取舍**：何时适用、何时失效、有什么成本。
4. **补工程边界**：版本兼容、异常处理、资源释放、观测和测试。
5. **给验证方式**：用最小代码、JFR/线程 dump、基准、集成测试或故障演练证明。

## 面试前检查

- 能解释一次请求从 Spring Web 入口到数据库提交的链路。
- 能说明线程池、锁、事务和连接池的边界，而不是只背 API 名称。
- 能把一次 JVM/GC/慢请求问题拆成现象、证据、假设、验证和修复。
- 能区分 Java 特有问题与 Backend 公共能力，不重复维护两套答案。
