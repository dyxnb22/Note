# Java 主题速答卡

## Java 的核心优势是什么？

答：Java 用静态类型、自动内存管理、成熟的 JVM 和庞大的服务生态降低大型后端的交付与维护成本；代价是运行时、框架和垃圾回收带来额外复杂度。面试时不要只说“跨平台”，还要说明字节码、JIT、生态和诊断工具如何共同形成工程优势。

## JVM、JUC 和 Spring 如何分工？

答：JVM 负责字节码执行、内存和垃圾回收；JUC 提供线程安全、同步、并发容器和线程池；Spring 负责对象组装、Web 请求、事务和应用扩展。排障时先判断问题属于执行运行时、并发语义还是框架生命周期，避免把所有问题都归因于 Spring。

## Java 后端题怎么回答？

答：先给结论，再解释机制，然后说明版本、边界和失败路径，最后补一个可验证的例子。涉及并发、事务、缓存或框架时，要把业务不变量、线程模型、资源释放和观测证据说完整。
