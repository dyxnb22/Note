## 覆盖范围

- 语言与 Runtime：类型、异常、反射、集合、JVM 和 GC。
- 并发与服务：JUC、线程池、I/O、网络线程模型和 Spring Web。
- 框架与数据访问：Spring、Spring Boot、Spring Cloud、JDBC、MyBatis、JPA。
- 工程与排障：Maven/Gradle、Tomcat、日志、可观测性、调试和生产问题定位。
