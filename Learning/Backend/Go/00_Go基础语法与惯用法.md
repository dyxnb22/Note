# Go 基础语法与惯用法

这篇补齐从“会其他语言”到“能写出符合 Go 习惯的程序”的入口。它不重复 Runtime、并发和服务工程专题；完成本篇后，继续学习 [01_Go语言与Runtime](./01_Go语言与Runtime.md) 和 [02_Go并发与内存模型](./02_Go并发与内存模型.md)。

## 1. 程序、Package 与入口

一个目录中的普通 `.go` 文件属于同一个 package。可执行程序使用 `package main` 并提供 `main` 函数：

```go
package main

import "fmt"

func main() {
	message := "hello, Go"
	fmt.Println(message)
}
```

导出的标识符以大写字母开头；小写标识符只在当前 package 内可见。Package 名应短、清楚，不把 `util`、`common` 当作默认垃圾桶。

## 2. 变量、零值与控制流

Go 的变量声明强调零值可用：数值是 `0`，布尔值是 `false`，字符串是 `""`，指针、Slice、Map、Channel、函数和 Interface 的零值是 `nil`。

```go
var retries int
var enabled bool
name := "agent-api" // 只可在函数内使用 :=

if retries == 0 && !enabled {
	fmt.Println(name)
}
```

Go 只有一种循环关键字 `for`。`switch` 默认不贯穿下一个分支；需要类型分派时使用 type switch。错误通常通过提前返回处理，避免把主路径埋进多层缩进。

## 3. Array、Slice、Map 与 String

- Array 的长度属于类型，`[3]int` 与 `[4]int` 不同。
- Slice 是对底层数组的视图，包含指针、长度和容量；`append` 后必须使用返回值。
- Map 读取不存在的键会得到零值；需要区分“不存在”时使用 `value, ok := m[key]`。
- String 是只读字节序列；按 Unicode code point 遍历使用 `range`，按字节处理使用索引或 `[]byte`。

```go
numbers := make([]int, 0, 4)
numbers = append(numbers, 1, 2)

counts := map[string]int{"go": 1}
count, exists := counts["rust"]
fmt.Println(count, exists) // 0 false

for index, r := range "Go语言" {
	fmt.Printf("%d: %c\n", index, r)
}
```

对外返回 Slice 或 Map 时要说明调用者能否修改；不能共享底层数据时显式复制。Map 的遍历顺序不稳定，测试和序列化逻辑不能依赖它。

## 4. Struct、方法与指针

Struct 表达数据和不变量，方法表达围绕该类型的行为：

```go
type Account struct {
	ID      string
	Balance int64
}

func (a *Account) Deposit(amount int64) error {
	if amount <= 0 {
		return fmt.Errorf("deposit must be positive")
	}
	a.Balance += amount
	return nil
}
```

接收者选择保持一致：需要修改、避免复制或类型本身包含同步原语时通常使用指针接收者；小型不可变值可以使用值接收者。指针不等于“面向对象引用”，也不应作为默认性能优化。

## 5. Interface、组合与泛型

类型不需要声明“实现”某个 Interface；只要方法集满足要求即可。Interface 应在使用方定义，并保持最小：

```go
type UserFinder interface {
	FindByID(ctx context.Context, id string) (User, error)
}
```

Go 倾向组合而不是继承。Struct 嵌入可以提升方法，但嵌入不表示业务上的 `is-a` 关系。泛型适合容器、算法和类型安全复用；业务能力边界仍优先用小 Interface 或普通函数表达。

## 6. Error、Defer、Panic 与资源

Error 是普通返回值。增加上下文时使用 `%w` 保留错误链，判断语义使用 `errors.Is` 或 `errors.As`：

```go
user, err := store.FindByID(ctx, id)
if err != nil {
	return User{}, fmt.Errorf("find user %q: %w", id, err)
}
```

获得资源后尽快安排释放，但先确认资源确实创建成功：

```go
response, err := client.Do(request)
if err != nil {
	return err
}
defer response.Body.Close()
```

`panic` 用于程序不变量被破坏或无法继续的初始化错误，不用于普通业务失败。`recover` 只能在同一 Goroutine 的延迟函数中捕获 Panic；服务入口可以记录并隔离单次请求，但不能假装状态仍然可靠。

## 7. Module、依赖与工具链

```bash
go mod init example.com/hello
go mod tidy
gofmt -w .
go vet ./...
go test ./...
go test -race ./...
```

`go.mod` 定义模块身份和最低语言版本。`internal/` 限制模块外导入；`cmd/<name>/` 放可执行入口。公共 API 尽量不暴露第三方库类型，避免依赖升级扩散到所有调用方。

提交前至少运行格式化、静态检查和测试。依赖安全检查使用 `govulncheck`；升级语言或依赖后重新执行测试、Race 和关键 Benchmark。

## 8. 从 Java/Python 迁移时的常见误区

| 误区 | Go 中更合适的做法 |
|---|---|
| 为每层都创建大 Interface | 由调用方定义小 Interface，只抽象真实替换边界 |
| 用异常表达所有失败 | 返回 Error；只在不可继续的不变量失败时 Panic |
| 每个对象都用构造函数和指针 | 优先零值可用；只有强制不变量时创建构造函数 |
| 启动 Goroutine 后不管理 | 明确所有者、取消、错误传播和最大数量 |
| 把框架类型传入领域层 | 在 Handler 边界转换为内部类型 |
| 看到分配就提前优化 | 先用 Benchmark、pprof 和真实负载定位热点 |

## 9. 正式学习练习

### 练习 A：文本统计 CLI

读取 UTF-8 文本，输出行数、字节数、字符数和词频前十。测试空输入、中文、非法路径和超大行；明确 Map 排序方式和文件关闭路径。

### 练习 B：带超时的 HTTP Client

调用一个 JSON API，设置整体超时和响应体上限，区分网络错误、非 2xx、非法 JSON 与 Context 取消。使用 `httptest.Server` 覆盖成功、超时和超大响应。

### 练习 C：内存 Todo Service

使用 Struct、方法、小 Interface 和 Error 完成创建、查询、完成 Todo；并发访问前先写清所有权，再选择 Mutex 或单 Goroutine 管理。

## 10. 验收标准

- 能解释零值、Slice 共享、Interface nil、值/指针方法集和 Error 链。
- 能创建 Module、组织 Package，并独立运行格式化、静态检查、测试和 Race。
- 写出的程序有正常路径、错误路径、资源释放和取消测试。
- 能说明为什么某个边界使用 Interface，而不是为了“看起来解耦”。
