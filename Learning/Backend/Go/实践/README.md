# Go 实践

这里放 Go 语言和后端工程的可运行练习；稳定机制回写上级主题文档，运行环境、代码、测试和实验结果保留在具体项目中。

## 当前项目

- [go-backend-service](./go-backend-service/README.md)：订单服务阶段 0 基线，覆盖标准库 HTTP、分层、内存幂等、请求超时、错误响应、Race 测试和优雅关闭。

## 推进规则

1. 按 [Go 后端项目实战](../05_Go后端项目实战.md)从阶段 0 推进到 PostgreSQL、下游可靠性、观测、性能与交付。
2. 每个阶段记录 Go/依赖版本、运行命令、预期结果、失败样本和未验证边界。
3. 数据库、消息、容器和负载实验使用固定环境；不把本机一次通过泛化为生产结论。
4. 同一订单项目持续演进，不为每个知识点创建新的演示仓库。

整体学习顺序见 [Go README](../README.md) 和 [Rust Agent 与 Go 后端学习地图](../../../00_Navigation/Rust-Agent与Go后端学习地图.md)。
