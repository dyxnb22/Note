# Rust 主题速答卡

| 主题 | 30 秒回答 |
|---|---|
| Ownership | 每个值有一个所有者，离开作用域自动 drop；move 防止重复释放，Copy 只适用于复制安全的小值。 |
| Borrow | 可以有多个不可变借用或一个可变借用，不能重叠；这是编译期的别名/可变性约束，不等于业务逻辑正确。 |
| Lifetime | 生命周期描述引用有效期关系，不延长对象寿命；返回引用不能超过输入数据，拥有值有时更简单。 |
| Trait | trait 描述能力，泛型适合编译期复用，dyn trait 适合运行时多态；要说明对象安全、性能和接口边界。 |
| Result/Option | `Option` 表示有/无，`Result` 表示成功/失败；`?` 简化传播，但不会自动补上下文、重试或恢复。 |
| Box/Rc/Arc | Box 单一堆所有权，Rc 单线程共享，Arc 跨线程引用计数；共享所有权不等于共享可变状态安全。 |
| Send/Sync | Send 可跨线程移动，Sync 表示共享引用可跨线程共享；编译器不替你证明锁顺序和业务状态机。 |
| Future | async 函数返回惰性 Future，executor poll 后才推进；`.await` 可能挂起任务，不等于开线程。 |
| Pin/Unpin | Pin 保证需要时对象不移动，支撑自引用 Future 的 poll 安全；它不是“自动堆分配”的同义词。 |
| 取消 | drop Future 常停止本地推进，但远端副作用可能已发生；timeout 后要查询、幂等、补偿或对账。 |
| 背压 | bounded channel、固定 worker、连接池和并发上限限制资源；无界 spawn/队列会把过载变成内存事故。 |
| unsafe | unsafe 把额外不变量交给开发者，安全封装要缩小范围并证明 ABI、别名、初始化和释放条件。 |
| Cargo/Workspace | workspace 组织多个 crate，lockfile 和 toolchain 保证解析/构建可复现，feature 控制可选能力；CI 要跑 check/test/fmt/clippy 和跨平台回归。 |
| FFI | `cdylib`/C ABI 只解决调用约定，不解决所有权、布局、字符串、线程、panic 和释放；跨边界必须定义谁分配、谁释放、失败如何返回。 |
| Axum/Hyper/Tokio | Axum 组织路由和提取器，Hyper 处理 HTTP 基础，Tokio 提供异步运行时；选型时仍要说明阻塞隔离、连接/请求限制、取消和优雅退出。 |
