# TypeScript

TypeScript 的价值是用类型表达边界、让重构可验证；类型不会替代运行时校验。本目录同时服务 Node、Web3 和 AI 应用。

- [TypeScript 工程基础](./TypeScript工程基础.md)：类型、收窄、泛型、模块、异步、API、Schema、测试及 Web3/AI 场景。
- [Node.js 运行时与服务工程](./Node运行时与服务工程.md)：事件循环、Stream、模块、包管理、HTTP 服务、构建、性能与优雅退出。
- [前端应用工程](./前端应用工程.md)：组件、状态、数据缓存、React、SSR、测试、构建、性能和发布。
- [AI 产品界面与交互](./AI产品界面与交互.md)：流式状态、工具/审批、错误恢复、可访问性和 AI 产品评估。

先用工程基础建立类型和契约边界；Node 服务进入运行时课程，Web 应用进入前端应用工程。底层导航、渲染和安全模型见[浏览器原理与前端工程](../CS/12_浏览器原理与前端工程.md)。

## 第一遍路线

`TypeScript 工程基础 → Node.js 运行时与服务工程 → 前端应用工程`；如果目标是 AI 产品，再读 [AI 产品界面与交互](./AI产品界面与交互.md)。先选后端或前端一条分支，不要同时学习两套框架。

## 完成标准

用 TypeScript 做一个小功能：对 `unknown` 外部输入进行运行时校验，完成一个 API 请求的超时/取消/错误处理，写一项测试并通过严格编译。前端分支再补一个可恢复的加载、失败或审批状态。
