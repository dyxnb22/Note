# 海量数据处理：让内存、精度与顺序决定算法

数据规模超过内存后，先估算能保存多少状态，再决定分区、排序或近似。记录数、不同键数、取值范围是三个不同的量：重复一亿次的同一个键，计数状态可能很小；稀疏的巨大值域却可能让位图完全不可行。

## 外部分区与全局排序

去重或求交集时，可按稳定哈希把相同键送到同一文件，再逐个文件流式建立集合。比较规则、字符规范化和哈希算法须在各参与方一致；Python 内置 hash 默认可能跨进程变化，不宜直接作为持久分区协议。

分区过大时要判断原因。不同键太多可继续按更多哈希位拆分；单个热键重复太多则不会因换一个哈希就散开，可先局部计数再汇总。分区还需控制文件句柄、磁盘空间与失败后的可重放性。

哈希分区不保留全局顺序。需要有序输出时，先生成能放入内存的排序段，再以多路归并处理，内存主要用于每个段的当前元素和读写缓冲；归并路数又受文件句柄和 I/O 约束。

## 精确 Top K 的局部候选为什么有效

设 N 是记录数、D 是不同键数。先计数，再用大小 K 的堆选择，工作量通常是 O(N + D log K)，不必对所有原始记录排序。

如果每个键的全部记录由唯一分区负责，在某分区排不进前 K 的键，前面已经有 K 个全局频次不低于它的键，因此它也不可能进入全局前 K。统一并列规则后，可以只合并各分区前 K。

这个结论不能用于按时间任意切开的局部频次：第一片 A=10、B=9，第二片 C=10、B=9，各取第一名会丢掉全局第一 B=18。需要先按键汇总完整频次，或使用保留足够信息的其他算法。

下面的完整程序使用临时文件和稳定哈希，同一键只有一个计数归属。每个桶的不同键数必须能放入内存，候选通过迭代器逐桶合并。

```python
from collections import Counter
from contextlib import ExitStack
import hashlib
import heapq
import json
from pathlib import Path
from tempfile import TemporaryDirectory


def disk_topk(records, k, buckets=4):
    if k < 0 or buckets <= 0:
        raise ValueError("invalid k or bucket count")
    if k == 0:
        return []
    rank = lambda pair: (-pair[1], pair[0])
    with TemporaryDirectory() as directory:
        paths = [Path(directory) / f"bucket-{i}.jsonl" for i in range(buckets)]
        with ExitStack() as stack:
            files = [stack.enter_context(p.open("w", encoding="utf-8")) for p in paths]
            for record in records:
                digest = hashlib.sha256(record.encode("utf-8")).digest()
                bucket = int.from_bytes(digest[:8], "big") % buckets
                files[bucket].write(json.dumps(record, ensure_ascii=False) + "\n")

        def candidates():
            for path in paths:
                with path.open(encoding="utf-8") as source:
                    counts = Counter(json.loads(line) for line in source)
                local = heapq.nsmallest(k, counts.items(), key=rank)
                del counts
                yield from local

        return heapq.nsmallest(k, candidates(), key=rank)


if __name__ == "__main__":
    assert disk_topk(iter(["b", "a", "b", "c", "a", "a"]), 2) == [("a", 3), ("b", 2)]
    assert disk_topk([], 3) == []
    assert disk_topk(["苹果", "苹果", "x\ny"], 5) == [("苹果", 2), ("x\ny", 1)]
```

真实任务还要限制分区状态、记录长度和同时打开的文件，并为重跑定义输出提交协议。这里的临时目录只验证算法，不代表生产任务可以忽略中间文件恢复。

## 位图按值域收费

精确位图为值域中每个可能值分配一位，空间约 R/8 字节，不是按实际出现的 D 个值收费。IPv4 的全部 2³² 个值需要 2²⁹ 字节，即 512 MiB；如果只出现几万个稀疏大整数，哈希集合或压缩位图可能更合适。

位图保存的是是否出现，不能凭一位恢复频次、顺序或原记录。布尔集合运算适合它，复杂对象与无界字符串则需要其他表示。

## Bloom Filter 的保证有前提

普通 Bloom Filter 用多个哈希位置保存集合摘要：有任一位为零，说明该元素未被加入；全部为一，只能说明可能存在。这个无漏报性质要求正确构建、使用同一规则且没有错误清位。

把它放在数据库前，还需要让过滤器覆盖真实数据的相应版本。新增键尚未同步、重建未完成或路由到错误过滤器，都可能把数据库中存在的键误拦截。普通过滤器不能安全删除单元素，也不能代替真实存储、授权或精确计费。

## 从 rand5 推导严格均匀的 rand7

假设每次 rand5 独立且均匀返回 1 到 5。两次调用映射为 (r1-1)×5+(r2-1)，才得到 0 到 24 的 25 个等概率状态；第二项漏减 1 会使范围和后续判断错位。

保留 0 到 20，对 7 取模再加 1，每个结果恰好有三个来源；21 到 24 重新抽取。成功率为 21/25，平均轮数为 25/21，平均 rand5 调用次数为 50/21，实际重试次数没有固定上限。

```python
from collections import Counter


def rand7(rand5):
    while True:
        state = (rand5() - 1) * 5 + (rand5() - 1)
        if state < 21:
            return state % 7 + 1


if __name__ == "__main__":
    accepted = Counter()
    for first in range(1, 6):
        for second in range(1, 6):
            state = (first - 1) * 5 + (second - 1)
            if state < 21:
                accepted[state % 7 + 1] += 1
    assert accepted == Counter({value: 3 for value in range(1, 8)})
    draws = iter([5, 5, 1, 1])
    assert rand7(lambda: next(draws)) == 1
```

任意缩放再取整不能凭空消除来源数量的不整除，严格均匀来自接受集合中每个结果拥有相同数量的等概率来源。

## 未知长度数据流与蓄水池

保留前 k 项后，第 i 项在 1 到 i 中均匀选一个位置；落在前 k 个位置才替换对应样本。新项进入概率为 k/i，旧项经历后续保留后，最终每个输入位置被选中的概率为 k/n，前提是 n≥k；不足 k 项时全部保留。

```python
import random


def reservoir(records, k, rng):
    if k < 0:
        raise ValueError("k must be nonnegative")
    if k == 0:
        return []
    sample = []
    for index, record in enumerate(records, 1):
        if index <= k:
            sample.append(record)
        else:
            slot = rng.randrange(index)
            if slot < k:
                sample[slot] = record
    return sample


if __name__ == "__main__":
    result = reservoir(iter(range(100)), 5, random.Random(7))
    assert len(result) == 5 and len(set(result)) == 5
    assert reservoir(iter(["a", "b"]), 5, random.Random(7)) == ["a", "b"]
    assert reservoir(iter(range(10)), 0, random.Random(7)) == []
```

均匀针对输入位置，而不是去重后的不同值。分布式分片大小不同时，等量取样再等权混合会偏向小分片；可使用有完整合并规则的样本摘要，或为记录保留独立随机优先级后合并相应候选。

带权无放回抽样还需定义希望的分布。正权重 w、独立 0<U<1 时，A-Res 可取 U^(1/w) 的最大 k 项，等价于取 -log(U)/w 的最小 k 项；带权抽样的分布需要按所选算法推导。[带权数据流采样](https://arxiv.org/abs/1012.0256)
