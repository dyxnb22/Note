# 信用周期与资产价格

信用周期描述融资条件、资产负债表、风险偏好和经济活动之间的反馈。它不是固定长度的时钟，也不是独立于[货币与信用](./货币与信用.md)和[经济周期](./经济周期.md)的另一套周期理论；本页只聚焦一个更窄的问题：信用变化为什么会被资产价格放大，以及投资判断如何避免把阶段标签当成择时信号。

## 1. 核心反馈链

扩张阶段常见链路是：

```text
融资成本下降 / 放贷标准放松
  → 借款与杠杆增加
  → 资产需求和投资上升
  → 资产价格、收入或抵押品价值上升
  → 违约率看起来更低、风险承受能力提高
  → 可获得的信用继续增加
```

收缩时方向反转：现金流变弱或风险溢价上升，抵押品价格下跌，贷款价值比和偿债压力恶化，金融机构收紧额度，借款人被迫卖出资产或削减投资，价格和信用质量进一步下降。

关键机制不是“价格涨所以乐观”，而是资产价格会改变融资约束。以抵押贷款为例，即使债务本金不变，抵押品价格下跌也会抬高贷款价值比；若合同要求补充保证金或再融资，账面损失就可能转成被迫卖出。

## 2. 信用如何进入资产定价

资产价格可以粗略理解为未来现金流、折现率、风险溢价和市场流动性的共同结果。信用环境会同时影响四项：

| 传导渠道 | 宽松时可能发生 | 收紧时可能发生 |
|---|---|---|
| 现金流 | 消费、投资和收入改善 | 需求与盈利预期下调 |
| 无风险利率 | 融资成本下降 | 利率或实际融资成本上升 |
| 风险溢价 | 投资者愿意承担更多风险 | 信用利差扩大，要求回报提高 |
| 流动性与杠杆 | 交易融资更容易，买方容量增加 | 保证金提高、赎回和被迫卖出增加 |

因此，同一项政策变化对不同资产未必同向。降息可能降低折现率，但如果它发生在盈利快速恶化和信用风险上升时，风险资产仍可能下跌。不能把“宽松”直接翻译成“所有资产上涨”。

## 3. 观察对象

不要用单一指标宣布周期阶段，应同时观察数量、价格、质量和行为：

- 数量：新增贷款、融资规模、债券净发行和杠杆变化；
- 价格：政策利率、实际利率、信用利差、融资和保证金成本；
- 质量：违约率、逾期、拨备、评级迁移和利息覆盖能力；
- 标准：银行放贷条件、抵押率、契约条款和再融资期限；
- 行为：资本开支、回购、并购、库存、基金赎回和被迫卖出；
- 资产负债表：家庭、企业、金融机构和政府中，债务由谁承担、期限是否错配、损失能否被吸收。

数据定义、频率和修订边界按[来源与验证](../来源与验证.md)记录。观察重点是变量的方向、速度和相互印证，而不是给当前时点贴一个确定标签。

## 4. 三类常被混淆的状态

### 流动性紧张

主体可能仍有偿付能力，但短期无法滚动融资或出售资产。此时期限错配、市场深度和融资渠道比长期估值更重要。

### 偿付能力恶化

资产或未来现金流不足以覆盖债务，延长到期日只能推迟确认损失。需要减记、重组、补充资本或破产处置。

### 风险偏好下降

融资渠道尚未关闭，但投资者要求更高风险溢价。估值会先调整，之后是否演变为流动性或偿付危机取决于杠杆、期限和政策反应。

三者可能相互转化，但处理方式不同。把所有价格下跌都称为“流动性问题”，会低估真实信用损失。

## 5. 为什么不能机械择时

- 周期没有固定长度，政策、产业结构和债务承担者会改变传导速度；
- 资产价格会提前反映预期，等宏观数据确认时可能已经调整；
- 同一指标可能由不同原因变化，例如利差扩大既可能来自违约风险，也可能来自市场流动性下降；
- 数据存在滞后与修订，跨国家和跨时期口径不同；
- 政策能缓解现金流和流动性，却未必消除错误投资与偿付损失。

信用周期更适合用于压力测试和风险预算，而不是预测某个精确转折日。投资组合层面的应对见[仓位管理](../09_Portfolio_and_Risk/仓位管理.md)、[分散化与相关性](../09_Portfolio_and_Risk/分散化与相关性.md)和[波动率与最大回撤](../09_Portfolio_and_Risk/波动率与最大回撤.md)。

## 6. 分析实际周期时

只有准备分析一次真实信用紧缩时，才按月或按季度记录政策利率、信用利差、贷款增速、违约率、代表性资产价格和企业投资。先画时间线，再回答：

1. 哪个变量最先变化，哪个只是滞后确认？
2. 冲击首先发生在流动性、偿付能力还是风险偏好？
3. 哪类主体杠杆最高、期限最短，谁承担了最终损失？
4. 政策修复了融资、现金流还是资本缺口？
5. 如果删掉事后数据，当时能做出的稳健决策是什么？

结论应保留数据来源、取得日期、口径与反例；不能只用一张资产价格图反推完整因果链。
