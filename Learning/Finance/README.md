# 金融与经济学

本目录只维护学习入口；正文负责一个主题，`来源与验证`负责数据、规则和时效性。内容用于建立机制与研究框架，不荐股、不喊单，也不替代投资、税务或法律意见。

## 使用方式与成果

从真实问题进入相关正文；只有基础不足时才走上面的入门路线，量化、衍生品、行为金融和研究流程按问题选择。概念页说明机制、假设和失效条件，查询页不是待完成的课程，也不需要为每篇概念重复做练习。

需要形成研究成果时，写一页备忘录记录事实与来源、假设、现金流或风险、替代方案、失效条件和核对日期。避免为同一主题维护多份“总结版”。

## 来源与时效

稳定原理页标明采用的模型或定义来源；具体案件、模型阈值、数量结论，以及利率、税制、监管、交易规则、产品参数和时点数据，应在正文附直接来源，或链接到[逐篇来源索引](./来源索引.md)中本篇专属条目。条目须列出直接来源、支持范围、局限和核对日期或动态核验方式。通用入口页不能替代逐篇证据；具体数据和规则按[来源与验证](./来源与验证.md)重新核对，并区分稳定概念与变化事实。
