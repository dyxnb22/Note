# 因子投资框架

## 1. 核心概念

**因子（Factor）**
对股票横截面超额收益提出预测假设的特征变量。只有在跨时期、样本外、成本后和不同市场中重复验证，才有资格把它称为较可信的收益来源；单个回测不能证明因子稳定有效。

**因子溢价（Factor Premium）**
持有某一因子暴露所获得的长期超额收益。例如，长期持有低 PE 股票组合（价值因子）相对于全市场的超额回报。

**因子暴露（Factor Exposure / Factor Loading）**
投资组合对某一因子的敞口大小。因子暴露 = 1 表示标准化暴露，越高说明组合越倾向于该因子方向。

**Smart Beta**
在传统市值加权指数之外，按因子规则构建的系统性策略，介于纯被动指数和主动管理之间。

---

## 2. 核心机制

**主流因子分类**

| 因子 | 代表指标 | 经济学解释 |
|------|---------|-----------|
| 价值（Value）| PE、PB、PS 低 | 市场对低估股票过度悲观，长期均值回归 |
| 动量（Momentum）| 过去 6-12 个月涨幅 | 信息扩散缓慢，投资者行为惯性 |
| 质量（Quality）| ROE 高、负债低、盈利稳定 | 高质量公司风险更低，定价被低估 |
| 规模（Size）| 小市值 | 小公司流动性溢价、分析师覆盖少 |
| 低波动（Low Volatility）| 低 Beta、低波动率 | 投资者对高波动股票过度追捧 |
| 盈利修正（Revisions）| 分析师上调比例 | 信息更新缓慢，超预期收益持续 |

**因子有效性的三种解释框架**

1. **风险补偿**：因子溢价是对某种系统性风险的补偿（价值股在经济下行时更脆弱）→ 溢价是理性的、持久的
2. **行为偏差**：投资者系统性认知错误导致错误定价（过度外推、锚定效应）→ 溢价可能被套利消除
3. **数据挖掘**：从历史数据中过度拟合出来的伪关系 → 样本外不再有效

三种解释并存，评估因子时需要区分"哪种解释更可能成立"。

**多因子组合的构建逻辑**

```
单因子打分
↓
合成综合因子得分（加权平均 or 机器学习）
↓
按综合得分排序，选前 N 分位股票（如前 20%）
↓
行业中性化（避免组合变成行业押注）
↓
市值加权 or 等权 or 优化加权
↓
定期调仓（月/季）
```

**因子之间的相关性**

| 因子对 | 相关性 | 含义 |
|--------|--------|------|
| 价值 × 动量 | 弱负相关 | 两者组合有分散化效益 |
| 质量 × 价值 | 弱正相关 | 质量好的公司往往不便宜 |
| 低波动 × 质量 | 中等正相关 | 低波动公司往往质量更高 |
| 动量 × 低波动 | 弱负相关 | 强势股往往波动更大 |

因子相关性低 → 组合时分散化收益明显；因子相关性高 → 组合时冗余，不增加多样性。

## 3. 分析框架

**评估一个因子的有效性框架：**

1. **逻辑合理性**：有没有经济学/行为学解释？无逻辑 = 更可能是数据挖掘
2. **历史持续性**：因子溢价在不同历史时期是否稳定存在（包括不利市场环境）？
3. **跨市场普遍性**：在美国、欧洲、亚洲等不同市场是否同样有效？
4. **样本外有效性**：在公开发表后（"发现后"），因子溢价是否仍然存在？
5. **成本敏感性**：扣除换手成本、冲击成本后，Alpha 是否仍然为正？
6. **衰减速度**：因子溢价是否在快速消失？

## 4. 关键指标或关键变量

**IC（信息系数，Information Coefficient）**
= 因子值与下期收益的横截面相关系数（Spearman 或 Pearson）

IC > 0 只表示样本中的方向为正。`0.03-0.05` 等阈值只能作为特定频率、样本规模和成本假设下的经验参考，不能跨市场、持有期和数据处理流程直接套用；应同时报告置信区间、t 统计量、样本外结果和成本后收益。IC 的稳定性（ICIR = IC均值/IC标准差）比 IC 均值本身更重要。

**ICIR（IC 信息比率）**
= IC 均值 / IC 标准差

衡量因子信号的稳定性。`0.5` 或 `1.0` 不是通用分界线；ICIR 会受观察频率、横截面数量、相关性、异常值处理和样本窗口影响，必须和经济意义及交易成本一起判断。

**因子换手率**
因子构建的组合每期更换多少比例的股票。换手率高 = 交易成本更高 = 需要更大的 Alpha 才能保留净收益。

## 5. 实际例子

**例 1：价值因子的历史表现**
Fama-French 三因子模型中的 HML 是高账面市值比组合减低账面市值比组合。官方数据页明确了组合构造、样本和是否计入交易成本；不同数据版本、市场、权重和观察窗口会得到不同的年化结果，因此不要脱离数据版本背诵一个固定的“3-4%”。研究时应下载指定版本并记录计算窗口，再讨论价值因子是周期性低迷还是结构性衰减。

来源：[Kenneth French Data Library：Fama/French Benchmark Factors](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/f-f_bench_factor.html)。

**例 2：因子拥挤效应**
2017-2019 年 A 股市场，大量量化私募同时使用相似的价值+质量因子策略。因子拥挤导致：① 因子换手时买卖冲击增大 ② 大量资金同进同出时短期内出现极端回撤 ③ 因子溢价被侵蚀。

**例 3：行业中性化的重要性**
未经行业中性化的低 PE 因子，在某些时期会大量选入银行股（PE 天然低）。这不是"价值因子"在起作用，而是在做行业押注。行业中性化后，策略的超额收益来源才是真正的选股能力。

## 6. 常见误区

**误区 1：因子越多越好**
多因子不等于分散化——相关性高的因子叠加只是重复计算。真正有价值的是低相关、逻辑独立的因子组合。超过 5-8 个核心因子后，边际收益递减，过拟合风险上升。

**误区 2：历史 IC 高 = 未来有效**
IC 是样本内统计。因子在发现并被广泛使用后，溢价往往会衰减（"因子拥挤"）。历史有效是必要条件但不是充分条件。

**误区 3：因子投资 = 被动投资**
因子投资需要持续管理：因子权重调整、行业中性化再平衡、新因子研究、衰减监控。本质上是系统化的主动管理，不是被动指数基金。

**误区 4：小市值因子可以无限规模化**
小市值股票流动性有限，策略容量低。当资金规模足够大时，买入/卖出本身会影响价格，小市值因子的超额收益会被冲击成本消耗殆尽。

## 8. 最小可执行练习

**练习 1（因子逻辑）**
为以下每个因子写出 2 句话的"经济学/行为学解释"：价值因子、动量因子、低波动因子。哪个解释最让你信服？哪个更像是数据挖掘的结果？

**练习 2（IC 直觉）**
假设某因子对 100 只股票打分（1-100），与下一季度涨幅的相关系数为 0.05。这个信号微弱，但用于 1000 只股票时价值几何？计算每季度能覆盖多少个独立押注，直觉上理解"分散化放大微弱信号"。

**练习 3（因子组合设计）**
设计一个三因子组合：选择价值、动量、质量中的两个加一个你自选的因子，说明：① 每个因子的权重和理由 ② 是否需要行业中性化 ③ 预计换手率和调仓成本。

## 11. 研究证据与最小计算骨架

因子研究至少要把“信号定义、信息可得时间、组合形成、交易成本和样本外切分”写成可复核记录。特别是财报因子，必须使用公告日或可获得日，不能直接使用后来修订后的年报字段。

```python
from statistics import mean, stdev


def icir(ic_series: list[float]) -> float:
    """计算 ICIR；样本太少或标准差为 0 时不返回虚假的稳定性。"""

    if len(ic_series) < 2:
        raise ValueError("need at least two IC observations")
    dispersion = stdev(ic_series)
    if dispersion == 0:
        raise ValueError("IC standard deviation is zero")
    return mean(ic_series) / dispersion


def net_return(gross_return: float, turnover: float, cost_per_turnover: float) -> float:
    # 成本模型只是示例；真实成本应按市场、股票流动性和订单执行记录校准。
    return gross_return - turnover * cost_per_turnover


ic_history = [0.03, -0.01, 0.04, 0.02]
print("IC mean =", round(mean(ic_history), 4))
print("ICIR =", round(icir(ic_history), 4))
print("net return =", net_return(0.08, turnover=1.5, cost_per_turnover=0.01))
```

最小研究台账应记录：数据截止日、可得日、因子版本、行业/市值中性化方式、调仓频率、组合权重、换手、成本模型、样本内/样本外区间、基准和失败样例。没有这些字段时，IC 和收益曲线只能作为探索结果，不能直接升级为投资结论。
