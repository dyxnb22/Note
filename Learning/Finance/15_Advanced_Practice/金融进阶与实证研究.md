# 金融进阶与实证研究

本篇补齐会计勾稽、税务监管边界、期权 Greeks/波动率、时间序列、组合优化、量化研究工程和真实案例。它不构成投资、税务或法律建议。

## 1. 会计恒等式

```text
资产 = 负债 + 所有者权益
```

任何交易至少影响两个账户。理解业务如何进入会计记录，比背报表项目更重要。

## 2. 利润表

利润表描述一段期间收入、成本、费用、利息、税和利润。需要区分：

- 收入确认与收款。
- 费用确认与付款。
- 经常性与一次性。
- 会计估计与现金事实。
- 毛利、经营利润与净利润。

利润不是现金。

## 3. 资产负债表

资产负债表描述时点状态。重点：

- 现金与受限现金。
- 应收、存货和减值。
- 固定/无形资产与折旧摊销。
- 有息债务与租赁。
- 递延税项。
- 商誉。
- 少数股东权益。

高资产不等于高价值，关键是未来现金流和资产质量。

## 4. 现金流量表

- 经营现金流。
- 投资现金流。
- 融资现金流。

间接法从净利润调整非现金项目和营运资本。自由现金流定义不唯一，使用时写明口径。

## 5. 三表勾稽

典型关系：

- 净利润进入权益并作为经营现金流起点。
- 折旧降低利润但非当期现金流出。
- 资本开支增加资产并在投资现金流流出。
- 借款增加现金和负债。
- 分红减少现金和权益。
- 期末现金与资产负债表现金一致。

## 6. 会计质量

检查：

- 收入增长与应收。
- 利润与经营现金流。
- 存货和减值。
- 资本化政策。
- 关联交易。
- 审计意见与会计政策变化。

异常只是研究线索，不自动证明造假。

## 7. 税务边界

税务结论取决于税收居民、收入来源、资产性质、账户、交易频率、持有目的和司法管辖区。

建立税务清单：

- 自己在哪些地区可能为税收居民？
- 哪类收入或交易需要申报？
- 券商/银行是否代扣？
- 成本、汇率和交易记录是否完整？
- 股息、利息、资本/经营收益如何分类？
- 跨境信息交换和申报义务是什么？

不根据网上一句“某地没有资本利得税”直接下结论；事实与性质判断可能改变处理。

## 8. 账户与托管

区分：

- 证券所有权和券商账簿。
- 现金账户与保证金账户。
- 托管、名义持有人和最终受益人。
- 存款保障、投资者赔偿和不覆盖风险。
- 券商破产、资产隔离和跨境追索。

开户文件和产品条款是合同事实源。

## 9. 监管

监管覆盖发行、交易、销售、适当性、市场操纵、反洗钱、托管和信息披露。个人投资者至少理解：

- 产品是否受监管。
- 中介是否持牌。
- 投诉与赔偿渠道。
- 复杂产品风险披露。
- 市场和账户的交易规则。

规则会变化，交易前核对监管机构和交易所。

## 10. Greeks

Greeks 是价格对输入的局部敏感度：

- Delta：标的价格变化。
- Gamma：Delta 对标的变化。
- Vega：隐含波动率变化。
- Theta：时间流逝。
- Rho：利率变化。

它们是模型和当前点附近的敏感度，不保证大幅变化下线性有效。

## 11. Delta 与 Gamma

Delta Hedge 需要动态调整。Gamma 高时 Delta 变化快，频繁再平衡带来交易成本和跳跃风险。

到期附近、接近平值时 Greeks 可能快速变化，不能只看初始 Delta。

## 12. Vega 与 Theta

买期权通常具有正 Vega、负 Theta；卖期权相反，但具体组合需逐腿计算。

“赚时间价值”不代表低风险，短波动头寸可能承受极端跳跃和流动性损失。

## 13. 隐含波动率

IV 是把市场价格代入定价模型反推的参数，不是未来波动的确定预测。

同到期不同行权价形成 Smile/Skew，不同到期形成 Term Structure。曲面反映供需、尾部风险和市场结构。

## 14. 波动率曲面

构建时处理：

- 无套利约束。
- 稀疏和噪声报价。
- Bid/Ask。
- 到期与行权价插值。
- 公司行动和利率/股息。

平滑曲面不能掩盖缺乏流动性的原始数据。

## 15. 时间序列

金融时间序列常具有非平稳、波动聚集、厚尾和结构变化。

分析前：

- 明确价格、收益率或差分。
- 检查频率和交易日。
- 对齐时区与公司行动。
- 避免未来数据。
- 分离训练、验证和测试时间段。

## 16. 自相关与平稳

平稳要求统计性质在所研究范围相对稳定。单位根、趋势和季节性会造成伪回归。

统计检验不是自动裁决；样本长度、结构突变和多重检验会影响结论。

## 17. 波动模型

移动窗口、EWMA、ARCH/GARCH 等用于描述条件波动。比较：

- 样本内拟合。
- 样本外预测。
- 极端期表现。
- 参数稳定性。
- 经济价值与交易成本。

复杂模型不保证更可交易。

## 18. 因果与预测

回归相关不等于因果。因果问题要明确处理、结果、混杂和识别假设；预测问题重点是样本外性能和稳定性。

不能用预测准确率包装未经识别的因果叙事。

## 19. 组合优化

均值—方差优化对期望收益估计非常敏感。输入微小变化可能导致极端权重。

稳健方法：

- 权重和换手约束。
- Shrinkage 协方差。
- 风险平价/风险预算。
- Black-Litterman。
- Resampling。
- 简单等权基线。

## 20. 约束

真实组合包含：

- Long-only/杠杆。
- 单资产和行业上限。
- 流动性和容量。
- 交易成本和税。
- 最小交易单位。
- 跟踪误差。
- 回撤和尾部风险。

约束不是优化后的补丁，而是问题定义。

## 21. 回测工程

```text
原始数据 → 版本/校验 → 特征
→ 信号 → 组合 → 订单 → 成交模拟
→ 费用/滑点 → 归因 → 报告
```

每层保留输入输出和时间戳。Research Notebook 不能直接充当生产交易系统。

## 22. 数据血缘

记录：

- Vendor 和下载时间。
- 原始文件 Hash。
- 字段、单位和时区。
- 复权与公司行动。
- 缺失和异常处理。
- 可用时间而非事后发布时间。
- 修改历史。

“干净 CSV”没有血缘就不是可靠研究资产。

## 23. 代码质量

- 配置与代码分离。
- 特征使用 Point-in-time 数据。
- 单元测试验证收益、权重和费用。
- Golden Dataset 防止逻辑漂移。
- 随机种子与环境锁定。
- 结果绑定代码和数据版本。

## 24. 实盘归因

区分：

- 信号收益。
- 组合构建影响。
- 交易执行。
- 费用和融资。
- 数据/系统错误。
- 市场 Beta 与风格暴露。

回测与实盘偏差要能定位到链路阶段。

## 25. 真实案例模板

### 公司

三表 → 商业模式 → 资本配置 → 估值 → 反证。

### 债券

现金流 → 曲线 → Duration/Convexity → 信用 → 流动性。

### 基金

基准 → 持仓 → 风格 → 费用 → 跟踪/主动风险。

### 组合

目标 → 约束 → 风险预算 → 再平衡 → 税费 → 复盘。

## 26. 最小实践

1. 为一家公司做三表勾稽。
2. 绘制期权 Greeks 和波动率曲面。
3. 实现时间顺序严格的预测实验。
4. 比较等权、均值方差和风险预算。
5. 加入成本、容量和税务占位。
6. 用真实成交做回测—实盘归因。

## 验收清单

- 能从交易解释三张报表变化。
- 税务与监管结论标记管辖区、日期和来源。
- Greeks 与 IV 只作为模型敏感度使用。
- 时间序列严格避免未来数据。
- 优化包含约束、成本和稳健性。
- 数据、代码、回测和实盘结果可追溯。
