# 金融进阶与实证研究

本文是综合检查清单，不替代会计、税务、监管或投资建议。它把会计、衍生品、计量、组合和研究工程串成一条实证主线；具体概念回到对应目录。

## 1. 会计与事实源

```text
资产 = 负债 + 所有者权益
利润 ≠ 现金
```

读三张表时先看关系而不是背科目：收入/费用确认与收付款可能错位；折旧影响利润但不是当期现金流；资本开支增加资产并产生投资现金流；借款、分红和期末现金分别影响负债/权益/现金。

重点检查：收入与应收、利润与经营现金流、存货与减值、资本化政策、关联交易、审计意见和会计政策变化。异常是研究线索，不自动等于造假。

## 2. 税务、账户与监管边界

税务结论至少依赖税收居民、收入来源、资产性质、账户、交易频率、持有目的和司法管辖区。研究记录应回答：收入如何分类、是否代扣、成本/汇率/交易记录是否完整、跨境申报和信息交换如何处理。

账户分析要区分证券所有权、券商账簿、现金/保证金、托管、最终受益人、保障范围、破产隔离和跨境追索。发行、销售、适当性、市场操纵、反洗钱、托管和信息披露也要按目标地区核验。

不要根据“某地没有资本利得税”或产品宣传直接下结论；开户文件、产品条款和监管机构是事实源。

## 3. 期权与波动率

Greeks 是价格对输入的局部敏感度：Delta（标的）、Gamma（Delta 变化）、Vega（隐含波动率）、Theta（时间）、Rho（利率）。它们不是大幅变化下的线性保证。

```text
报价 → 代入定价模型 → 反推出 IV
不同执行价 → Smile/Skew
不同到期 → Term Structure
```

对冲需考虑 Gamma、跳跃、再平衡频率、流动性和交易成本；“赚时间价值”可能隐藏短波动和尾部风险。构建波动率曲面要处理 Bid/Ask、稀疏报价、无套利、插值、公司行动、利率和股息。

## 4. 时间序列与因果

金融序列常见非平稳、波动聚集、厚尾和结构变化。分析前明确价格/收益率/差分、频率、交易日、时区、复权和可用时间；按时间切分训练、验证和测试，禁止未来数据泄漏。

移动窗口、EWMA、ARCH/GARCH 等模型都要比较样本外预测、极端期表现、参数稳定性和交易成本。相关性不是因果；因果问题要写清处理、结果、混杂和识别假设，预测问题要看样本外稳定性。

## 5. 组合优化与风险

均值—方差优化对期望收益极敏感，权重约束是问题定义的一部分：long-only/杠杆、单资产/行业上限、流动性/容量、交易成本/税、最小交易单位、跟踪误差、回撤和尾部风险。

至少与等权基线比较，并评估 Shrinkage 协方差、风险平价/风险预算、Black-Litterman 或重采样等稳健方案。优化结果要说明输入误差、换手、容量和最坏情景，而不只展示回测收益。

## 6. 回测、数据与实盘

```text
原始数据 → 版本/校验 → 特征 → 信号 → 组合
→ 订单/成交模拟 → 费用/滑点 → 归因 → 报告
```

每层保存输入、输出、时间戳和版本。数据血缘至少记录 Vendor、下载时间、原始 Hash、字段/单位/时区、复权、缺失/异常处理和可用时间。代码质量至少包括配置分离、Point-in-time 特征、收益/权重/费用测试、Golden Dataset、环境锁定和结果版本绑定。

实盘归因区分信号、组合构建、执行、费用/融资、系统错误、Beta 与风格暴露；回测—实盘偏差必须能定位到链路阶段。

## 7. 实际研究时选择一种结构

| 案例 | 最小结构 |
|---|---|
| 公司 | 三表 → 商业模式 → 资本配置 → 估值 → 反证 |
| 债券 | 现金流 → 曲线 → Duration/Convexity → 信用 → 流动性 |
| 基金 | 基准 → 持仓 → 风格 → 费用 → 跟踪/主动风险 |
| 组合 | 目标 → 约束 → 风险预算 → 再平衡 → 税费 → 复盘 |

不需要把这些结构逐个做一遍。当真实问题涉及公司、衍生品、时间序列或投资组合时，只选对应结构，并把费用、容量、税务和实盘偏差放进同一份研究记录。

## 研究产出自检

- 能从交易解释三张报表变化；
- 税务/监管结论写清管辖区、日期和来源；
- Greeks/IV 只作为敏感度和模型输入使用；
- 时间序列没有未来数据；
- 组合优化包含约束、成本和稳健性；
- 数据、代码、回测和实盘结果可追溯。
