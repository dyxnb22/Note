# 财务造假识别

> 本篇来源与证据边界见[来源索引中的对应条目](../来源索引.md#finance-source-101)。

## 1. 核心概念

**财务造假（Financial Fraud）**
公司通过虚报、隐瞒、错误分类等手段，使财务报表与真实经营状况不符，以达到欺骗投资者、银行或监管机构的目的。

**造假的动机三角（Fraud Triangle）**
1. **压力（Pressure）**：完成盈利目标的压力、偿债压力、股价维护压力
2. **机会（Opportunity）**：内部控制薄弱、审计缺乏独立性、信息不透明
3. **合理化（Rationalization）**：管理层认为造假是"暂时的"或"有充分理由的"

这是组织风险评估的常用框架，不是经验证的诊断公式；即使出现这些条件，也不能单独证明发生造假。

**造假的主要类型**

| 类型 | 手法 | 目的 |
|------|------|------|
| 收入虚报 | 提前确认收入、虚构销售 | 拉高利润和估值 |
| 费用隐藏 | 将费用资本化、关联方转移 | 降低成本，虚增利润 |
| 资产虚增 | 高估存货、应收款、商誉 | 使资产负债表看起来健康 |
| 负债隐藏 | 表外负债、关联方担保 | 降低债务比率 |
| 现金流造假 | 将经营现金流与融资活动混淆 | 掩盖经营现金流恶化 |

## 2. 核心机制

**七大财务造假红旗**

**红旗 1：利润增长与经营现金流长期背离**
```
观察：比较多个期间的净利润与经营现金流，并检查营运资本、季节性、并购和会计分类
风险信号：长期背离且管理层无法用业务变化和现金收付时点解释
```
持续的利润/现金流背离是需要调查的风险信号，但不能据此单独认定造假。现金余额、银行回函和单据也可能因伪造、资金占用、受限资金或核验路径失效而不可靠；应取得独立银行证据，并与流水、客户/供应商资料及关联交易交叉核对。康美药业案中，证监会认定公司伪造、变造银行存单和对账单并虚增货币资金，说明账面现金不是天然可靠的独立证据。

**红旗 2：应收账款增长远快于收入**
```
观察：应收账款增速、账龄和收款天数应与赊销条款、客户结构和行业变化一起比较
风险信号：多期收款显著变慢或账龄恶化，且没有合理业务解释
```
提前确认收入可能推高应收账款；应收上升也可能来自扩张、结算周期或客户结构变化，需检查合同、发货、回款和期后退货。

**红旗 3：存货异常增加**
```
观察：结合行业、季节、采购安排、产品周期与存货周转比较存货变化
风险信号：库存积压或减值迹象持续增加，却没有与销售计划、订单和可变现价值相符的解释
```

**红旗 4：关联交易占比高且披露不透明**
```
警告信号：
- 大额应收款来自关联方
- 与关联方的交易价格明显偏离市场价格
- 关联方众多且关系复杂（"空壳公司"网络）
- 频繁更换审计师
```

**红旗 5：审计意见异常**
```
重要信号：
- 审计师出具保留意见或无法表示意见
- 频繁更换审计师（尤其在年报审计临近时）
- 由小型审计事务所审计大型公司
- 审计费用异常低（暗示审计可能不独立）
```

**红旗 6：毛利率/净利率远高于同行且无合理解释**
```
如果某公司毛利率显著偏离可比同行或自身历史，可能的解释包括产品组合、定价权、会计口径变化、成本漏记或收入确认问题；应先统一口径，再查找支持或反驳证据。
```
异常利润率是需要解释的线索；差异本身不能证明造假。

**红旗 7：大股东/管理层频繁减持**
```
核查减持时间、比例、预先披露计划、锁定期、资金用途及同时发布的公司信息；单次或计划内减持不能直接说明管理层判断公司前景恶化
```
若管理层公开陈述与其交易、风险披露或经营数据之间存在难以解释的矛盾，可提高核查优先级；内部人交易也可能受个人流动性、税务和既定计划影响，不能单独定性。

## 3. 分析框架

**Beneish M-Score 模型**
一个基于 8 个财务比率的定量造假检测模型：

| 指标 | 含义 |
|------|------|
| DSRI（应收账款增长指数）| 应收账款/收入比率的变化 |
| GMI（毛利率指数）| 毛利率的变化（恶化暗示压力）|
| AQI（资产质量指数）| 非流动资产占比变化 |
| SGI（销售增长指数）| 收入增速（高增速与造假正相关）|
| DEPI（折旧指数）| 折旧率变化（减少折旧虚增利润）|
| SGAI（销售和行政费用指数）| 费用/收入比率变化 |
| LVGI（杠杆变化指数）| 负债率变化 |
| TATA（应计利润比率）| 应计项目占总资产比例 |

文献中的 M-Score > -1.78 是特定模型设定和研究样本下常用的筛查界点，不是通用审计标准、法律结论或跨行业保证；使用时要注明模型版本、样本适用性和数据口径。参见 Beneish 的原始研究：[The Detection of Earnings Manipulation](https://doi.org/10.2469/faj.v55.n5.2296)。

**三表交叉验证法**
```
利润表 → 验证 → 资产负债表
（利润增加应体现为资产增加或负债减少）

利润表 → 验证 → 现金流量表
（跨期核对利润与现金流差异；两者无需在单一期间一一对应）

资产负债表 → 验证 → 现金流量表
（资产和负债的变化应能被现金流解释）
```

三表之间出现无法解释的差异（例如利润持续增加而经营现金流偏弱、资产变化缺少对应现金流解释）应触发进一步核验；单个期间的差异也可能来自营运资本变化、季节性、并购或会计分类，不能直接等同于造假。

## 4. 关键指标或关键变量

**DSO（应收账款天数，简化口径）**
= 平均应收账款 / 日均赊销收入；没有赊销收入数据时，才用总收入近似并明确标注。

DSO 持续增加可能来自收款变慢、客户/产品结构变化、结算条款或收入确认问题。比较时统一应收账款和收入口径，并核对行业、季节与客户结构；异常只触发调查，不等于造假结论。

**经营现金流 / 净利润比率**
没有适用于所有行业和期间的统一安全阈值。应结合多年趋势、同行口径、营运资本变化、季节性、资本化政策和企业扩张阶段解释比率；持续背离是调查线索，不是单独的造假结论。

**应计利润率**
= (净利润 - 经营现金流) / 平均总资产

这是一个简化口径；不同研究可能对经营现金流、总资产期间和应计项目作不同定义，引用或比较时要写清公式。正值表示净利润高于经营现金流；解释时要同时检查营运资本、非现金项目、并购和分类变化。应计利润本身是权责发生制会计的组成部分，不能简单等同于“账面造假”。

## 5. 实际例子

**例 1：瑞幸咖啡（2020 年）**
财政部检查发现，瑞幸境内运营主体在 2019 年 4 月至年末通过虚构商品券业务增加交易额 22.46 亿元、虚增收入 21.19 亿元；美国 SEC 的和解公告另记载其虚构零售销售超过 3 亿美元。两个来源的期间和统计口径不同，不应把金额简单合并。参见[财政部检查通报](https://jdjc.mof.gov.cn/gongzuodongtai/202007/t20200731_3560072.htm)和[SEC 公告](https://www.sec.gov/newsroom/press-releases/2020-319)。

**例 2：康美药业（2019 年）**
关键信号：① 货币资金规模很大但仍大量借贷，需核对资金可用性与受限情况 ② 应收账款异常增长 ③ 审计证据和资金核验路径需要独立复核。
证监会行政处罚决定认定，康美药业 2017 年年报虚增货币资金约 299.44 亿元，并披露了伪造、变造银行存单和对账单等手法。参见[证监会行政处罚决定书](https://www.csrc.gov.cn/csrc/c101928/c1042341/content.shtml)。

**例 3：三表验证失败案例**
以下数字为假设情景，不对应真实公司或调查结论。
某公司利润表显示净利润 5 亿，资产负债表货币资金增加 0.5 亿，但经营现金流量表显示经营现金流为 -1 亿。
三表核对发现差异后，应核对融资流入、营运资本、受限现金、投资支出及合并范围等项目；仅凭这些假设数字不能断定利润虚报。

## 6. 常见误区

**误区 1：审计过的财报一定可信**
审计只是合理保证，不是绝对保证。审计师有局限性（依赖管理层提供的文件）且有时缺乏独立性（审计关系长期化、非审计服务创造利益关联）。四大审计过的公司同样有大规模造假先例（安然、安拓等）。

**误区 2：股价一直在涨说明没问题**
造假公司在曝光前往往股价很好——这是造假的目的之一。依赖市场定价作为真实性判断的代理指标，会在泡沫破裂时遭受最大损失。

**误区 3：只有中小公司会造假**
大型公司、知名公司也有造假记录（安然、世通、乐视、康美）。公司规模不是真实性的保证；有时规模越大，骗局能持续的时间越长。

**误区 4：一个红旗就能确定造假**
单个指标异常可能有合理解释（行业特殊性、会计政策变更、业务结构变化）。需要多个红旗信号叠加，且无法找到合理解释时，才能得出较高可信度的结论。
