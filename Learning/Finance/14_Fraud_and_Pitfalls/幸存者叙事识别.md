# 幸存者叙事识别

> 本篇来源与证据边界见[来源索引中的对应条目](../来源索引.md#finance-source-098)。

## 1. 核心概念

**幸存者偏差（Survivorship Bias）**
在观察样本中，只包含"幸存"下来的案例（成功的公司、成功的投资者、成功的策略），而忽视了已经消失的失败案例——因为失败的案例无法被看到或不被传播。

**幸存者叙事（Survivorship Narrative）**
基于幸存者偏差构建的投资故事：成功者的方法被总结为可复制的经验，但这些方法在所有尝试者中的成功率被系统性高估。

**典型场景**
- 只看到留存到今天的明星基金经理，不知道同期有多少同类策略的基金已经清盘
- 只看到成功上市公司的创始人故事，不知道有多少同等努力的人以失败告终
- 股票投资书籍写的都是买对了的案例，买错的案例被"遗忘"

## 2. 核心机制

**幸存者叙事的三种主要类型**

**类型 1：基金经理的能力幻觉**
```
看到的：某基金经理连续 10 年跑赢市场，媒体大量报道其"选股秘诀"
看不到的：
  - 同期有多少同类策略的基金？
  - 其中多少已经清盘？
  - 如果有 1000 个基金经理随机买卖，统计上有多少人可能"偶然"连续 10 年跑赢市场？

统计模拟（1000 个基金经理，假设各经理和各年份结果独立，年均 50% 概率跑赢市场）：
  连续 5 年跑赢：期望约 31 人（1000 × 0.5⁵）
  连续 10 年跑赢：期望约 1 人（1000 × 0.5¹⁰）；至少出现 1 人的概率为 1 − (1 − 0.5¹⁰)¹⁰⁰⁰ ≈ 62%
→ 这是说明筛选大量候选者可能产生极端赢家的玩具模型，不代表真实经理的业绩独立或完全随机。
```

**类型 2：投资策略的成功率幻觉**
```
看到的：某书中记录了用 PEG < 1 策略的 20 个成功案例
看不到的：
  - 同样的策略用于多少只股票？
  - 失败的案例（亏损的股票）被系统性省略了
  - 书的作者在写作前已知道哪些股票上涨（事后选择样本）

更可靠的方法：使用全量化、系统化回测（包含所有股票），而非精选案例
```

**类型 3：企业经营的成功路径幻觉**
```
看到的："X 公司通过进入新市场实现了 10 倍增长"（成功企业的案例书）
看不到的：
  - 同期有多少公司也"通过进入新市场"但以失败告终？
  - 成功路径中有多少是运气（市场时机），多少是战略（可复制）？

结果：我们学到的"成功规律"，可能只是幸存者的共同特征，而非导致成功的原因
```

**识别幸存者叙事的核心问题**

```
每当看到"成功案例"时，问：
1. 同样策略/方法的总体样本有多大？
2. 在这个总体样本中，成功的比例是多少？
3. 失败的案例在哪里？为什么看不见它们？
4. 成功的共同特征中，哪些是可复制的技能，哪些是不可复制的运气？
```

## 3. 分析框架

**基金经理评估的幸存者偏差修正**

```
步骤 1：找出在同一策略/风格下，同期的全部基金数量
步骤 2：统计这些基金中已清盘/解散的比例（代表失败者）
步骤 3：将明星基金经理的业绩放入这个完整分布中评估
  - 如果完整样本中只有少数经理长期留存，单个幸存者的好业绩仍可能含有较大选择偏差
  - 同类比较排名可提供信息，但不能单凭名次区分技能和运气
步骤 4：查看其在逆境（熊市/策略失效期）的表现
  - 逆境表现可以作为研究材料之一，但市场状态、风险暴露和策略适用范围也会影响结果
```

**策略评估的基金墓地检查**

```
在评估任何"有效"投资策略时：
  - 是否存在"策略墓地"（很多用过同类策略但已消失的产品）？
  - 目前看到的成功案例，是否是因为幸存下来才被看到的？
  - 如果强制包含所有历史尝试者（包括失败者），策略的有效比例是多少？
```

## 4. 关键指标或关键变量

**清盘率（Attrition Rate）**
= 在给定时期内停止运营的基金数量 / 期初基金总数

清盘率较高的策略类别，其存续样本可能存在幸存者偏差。具体偏差幅度和清盘率取决于基金类型、国家、起止年份与数据库处理方法；引用时应给出对应研究样本，不使用统一比例。

**前 10% 基金业绩的持续性**
业绩排名持续性可用于研究技能，但结果会因样本、时期、费用和排名方法而异；不要把某一研究的预测结果推广到所有基金类别或市场。

## 5. 实际例子

**例 1：二战飞机的"错误"装甲**
经典案例：Abraham Wald 在飞机易损性研究中指出，返航飞机的损伤样本不能代表所有受击飞机；应考虑未返航飞机带来的缺失机制。常见的“弹孔应补在未见弹孔处”是对其统计思路的教学性简化。参见 [CNA 对 Wald 报告的重印](https://www.cna.org/analyses/1980/a-method-of-estimating-plane-vulnerability)。

**例 2：投资书籍的幸存者偏差**
成功案例集可能只展示事后已知表现突出的公司，而没有说明筛选时观察过的完整候选集合和失败案例。读者因此无法判断这些公司特征是成功原因，还是事后从幸存者中归纳出来的共同点。

**例 3：基金经理能力的幸存者检验（假设情景）**
假设某公司发行过多只同类基金，其中部分后来清盘，另有一只持续跑赢市场。下列数字仅用于说明需要追踪完整样本，不代表真实公司或基金：
- 其所在基金公司同期发行了 12 只同类风格基金
- 其中 8 只已清盘（平均运营 4 年）
- 这 8 只基金的平均年化跑输市场约 3%
- 该明星经理是 12 只中唯一仍在运营且业绩好的
→ 这些片段仍不足以估计公司的选股能力：还需其余基金的结果、资产规模、成立与清盘时间、费用、基准和风险暴露。合成样本只能演示选择偏差问题。

## 6. 常见误区

**误区 1：成功者的建议一定有价值**
成功者的经验来自他们特定的路径，但这条路径是否可复制，很大程度上取决于运气成分有多少。失败者可能也做了同样的事，只是运气不好。

**误区 2：历史业绩好的基金经理下一步也会好**
过往排名不能单独证明未来表现；持续性研究会随基金类型、样本期、费用、基准和清盘处理而变化。仅凭过去排名筛选基金，可能遗漏选择偏差和不确定性。

**误区 3：成功的公司证明了某种商业策略有效**
案例研究中的成功公司，往往也做了很多其他同样失败的事。"赢家"的特征不一定是成功的原因，可能只是在成功结果出现后才被总结出来的共同点。

**误区 4：只看幸存者是"自然的"，没什么问题**
幸存者偏差不只是认知问题，它会系统性扭曲风险判断（低估失败概率）、策略评估（高估有效性）和人才评价（高估技能占比），导致错误的投资决策和错误的资源配置。
