# 伪量化识别

> 本篇来源与证据边界见[来源索引中的对应条目](../来源索引.md#finance-source-096)。

## 1. 核心概念

**伪量化（Pseudo-Quant）**
使用量化语言和工具的外观（算法、模型、回测图表），但实质上缺乏真实 Alpha 来源、存在严重的回测偏差，或使用欺骗性手段误导投资者的策略或产品。

**真量化 vs. 伪量化的本质区别**

下表是尽调线索，不是分类定律；单项异常不能单独证明策略造假。

| 维度 | 真量化 | 伪量化 |
|------|--------|--------|
| 逻辑来源 | 先有假说，再验证数据 | 先挖数据，再构造解释 |
| 回测样本 | 样本外验证 + 实盘跟踪 | 仅样本内，无样本外 |
| 成本假设 | 保守，贴近实际 | 极低或未说明 |
| 参数设计 | 参数有业务/统计解释，并控制筛选偏差 | 大量尝试后只展示最优参数，缺少独立验证 |
| 实盘表现 | 差异能结合市场状态、成本、容量和风险解释 | 只展示回测，或回测与实盘差异无法解释 |
| 策略透明度 | 核心逻辑可解释 | 黑箱，"算法保密" |

## 2. 核心机制

**伪量化的常见手法**

**手法 1：只展示样本内回测**
```
红旗：没有样本外验证，只展示一条漂亮的历史净值曲线
识别：问：回测数据是否参与了策略开发？样本外期间（未参与优化）的表现如何？
```

**手法 2：回测成本假设极低**
```
红旗：高换手策略的成本假设明显低于相关市场、规模和成交方式可支持的水平，或完全未披露
识别：问换手率、问成本假设；自己估算真实年化成本并重新计算净 Alpha
```

**手法 3：选择性展示时间段**
```
红旗：研究者在看到结果后选择起点，或只报告有利时期
识别：要求按事先说明的样本、多个市场状态和合理基准展示结果；选择哪些时期要与策略的适用范围相符
```

**手法 4：参数过度拟合（曲线拟合）**
```
红旗：尝试大量参数组合后只报告最优结果，且参数缺少事前理由或独立验证
识别：在有业务含义的邻近参数范围内做稳健性检查；范围应按参数定义确定，不套固定数量或百分比，结果敏感也需调查而非直接定性
```

**手法 5：幸存者偏差数据**
```
红旗：回测数据库不包含退市股票，只含目前存续的股票
识别：问：数据库是否含历史退市股？对价值类策略影响尤其大
```

**手法 6："黑箱"掩护**
```
红旗："具体算法是核心机密，无法披露"——真正有价值的量化策略，逻辑可以解释，具体参数才是机密
识别：策略逻辑（价值、动量、质量等）应该能解释；"连逻辑都保密"通常是没有合理逻辑
```

**手法 7：误导性业绩归因**
```
红旗：只宣传绝对收益，不提供同期基准、风险暴露和费用口径（市场普涨时，绝对收益可能主要反映市场贝塔）
识别：要求看同期的 Alpha（相对基准超额），而非绝对收益
```

## 3. 分析框架

**评估一个量化产品的尽职调查清单**

**回测质量**
- [ ] 是否有事前划分、未参与选模的验证数据，并在开发后保持未触碰？
- [ ] 是否覆盖与策略适用范围相关的多种市场状态？样本范围是否由明确问题决定，而非事后挑选？
- [ ] 交易成本假设是否合理（可以独立估算）？
- [ ] 数据是否包含退市股票？是否有前视偏差？

**策略逻辑**
- [ ] 能否用非技术语言解释策略的核心逻辑？
- [ ] 策略有经济学/行为学解释，还是纯粹的数据发现？
- [ ] 参数选择是否有事前解释？是否披露尝试过的模型/参数范围，并处理多重检验和选择偏差？

**实盘历史**
- [ ] 有没有实盘记录？实盘与回测的相关性如何？
- [ ] 实盘期间的 Alpha 相对于同期市场基准是多少？
- [ ] 规模变化与 Alpha 变化的关系（是否有容量问题）？

**风险与透明度**
- [ ] 是否清楚说明了策略的风险因子暴露？
- [ ] 最大回撤在回测和实盘中分别是多少？
- [ ] 是否有独立的第三方业绩审计？

## 4. 关键指标或关键变量

**回测 → 实盘差异**
= 实盘年化 Alpha / 回测年化 Alpha

这个比值仅在两边 Alpha 定义、基准、费用和风险口径一致时才有描述意义，不能用统一区间判断策略真假。分母接近零时比值不稳定，短实盘样本会受市场状态和估计误差支配；还应比较置信区间、实际成交、容量和逐期归因。

**信息比率（ICIR）的时序稳定性**
分期 ICIR 用于检查信号是否只在特定状态生效。状态依赖不等于虚假，但必须在策略假设、仓位和风险预算中明确，不能用全期平均值掩盖。

**参数空间的平滑性**
检查核心参数邻域而非只看最优点。邻域范围应由参数含义和交易频率决定，不机械套用固定百分比；狭窄尖峰值得调查，但不能单独证明过拟合或数据问题。

## 5. 实际例子

以下均为教学用合成情景，数字为假设值，不代表真实产品、市场平均值或实证阈值。

**例 1：回测与实盘的断层**
某量化私募展示回测：2013-2021 年年化 35%，最大回撤 8%，夏普 3.2，看起来完美。实盘（2022 年起）：年化 8%，最大回撤 25%，夏普 0.4。原因分析：① 回测覆盖了 2013-2021 的特定市场结构 ② 回测使用了退市后才知道的股票列表 ③ 成本假设万分之一（实际远高于此）。

**例 2：参数优化导致的过拟合**
某策略核心参数是"均线交叉周期"。研究员测试了从 3 天到 120 天的所有整数组合（118 个参数值），发现 47 天和 48 天的组合夏普最高（2.8）。但当改变为 46 天或 49 天时，夏普降至 0.6。47-48 天没有任何经济学意义，这是典型的曲线拟合——只在历史数据上"碰巧"有效。

**例 3："量化"名义下的主观择时**
某产品宣称"AI 驱动量化策略"，实际上是用机器学习模型做宏观择时（满仓/空仓切换），2019-2020 年因为恰好在牛市期间重仓而表现亮眼。但深入看：① 模型每月只切换一次，不是真正的量化高频信号 ② 模型参数每季度人工调整 ③ 2022 年回撤 35%（与指数相当）。本质是加了算法包装的主观择时，与传统量化完全不同。

## 6. 常见误区

**误区 1：有回测图表就是量化**
美观的净值曲线图 + 数学公式 ≠ 有效的量化策略。反复尝试模型和参数会增加样本内过拟合风险，关键是评估过程是否独立、可复核并考虑真实交易条件。

**误区 2：夏普比率很高 = 策略很好**
单个样本内夏普值不能证明策略稳健；重复尝试会带来选择偏差，样本外结果也有估计误差，仍需结合预先设定的检验、成本、风险暴露和经济机制。

**误区 3：规模大 = 策略真实**
大规模量化产品也可能依赖回测偏差建立声誉，再用规模背书自身。规模是营销能力的体现，不是策略有效性的保证。

**误区 4：团队学历背景保证质量**
学历和从业背景既不是策略真实有效的充分条件，也不是必要条件；应核验数据、交易记录、方法、费用、风控和独立审计证据。
