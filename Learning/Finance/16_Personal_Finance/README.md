# 个人财务与规则核对

现有 Finance 已覆盖资产、负债、现金流、保险、投资、组合和风险。本目录补充把这些知识落到个人财务系统、账户边界和税务/规则核对流程。

## 主线

~~~text
现金流与资产负债表
  → 应急与风险转移
  → 投资政策与账户边界
  → 税务/监管/产品核对
  → 年度复盘与人生目标
~~~

## 边界

- 不提供特定司法辖区的税务、法律或投资建议。
- 税率、申报、账户保障、产品条款和监管规则必须以目标地区官方来源和最新文件为准。
- 个人计划先记录目标、期限、流动性、风险承受和家庭责任，再讨论产品。
