# 个人财务系统与决策

个人财务的核心不是寻找单一最佳产品，而是让现金流、风险、目标、账户和决策记录相互一致。

## 1. 四张表

定期更新：

- 资产负债表：拥有什么、欠什么、净值和流动性。
- 现金流表：收入、固定支出、弹性支出、储蓄和投资。
- 风险表：失业、疾病、家庭责任、汇率、平台和欺诈暴露。
- 目标表：金额、时间、优先级、可接受波动和最晚决策时间。

账面净值高不等于短期有支付能力；高收益资产也不等于应急资金。

## 2. 决策顺序

1. 先保证基本现金流和短期安全垫。
2. 识别不可承受的风险并考虑保险、负债和分散。
3. 按目标期限分配流动性和风险预算。
4. 写出投资政策：资产范围、仓位、再平衡、停止条件。
5. 定期复盘目标是否改变，而不是只追踪市场涨跌。

## 3. 产品评估

每个产品至少记录：

~~~text
法律/经济上的所有权：
收益来源：
费用、税费和隐含成本：
流动性与退出条件：
杠杆、保证金和尾部损失：
发行方/托管方/平台风险：
适用目标：
不适用情形：
核对来源与日期：
~~~

不要根据历史收益、宣传语或单个评级替代现金流、条款和风险分析。

## 4. 年度复盘

复盘实际现金流、风险事件、目标变化、资产配置偏离和决策错误。区分市场结果、策略结果、执行错误和生活变化，不把短期盈亏当成全部反馈。

## 实际整理个人财务时

在需要真正整理时，可用脱敏数据建立一份个人财务仪表盘和一页投资政策，明确短期资金、长期资金、不可承受风险和产品核对来源；不必为练习制造虚构数据。
