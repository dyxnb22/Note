# AI 实践

本目录的实践代码按“能运行、能解释、能复现”维护。每个实验至少注明依赖/模型版本、输入数据、运行命令和结果位置；代码注释优先说明张量形状、数据边界、随机性、资源生命周期和失败处理。

实验结果没有实际运行证据时，统一标记为“待验证”，不把代码存在写成实验完成。

这里存放与 `Learning/AI` 理论笔记配套的可运行实验。

- [llm_learning 课程实践](./llm_learning/README.md)：从深度学习、Transformer、Agent、RAG 到评测、微调、生产系统和研究方法的 00–11 宽路线；Agent 应用主线仍以 `Learning/Agent/实践/ai-agent-learning` 为准。
- [DeepPath Lab](./DeepPathLab/README.md)：以“笔记 → 基线复现 → 从零实现 → 实验 → 报告”的方式，实践深度学习核心模块。
- [Agent Runtime 实践](../../Agent/实践/learn-claude-code/README.md)：以 s01–s20 学习 Agent Loop、Tool Calling、Context、Durable Execution、团队协作和 MCP。

原则：理论只在 `Learning/AI`、`Learning/Agent` 的主笔记中维护；实践目录保留运行代码、实验输入、输出样例和最小运行说明。
