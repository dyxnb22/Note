# 多层感知机与激活函数

线性模型把输入直接映射为输出。即使连续叠加多个仿射层，`(XW₁ + b₁)W₂ + b₂` 仍能整理为一次仿射变换；隐藏层需要加入非线性，才能改变可表示的关系。

## 用 XOR 观察非线性的作用

XOR 在两个二进制输入不同的时候输出 1，相同时输出 0。一个线性分界无法同时把两个对角位置归到同一侧；分段线性的 ReLU 可以先构造中间特征，再组合它们。

令 `h₁ = ReLU(x₁ + x₂)`、`h₂ = ReLU(x₁ + x₂ - 1)`，输出为 `h₁ - 2h₂`。输入和分别为 0、1、2 时，输出依次为 0、1、0。这个固定参数的小网络展示了表示能力，尚未涉及通过训练找到参数。

```python
def relu(value):
    return max(0, value)

def xor_score(x1, x2):
    hidden1 = relu(x1 + x2)
    hidden2 = relu(x1 + x2 - 1)
    return hidden1 - 2 * hidden2

assert [xor_score(a, b) for a, b in [(0, 0), (0, 1), (1, 0), (1, 1)]] == [0, 1, 1, 0]
```

## 激活函数同时影响表示与梯度

ReLU 保留正半轴，负半轴输出 0；某个单元若持续落在负半轴，经过它的局部梯度也会为 0。Sigmoid 与 Tanh 在输入绝对值很大时趋于饱和，梯度可能变小；GELU 使用平滑的门控形状。选择激活时既要看输出范围，也要看反向传播经过它时的行为。

输出层还要服从任务含义。连续值回归可以直接输出实数，多分类通常输出 logits；二分类可以输出一个 logit，再由 `BCEWithLogitsLoss` 计算损失。隐藏层的非线性和最终概率解释承担不同职责。

## 反向传播连接每一层的局部变化

前向传播保存中间值并计算损失，反向传播按链式法则计算参数如何影响这项损失。多层导数相乘时，梯度可能缩小或放大；初始化、归一化、残差路径和学习率都会影响这个过程。

Xavier、He 等初始化方法根据层的结构与激活特性控制初始尺度。出现 NaN 或梯度异常时，要检查输入有限性、损失实现、激活分布和梯度范数；裁剪梯度能限制单次更新，却无法修复持续错误的数据或计算。

增加宽度和深度扩大了表达空间，也增加拟合噪声的可能。能表示 XOR 解释的是模型容量，能否在新样本上工作则需要[模型选择与泛化](./模型选择、欠拟合与过拟合.md)继续判断。
