# 卷积神经网络基础

图像的相邻像素往往相关，同一种边缘或纹理也可能出现在不同位置。卷积层让一个小的加权计算在空间上重复使用，用局部连接与参数共享表达这种结构。

## 一个卷积核怎样生成特征图

取 3×3 输入，内容依次为 1 到 9；用全为 1 的 2×2 核、步幅 1、不填充。左上角窗口求和为 `1+2+4+5=12`，向右移动得到 16；下一行得到 24、28，因此输出是 2×2。

```python
image = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
kernel = [[1, 1], [1, 1]]
output = [
    [sum(image[row + i][column + j] * kernel[i][j]
         for i in range(2) for j in range(2))
     for column in range(2)]
    for row in range(2)
]
assert output == [[12, 16], [24, 28]]
```

同一组核参数在所有窗口共享；训练更新这组参数后，会同时改变各个位置的响应。局部感受野限制一层直接看到的区域，叠层和下采样再扩大后续特征所覆盖的输入范围。

## 填充、步幅与输出尺寸

对高度 H、核大小 K、两侧对称填充 P、步幅 S、膨胀率 D，输出高度为 `floor((H + 2P - D(K-1) - 1) / S) + 1`，宽度同理。常见不使用膨胀卷积的情形取 D=1。

步幅为 1、奇数核与适当填充可以保持高宽；增加步幅会减少输出位置。平移等变也受步幅、填充和边界影响，不能由“用了卷积”直接推得任意平移下分类结果完全不变。

## 通道与池化承担什么职责

每个输出通道的核同时覆盖输入通道，并把各通道的局部结果相加。若有 3 个输入通道、8 个输出通道、3×3 核，标准卷积的核参数数为 `8×3×3×3=216`，另可有 8 个偏置。输出通道表示不同的特征响应。

池化聚合相邻位置，通常没有可训练参数，但会减少空间细节。分类可以利用这种汇总；检测和分割还需要保留定位信息，因此要结合任务分析下采样的代价。

## 从特征图到分类

LeNet 把卷积、激活、池化和分类头串成完整过程：前部生成空间特征，后部汇总并输出类别分数。观察每层张量形状，可以把感受野、参数量和分类头的输入对应起来。

准确率异常时先核对图像范围、标签、训练与评估模式，再分析模型容量和优化。后续架构通过多尺度、残差与特征复用改变这条计算链路，见[现代卷积网络](../06_现代卷积网络/现代卷积网络.md)。
