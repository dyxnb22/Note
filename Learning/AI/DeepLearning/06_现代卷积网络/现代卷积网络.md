# 现代卷积网络

卷积网络的演进可以沿三个问题理解：怎样获得更有用的特征，怎样控制计算和参数量，以及深度增加后怎样继续训练。网络名称对应的是这些问题的不同组合。

## 深度、局部感受野与分类头

AlexNet 展示更深网络、ReLU、Dropout 与 GPU 训练的组合；VGG 用重复的小卷积核形成规则结构。多个小核叠加可以扩大感受野，并在层间加入额外非线性，表示与成本都随之变化，不能只比较最终感受野大小。

NiN 使用 1×1 卷积组合同一空间位置的通道，再用全局平均池化汇总分类特征。它改变的是通道处理和分类头组织方式；1×1 核虽然不直接扩大空间感受野，仍然能够学习通道之间的关系。

## 多尺度分支与通道压缩

Inception 把不同尺度的卷积和池化并行计算，再沿通道维拼接。若四个分支分别输出 32、64、16、16 个通道，拼接后就是 128 个通道；各分支高宽必须能够对齐。

1×1 卷积可以先压缩输入通道，减少后续较大卷积核的成本。忽略偏置，直接把 256 通道经 3×3 核映射为 64 通道需要 147456 个参数；先用 1×1 压到 32 通道，再用 3×3 输出 64 通道，共需 26624 个参数。压缩也改变了中间表示，是否值得仍取决于任务效果。

BatchNorm 根据统计量调整激活，再学习缩放和偏移。默认运行方式中，训练使用批次统计并更新运行统计，评估使用保存的运行统计；小批次和分布变化会影响估计，训练、评估状态混用也会改变结果。

## 相加与拼接形成不同路径

ResNet 输出 `F(x)+x`，让变换路径之外还存在直接传递信息和梯度的路径。相加要求形状一致；通道数或空间尺寸变化时，捷径也需要作对应变换。

DenseNet 将已有特征与新特征拼接。例如输入 64 通道、某层新增 32 通道，拼接后为 96；下一层再新增 32，就成为 128。已有特征可以继续使用，代价是更大的激活与通道管理开销。

这两种连接不能仅按“都有跳连”理解：相加合并同一形状的表示，拼接保留不同通道的表示。架构取舍需要同时观察参数、激活内存、计算量和实际训练表现。
