# 线性回归：从预测误差到参数更新

线性回归用输入的加权和预测连续值：`ŷ = Xw + b`。每个权重表示一个输入维度怎样影响预测，偏置提供不依赖输入的平移；训练需要根据误差调整这些参数。

## 损失如何给出更新方向

对 N 个样本，使用半均方损失 `L = Σ(ŷᵢ - yᵢ)² / (2N)`。一维输入时，权重梯度为 `Σ((ŷᵢ - yᵢ) xᵢ) / N`，偏置梯度为 `Σ(ŷᵢ - yᵢ) / N`。梯度描述损失增大的方向，更新则沿相反方向移动。

取两条数据 `(1, 2)`、`(2, 4)`，从 `w=0、b=0` 开始。预测均为 0，损失为 5，两个梯度分别为 -5 和 -3。学习率取 0.1，一步更新得到 `w=0.5、b=0.3`，损失降为 2.1825。

```python
from math import isclose

samples = [(1.0, 2.0), (2.0, 4.0)]

def loss(w, b):
    return sum((w * x + b - y) ** 2 for x, y in samples) / (2 * len(samples))

w = b = 0.0
errors = [w * x + b - y for x, y in samples]
grad_w = sum(error * x for error, (x, _) in zip(errors, samples)) / len(samples)
grad_b = sum(errors) / len(samples)
w -= 0.1 * grad_w
b -= 0.1 * grad_b

assert isclose(w, 0.5) and isclose(b, 0.3)
assert isclose(loss(w, b), 2.1825)
assert loss(w, b) < loss(0.0, 0.0)
```

例子使用 Python 标准库，直接展示一次更新。损失在这一步下降，只说明这组数据与步长下的行为；更大的学习率仍可能跨过合适区域，使损失上升。

## 张量形状怎样改变计算

把多个样本合在一起时，X 可以是 `(N, d)`，w 是 `(d, 1)`，输出为 `(N, 1)`。标签若是 `(N,)`，需要明确调整形状；依赖隐式广播可能意外得到 `(N, N)` 的误差矩阵。

下面两个函数用于张量计算，分别表达模型和逐元素损失：

```python
def linreg(X, w, b): return X @ w + b
def squared_loss(y_hat, y): return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2
```

自动微分负责计算梯度，优化器负责根据梯度更新参数。训练循环依次完成前向计算、损失、反向传播、参数更新与梯度清空；梯度是否累积应由训练方案明确决定。

## 从手动计算到框架封装

`nn.Linear` 保存权重与偏置，`nn.MSELoss` 计算平方误差，`torch.optim.SGD` 执行更新。默认均方误差与前文半均方损失相差系数 2，对照手算结果时需要统一归约方式和学习率。

合成已知参数的数据可以检查模型是否沿预期方向学习；真实数据还需要验证集观察泛化。损失不降时先检查输入、标签形状和更新是否执行；训练表现好而验证差时，再分析切分、泄漏与模型对数据的适配程度。分类任务会把误差定义换成类别概率，见[Softmax 回归](./Softmax回归与图像分类.md)。
