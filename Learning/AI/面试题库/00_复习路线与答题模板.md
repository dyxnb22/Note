# AI 面试复习路线与答题模板

## 复习路线

1. Token、Embedding、Attention、Transformer 和生成。
2. 预训练、SFT、LoRA/QLoRA、偏好优化和模型行为。
3. KV Cache、量化、批处理、长上下文和推理服务。
4. 评测、数据、成本、延迟、部署和安全边界。

## 统一答题模板

回答模型问题时按以下顺序：

1. **先说它解决什么问题**。
2. **解释输入、状态、计算和输出的因果链**。
3. **说明复杂度、数据、显存、延迟或质量代价**。
4. **补模型版本、数据边界、失败模式和安全风险**。
5. **给验证方法**：数值检查、离线评测、消融、压测或线上灰度。

## 与 Agent 的连接

模型基础题回答“模型怎么工作”；Agent 题回答“系统怎样围绕模型控制状态、工具、副作用和恢复”。不要把模型能力问题、Context 组装问题和 Tool 执行问题混成一个答案。
