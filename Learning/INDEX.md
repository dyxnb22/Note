# Learning 总索引

这里按“可复用知识”组织长期内容。它只负责选择主题，不维护逐篇阅读顺序和完成度。

从与当前问题最接近的主题入口开始。不要把本页或任何目录当成连续必修课。

技术主线不是固定课程。常见关系是：

```text
计算机基础 → 工程实现 → 系统设计 → AI/Agent 应用 → 项目验证
```

已经具备的能力直接跳过；具体学习顺序回到对应主题入口。

## 使用规则

1. 先处理真实问题；遇到知识缺口再进入相应主题。
2. 概念正文用于理解，不默认附带必须完成的练习；实践和项目负责运行与验证。
3. 格式、措辞和轻微重复不应打断当前学习；只在下次使用该主题时顺手整理。
4. 跨主题导航只链接稳定入口，局部拆分和重命名尽量留在主题内部。
