三层检测 + 一条执行原则:

1. **标题级相似度**(字符 bigram Jaccard + difflib,703 题两两比对):14 对候选 → 确认 5 对真重复(其余为递进/视角)。

3. **主题级人工裁决**(6 个并行子代理分组通读全部 29 文件、约 700 题):按题库 README 既有权威归属规则,区分三类——
   - **真重复**(同深度讲同一内容)→ 桥接化
   - **递进复现**(同概念按 Level 递进加深)→ 不动(设计意图)
   - **视角差异**(同一主题不同切面)→ 不动
4. **执行原则**:桥接化只压缩答案体,题干、题号、题量一律不动;主入口写完整答案,重复处保留 ≤3 行差异点和指向主入口的 wikilink(即 README "主入口/桥接入口" 规则)。跨库桥接(指向 ../AI、../Backend)前逐一 grep 验证主库确有实质覆盖,无覆盖则降级为"保留原答案+指向行"。
