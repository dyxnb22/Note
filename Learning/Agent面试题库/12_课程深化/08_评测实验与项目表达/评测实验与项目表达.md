# 评测实验、实践路线与项目表达

> 递进路径：先把完整 Agent 任务拆成可验证证据，再建立 Harness、Replay 和发布门禁，最后把实践项目讲成有边界、有数据的项目经历。

## Level 1｜Agent 专项评测

1. 为什么 Agent Eval 不能只评最终文本？
2. 一个 Agent Case 除了输入和答案，还应描述什么？
3. 完整 Agent 评测至少要分哪几层？
4. Unit、Mock Provider、Isolated Scenario 和 Replay 各证明什么？
5. Agent 专项指标应关注哪些轨迹和安全信号？
6. 一条可重放的 Agent 记录至少包含什么？
7. 为什么程序验证优先于 LLM Judge？

## Level 2｜Harness 与发布

8. 一个最小 Eval Harness 由哪些组件组成？
9. 测试集如何同时覆盖正常、边界、事故和对抗样本？
10. 如何避免评测集泄漏、重复和过拟合？
11. Mock Provider 的价值和边界是什么？
12. 如何设计隔离场景，避免真实副作用污染测试？
13. Baseline、Candidate 和 Slice 应如何比较？
14. CI 中的 Agent 测试应如何分层？
15. Online feedback、Replay 和永久回归集如何形成闭环？
16. 如何设计一次 Prompt/模型/工具改动的发布门禁？

## Level 3｜实践项目与项目表达

17. 一个 Agent 项目应该如何从一次调用逐步演进到服务化、图编排、Memory、RAG 和 MCP？
18. 为什么实践项目中的 Mock Provider、内存 Checkpointer 和关键词检索不能直接当生产方案？
19. Tool Calling 实践中，`tool_call → execute → tool_result` 的关键合同是什么？
20. LangGraph Tool Agent 的 Planner、ToolNode 和 Final Answer 如何分工？
21. MCP Server 中 Tool、Resource、Prompt 的边界是什么？
22. DevPilot 这类 Coding Agent MVP 为什么先生成建议级 diff？
23. 如何把一个练习项目讲成“自己解决了什么工程问题”？
24. AI 项目的项目表达骨架是什么？
25. RAG 项目面试时应重点准备哪些追问？
26. Agent 项目面试时应重点准备哪些追问？
27. Agent 系统设计题应该如何从业务目标开始回答？

## Level 4｜场景追问

28. 设计一个最小的 10 条 Agent Eval 集，你会覆盖哪些 Case 和验证器？
29. 面试官问“你的 Agent 线上效果怎么样”，在没有完整线上数据时如何准确回答？
30. 如何把一次失败的实践实验转化成项目亮点，而不是只说“代码跑通了”？
