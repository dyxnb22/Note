# 课程深化

这里承接原 `Learning/Agent` 课程中适合面试刷题、但不宜继续保留为长篇课程正文的内容。每个专题都按“基础认知 → 原理机制 → 工程取舍 → 场景追问”递进，答案直接跟在每道题下方。

- [[01_Provider与框架/Provider适配与框架选型]]：Provider Adapter、流式/结构化输出、框架选型和图编排。
- [[02_代码Agent与ComputerUse/代码Agent与ComputerUse]]：代码库导航、Patch、验证、Worktree、Computer Use 和 GUI 安全。
- [[03_Durable与生产运维/Durable与生产运维]]：任务状态、幂等、队列恢复、部署、灰度、降级和事故响应。
- [[04_知识摄取与GraphRAG/知识摄取与GraphRAG]]：文档解析、OCR、表格、混合检索、知识版本和 GraphRAG。
- [[05_身份治理与跨Agent/身份治理与跨Agent]]：身份、数据治理、能力授权、多 Agent 委托和跨 Agent 协议。
- [[06_推理与模型行为/推理与模型行为]]：推理服务、额外推理预算、工具行为诊断和训练边界。
- [[07_实时交互与产品/实时交互与产品]]：语音/实时 Agent、自主性、审批、接管、Skill 和渐进式披露。
- [[08_评测实验与项目表达/评测实验与项目表达]]：Agent Eval、Replay、发布门禁、实践路线和项目表达。

实践代码没有整体复制到题库；有价值的实现边界已经转化为 `08_评测实验与项目表达` 中的项目题和场景题。

课程深化之后，可继续刷各主分类下标注“面经高频补充”的子题单，把近期面经中更偏 Loop/Harness、线上故障、系统取舍和高频八股的追问补齐。
