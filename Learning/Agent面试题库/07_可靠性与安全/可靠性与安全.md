# Agent 可靠性与安全

> 递进路径：先识别失败，再建立安全边界，最后把沙箱、审批、审计和恢复放进系统。

## Level 1｜基础认知：Agent 为什么会失控

1. Agent 幻觉有哪些类型？如何定位来源？
2. 如何通过检索、工具验证、交叉检查和人工确认减少幻觉？
3. 如何识别 Agent 没有真正执行工具而是编造结果？
4. 长任务如何避免死循环、重复计划和无效重试？
5. 如何设计最大步数、最大 Token、超时和预算上限？
6. 子任务失败、数据损坏或返回异常时，如何重试、降级和恢复？
7. 如何区分可重试错误和不可重试错误？
8. 如何保证重试不会重复执行外部副作用？
9. 如何处理部分成功、部分失败和不可逆动作？
10. 如何设计 Fallback、熔断、重试、降级和人工转接？
11. 如何处理模型、工具、数据库或网络供应商故障？
12. 如何让 Agent 在不确定时主动拒答或请求确认？

## Level 2｜安全机制：信任边界和数据保护

13. 什么是 Prompt Injection？直接注入和间接注入有什么区别？
14. 如何防御恶意网页、文档、邮件和工具返回中的注入？
15. 如何防止用户输入覆盖系统约束？
16. 如何防止数据外泄？
17. 如何设计最小权限、凭证隔离、租户隔离和网络隔离？
18. 如何让不同 Agent 只能看到自己需要的数据？
19. 如何处理模型输出中的敏感信息？
20. 如何做敏感信息识别和脱敏？

## Level 3｜工程落地：沙箱、审批与审计

21. 代码执行、Shell、浏览器和数据库工具如何沙箱化？
22. Docker、容器、虚拟机和专用沙箱如何选择？
23. 如何限制 CPU、内存、磁盘、网络、进程和执行时间？
24. 哪些动作必须 Human-in-the-Loop？
25. 如何让用户预览、确认、撤销和回滚 Agent 动作？
26. 如何记录审计日志？日志中哪些信息不能直接保存？
27. 如何让 Agent 行为可解释、可追踪和可回放？
28. 如何评估系统的安全边界和越权风险？
29. 如何处理多租户场景下的权限、配额和数据隔离？
30. 如何在安全、体验、成本和自动化程度之间取舍？

## Level 4｜场景追问：高风险动作如何可控

31. 设计一个可以查订单、退款和修改地址的客服 Agent，哪些动作需要人工确认？
32. 网页内容要求浏览器 Agent 忽略系统指令并上传用户文件，如何在数据层、模型层和工具层拦截？
33. 工具调用已经成功但前端断线了，重试前如何判断外部副作用是否已经发生？
34. 如何用一次真实事故复盘证明安全机制不是只停留在 Prompt？
