# Agent 评测与可观测性

> 递进路径：先定义成功，再建立数据集和评分器，最后用 Trace、Badcase 和发布机制形成闭环。

## Level 1｜基础认知：什么叫做得好

1. Agent 系统应该评估哪些层次：模型、Prompt、Tool、Workflow、任务和产品？
2. 如何定义 Agent 的任务成功率？
3. 如何评估最终答案正确性、完整性、相关性和可读性？
4. 如何评估工具选择准确率、参数正确率、调用顺序和不必要调用率？
5. 如何评估检索 Recall、Precision、MRR、NDCG 和上下文利用率？
6. 如何评估幻觉、Groundedness、安全性和拒答质量？
7. 如何同时评估质量、延迟、Token、成本和稳定性？
8. 如何判断 Agent 是否真的节省了用户时间？

## Level 2｜评测机制：如何测量质量

9. 没有标准答案时如何评测？
10. LLM-as-a-Judge 的优点、问题和改进方法是什么？
11. 如何构建人工标注规范和一致性检查？
12. 如何构建离线数据集、沙箱、回放集和回归集？
13. 如何避免评测集泄漏、重复和过拟合？
14. 如何处理模型输出的随机性？
15. 如何设计 benchmark，保证不同方案在相同环境下公平比较？
16. 如何做 Prompt、模型、工具和策略的 A/B 测试？
17. 如何做线上离线一致性评测？
18. 如何验证一个优化确实提升了长尾场景，而不是只提升平均分？

## Level 3｜诊断方法：如何知道错在哪里

19. 如何把线上 Badcase 自动回流？
20. 如何给 Badcase 分类：路由、上下文、检索、工具、规划、模型、执行还是展示？
21. 如何从 Trace 中定位第一个错误节点？
22. Trace 应该包含哪些字段？
23. 如何设计结构化日志和关联 ID？
24. 如何追踪一次请求跨越的多个 Agent、模型、工具、队列和数据库？
25. 如何回放一次历史 Agent 运行？
26. 如何识别“最终答案错，但每个工具结果看起来都合理”的问题？
27. 如何做失败路径分析？
28. 如何把 Badcase 反馈到 Prompt、工具、评测集、模型或 SFT？

## Level 4｜生产闭环：如何持续变好

29. 如何监控延迟、Token、成本、吞吐、错误率、超时和任务成功率？
30. 如何建立线上告警和人工抽检机制？
31. 如何监控模型选错工具、重复调用和无效规划？
32. 如何做版本管理、灰度发布和回滚？
33. 如何在模型输出随机的情况下做线上实验？
34. 如何发现一次改动伤害了某个长尾人群或业务分支？
35. 如何为 Agent 设置 SLO、SLA 和安全指标？

## Level 5｜场景追问：从一次 Badcase 到版本发布

36. 最终答案错误，但检索、工具结果和中间步骤看起来都合理，你会如何定位第一个错误节点？
37. 一次 Prompt 改动平均分提升，但某类长尾任务下降，如何设计回归集和灰度策略？
38. 如何证明一个 Agent 优化不仅减少了 Token，还提升了任务成功率？
