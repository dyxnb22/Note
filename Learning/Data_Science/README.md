## 主线

~~~text
问题定义
  → 数据合同与抽样
  → Python 数据分析与 EDA
  → 可解释基线
  → 特征与模型
  → 评估、实验与决策
  → 部署、监控与复盘
~~~

数据科学不是“选择一个模型并追求最高分”。完整结果必须说明：

- 模型服务的哪个决策。
- 样本和标签代表谁。
- 预测在什么时间点可用。
- 错误由谁承担。
- 离线指标如何连接到线上结果。
- 结果失效时如何发现和停止使用。

## 最低实践标准

每个项目至少保存：

~~~text
问题合同、数据清单、时间点、探索图表、朴素基线
特征版本、训练/验证/测试切分、模型指标、错误样本
业务指标、资源成本、失败记录、结论边界和复现命令
~~~

没有数据版本、随机种子、切分规则和失败样本的结果，不应被写成“模型有效”。
