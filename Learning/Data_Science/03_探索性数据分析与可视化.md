# 探索性数据分析与可视化

EDA 的目的不是生产好看的图，而是发现数据生成过程、分布、缺失、异常、分群和可能的错误。

## 1. 四类问题

### 分布

观察中心、离散程度、长尾、零值、截断和多峰。平均数不能代替分位数；长尾数据应同时看原始尺度和合适的变换。

### 缺失

按字段、时间、来源和群体观察缺失率。缺失本身可能携带业务信号，也可能暴露采集流程故障。

### 关系

区分单变量、两变量和多变量关系。相关图不能证明因果；分层前后关系变化，可能意味着混杂或 Simpson 悖论。

### 分群

按时间、地区、产品、渠道、客户状态和数据来源切分，检查总体平均是否掩盖了关键群体的差异。

## 2. 图表选择

| 问题 | 可选图表 | 主要风险 |
|---|---|---|
| 分布 | 直方图、箱线图、ECDF | 分箱、极端值和样本量被隐藏 |
| 时间变化 | 折线、滚动统计 | 频率、缺口和季节性被忽略 |
| 类别比较 | 点图、排序条形图 | 类别过多、基线不一致 |
| 两变量关系 | 散点、分箱均值 | 相关被误读为因果 |
| 分群 | 分面图、热力图 | 分组过多导致图表不可读 |

图表必须标出单位、时间范围、分母、样本量、过滤规则和不确定性。

## 3. 异常值处理

异常值可能是：

- 录入错误。
- 单位错误。
- 真实极端事件。
- 业务规则变化。
- 欺诈或攻击信号。

不能把所有极端值直接删除。应先保存原始值，再记录识别规则、处理理由和敏感性分析。

## 4. EDA 输出

一份可复用报告至少包含：

1. 数据来源、范围和粒度。
2. 字段、缺失、重复和质量问题。
3. 关键分布与分群差异。
4. 可能的标签泄漏和时间问题。
5. 需要验证的假设。
6. 对建模、采样和实验设计的影响。

## 项目使用时检查

选择一个业务问题，输出不超过十张核心图表；每张图都能回答一个具体问题，并附上分母、时间边界和未解释部分。
