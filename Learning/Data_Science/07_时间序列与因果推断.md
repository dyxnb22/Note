# 时间序列与因果推断

时间序列预测和因果推断都处理变化，但问题不同：前者预测未来，后者估计如果改变某个因素会发生什么。

## 1. 时间序列预测

先确认：

- 预测对象和频率。
- 可用时间、发布延迟和修订规则。
- 趋势、季节性、节假日和结构变化。
- 预测范围和滚动更新方式。

基线至少包括上一期、季节性上一期、移动平均或简单趋势。复杂模型必须证明比基线更稳定，而不是只在某个区间更好。

验证使用时间顺序：

~~~text
训练窗口 → 验证窗口 → 测试窗口
向前滚动 → 重复预测 → 汇总样本外误差
~~~

不能随机打乱时间序列，也不能使用事后修订数据假装实时可用。

## 2. 因果问题

一个因果问题至少写清：

- 处理或干预是什么。
- 结果是什么。
- 作用对象和时间窗口是什么。
- 哪些变量可能同时影响处理和结果。
- 哪些变量在处理之后产生，不能被错误控制。
- 目标是平均效果、分群效果还是个体决策。

相关性、预测重要性和因果效果不是同一结论。

## 3. 识别策略

- 随机实验：依靠随机化平衡混杂，是优先方案。
- 前后比较：容易把趋势、季节和同时发生的事件误当效果。
- 差分中的差分：需要平行趋势等假设。
- 工具变量、断点和匹配：各自有适用条件，不能只因没有随机实验就随意套用。

每种方法都要写识别假设、可检验迹象、敏感性分析和不能回答的问题。

## 4. 常见误区

- 先看到相关关系，再倒推因果故事。
- 把处理后的变量当控制变量造成中介偏差。
- 只报告显著性，不报告效应大小和区间。
- 多次试验和多次切片后只挑显著结果。
- 把预测准确误认为干预有效。
