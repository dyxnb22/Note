# 不确定性与决策理论

预测、统计检验和模型评估最终都服务于决策。决策理论补充一个问题：在信息不完整、结果有成本的情况下，什么动作更值得做。

## 1. 描述不确定性

区分：

- 随机性：相同条件下结果本身有变化。
- 认识不确定性：数据、模型或机制理解不足。
- 测量误差：观测不准确。
- 分布变化：未来和训练数据不是同一个过程。

置信区间、预测区间、校准概率和敏感性分析回答不同问题，不能互换。

## 2. 贝叶斯更新

贝叶斯思维不是“主观就不科学”，而是把先验、证据和后验更新显式化：

~~~text
先验信念 + 新证据 + 证据质量
→ 更新后的概率/范围
→ 行动阈值与后续信息需求
~~~

先验可能来自历史数据、机制、专家判断或基线；新证据要检查选择偏差、测量误差和独立性。

## 3. 期望效用和阈值

一个动作是否值得，不只看成功概率，还要看：

- 成功收益。
- 失败损失。
- 可逆性。
- 时间和资源成本。
- 对不同群体的分配影响。
- 是否有更便宜的信息可以先获得。

高风险动作应使用更高的证据门槛、人工审批和可撤销设计。

## 4. 信息价值

在行动前询问：

- 这个信息会改变决策吗？
- 获取成本和延迟是多少？
- 是否可以用小实验代替完整建设？
- 错过时机的成本是多少？
- 信息是否会引入新的隐私或安全风险？

不确定性高不等于永远不行动；可以选择小范围、可逆、能产生信息的动作。

## 5. 验收

为一个产品实验、投资决策或 Agent 自动化动作写出：

- 结果状态和概率范围。
- 不同行动的收益/成本。
- 最小可接受证据。
- 可逆性和停止条件。
- 下一条最有价值的信息。
