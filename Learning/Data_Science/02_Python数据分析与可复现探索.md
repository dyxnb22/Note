# Python 数据分析与可复现探索

Python 数据分析的核心不是记住库函数，而是让数据类型、缺失语义、连接关系、排序和时间边界保持可解释。

## 1. 最小工具层

- NumPy：同质数值数组、向量化运算和线性代数接口。
- pandas：带标签的表格、索引、分组、连接和时间序列操作。
- Polars 或其他列式工具：数据量和执行模型需要时再引入。
- Jupyter：适合探索，但最终结论应能回到脚本、报告或可复现管线。
- Matplotlib 等绘图库：图表服务于问题，不替代统计解释。

工具选择应由数据量、团队维护能力、内存限制和部署边界决定，不要把库名当成方法论。

## 2. 读入后先检查

至少检查：

- 行列数量和字段类型。
- 主键、重复行和重复实体。
- 缺失值的编码方式。
- 时间区间、时区和排序。
- 分类值、单位和异常范围。
- 数据来源、下载时间和版本。

缺失值不是单一类型：未知、未发生、不适用、被拒答和采集失败不能默认填成零。

## 3. 表格操作的风险

连接前写清关系基数：

- 一对一、一对多还是多对多？
- 连接后行数预期是多少？
- 是否会重复计算金额或事件？
- 左连接产生的缺失表示什么？

分组聚合前要明确分母。平均值、加权平均、去重用户数和事件次数回答的是不同问题。

## 4. 时间与随机性

可复现探索需要固定：

- Python 和依赖版本。
- 数据文件或原始数据的 Hash。
- 随机种子。
- 时区、排序和过滤条件。
- Notebook 执行顺序或脚本入口。

Notebook 可以帮助发现问题，但不能依赖隐藏状态。清空内核后重新运行，是最低检查。

## 项目使用时检查

对一份脱敏表格数据，能够从原始文件生成一份数据字典、质量报告、清洗脚本和可复现的探索结果；任何删除、填充和聚合都能解释原因。
