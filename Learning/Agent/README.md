# Agent：从运行闭环到生产系统

本模块围绕一条主线组织：**模型提出下一步，程序控制执行，环境返回事实，验证器判断任务是否完成。** 先理解一个可控的单 Agent，再按业务需要引入检索、记忆、多 Agent 和生产能力。目录按 01–12 划分主题；多篇文章的标题使用“模块.篇目”编号表示模块内建议顺序，按需深入的分支可以跳读。

## 从这里开始

- **第一次学**：[Agent 系统全景](./00_01_Agent系统全景.md) → 基础架构 → Context / State → Tool → 一个最小 Loop。
- **准备面试**：先掌握 01–04、07–08 和 09 的平台/恢复主线；再按岗位深入 05、06、09–12。GraphRAG、语音和模型训练等内容按需选学；答题框架与项目证据见 [实践路线与项目表达](./12_综合设计与项目表达/实践路线与项目表达.md)。
- **已有项目要补短板**：从表中对应主题进入，并结合一次真实运行、失败经历或设计约束阅读。

问答是展开知识的方式，不代表必须逐题背诵。各页的分节描述内容，不构成一套统一的难度等级。

## 后续维护

1. 新问题放进所属主题；基础与深化在同一模块内衔接，不再另建一个跨主题的“补充/深化”目录。
2. 同一知识点确定一个主答案，其他页保留场景差异和回链；模型理论、语言基础与来源记录不在这里再建一份完整副本。
3. 具体 API、协议字段、框架行为标明版本；经验性的数量与阈值用实验验证，不当作通用规范。
4. 项目效果写明样本、环境、成功定义和实际数据；没有运行或没有采集的部分明确标为设计或待验证。
