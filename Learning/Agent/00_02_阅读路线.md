# Agent 阅读路线

先运行只读订单咨询案例，跟着消息看工具怎样被调用、结果怎样进入下一轮。读懂这个循环后，再按目标选读下方专题。

## 阅读前需要的基础

能够阅读 Python 的函数、列表、字典、异常、模块导入和 JSON 即可开始。相应入口在[Python 阅读路线](../Python/00_阅读路线.md)。已有后端经验的读者可以直接看下方主线。

先记住四个词：LLM 提出动作，Provider 提供模型接口，Tool 由程序执行，工具返回的结果称为观察。后面的章节会逐步展开它们的关系。
