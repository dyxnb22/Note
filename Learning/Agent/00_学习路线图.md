# AI Agent 学习地图

本页维护稳定的主题依赖，不记录完成进度。日常只更新 [当前学习](../00_当前学习.md)；目录里的文档不是一份必须全部完成的课程清单。

## 第一阶段：只建立核心循环

```text
LLM 调用基础 ↔ 实践 03：Provider 调用
    ↓
Tool Calling  ↔ 实践 04：一次工具调用
    ↓
Agent 架构    ↔ 实践 05：有限循环
    ↓
Context 工程：回看每轮实际输入
```

对应入口：

1. [01 LLM 调用基础](./01_LLM调用基础.md)配合[实践 03](./实践/ai-agent-learning/agent-learning-projects/03_openai_cli_chat/README.md)：观察 Provider 请求、响应、错误和调用元数据。
2. [02 Tool Calling](./02_Tool%20Calling.md)配合[实践 04](./实践/ai-agent-learning/agent-learning-projects/04_tool_calling_agent/README.md)：观察模型提出动作、程序校验并执行动作。
3. [03 Agent 架构与设计](./03_Agent架构与设计.md)配合[实践 05](./实践/ai-agent-learning/agent-learning-projects/05_simple_agent_loop/README.md)：观察有限循环、State、停止条件和成功判定。
4. [04 Context 工程](./04_Context工程.md)：回到实践 05，检查每轮究竟让模型看到了什么。

这四步之外的内容都不是第一阶段前置。Python 和 HTTP 已经熟悉时跳过实践 `01–02`；不需要服务化时跳过 `06`。正文 `01` 可以快速通过，但仍需能解释 Provider 差异应停在哪一层。

## 第二阶段：让一个真实项目决定分支

| 项目遇到的问题 | 阅读顺序 | 何时停止扩展 |
|---|---|---|
| 文件、命令和代码库操作 | [代码 Agent 基础设施](./05_代码%20Agent%20基础设施.md) → [Durable Execution](./06_Durable%20Execution与分布式可靠性.md) | 已能限制权限、预算、重复副作用并恢复一次中断 |
| 安全、质量和上线 | [威胁建模](./07_Agent安全与威胁建模.md) → [安全与可控性](./08_安全与可控性.md) → [Eval](./09_Agent%20Eval实验方法.md) → [可观测性](./11_可观测性与调试.md) | 当前项目已有最小回归集、Trace 和失败处理 |
| 私有或持续更新的知识 | [文档摄取](./文档摄取与解析.md) → [RAG](./RAG.md) → [检索系统](./检索系统工程.md) → [知识系统](./知识系统.md) | 普通检索基线已可评测；没有多跳关系就不进入 GraphRAG |
| 固定步骤、分支或恢复 | [Workflow](./Workflow与编排.md) → [LangGraph](./LangGraph.md) | 普通函数和显式状态已经不够表达流程 |
| 跨客户端提供工具 | [MCP](./MCP与工具协议.md) → [Skills](./Skills与渐进式披露.md) | 单一应用内部调用不需要协议化；工具不多不需要 Skill 路由 |
| 跨会话记忆 | [Memory](./Memory与状态管理.md) | 项目确实需要召回、纠错和删除长期信息 |
| 子任务协作 | [多 Agent](./多Agent协作的边界与模式.md) → [A2A](./跨Agent协议与A2A.md) | 单 Agent 基线已经证明瓶颈来自任务隔离或并行，而不是设计不清 |

Computer Use、语音、推理模型、模型行为训练、框架选型和面试资料属于岗位或产品扩展，只有当前目标涉及时才打开。

- [learn-claude-code](./实践/learn-claude-code/README.md)：理解 Harness、权限、Context、恢复和团队机制时按问题挑实验。

## 学到什么程度算完成

| 里程碑 | 足够的证据 |
|---|---|
| 理解核心循环 | 能沿一次轨迹解释 Model、Tool、State、Context 和停止条件 |
| 能做最小 Agent | 有一个可运行项目，具备配置、超时、错误回填和循环上限 |
| 能可靠交付 | 当前项目有权限边界、固定测试、Trace，以及一次失败或恢复记录 |
| 能迁移能力 | 面对新框架或 Provider，能指出变化发生在适配、工具、状态还是编排层 |

完成里程碑比读完目录重要。可运行验证优先放进真实项目；只在没有现成证据且某项能力确实薄弱时，才额外选一个小验证。
