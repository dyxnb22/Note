# 大厂 Agent 公开题型参考

> 这里保留公开面经和系统设计资料中反复出现的题型，不宣称拥有任何公司的官方题库。公司、岗位、业务和面试轮次会变化；准备时应以目标岗位和自己的项目为准。

## 资料边界

公开资料适合用来发现“会被怎么问”，不适合用来断言“某家公司必考什么”。具体公司题目通常来自候选人回忆、社区整理或二手汇总，存在样本偏差和时效性问题。因此本页只做三件事：

1. 把公开资料归并成稳定的 Agent 题族。
2. 给出题族应该回到哪篇主文档。
3. 保留少量公司场景作为练习背景，而不是复制七套答案。

技术边界以这些资料为准：

- [Anthropic：Building effective agents](https://www.anthropic.com/engineering/building-effective-agents)：Workflow 与 Agent 的边界、简单可组合的设计、工具/检索/记忆等增强 LLM 能力。
- [OpenAI：A practical guide to building AI agents](https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/)：运行循环、退出条件、单 Agent 优先、工具、manager 和 handoff。
- [Anthropic：Demystifying evals for AI agents](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)：任务、试验、评分器、轨迹、结果和评测 Harness。
- [公开的 Generative AI system design interview guide](https://igotanoffer.com/en/advice/generative-ai-system-design-interview)：公开面试材料中常见的 RAG、工具、记忆、可靠性、安全、评测、监控、成本和系统设计题型；其中公司示例不是官方题库。

## 适合拿来练习的公司场景

以下只是把公开资料中常见的业务背景转换成练习题，不代表公司的固定面试偏好：

- 电商/客服：订单查询、退款、投诉升级；重点练工具副作用、审批、SLA、降级和审计。
- 企业知识库：多租户文档、权限检索、引用、更新和删除；重点练 RAG 与数据治理。
- 内容/推荐：实时用户请求、结构化推荐工具、流式响应；重点练延迟、模型路由和评测。
- 金融/风控：金额、规则和用户隐私；重点练规则与 LLM 分工、可解释性、权限和人工复核。
- Coding Agent：仓库读写、命令执行、补丁和测试；重点练沙箱、写后验证、恢复和 trace。

## 复习顺序

1. 先看 [学习范围与面试题型](./学习范围与面试题型.md)，确定 P0 和一个 P1 场景。
2. 按主文档完成机制学习，不在本页展开第二份实现。
3. 用 [Agent 主题速答](./Agent主题速答.md) 做 60 秒口述，再用 [项目表达与面试](../项目表达与面试.md) 做项目深挖。
4. 面试前根据岗位描述添加少量 P2 题，不回头扩写本页的公司清单。

## 面试前 Checklist

- [ ] 能在 2 分钟内讲清一个真实项目的目标、Loop、State、工具、权限、评测数字和一次失败。
- [ ] 能解释 Agent 与 Workflow 的边界，并给出“为什么不需要更复杂方案”的理由。
- [ ] 能说清工具 schema、授权、超时、重试、幂等和人工审批。
- [ ] 能区分 Context、State、Memory，说明长任务如何 checkpoint、恢复和取消。
- [ ] 能从任务结果、轨迹、工具行为、延迟、成本和安全解释 Agent 质量。
- [ ] 能完成一个企业知识、客服或 Coding Agent 的系统设计题。
