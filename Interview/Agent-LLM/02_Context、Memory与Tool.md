## A051｜Todo List 为什么能让模型更聚焦？如何生成、更新和校验 Todo List？

> 题类：Prompt 与 Context Engineering · 来源：[[Learning/Agent面试题库/02_Prompt与上下文/Prompt与Context Engineering#21. Todo List 为什么能让模型更聚焦？如何生成、更新和校验 Todo List？|原题与完整答案]]

**30 秒口述答案**

Todo List 把长任务的目标、已完成事实和下一步显式化，减少模型每轮重新回忆的负担。计划要有状态、依赖和验收条件，完成状态只能由工具结果或验证器推动，不能让模型自报完成。

## A052｜多轮对话中如何区分新任务、补充信息和纠正信息？

> 题类：Prompt 与 Context Engineering · 来源：[[Learning/Agent面试题库/02_Prompt与上下文/Prompt与Context Engineering#22. 多轮对话中如何区分新任务、补充信息和纠正信息？|原题与完整答案]]

**30 秒口述答案**

比较新消息与当前任务 ID、目标和未完成槽位：补充信息更新当前 State，纠正信息覆盖对应事实并标记旧值失效，新目标则创建新任务或明确切换。必要时向用户确认，不能仅凭语气猜测状态迁移。

## A053｜如何设计上下文窗口的 Token 预算？

## A056｜短期记忆、长期记忆、任务记忆、工作记忆分别是什么？

> 题类：Memory 与 State · 来源：[[Learning/Agent面试题库/03_Memory与状态/Memory与State#1. 短期记忆、长期记忆、任务记忆、工作记忆分别是什么？|原题与完整答案]]

**30 秒口述答案**

短期记忆是当前对话或上下文窗口中的近期信息，长期记忆是跨会话保存的稳定事实/偏好，任务记忆是某个任务的目标、计划和中间产出，工作记忆是当前一轮推理需要的临时变量。工程上应按生命周期和权限分开，而不是都塞进聊天历史。

## A066｜为什么可以用 RAG 检索 Memory？向量方式有什么优缺点？

## A098｜MCP Server 如何设计？工具、资源和 Prompt 如何组织？

## A100｜MCP 有什么优点和短板？
