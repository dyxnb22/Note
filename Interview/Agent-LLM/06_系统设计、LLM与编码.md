## A252｜什么时候应该用图状态机或重型框架，什么时候线性链和普通代码更合适？

**30 秒口述答案**

## A257｜Self-Attention 和 Multi-Head Attention 的原理是什么？

> 题类：模型与推理基础 · 来源：[[Learning/Agent面试题库/10_模型与推理/模型与推理基础#2. Self-Attention 和 Multi-Head Attention 的原理是什么？|原题与完整答案]]

**30 秒口述答案**

Self-Attention 用每个位置的 Query 与所有位置的 Key 计算相关性，再对 Value 加权求和；Multi-Head 用多个投影空间并行关注不同关系，拼接后再映射。它让 Token 能根据上下文动态聚合信息。

## A258｜为什么 Attention 使用 Q、K、V？

## A259｜为什么 KV Cache 不缓存 Q？

> 题类：模型与推理基础 · 来源：[[Learning/Agent面试题库/10_模型与推理/模型与推理基础#4. 为什么 KV Cache 不缓存 Q？|原题与完整答案]]

**30 秒口述答案**

自回归生成时新 Token 的 Query 只在当前步使用，而历史 Token 的 Key/Value 会在后续每一步重复参与注意力，因此缓存历史 K/V 能避免重复计算。Q 对每个新 Token 都不同且不需要被未来步骤反复读取，所以通常不缓存。

## A260｜Attention 的时间和空间复杂度是什么？

> 题类：模型与推理基础 · 来源：[[Learning/Agent面试题库/10_模型与推理/模型与推理基础#5. Attention 的时间和空间复杂度是什么？|原题与完整答案]]

**30 秒口述答案**

对序列长度 n，标准全注意力的计算和注意力矩阵空间通常是 O(n²)，这也是长上下文成本高的主要原因；生成阶段 KV Cache 可避免重复计算历史投影，但仍受序列长度和 KV 内存影响。不同稀疏/线性注意力会改变复杂度，但要结合质量和实现成本。

## A261｜Causal Mask 和 Padding Mask 有什么区别？

## A272｜如何估算模型服务的吞吐、并发和显存？
