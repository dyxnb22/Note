## J206｜Maven 的依赖范围有什么区别？

## J208｜Maven 生命周期和常用命令怎么理解？

> 题类：构建与依赖 · 来源：[[Learning/Backend/Java/面试题库/16_Maven#Maven 生命周期和常用命令怎么理解？|原题与完整答案]]

## J209｜Maven 多模块中的继承和聚合有什么区别？

> 题类：构建与依赖 · 来源：[[Learning/Backend/Java/面试题库/16_Maven#Maven 多模块中的继承和聚合有什么区别？|原题与完整答案]]

**30 秒口述答案**

**继承**：父 POM 提取公共插件、属性和依赖版本，子模块可以覆盖父配置。**聚合**：父 POM 用 `<modules>` 统一构建多个模块。聚合本身不等于继承，两者可以单独使用，也可以同时使用。分模块时常按 `api`、`service`、`repository` 等职责拆分，并保持依赖方向单向，避免模块互相依赖。

## J214｜MDC 和 TraceId 有什么作用？

> 题类：日志与可观测性 · 来源：[[Learning/Backend/Java/面试题库/17_Java日志与可观测性#MDC 和 TraceId 有什么作用？|原题与完整答案]]

**30 秒口述答案**

## J246｜String 为什么使用 SDS，而不是 C 字符串？

> 题类：Redis · 来源：[[Learning/Backend/Data/Redis#String 为什么使用 SDS，而不是 C 字符串？|原题与完整答案]]

**30 秒口述答案**

SDS 记录已使用长度和已分配容量，具备以下优点：获取长度是 O(1)，不需要遍历到 `\0`。二进制安全，可以保存包含 `\0` 的数据。拼接前可以检查容量，降低缓冲区溢出风险。支持空间预分配和惰性释放，减少内存重分配。

## J247｜Redis 哈希表如何扩容和 rehash？

> 题类：Redis · 来源：[[Learning/Backend/Data/Redis#Redis 哈希表如何扩容和 rehash？|原题与完整答案]]

**30 秒口述答案**

dict 扩容时会同时使用 `ht[0]` 和 `ht[1]`，通过渐进式 rehash 避免一次性迁移大量数据阻塞主线程。为 `ht[1]` 分配新空间，并将 `rehashidx` 设为 0。每次请求或定时任务迁移一部分 `ht[0]` 的桶。rehash 期间查询、删除、更新需要检查两张表。新增数据直接写入 `ht[1]`。

## J248｜Zset 底层是怎么实现的？为什么使用跳表？

> 题类：Redis · 来源：[[Learning/Backend/Data/Redis#Zset 底层是怎么实现的？为什么使用跳表？|原题与完整答案]]

**30 秒口述答案**

大数据量的 Zset 通常由两种结构组成：dict：保存 member 到 score 的映射，按成员查分数是 O(1)。skiplist：按 score 和 member 排序，支持范围查询、排名和顺序遍历。小数据量时通常使用 listpack；超过配置阈值后转为 skiplist + dict。score 相同时，按 member 的字典序排序。

## J250｜Redis 的 I/O 模型是怎样的？

> 题类：Redis · 来源：[[Learning/Backend/Data/Redis#Redis 的 I/O 模型是怎样的？|原题与完整答案]]

**30 秒口述答案**

Redis 使用 Reactor 模型：客户端连接生成 socket fd。Redis 将 fd 注册到事件循环。内核通过 epoll、kqueue 等机制监听读写事件。事件就绪后，Redis 读取请求、执行命令并返回响应。
