## 建议练法

1. 首轮只看题目，30 秒内按“结论 → 机制 → 边界”作答。
2. 对照口述答案，只修正遗漏，不背逐字稿。
3. 随机选择一条深挖追问，继续回答 60—90 秒。
4. 答不稳时点击“原题与完整答案”，回到原库复习；不要在训练层扩写新知识。
