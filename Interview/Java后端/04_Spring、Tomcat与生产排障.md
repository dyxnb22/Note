## J151｜MyBatis 如何控制 SQL、安全和缓存边界？

**30 秒口述答案**

MyBatis 让开发者保留 SQL 控制权，并负责参数映射和结果映射，适合查询复杂、需要精细优化的系统。`#{}` 使用预编译参数，普通值必须优先使用它。`${}` 是文本替换，只能用于经过白名单映射的结构元素。动态 SQL 要覆盖空集合、可选条件和批量大小边界。一级缓存属于会话范围；二级缓存会增加一致性和失效复杂度，不应默认开启。

## J156｜IoC 和 DI 分别是什么，为什么优先使用构造器注入？

> 题类：Spring Core · 来源：[[Learning/Backend/Java/面试题库/09_Spring核心#IoC 和 DI 分别是什么，为什么优先使用构造器注入？|原题与完整答案]]

**30 秒口述答案**

IoC 是把对象创建和依赖管理从业务代码交给容器；DI 是容器把依赖传给对象的实现方式。优先使用构造器注入，因为依赖显式、对象可保持完整状态，也便于单元测试。容器的核心流程可以概括为：BeanDefinition 是“如何创建对象”的元数据，Bean 是创建完成的实例。不要把容器理解成一个普通 `Map<Class, Object>`：它还要处理作用域、生命周期、代理、扩展点和依赖关系。

## J158｜Spring 循环依赖为什么会发生，三级缓存能解决什么？

> 题类：Spring Core · 来源：[[Learning/Backend/Java/面试题库/09_Spring核心#Spring 循环依赖为什么会发生，三级缓存能解决什么？|原题与完整答案]]

**30 秒口述答案**

循环依赖暴露了对象职责互相纠缠。Spring 对部分单例、Setter/字段注入的循环依赖可以通过提前暴露引用解决，但构造器循环依赖无法靠三级缓存绕过。三级缓存的意义不只是“提前放一个对象”，还要保证其他 Bean 取得的早期引用与最终 AOP 代理保持一致。工程上优先通过拆分职责、引入领域事件或中间服务消除循环，而不是依赖容器兜底。

## J159｜Spring AOP 如何通过代理实现，哪些调用会失效？

> 题类：Spring Core · 来源：[[Learning/Backend/Java/面试题库/09_Spring核心#Spring AOP 如何通过代理实现，哪些调用会失效？|原题与完整答案]]

**30 秒口述答案**

AOP 把日志、事务、鉴权、指标等横切逻辑织入业务方法。Spring AOP 主要基于运行时代理：JDK 动态代理：特点=基于接口、典型限制=调用方通常面向接口；CGLIB：特点=生成目标类子类、典型限制=`final` 类或方法不能被覆盖增强；代理只拦截“经过代理对象”的调用。对象内部 `this.method()` 通常不会再次经过代理，因此 `@Transactional`、`@Async`、`@Cacheable` 等都可能失效。

## J161｜Spring 事务传播和数据库隔离级别分别解决什么问题？

> 题类：Spring Core · 来源：[[Learning/Backend/Java/面试题库/09_Spring核心#Spring 事务传播和数据库隔离级别分别解决什么问题？|原题与完整答案]]

**30 秒口述答案**

传播行为解决“一个带事务的方法调用另一个事务方法时如何组合”，隔离级别解决“多个数据库事务并发时能看到什么”。二者不在同一层，`REQUIRES_NEW` 不能替代更高隔离级别，`SERIALIZABLE` 也不能自动决定内部方法是否新开事务。高频传播行为：`REQUIRED`：语义=有事务就加入，没有就新建、主要边界=内层标记 rollback-only 后，外层即使捕获异常也可能在提交时得到 `UnexpectedRollbackException`。

## J198｜Java 中如何安全、正确地使用正则？

> 题类：Java 正则 · 来源：[[Learning/Backend/Java/面试题库/14_正则表达式#Java 中如何安全、正确地使用正则？|原题与完整答案]]

**30 秒口述答案**

`matches()` 要求整个输入匹配；`find()` 查找任意子串；`lookingAt()` 从输入开头尝试匹配。循环 `find()` 读取多个匹配，捕获组通过 `group(1)` 获取。固定表达式可复用 `Pattern`，避免每次调用都重新编译；用户输入拼接前使用 `Pattern.quote()`，避免被当成正则语法。
