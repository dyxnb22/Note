## J101｜Java 进程 CPU 使用率接近 100% 怎么排查？

**30 秒口述答案**

## J105｜直接调用 `run()` 和调用 `start()` 有什么区别？

> 题类：并发与 JUC · 来源：[[Learning/Backend/Java/面试题库/05_并发与JUC#直接调用 `run()` 和调用 `start()` 有什么区别？|原题与完整答案]]

**30 秒口述答案**

`run()` 只是普通方法调用，在当前线程中同步执行，不会创建新线程。`start()` 才会创建并启动新线程，由 JVM 在新线程中调用 `run()`；同一个 `Thread` 只能成功调用一次 `start()`。线程已经结束后再次调用 `start()` 会抛出 `IllegalThreadStateException`。

## J111｜指令重排序和 happens-before 是什么？

## J113｜CAS 是什么？有什么缺点？

> 题类：并发与 JUC · 来源：[[Learning/Backend/Java/面试题库/05_并发与JUC#CAS 是什么？有什么缺点？|原题与完整答案]]

**30 秒口述答案**

CAS（Compare And Swap）包含内存值 V、预期值 A 和新值 B：只有 V 等于 A 时，才把 V 更新为 B。它是 Java 原子类和许多无锁算法的基础。缺点：ABA：值从 A 变成 B 又变回 A，CAS 可能误判；可用 `AtomicStampedReference` 加版本号。自旋开销：竞争激烈时 CAS 反复失败，会浪费 CPU。

## J120｜ReentrantLock 的工作原理和特点是什么？

> 题类：并发与 JUC · 来源：[[Learning/Backend/Java/面试题库/05_并发与JUC#ReentrantLock 的工作原理和特点是什么？|原题与完整答案]]

**30 秒口述答案**

`ReentrantLock` 是基于 AQS 的显式锁。AQS 中的 `state` 表示锁状态和重入次数，owner 表示当前持锁线程，获取失败的线程会进入等待队列并通过 `LockSupport.park()` 挂起。核心逻辑：`state == 0` 时通过 CAS 抢锁并设置 owner。当前线程已经是 owner 时，增加 `state` 实现重入。

**30 秒口述答案**

代理模式和适配器模式有什么区别？：目的：代理模式=控制访问或增加额外行为、适配器模式=转换接口，使不兼容的类协同工作；结构：代理模式=抽象主题、真实主题、代理、适配器模式=目标接口、适配器、被适配者；常见场景：代理模式=日志、权限、事务、缓存、适配器模式=兼容第三方 SDK、旧接口和新接口；反射提供运行时获取类信息和调用方法的能力，动态代理利用这些能力在不修改原对象的情况下增强方法行为。JDK 动态代理基于接口和 `InvocationHandler`；CGLIB 通过生成目标类子类实现增强。

## J149｜JDBC 查询如何避免资源泄漏和 SQL 注入？

## J150｜Java 连接池大小如何确定，连接池耗尽又该如何排查？

> 题类：Java 数据访问 · 来源：[[Learning/Backend/Java/面试题库/08_Java数据访问#Java 连接池大小如何确定，连接池耗尽又该如何排查？|原题与完整答案]]

**30 秒口述答案**

连接池容量不是越大越好。它受到数据库最大连接数、服务实例数、查询耗时和峰值并发共同约束：需要同时配置获取连接超时、连接存活检测、最大生命周期和泄漏检测。连接池耗尽通常是慢 SQL、长事务、连接未释放或下游拥塞的结果，而不只是池太小。
