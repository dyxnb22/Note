# Interview Training Layer

这是现有题库的面试训练层。它不新增知识点、不复制成长篇教程，也不修改原题库；只把库内高频主线重组为可口述、可追问、可回源的训练材料。

## 训练入口

- [[Interview/Java后端/README|Java 后端最高频 300 问]]
- [[Interview/Agent-LLM/README|Agent / LLM 最高频 300 问]]

## “最高频”的库内口径

本层不引入外部题目或外部频次数据。“最高频”按现有题库的推荐顺序、主线分类、题库中的“高频/面经”标记、通用岗位覆盖面和生产追问价值综合排序。Java 岗位遵循原库边界，除 Java 专属题库外，只从原库明确归属的 MySQL、Redis、消息队列与系统设计题中补齐后端公共能力；Agent / LLM 岗位优先主线题和现有高频补充题。

## 使用规则

- 每题先脱稿口述约 30 秒，再展开一条深挖追问。
- 口述答案是原答案的压缩入口，不是新的权威答案。
- 对细节有疑问时，点击题目下的来源链接回到原题与完整答案。
- 建议以 50 题为一轮，标记“熟练 / 模糊 / 不会”，下一轮只重刷后两类。
