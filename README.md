# Notes

知识内容和项目记录分为三个主要区域；`config-templates` 是用于配置复用的支持目录：

- `Learning`：技术、产品、工程与表达等可复用知识
- `Life_and_Society`：金融、哲学、健康与精力、历史与社会等长期主题
- `Projects`：正在推进或已经归档的项目

## 建议使用方式

- 技术、产品、工程与表达等可复用知识放 `Learning`
- 金融、哲学、健康、历史与社会等长期主题放 `Life_and_Society`
- 有明确目标和阶段的内容放 `Projects`
- 外部资料只有形成可复用结论时才进入对应主题；临时资料不建长期"稍后阅读"堆积
