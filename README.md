# Notes

这个知识库只保留 2 个核心区域：

- `Learning`：长期学习内容，包含技术、金融、健康、历史与社会、写作等可复用主题
- `Projects`：正在推进或已经归档的项目

## 建议使用方式

- 能复用的学习内容放 `Learning`
- 有明确目标和阶段的内容放 `Projects`
- 外部资料先在 `Learning/References` 落主题级结论；失去核对价值的临时资料直接删除，不建长期"稍后阅读"堆积
