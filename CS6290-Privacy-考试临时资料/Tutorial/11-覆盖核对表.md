## 考前最短复习链

~~~text
UTXO → 双花冲突 → 区块排序 → PoW 成本 → 最长链
→ Common Prefix / Chain Growth / Chain Quality
→ Safety / Liveness → 激励与攻击
→ Merkle / 轻客户端 → 隐私承诺与范围证明
→ ZK 证明 → 支付通道、Bridge、Rollup
~~~

只要每一箭头都能解释“上一步解决了什么问题、又留下了什么新问题”，就掌握了这套 Tutorial 的整体逻辑。
