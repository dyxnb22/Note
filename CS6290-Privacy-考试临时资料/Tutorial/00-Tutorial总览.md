
# CS6290 Tutorial 全部知识讲义

> 按 Tutorial 文件夹中的课程顺序整理：教材基础与 Tutorial 1–2 → Tutorial 3 → Tutorial 4 → … → Tutorial 10。本文档的目标不是只给答案，而是把每道题背后的概念、推理和常见陷阱讲清楚。

## 0. 先建立整门 Tutorial 的主线

这组材料围绕三条主线展开：

1. **区块链基础**：钱、信任、密码学、UTXO、交易、区块、PoW、链、最终性与安全证明。
2. **工程可靠性**：如何用规格、计划、审查、证据和持久化上下文，让人或 AI agent 做出可信的系统。
3. **区块链应用与隐私**：可靠广播、Merkle 树、托管、PoS、DEX、隐私交易、零知识证明、支付通道、跨链桥和 Rollup。

可以把全部知识压缩成下面这个问题链：

> **谁有权花钱？大家怎样同意哪笔交易先发生？怎样让轻客户端验证？怎样隐藏不该公开的信息？当系统跨链或自动化时，怎样证明它没有悄悄做错？**

### 0.1 本文常用符号

- H：密码学哈希函数；输出长度通常记为 κ 位。
- txid：交易的哈希标识。
- UTXO：尚未花费的交易输出。
- Δ：网络消息最大延迟的模型参数。
- q：共识中提交一个决定所需的 quorum（法定人数）。
- n：节点总数；f：攻击者控制的节点数。
- negl(κ)：关于安全参数 κ 的可忽略函数。
- ⊥：不交付、终止或 abort。
