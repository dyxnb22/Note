# Lecture 5：DeFi 基础、收益来源、AMM、借贷与风险

## 5.1 DeFi 试图解决什么

传统银行把储户资金借给借款人，收取较高利率，再把较低利率支付给储户，中间差额支付员工、网点、合规和利润。DeFi 用公开的智能合约、抵押品和自动化规则替代部分中介。

DeFi 的承诺包括：任何有网络的人都能参与；用户控制私钥；全天候运行；代码可审计；协议费用透明。代价是没有银行经理帮你纠错，没有存款保险，代码错误、预言机错误和清算会直接影响用户。

## 5.2 第一个也是最重要的问题：收益从哪里来

在存钱前先问：

> 谁在付我钱？他为什么愿意付？

真实的经济收益来源主要有：

1. **交易手续费**：交易者为即时兑换支付费用；
2. **借款利息**：借款者为流动性、杠杆或避免出售资产而付利息；
3. **网络奖励**：PoS 网络发行 token 或收取小费以购买验证者安全；
4. **代币激励**：协议用新发行 token 或 treasury 预算吸引流动性，通常是暂时性营销支出。

前 3 类可与真实需求绑定，第四类不一定是骗局，但必须知道其资金来自哪里、何时会减少以及 token 通胀是否抵消名义 APY。

稳定币是 DeFi 的共同计价单位。法币储备型、加密超额抵押型和算法型稳定币之间，是稳定性、中心化和死亡螺旋风险的取舍。

讲义还把 DeFi 的范围扩展到 **Real World Assets（RWA）**：把美国国债、私人信贷、房地产等现实资产的权利表示为链上 token，收益来自国债利息、企业贷款偿付或租金，而不是单纯增发协议 token。RWA 能把传统金融的现金流带进 DeFi，但会重新引入托管、法律所有权、身份和现实世界执行等信任边界；“上链”并不会自动让现实资产变成无信任资产。

## 5.3 风险基准与收益率阶梯

课件用美国国债收益率作为近似无风险基准，核心公式是：

```text
expected return = risk-free rate + risk premium
```

如果国债约 4%，Aave 稳定币借贷约 8%，额外 4% 必须补偿智能合约、协议治理、流动性、监管等风险。没有“无风险高收益”；收益越高，风险或复杂度必然更高。

大致阶梯：国债/现金收益最低；PoS 质押稍高；稳定币借贷更高；波动资产 LP 更高；随机 farm 可能 100% 以上，但可能归零。评估重点不是 APY 数字，而是收益的支付者、风险溢价和最坏结果。

## 5.4 AMM：不用订单簿做交易

传统交易所依赖订单簿、买卖双方和做市商。链上逐个挂单成本高、速度慢，而且不能假设专业做市商随时在线。AMM 建立一个流动性池，让交易者直接与池子交易。

Uniswap v2 风格的恒定乘积模型：

```text
x × y = k
```

`x` 和 `y` 是两种 token 的池中数量，`k` 在交易前后保持近似恒定。池子初始有 100 ETH 和 170,000 USDC，则 `k=17,000,000`。有人买走 1 ETH，池中剩 99 ETH，新 USDC 数量应为：

```text
y_new = 17,000,000 / 99 ≈ 171,717
支付 ≈ 1,717 USDC
```

价格来自曲线斜率而非订单簿。买得越多，池中剩余 ETH 越稀缺，曲线越陡，平均成交价越差，这就是 **slippage**。

### 5.4.1 流动性提供者（LP）

LP 把两种资产存入池子，获得交易手续费的一部分。若池 TVL 是 1000 万美元，你提供 1 万美元，占 0.1%；日交易量 100 万美元，手续费率 0.3%，则每日手续费约 3000 美元，你的份额约 3 美元。

粗略年化公式：

```text
fee APY ≈ volume × fee_rate × 365 / TVL
```

实际还要考虑交易量变化、池子份额变化、gas、价格变化和 impermanent loss。

### 5.4.2 Aggregator

Aggregator 像机票比价网站，同时搜索 Uniswap、Curve、Balancer 等多个池，按深度、价格和 gas 计算最优拆单路线。大额交易拆到多个池中可能显著降低 slippage；稳定币通常选择专门的稳定池。交易金额越大，比较路由越重要。

## 5.5 借贷协议

Aave、Compound 用抵押品而非信用评分强制还款：

1. 用户存入 1500 美元 ETH；
2. 借出 1000 USDC；
3. 借款支付利息；
4. 偿还债务后取回抵押品。

如果价格下跌导致健康因子低于阈值，清算机器人偿还一部分债务并取得抵押品和奖励。接近最大借贷额意味着价格稍微波动就可能被清算。

存款人通常收到 aToken/cToken 等 receipt token。它们是 ERC20，可继续作为其他协议的抵押品，形成可组合的收益：USDC -> Aave -> aUSDC -> 作为抵押 -> 借 DAI -> 再交易。

### 5.5.1 预言机

区块链执行必须确定性，不能直接调用 Coinbase API；协议需要 Chainlink、Pyth 等 oracle 网络，把多个链下报价聚合成链上价格。预言机错误或被操纵可能制造虚假清算、错误铸币或盗走抵押品。

### 5.5.2 Flash loan

Flash loan 在单个原子交易内借出任意规模资金；若交易末尾没有还清，整个交易回滚。合法用途包括 DEX 套利、清算、抵押品交换；攻击用途是借大量资金操纵 AMM 价格，再让脆弱 oracle 按假价格清算或放贷。

## 5.6 Staking、MEV 和流动性质押

PoS 验证者执行提议、验证和共识工作，收益来源包括新发行 ETH、用户 priority tips 和交易排序产生的 MEV。验证者诚实工作得奖励，双签等错误会被 slash。

Liquid staking 让用户存入任意数量 ETH，取得 stETH 等可交易 token，同时获得质押收益。用户可以交易 stETH、把它存入借贷协议或做 LP。额外风险是 token 脱锚、协议智能合约和验证者惩罚。

MEV 的主要形式：

- front-running：攻击者先执行，受害者价格变差；
- back-running：在大交易后做套利，帮助价格恢复；
- sandwich：攻击者前后夹住用户交易，用户承担价格损失。

MEV-aware aggregator、private order flow 和 intent-based execution 可以减少公开 mempool 暴露。

## 5.7 Impermanent Loss：LP 最容易误解的成本

初始有 1 ETH（1700 美元）和 1700 USDC。若直接持有，ETH 翻倍后总值是 5100 美元。如果放进 50/50 恒定乘积池，套利者会不断买走变贵的 ETH，使池子最终约有 0.707 ETH 和 2404 USDC，总值约 4808 美元，低于 HODL 的 5100 美元；差额是相对于持有策略的 impermanent loss，还没计算手续费和 gas。

设外部价格相对初始价格变化比例为 `r`，50/50 AMM 相对于 HODL 的 LP 比值是：

```text
LP / HODL = 2√r / (1+r)
IL = 2√r / (1+r) - 1
```

因此价格翻倍时相对损失约 5.7%，价格上涨或下跌的对称变化会产生类似损失。LP 是否赚钱取决于：

```text
LP profit = trading fees - impermanent loss - gas - other risks
```

高交易量、低波动的稳定币池通常更适合初学者；高波动 meme coin 池可能手续费很高，但 IL、合约风险和 rug pull 风险也很高。

## 5.8 DeFi 风险与尽调清单

主要风险：

- smart contract bug；
- oracle manipulation；
- 清算和流动性不足；
- 预言机、桥和治理权限；
- rug pull、匿名团队、无审计、无 timelock；
- token unlock 和内部人抛售；
- 稳定币脱锚；
- 合规和冻结风险。

课件列举的典型协议类别包括 Uniswap/Curve 等 DEX，Aave/Compound 等借贷，Lido/Rocket Pool 等质押，以及 1inch/ParaSwap 等聚合器。理解类别比背 TVL 更重要：它们分别依赖交易手续费、借款利息、网络发行和路由优化。

Terra/Luna 的案例说明：UST 的算法锚定和 Anchor 的 20% 高收益依赖信心和持续流入；重度抛售后，系统铸造更多 LUNA 维持锚定，形成 UST 与 LUNA 同时下跌的死亡螺旋。

使用协议前回答：

1. 收益由谁支付？
2. 相对基准的额外收益补偿什么风险？
3. 最坏情况下是损失利息，还是本金归零？
4. 协议是否经过长时间使用、多次独立审计？
5. 管理员能否瞬间升级代码或转走资金？
6. LP 是否计算过 IL？借贷健康因子是否留有足够缓冲？
