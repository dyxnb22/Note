# 历史与社会案例研究

这些案例把技术、制度、组织、市场和利益分配放进具体时间与地区中考察。每篇先给出可核对的历史脉络，再区分研究资料支持的事实、对机制的解释，以及仍有争议的因果判断。

案例适合用来检验概念，不代表完整的地区史或政策评估。不同来源的口径、时期和研究立场可能不同；继续扩展时，应注明统计范围、原始资料和替代解释。

## 案例

- [中国改革、增长与国家能力](./中国改革、增长与国家能力.md)：观察农村改革、开放、地方试验和市场制度变化如何交织。
- [东亚工业化与发展型国家](./东亚工业化与发展型国家.md)：比较教育、出口、政府协调和产业升级的不同组合。
- [全球化、供应链与平台经济](./全球化、供应链与平台经济.md)：从成本、韧性、市场结构和规则分配理解连接扩张的收益与风险。
- [互联网平台与 AI 治理的历史连续性](./互联网平台与AI治理的历史连续性.md)：比较信息分发、生成内容和 Agent 行动带来的治理问题。

## 阅读时怎么判断因果

先限定时间、地区和比较对象；再看政策或技术变化发生之前的条件、执行方式和实际结果。若只观察到“政策之后增长”，还不能证明增长由该政策造成。需要寻找机制证据、反例和未采用该政策时可能出现的结果。

案例中提出的解释应能被新材料修正。数据与文献仍不足时，明确写出未知项，不用一张空白模板代替结论。
