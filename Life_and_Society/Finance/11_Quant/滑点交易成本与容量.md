# 滑点、交易成本与容量

## 显性成本、滑点与市场冲击

**交易成本（Transaction Cost）**
每次交易发生的总成本，包括显性成本（佣金、税费）和隐性成本（买卖价差、冲击成本、等待执行的机会成本）。费率与交易规则取决于市场、产品、账户和日期。

**滑点（Slippage）**
实际成交价格与期望成交价格的差距。来源：① 市场报价变动 ② 买卖价差 ③ 大单对价格的冲击。

**市场冲击成本（Market Impact）**
大额交易本身对价格的推动效应。买入越多，价格被推得越高；卖出越多，价格被压得越低。规模越大，冲击越严重。

**策略容量（Strategy Capacity）**
在可接受的 Alpha 衰减程度内，策略能够有效管理的最大资金规模。超过容量后，冲击成本侵蚀了大部分 Alpha。

## 成本构成、规模效应与容量

**交易成本的完整构成**

```
总交易成本 = 显性成本 + 隐性成本

显性成本：
  - 佣金与交易所费用：按适用市场、经纪商费率表和账户条款核对
  - 税费：按证券类别、交易方向和现行辖区规则核对；不要把历史费率当作当前费率

隐性成本：
  - 买卖价差（Bid-Ask Spread）：最佳买价与卖价的差，流动性差的股票更宽
  - 市场冲击（Market Impact）：大单推动价格的成本，与规模正相关
  - 时机成本（Timing Cost）：等待执行期间价格变动的成本
```

**冲击成本的规模效应**

冲击成本与交易规模的关系通常是非线性的：

```
冲击成本（bps）≈ k × √(交易量 / 日均成交量)

其中 `k` 是需要用具体市场、证券、交易方向和执行样本估计的参数；函数形式只是经验模型，不是通用交易所规则。
```

不能只凭参与率推断固定的基点成本。应使用成交记录校准，并把买卖方向、波动率、价差、订单拆分、交易时段和市场压力情景纳入估算。

**策略容量的估算框架**

```
步骤 1：确定策略需要达到的最低净 Alpha 或其他绩效要求。
步骤 2：估算换手率、订单参与率和可交易标的范围。
步骤 3：用历史成交或可解释的冲击模型估算不同规模下的总成本。
步骤 4：在基准和压力情景下检查净 Alpha、回撤和可执行性。
容量是策略仍满足风险与收益约束的规模区间，不只是解出“毛 Alpha = 冲击成本”的单一数值。
```

从理论容量到可运行规模还要考虑估计误差、市场状态变化和集中交易；没有适用于所有策略的固定折扣比例。

**不同类型策略的成本特征**

| 策略形态 | 常见交易特征 | 容量判断重点 |
|---------|------------|-----------|
| 高频策略 | 交易次数多、单笔持有期短 | 延迟、价差、队列位置和撤单成本 |
| 月度因子策略 | 定期调仓，换手因信号而异 | 成分股流动性、参与率和组合规模 |
| 低换手指数策略 | 调整较少，但换仓日可能集中 | 指数调仓、跟踪误差和大单执行 |
| 主动选股 | 取决于持仓与交易决策 | 组合集中度、交易时点和流动性 |

## 校准回测成本并判断容量

**回测成本假设应按策略和成交样本校准**

回测至少拆出佣金与税费、买卖价差、市场冲击和延迟成本，并明确标的范围、价格来源、交易时段、订单规模及规则生效日期。若没有可用成交样本，可使用多档成本情景做敏感性分析，不应把一张固定费率表称为所有策略的“合理成本”。

**策略容量的定性判断**

换手率只能提示成本暴露，不能单独推算资金容量。应结合订单参与率、个股成交额分布、成本函数和目标净收益，按资金规模做压力测试。

## 换手、净Alpha与规模

**年化换手率**
= 每年全部持仓变动的总比例（双边）。月调仓策略，每月换手 30% → 年换手率约 360%。

换手率 × 单次成本 = 年化成本损耗。这是将 Gross Alpha 转化为 Net Alpha 的核心公式。

**净 Alpha（Net Alpha）**
= Gross Alpha - 年化交易成本

只有净 Alpha 才是投资者实际获得的超额收益。高 Gross Alpha + 高换手成本 = 可能的净 Alpha 为零甚至负。

**容量系数（Capacity Ratio）**
= 当前管理规模 / 策略理论容量

容量比率可用于比较当前规模与估算容量，但阈值应由策略容忍的成本和净收益确定，不存在通用的 0.3 或 0.7 分界线。

## 研究例子

**例 1：成本对净 Alpha 的侵蚀**
某因子策略 Gross Alpha = 8%（年化），月换手率 30%（年换手 360%）。
假设成分股平均单次双边成本 0.6%：
年化成本 = 360% × 0.6% = 2.16%
净 Alpha = 8% - 2.16% = 5.84%

如果改为集中在小市值股票，单次成本 1.5%：
年化成本 = 360% × 1.5% = 5.4%
净 Alpha = 8% - 5.4% = 2.6%（仅剩 1/3）

**例 2：规模对容量的影响**
示意：若组合规模从 1 亿元扩到 100 亿元而持仓数、换手率和标的流动性不变，单笔订单相对成交量会显著放大。能否成交、冲击多少，必须按具体证券和订单簿数据估算；这里的规模换算不代表某个真实策略的成本或容量。

**例 3：换手率优化降成本**
同等因子信号，月调仓换手率 30% vs. 每季度换手 10%（降低换手但略微牺牲信号及时性）：
- 月调仓：年成本 = 360% × 0.5% = 1.8%
- 季调仓：年成本 = 40% × 0.5% = 0.2%

成本降低 1.6%，但信号衰减（因子效应衰退导致）约减少 Alpha 0.8%。净效果：季调仓净 Alpha 更高。

## 回测与实盘中的误判

**误区 1：回测中使用收盘价成交**
实际上无法以当天收盘价下单（收盘价在收盘那一刻才确定）。应使用下一交易日开盘价，或加入滑点假设。使用收盘价会系统性低估交易成本。

**误区 2：忽视冲击成本，只算佣金**
对于资金规模超过 1 亿的策略，冲击成本往往远大于佣金。只算佣金的成本估算严重失真。

**误区 3：认为策略容量可以无限扩张**
所有 Alpha 来源都有容量限制。规模越大，Alpha 越低，这是不可回避的物理约束（流动性有限）。任何声称"策略可以无限扩张"的说法都应当怀疑。

**误区 4：小市值因子在大规模资金下仍然有效**
小市值因子的超额收益在学术研究中显著，但学术研究是等权、小仓位的模拟。实盘中，试图用数十亿资金操作小市值股票，冲击成本会完全消灭 Alpha，甚至变成负 Alpha。

## 7. 成本情景的最小计算（Python 标准库）

冲击成本模型不是跨市场常数。下面只提供一个“把成本显式放进敏感性分析”的骨架，参数必须用真实成交、流动性和订单参与率校准。

```python
def square_root_impact(
    participation: float,
    daily_volatility: float,
    impact_coefficient: float = 0.5,
) -> float:
    if not 0 <= participation <= 1:
        raise ValueError("participation must be between 0 and 1")
    # 平方根冲击只是常见的研究形式，不是交易所保证的定律。
    return impact_coefficient * daily_volatility * participation**0.5


def net_alpha(
    gross_alpha: float,
    annual_turnover: float,
    explicit_cost: float,
    impact_per_turnover: float,
) -> float:
    # 显性成本和冲击成本都按双边换手口径传入，避免把单边/双边混用。
    return gross_alpha - annual_turnover * (explicit_cost + impact_per_turnover)


for participation in (0.01, 0.05, 0.10):
    impact = square_root_impact(participation, daily_volatility=0.02)
    print(participation, round(impact, 4))
```

容量报告至少同时给出规模、换手、参与率、成本假设、净 Alpha、最大回撤和尾部情景；只给一个“可管理规模”而不说明可接受的收益衰减，定义是不完整的。

## 资料与校准

成本模型只提供估算框架。真实费率以交易所、监管机构和券商的现行规则为准；冲击参数应从策略自己的成交记录或明确披露的数据估计。
