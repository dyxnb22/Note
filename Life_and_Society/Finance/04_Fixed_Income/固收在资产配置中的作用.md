# 固收在资产配置中的作用

## 固收的配置用途与股债相关性

**固收资产的四大功能**

1. **收益来源**：提供稳定的利息现金流（票息）
2. **组合波动性降低**：债券通常与股票相关性低（甚至负相关），加入组合可降低整体波动
3. **潜在防御性**：若衰退带来利率下降，既有固定票息债券价格在其他条件不变时可能上涨；信用利差扩大或通胀冲击也可能抵消这项收益
4. **流动性储备**：国债流动性极好，可以在需要时快速变现，维持组合流动性

**股债的历史相关性**

在一些降息和避险主导的时期，国债曾对冲部分股票下跌；在通胀和利率上升的时期，股债也可能同时下跌。相关性会随时期、期限、币种和债券指数变化，因此应使用明确的总回报序列计算，而不要假设“股票跌、国债必涨”。

## 不同债券怎样影响组合风险

**为什么股债负相关创造了分散化价值**

从组合方差公式：
```
σ²(portfolio) = w₁²σ₁² + w₂²σ₂² + 2w₁w₂σ₁σ₂ρ₁₂
```
当 ρ₁₂（股债相关系数）< 0 时，第三项为负，组合波动率低于各资产简单加权。

60/40 是一种常见的配置基准。它在某些历史区间改善了波动或回撤表现，但是否优于纯股票、夏普比率有多高，取决于市场、币种、期限、通胀和样本区间；每次比较都应说明数据口径。

**不同类型债券在配置中的作用差异**

| 债券类型 | 配置功能 | 主要风险 |
|---------|---------|---------|
| 国债（长期）| 最强防御性，对利率最敏感 | 加息环境中大幅受损 |
| 国债（短期）| 流动性储备，低风险 | 收益率低 |
| 投资级信用债 | 增厚收益，中等防御 | 信用和利率双重风险 |
| 高收益债 | 类股票收益，相关性高 | 与股票危机相关性高，防御性差 |
| 通胀保护债券 | 对冲通胀风险 | 防御效果在通缩环境中弱化 |

**久期在配置中的含义**

组合中债券的久期决定了：
- 对利率下降的受益程度（久期长 = 降息时涨更多）
- 对加息环境的损失程度（久期长 = 加息时跌更多）
- 与股票的对冲效果（长久期国债对股市下跌的对冲效果最强）

`长期投资视角：在较长的投资期限内，股票通常被认为有更高的预期回报，但也伴随更大的波动和回撤。是否配置债券，取决于资金用途、流动性需求、风险承受力和投资纪律；债券可能降低部分时期的波动，但不能保证投资者避免亏损。`

## 按目标与负债安排债券配置

**确定债券配置比例的框架：**

第一步：确定投资目标和约束
- 投资期限：越短，债券比例应越高
- 最大可接受回撤：越低，债券比例越高
- 流动性需求：有近期用款需求，增加短期债券

第二步：评估当前宏观环境
- 利率环境：加息周期应降低久期，减少长期债券
- 通胀环境：高通胀时名义债券实际价值被侵蚀，应考虑 TIPS 或减少债券

第三步：考虑相关性假设
- 正常情况：股债负相关，债券提供分散化价值
- 滞胀环境：股债可能同涨同跌（实际负利率），债券分散化效果减弱

第四步：压力测试
- 如果股票下跌 40%，债券的表现如何？
- 如果利率上升 2%，债券损失多少，是否能被其他资产的表现补偿？

## 组合结构与压力时期表现

**"60/40"组合的有效性**
60/40 是常见的历史配置基准之一，但其表现受样本起止和股票、债券指数选择影响。分析时要明确回报序列是否含分红/票息、币种和再平衡规则；不能把特定时期的结果当成永久特征。

**2022 年的股债双杀**
2022 年美国通胀和利率上升期间，股票和部分长期债券同时下跌，展示了股债组合在某些利率冲击下也会承受损失。若引用具体百分比，应注明股票/债券指数、是否采用总回报、币种和测量区间。

**高收益债与股票的高相关性**
高收益债的信用风险和风险偏好暴露通常比高评级国债更接近风险资产；它与股票的相关性会随时期、币种和指数变化，不应把固定相关系数当作常数。配置时要同时检查违约风险、利率风险和流动性。

## 计算与情境

**例 1：2008 年股债表现的差异**
2008 年美国股票市场大幅下跌，信用危机和避险需求上升期间，美国国债总回报为正。股票与高信用质量国债的差异帮助部分股债组合缓冲了损失，但组合结果取决于所用指数、币种、再平衡方式和具体期限。这个案例说明分散化可能有效，不代表债券在每次股市下跌时都会上涨。

**例 2：债券配置比例与年龄**
传统"100 - 年龄 = 股票配置"的经验法则（如 60 岁投资者配 40% 股票，60% 债券），背后逻辑是：年龄越大，可承受的投资期限越短，下行风险越难接受，债券保护越重要。这是简化但直觉合理的框架（不适合作为精确建议）。

## 容易误判的地方

**误区 1：债券永远是安全资产**
长期国债有显著的利率风险，高通胀 + 加息环境中表现极差（如 2022 年）。"债券安全"只是相对股票而言、且在特定宏观环境下成立的。

**误区 2：高收益债可以替代国债的防御功能**
高收益债与股票相关性高，在经济危机中往往与股票同跌，无法起到真正的防御作用。组合中的防御功能应由高信用质量债券（国债或投资级债）承担。

**误区 3：只要加入债券，组合就稳定了**
债券的分散化作用取决于与股票的相关性。在滞胀（高通胀 + 低增长）环境中，股债可能正相关，债券无法提供预期的对冲。资产配置需要考虑不同宏观情景下各资产的相关性。

**误区 4：债券是被动资产，不需要主动管理**
债券的利率风险、信用风险需要持续管理。久期管理（根据利率预期调整）和信用管理（监控发行人状况）对债券组合的表现影响显著。

## 数据入口

- [Aswath Damodaran：Historical Returns on Stocks, Bonds and Bills](https://pages.stern.nyu.edu/adamodar/New_Home_Page/datafile/histretSP.html)：美国长期年度总回报序列；使用时核对资产定义和数据截止年份。
- [FRED：Treasury term-spread series](https://fred.stlouisfed.org/series/T10Y2Y)：利率期限结构数据，不直接等同于债券总回报。
