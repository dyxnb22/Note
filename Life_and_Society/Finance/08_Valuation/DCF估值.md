# DCF 估值

## 自由现金流、终值与贴现

**DCF（Discounted Cash Flow）**
将公司未来所有自由现金流按折现率折现，求和得到公司内在价值的估值方法。

`DCF 估值 = Σ (FCFt / (1+WACC)^t) + 终值 / (1+WACC)^n`

**自由现金流（FCF，Free Cash Flow）**
公司真正可以自由支配的现金：
`FCFF = EBIT × (1 - T) + 折旧摊销 - 资本支出 - 营运资本增量`

（FCFF = 自由现金流，F 代表 Firm，即公司层面，供股东和债权人共享）

**终值（Terminal Value，TV）**
预测期结束时对后续现金流的估值。它在企业价值中的占比取决于预测期、现金流路径、稳定增长率和折现率，不存在固定的通用比例。

两种计算方法：
1. 永续增长率法：`TV = FCFn+1 / (WACC - g)`（g = 永续增长率）
2. 退出倍数法（Exit Multiple）：`TV = EBITDAn × EV/EBITDA 倍数`

## DCF的计算过程与终值约束

**DCF 的完整计算流程**

```
Step 1：预测 5-10 年的自由现金流（FCFF）
Step 2：确定 WACC（折现率）
Step 3：计算各期现金流的现值
Step 4：计算终值（永续增长法或退出倍数法）
Step 5：终值折现回当前
Step 6：求和 = 企业价值（EV）
Step 7：EV - 净负债 = 股权价值
Step 8：股权价值 / 总股本 = 每股内在价值
```

**终值占比没有固定比例**

永续增长模型计算的是预测期末的终值：`TVₙ = FCFₙ₊₁ / (WACC - g)`。今天的终值现值还要再折现；它占企业价值的比例，取决于显性预测期现金流、预测期长度、WACC 和 g，不能从 `g / (WACC - g)` 直接推出一个通用比例。

本文后面的示例中，终值现值约为 183.8 亿元，企业价值约为 241 亿元，占比约 76%。这只是该组假设下的结果，不代表 DCF 的固定经验比例。终值占比较高时，估值会更依赖稳定期假设，应报告区间并检查敏感性。

**永续增长率 g 的限制**

稳定期增长率应与现金流使用同一币种、同为名义或实际口径，并与企业长期经营范围相匹配。它通常不应长期高于企业所处经济体的可持续增长率；不要直接套用固定的国家增长率区间。

## 拆解驱动因素并做敏感性分析

**DCF 的驱动因素分析框架（价值三角）：**

```
公司价值 =
  ├── 现金流大小（当前盈利能力）
  ├── 现金流增速（增长率预测）
  └── 折现率（WACC，反映风险和资本成本）
```

提升公司价值的四条路径：
1. 提高现有资产回报（更高的 ROIC）
2. 增加再投资规模（更多项目 × 正 NPV）
3. 延长高增长期
4. 降低折现率（降低风险）

**DCF 的敏感性分析（必做）**

沿用例 1 的显性期现金流（当前 FCF 10 亿元、前 5 年年增长 15%），仅改变 WACC 和 g，得到的企业价值如下（亿元，四舍五入）：

| WACC \ g | 2% | 3% | 4% |
|----------|----:|----:|----:|
| 8% | 293.3 | 342.6 | 416.5 |
| 9% | 249.4 | 283.3 | 330.8 |
| 10% | 216.5 | 241.0 | 273.7 |

这是对同一组现金流假设的情景计算，不是估值区间或目标价；终值占比较大时，WACC 与 g 的小幅变化会明显改变结果。

## 贴现率、增长率与预测期

**WACC（折现率）**
反映什么：公司资本成本，是 DCF 最敏感的输入变量。
容易误判：WACC 的小幅变化可能明显影响估值，但影响幅度取决于现金流期限、增长路径和终值假设。不要套用固定误差比例或把输入精确到超出证据支持的位数；应展示情景区间。

**永续增长率 g**
反映什么：公司进入稳定期后的长期增长率。
容易误判：g 越接近 WACC，终值对假设越敏感。稳定增长模型要求 `WACC > g`；当二者相等时分母为零，模型无定义；若 `g > WACC`，正现金流会算出负终值，说明这组稳定期假设不成立，不能把结果解释成经济价值。

**预测期长度**
反映什么：多少年的现金流被显式预测。
容易误判：预测 10 年以上的精确数字是伪精度，应该集中精力把握增长轨迹的大方向，而不是精确到每年 0.1% 的差异。

## 示例与情景

**例 1：简单 DCF 计算**
某公司当前 FCF = 10 亿，预计未来 5 年增长 15%/年，之后永续增长 3%，WACC = 10%。

5 年 FCF 预测（亿元）：11.5、13.2、15.2、17.5、20.1
5 年现值之和（折现 10%）：10.5 + 10.9 + 11.4 + 11.9 + 12.5 = 57.2

终值（在第 5 年末）= 20.1 × 1.03 / (0.10 - 0.03) = 295.9 亿
终值现值 = 295.9 / 1.10^5 = 183.8 亿

EV = 57.2 + 183.8 = 241 亿

若净负债 20 亿：股权价值 = 221 亿。若总股本 10 亿股：每股内在价值 = 22.1 元。

**例 2：终值假设的敏感性**
同上例，仅改变 g：
- g = 2%：终值现值 = 159.2 亿，EV = 216.5 亿
- g = 3%：终值现值 = 183.8 亿，EV = 241.0 亿
- g = 4%：终值现值 = 216.5 亿，EV = 273.7 亿

以上按未四舍五入的第 5 年 FCF `20.113571875` 和显式预测期现值 `57.24575018` 计算，正文展示保留 1 位小数。g 仅差 2 个百分点，EV 就有明显变化；DCF 对终值假设的高度敏感性一览无余。

## 估值中常见的错误

**误区 1：DCF 输出的是精确答案**
DCF 是基于大量假设的估值工具，输出的是一个区间而不是精确数字。"公司内在价值精确到 22.37 元"是虚假的精度。正确的使用方式是：DCF 给出一个合理的价值区间，结合安全边际做判断。

**误区 2：永续增长率可以高于经济增速**
稳定期 g 需与现金流采用同一币种和同一名义/实际口径，并匹配企业长期经营范围；可用相关经济体的长期增速作约束，但不能把不同口径的 GDP 数值直接比较。

**误区 3：DCF 可以适用于所有公司**
DCF 需要现金流预测相对可靠。对于初创公司（现金流为负、前景高度不确定）、周期性公司（现金流大幅波动）、金融企业（现金流定义不同），DCF 的适用性较差，需要使用替代方法或修正版 DCF。

**误区 4：只做基准情景，不做敏感性**
DCF 的最重要输出不是单一数字，而是假设区间内的估值范围。不做敏感性分析的 DCF 是不完整的。

## 7. 可复现计算（Python 标准库）

下面的函数只演示永续增长法，单位由输入决定（例如都用“亿元”）。它把显式预测期现金流、终值和折现过程分开，便于逐项核对模型，而不是只抄最终 EV。

```python
def dcf_value(
    current_fcf: float,
    growth: float,
    years: int,
    wacc: float,
    terminal_growth: float,
) -> tuple[float, float, float]:
    if wacc <= terminal_growth:
        raise ValueError("WACC must be greater than terminal growth")

    # 先生成显式预测期现金流；第 t 年现金流从当前 FCF 往前增长 t 次。
    forecast = [current_fcf * (1 + growth) ** t for t in range(1, years + 1)]
    explicit_pv = sum(
        cash_flow / (1 + wacc) ** t
        for t, cash_flow in enumerate(forecast, start=1)
    )

    # 终值使用第 years+1 年 FCF，并在预测期末先计算、再折现回今天。
    terminal_value = forecast[-1] * (1 + terminal_growth) / (wacc - terminal_growth)
    terminal_pv = terminal_value / (1 + wacc) ** years
    return explicit_pv, terminal_pv, explicit_pv + terminal_pv


for g in (0.02, 0.03, 0.04):
    explicit_pv, terminal_pv, enterprise_value = dcf_value(
        current_fcf=10,
        growth=0.15,
        years=5,
        wacc=0.10,
        terminal_growth=g,
    )
    print(g, round(explicit_pv, 1), round(terminal_pv, 1), round(enterprise_value, 1))
```

这段代码可以复核上面的敏感性示例，但不替代真实公司的 FCF 口径、净债务、少数股东权益、期中折现和情景假设审阅。模型交付时应同时保存输入表、公式版本和输出日期。
